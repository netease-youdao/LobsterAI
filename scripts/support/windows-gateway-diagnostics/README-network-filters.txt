LobsterAI 网络过滤诊断

适用情况：引擎连接诊断显示“本机回环连接在系统层被拦截”（本机程序之间的连接被系统丢弃），
需要找出是哪个软件留下的网络过滤规则在拦截。

1. 双击 LobsterAI-Network-Filter-Diagnostics.cmd。在压缩包里直接双击或解压后双击都可以。
   如果 Windows 提示“是否运行此文件”，请选择“运行”。
2. 中途会弹出“你要允许此应用对你的设备进行更改吗？”，请点“是”。
   读取 Windows 的网络过滤规则需要管理员权限；点“否”的话只能收集到很少的信息。
3. 等待完成，通常 1～3 分钟。完成后会自动打开桌面上的诊断 ZIP 所在位置。
4. 把 LobsterAI-Network-Filter-Diagnostics-日期时间.zip 发给技术支持。窗口里带 ★ 的行就是找到的拦截规则，截图也可以一起发。

如果安全软件弹出拦截或询问提示，请截图后选择“允许”。

此工具会收集：
- 本机连接测试的结果；
- Windows 过滤平台（WFP）的过滤规则、提供者和最近的丢包记录；
- 驱动列表、文件系统过滤驱动列表、Windows 防火墙配置和已启用的入站阻止规则。

此工具不会：
- 修改、删除或关闭任何过滤规则、驱动、防火墙设置或软件；
- 自动上传任何内容。

导出过程中会在 C:\Windows\Temp 下临时保存文件，结束后自动删除。
