LobsterAI 网关一键诊断

1. 将此 ZIP 完整解压到一个文件夹。
2. 保持 LobsterAI 当前报错页面打开，双击 collect.cmd。
3. 等待约 1～3 分钟。完成后会打开桌面上的诊断 ZIP 所在位置。
4. 把生成的 LobsterAI-Gateway-Diagnostics-日期时间.zip 发给技术支持。

通常不需要管理员权限，也不需要安装 Node.js 或其他软件。
若找到多个安装或未找到当前安装，会请您选择正在使用的 LobsterAI.exe。
如果公司策略阻止脚本运行，请把阻止提示截图交给技术支持或公司 IT。

此工具收集系统和应用版本、安全软件名称、相关进程 DLL 信息、筛选脱敏的启动/修复日志。
它还使用应用自带运行时和一个临时测试数据库，记录 SQLite worker 的输出、退出码和独立结果文件，兼容修复前后的引擎。
不会执行修复、修改或删除用户数据库、关闭正在运行的 LobsterAI、关闭安全软件或自动上传。
不会复制聊天数据库、聊天内容、记忆文件、模型配置或整个修复备份目录。

若提示部分信息不可读取，仍请发送生成的 ZIP；里面会注明缺失项目。
如果没有生成 ZIP，请把最后的窗口截图发给技术支持。
