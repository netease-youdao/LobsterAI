LobsterAI 启动性能诊断

适用情况：AI 引擎网关启动失败、一键修复失败，或提示中出现 "Command failed"。

1. 建议先从屏幕右下角托盘图标退出 LobsterAI，再继续。
2. 双击 LobsterAI-Performance-Diagnostics.cmd。在压缩包里直接双击或解压后双击都可以。
   如果 Windows 提示“是否运行此文件”，请选择“运行”。
3. 等待完成，通常 5～15 分钟，电脑较慢时最长约 30 分钟。窗口里会显示当前进度和已用时间，请不要关闭窗口。
4. 完成后会自动打开桌面上的诊断 ZIP 所在位置。把 LobsterAI-Performance-Diagnostics-日期时间.zip 发给技术支持。

如果需要提前结束，按 Ctrl+C，已收集的信息仍会打包到桌面。
如果安全软件弹出拦截或询问提示，请截图后选择“允许”；截图同样有助于排查。
如果公司策略阻止脚本运行，请把阻止提示截图交给技术支持或公司 IT。

此工具会收集：
- 系统版本、CPU、内存、磁盘类型和剩余空间，以及是否运行在虚拟机中；
- 安全软件的名称和开关状态，当前运行的程序名称（不含命令行）；
- 这台电脑读写文件、启动进程和数据库写入的速度；
- 引擎启动步骤的耗时：这些步骤在一个临时的空目录里运行，结束后自动删除；
- 最近的应用日志和引擎日志（已去除密钥和令牌），以及引擎数据的文件大小。

此工具不会：
- 修改、修复或删除您的聊天记录、记忆、模型配置和数据库；
- 读取数据库里的内容（只测量读取速度）；
- 关闭 LobsterAI 或安全软件，更改任何系统设置，或自动上传任何内容。

测速时会在 LobsterAI 数据目录和临时目录里写入少量测试文件，结束后自动删除。
