LobsterAI 引擎连接诊断

适用情况：LobsterAI 能打开，但 AI 引擎一直显示启动中或启动失败，没法对话；
尤其是“刚装好能用一次，重启电脑后就不行了”。

1. 在问题出现时运行：重启电脑后打开 LobsterAI，看到引擎启动中或启动失败时，不要关闭 LobsterAI。
2. 双击 LobsterAI-Connection-Diagnostics.cmd。在压缩包里直接双击或解压后双击都可以。
   如果 Windows 提示“是否运行此文件”，请选择“运行”。
   如果 LobsterAI 没有在运行，工具会在 15 秒后自动打开它并等待引擎启动（按 N 可以跳过）。
3. 等待完成，通常 2～4 分钟。请不要关闭窗口。完成后会自动打开桌面上的诊断 ZIP 所在位置。
4. 把 LobsterAI-Connection-Diagnostics-日期时间.zip 发给技术支持。

如果安全软件弹出拦截或询问提示，请截图后选择“允许”；截图同样有助于排查。
如果公司策略阻止脚本运行，请把阻止提示截图交给技术支持或公司 IT。

此工具会收集：
- 系统版本、安装和开机时间、账户类型；
- 哪个程序在使用引擎端口，以及 PowerShell、curl 和 LobsterAI 自带运行时的本机连接测试结果；
- 代理设置、端口转发、系统保留端口、网络组件（Winsock）、虚拟网卡和防火墙规则；
- 安全软件、正在运行的程序名称（不含命令行）、第三方服务和驱动、开机启动项、已安装程序的名称和版本；
- 最近的应用日志和引擎日志（已去除密钥和令牌，内容与应用内“导出日志”相同），以及开关机记录。

此工具不会：
- 修改、修复或删除任何数据、配置和系统设置；
- 关闭 LobsterAI 或安全软件；
- 自动上传任何内容。

连接测试只连接本机地址 127.0.0.1，临时文件在结束后自动删除。
