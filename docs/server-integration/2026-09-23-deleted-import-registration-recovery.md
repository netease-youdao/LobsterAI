# 已删除任务的遗留导入恢复修复

日期：2026-09-23。桌面修复已完成，未安装到报障设备，未修改 iOS。

## 变更概要

旧任务的 import begin 被 `410 / 47010 / SESSION_DELETED` 拒绝后，本地仍可能保存导入尝试。注册阶段查询该 import 得到 `404 / 47002`，过去会使整台设备无法连接，导致新任务、WebSocket 和设备列表一起不可用。

本次仅修改桌面恢复逻辑和状态展示；服务端接口、开关、数据库结构均不变。测试库仅做只读核验。服务端证据文档：`../lobsterai-server/docs/operations/2026-09-23-deleted-import-registration-recovery.md`（相对桌面项目根目录）。

## 既有接口与认证

- `GET /api/remote/v1/sync/imports/{importId}`：只有明确的 HTTP 404、业务码 47002 才进入下述核验。
- `GET /api/remote/v1/sync/state?localSessionId={localId}`：使用当前 JWT、设备凭证与已发现的同步目标请求头，沿用现有账号/空间/设备权限校验。
- 核对 `deviceId/sessionId/localSessionId/syncProtocolVersion/streamEpoch/lastSourceSeq/lastSeq`，要求原身份和同步序列连续，`deleted=true` 且无 active import。

普通 404、权限失败、网络异常、错误会话或未知数据空间都不授权清除本地记录。接口请求及响应没有新增字段，无需 App 配合升级。

## 桌面行为

1. 可信删除状态允许设备注册继续；仅将旧任务标为不可继续补传。原导入、本地任务、ACK 和映射仍保留，不删除用户文件、不复活远端任务，不从 state 伪造导入成功回执。
2. 原目标首次认领仍须逐会话验证；缺少证据时不绕过目标保护。已有目标下的会话级冲突继续隔离。
3. 清除历史全局错误时，只清除与这条已核验导入匹配的错误；无关请求错误不被掩盖。
4. 未在线且存在同步队列时，设备页显示“同步暂停”，不再显示“同步中”。在线同步与异常提示保持原语义。
5. 账号/域名切换后的迟到响应仍不能绑定目标或修改 ACK。
