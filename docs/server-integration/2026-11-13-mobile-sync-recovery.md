# 手机任务内容同步：恢复重试入口

日期：2026-11-13。范围：LobsterAI 桌面任务同步状态展示与现有重试入口；不涉及手机 App 源码。

## 修复内容

部分任务已经进入会话级 `isolated` 状态，但设备管理的同步详情显示“未知”或等待连接，无法发起重试。`remoteOwnershipContentSync.ts` 修复两个状态判断：

- 普通 `deletionGuard` 是删除版本信息，不表示任务正在删除；只有实际删除 fence，以及既有关闭/删除记录，继续阻止重试。
- 经当前账号、设备和数据目标校验的会话级 `isolated`，显示内容同步失败，并按既有恢复预算提供“重试”。设备、服务或账号空间级故障不因此开放单任务重试。

状态查询保持只读，不会自行清除隔离或修改同步数据。既有服务端退避、60 秒手动重试间隔、恢复次数限制和异常恢复记录保护继续生效。

## 恢复流程与兼容

用户在桌面同步详情点击现有重试入口后，继续调用既有 `manualRetry` 与任务同步流程。对于已发送的历史导入，先查询并核验原 import 的服务端状态和目标身份；只有确认已过期或中止后，才按原流程放弃旧导入并生成新快照。已提交的导入按原回执完成本地确认，状态未知时不能直接重建或重复提交。

服务端 API、认证、协议版本和数据库 schema 均无需变更。继续使用现有 `/api/remote/v1/sync/imports` 创建、`GET /sync/imports/{id}` 状态查询及 parts/commit/abort 接口；没有新增字段或手机 App 行动项。既有账号归属、数据目标、连接状态和执行权限检查不变。
