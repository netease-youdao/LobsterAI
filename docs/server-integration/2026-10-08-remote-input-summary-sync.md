# 输入摘要冲突与任务同步恢复接入说明

## 变更摘要与接口

服务端允许旧桌面在相同 `inputVersion` 下刷新同一模型的目录版本；迟到历史摘要保留云端较新的输入配置，避免阻断整批历史。完整规则、字段示例及错误边界见 [接口说明](../../../lobsterai-server/docs/api/remote-input-summary-sync-2026-10-08.md)。

桌面继续使用 `POST /api/remote/v1/sync/batches`、既有导入及控制发布接口。请求/响应类型和路径不变，仍发送 JWT Bearer、设备凭据及原 owner/设备/连接代次字段；App 的输入准备、commands、读取接口及认证不变。不新增功能开关或 DDL，兼容 MySQL 5.7。

## Electron 行动项

- 模型摘要实际变化时，原子更新摘要和会话输入版本；同一摘要重复写入不增加版本。会话自身输入配置变更与摘要写入统一处理，远程输入操作记录最终版本。
- 已封存的 outbox 原样发送，保留 eventId、sourceSeq、hash、请求回执，不修改历史包以绕过冲突。
- 对旧版已隔离的 `INPUT_VERSION_CONFLICT` 任务执行一次持久化标记的恢复探测，沿原核对流程重放。再次确认真实冲突后维持任务隔离，不因重启无限自动解除；其他任务继续同步。

## App 行动项

本次无需新增参数或升级才能使用服务端兼容修复。继续消费服务端最新输入摘要；区分 `inputVersion` 与 `inputModel.version`，保留十进制字符串。真实命令输入冲突仍须刷新、重新准备，保留草稿和原未知命令结果核对。展示同步失败不能推断桌面任务执行失败。本次不修改手机 App 源码。

## 发布和验收

先全量发布服务端，再更新/重启 Electron，使一次性恢复探测命中修复后的节点。仅重启旧版桌面不能解除持久化隔离；仅更新服务端也不会主动唤醒已隔离任务。若探测先命中旧节点再次隔离，完成服务端升级后使用既有单任务重试入口，不清表或删除会话。

回归范围：同模型目录 `4→5` 后同批后续消息可同步；旧目录 `5→4` 和旧 inputVersion 历史重放不降级；真正同版本模型选择/思考变化继续拒绝；原批次重试无重复事件；升级仅恢复目标原因一次。数据库只读取问题会话输入元数据定位，本次没有数据修补或迁移。编译及本地检查不替代真实混部、手机和运行中桌面联调。
