# 图片与视频生成体验设计文档

## 1. 概述

### 1.1 问题与背景

生成失败时，用户可能只看到 HTTP 400；已经失败的任务仍显示等待；耗时较长时，会话阻塞、重启后结果恢复和文件保存缺少清晰反馈。此外，视频确认中的固定积分估算不能准确反映所选模型的费用。

### 1.2 目标

让用户知道任务处于哪个阶段、是否可以离开会话、失败后应如何处理，以及生成结果是否已经保存。恢复已有任务时避免重复生成，文件下载失败时继续获取原结果。本次不实现先生成后付款、充值领取或积分不足专项引导。

本文仅描述端侧体验与实现。服务端接口、鉴权、数据库及部署集成信息由服务端工程维护。

## 2. 用户场景

### 场景 1：生成并使用图片

**Given** 用户已启用图片生成并选好模型。

**When** 用户在会话中提出生成要求。

**Then** 展示生成状态，完成后保存文件、回填原会话并支持预览。

### 场景 2：视频耗时较长

**Given** 用户已确认视频描述和素材。

**When** 视频仍在生成。

**Then** 展示当前阶段及等待提示；普通会话可以结束本轮工具等待，完成后再展示结果。

### 场景 3：重启后继续查看

**Given** 当前账号已经提交任务或已保存生成结果。

**When** 应用重启并重新打开会话。

**Then** 恢复原任务状态，已交付任务仍可查询，已有文件可以直接预览。

### 场景 4：失败与交付异常

**Given** 输入不符合模型要求、生成失败或生成后的文件下载暂未完成。

**When** 应用收到相应状态。

**Then** 展示具体可操作的提示；终态停止等待；下载失败只重试原文件，不重新生成。

## 3. 功能需求

### FR-1：具体错误与输入提示

保留适合用户阅读的错误原因和修改建议。端侧提前检查参考素材大小、图片最低尺寸及参考视频输入形式；失败提示不得包含凭证或供应商原始响应。

### FR-2：任务状态卡片

分别呈现等待提交、提交中、生成中、核实结果、获取文件以及完成/失败/超时/取消。较慢提示不等于失败。只有实际允许取消时才展示取消操作；离开会话不表示取消生成。

### FR-3：等待与恢复

普通生成工具约等待 60 秒后可以返回后台继续。依赖生成结果的工作流（例如 AI skin）继续等待本地文件。端侧停止观察不得被显示为生成超时。

### FR-4：独立的文件交付

生成成功和文件保存分别记录。下载暂未完成时展示自动重试提示，同一任务文件不重复下载，完成消息只写入一次。

### FR-5：视频确认与播放

取消固定每秒积分估算；无法可靠估价时说明费用与所选模型、时长、规格有关。保留确认步骤。已保存视频支持在现有预览面板正常播放和拖动进度。

## 4. 实现方案

### 4.1 端侧任务记录

主进程使用 `mediaTaskStore` 保存提交意图、原会话与工具调用归属、任务快照和交付结果，按账号与服务地址隔离。恢复时既检查活动任务，也能查询已经交付的持久记录。完成消息与交付标记在同一 SQLite 事务中更新，避免重启后重复回填。

`mediaDownloadCoordinator` 负责下载去重与原文件重试。会话停止等待不销毁任务记录，账号切换不复用其他账号的任务。

### 4.2 会话展示

`MediaTaskCard` 根据共享状态和阶段常量生成卡片；`ToolCallGroup` 展示卡片，消息展示工具防止不同任务之间互相覆盖。中英文文案统一维护于 `src/shared/media/copy.ts`，主进程和渲染进程沿用各自翻译入口。

### 4.3 工具等待

媒体扩展区分终态、后台继续和本地停止观察。依赖型调用保留显式等待选项，以已经保存的文件供后续步骤使用。仅在检测到支持相应能力时启用持久任务路径，保留既有生成流程的兼容行为。

### 4.4 本地视频预览

本地文件 URL 使用明确的主机部分，避免 Chromium 拒绝媒体地址；沿用已有本地文件协议和分段读取，不改变现有安全隔离设置。

## 5. 边界情况

| 场景 | 处理方式 |
| --- | --- |
| 提交响应不明确 | 恢复已有意图并查询原任务，避免创建重复生成 |
| 已交付任务在重启后查询 | 从持久归属记录校验并返回已有结果 |
| 生成完成、下载未完成 | 显示获取文件或自动重试；不重新生成 |
| 本地观察到期 | 停止当前观察，不冒充生成超时 |
| 已失败、超时或取消 | 停止等待；按实际状态呈现原因与积分信息 |
| 账号或服务地址切换 | 隔离任务和交付记录 |
| 参考视频仅有本地文件 | 对要求可访问链接的模型提示先准备链接，不自动公开上传素材 |
| 旧版本能力不足 | 保留原有生成体验 |
