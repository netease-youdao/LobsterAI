# Excel 编辑第二阶段实现记录

日期：2026-09-27。在[第一阶段](./2026-09-27-excel-editing-stage1.md)的基础上，把高频的结构编辑、显示与交互补齐到接近 Excel 原生体验：行列与工作表操作、冻结、查找替换、排序、条件格式、图片、图表、数据验证下拉、超链接、筛选和批注。写回原则不变：以原始文件包为准，只改写变化的部分，写回器表达不了的操作在命令层拒绝并说明原因。本阶段同样没有生成安装包，也没有在 Windows、Linux 或 Microsoft Excel 上人工比对（在 macOS 上用 WPS 与 Numbers 打开核对过）。

## 用户可见的变化

- 行列：插入、删除行列（右键菜单、行列头菜单、Agent 工具），公式、名称、打印区域、合并区域、条件格式、数据验证、表格、图表引用、图片锚点、批注、超链接、筛选区域全部按 Excel 规则平移；删除的引用变成 `#REF!`。撤销可以完整恢复文件。
- 工作表：新建（沿用工作簿默认行高列宽）、删除、重命名、拖动排序、隐藏/取消隐藏、标签颜色；冻结与取消冻结写回 `pane`。
- 查找替换（Cmd/Ctrl+F）、按区域排序：批注和能显示的超链接随行移动（批注保留原作者和格式）；区域内有设在数字或公式上的超链接（编辑器不显示、原样保留）时拒绝。
- 条件格式：Excel 的全部常见规则（单元格值、文本、日期、前 N 项、高于平均、重复/唯一、公式、色阶、数据条、图标集）按 Excel 效果显示；清除、粘贴、填充、插入删除行列后写回。
- 图片：显示、移动、缩放、删除并写回锚点；工具栏“插入图片”（或粘贴图片文件）把 PNG、JPEG、GIF、BMP 图片按原尺寸放在当前单元格，写回为媒体文件和图片锚点（随单元格移动、不随之缩放，与 Excel 插入图片相同）；其他格式给出提示。组合、裁剪、翻转、调整层次和单元格内嵌图片暂不支持，界面上拒绝。
- 图表：柱形/条形（含堆积、百分比）、折线、面积、饼图/圆环、散点、气泡、雷达及组合图、次坐标轴用 ECharts 按 Excel 默认观感绘制，数据随单元格实时更新；可以移动、缩放、删除。Excel 2016 新图表类型、股价图、曲面图显示占位说明，文件中保持原样。
- 新建图表：工具栏“插入图表”选择柱形/条形/折线/面积/饼图/圆环/散点图，按 Excel 的方式读取选区（首行文字为系列名、首列文字为分类，只有含数字的列或行作为系列，其余文字列不画成空系列；选中单个单元格时取其所在的连续数据区域），放在数据右侧、默认 480×288，插入后自动选中。与 Excel 2013 起的默认一致：单系列以系列名为标题、不显示图例；多系列和饼图显示“图表标题”占位、图例在底部。新图表写回为标准 DrawingML 图表部件（带缓存值，WPS 直接显示），工作表没有绘图部件时一并创建；改过设置的原有图表按新设置重写图表部件。之后插入或删除行列，新图表的引用按 Excel 规则跟随。
- 图表设置：选中图表后工具栏的“图表设置”按钮或图表旁菜单的“图表设置”打开面板，可改类型、数据区域（与 Excel“选择数据”相同：显示图表读取的单元格块，改成新的区域后按插入图表的规则重新读取系列，颜色、数据标签、堆积、图例和坐标轴设置保留，自动标题跟随新数据）、堆积方式（不堆积/堆积/百分比堆积）、标题、图例位置、数据标签、网格线、横/纵轴标题和各系列颜色，每项修改是一步撤销。图表旁的菜单只保留“图表设置”和“删除”（Univer 原菜单的裁剪、翻转、重置大小对图表无效）。设置面板浮在页面最上层，图表靠右时不再被 Univer 的菜单按钮压住。坐标轴标题按标签宽度留出位置，不再被裁掉或压住刻度。双击图表标题可以直接在图表上修改（回车或点别处生效，Esc 取消，清空即删除标题），同样是一步撤销。
- 两级分类轴：选区里分类列右侧紧挨着的文字列（如“区域 / 产品 / 销量”）按 Excel 的方式成为分类的外层，外层标签放在各组中间、组之间画分隔线；写回为 `multiLvlStrRef`（带各级缓存）。文件中的多级分类（`multiLvlStrRef`，或其他工具写成跨多列的 `numRef`/`strRef`）此前被读成双倍长度的分类，现在按级显示。
- 数据验证：列表规则显示下拉箭头（与 Google 表格导入 Excel 时相同的“箭头”样式），选择即写入；其他规则按 Excel 校验输入，不符合的单元格右上角标红。
- 超链接：链接单元格显示为链接，点击弹出地址，可打开（仅 http/https/mailto）、复制、编辑、取消；工作簿内链接跳转到目标表和单元格；右键“添加链接”新建。
- 筛选：表头筛选按钮、按值/按条件/按颜色筛选与排序，筛选结果写回为隐藏行并同步 `autoFilter`、`_xlnm._FilterDatabase`；清除筛选后行重新显示。Excel 的前 N 项、高于/低于平均值、相对日期（本月等）按文件中保存的阈值或日期范围显示为条件筛选；按颜色筛选按差异格式解析出颜色；日期分组（年/月/日树）、按月/季度和图标筛选在打开后按单元格显示值换算为值列表。没有改动的筛选列保存时保留 Excel 原有写法。
- 批注：单元格右上角标记，悬停显示内容，可以直接编辑、删除、右键“添加批注”；新批注的作者为 `LobsterAI`。编辑时只改动变化的文字，加粗的作者名等格式保留；排序、剪切粘贴移动的批注保留原批注、作者和批注框。线程批注（新版 Excel 的“评论”）以“姓名: 内容”的对话形式显示，随单元格移动；编辑后转为普通批注，删除会移除整段对话。
- 公式中表格的“本行”简写（`Sales[@Qty]`、`[@[Unit Price]]`、`Sales[@]`）在输入、粘贴和打开文件时写成 Excel 文件里的完整形式 `Sales[[#This Row],[Qty]]`，表格内没有表名的写法补上所在表格的表名；此前这类公式算成 `#NAME?`。公式栏和单元格编辑器反过来按 Excel 的样子显示简写（表格内为 `[@Qty]`，其他位置为 `Sales[@Qty]`），文件中仍是完整形式。
- 工具栏的加粗、换行等状态只反映单元格自身格式，不再把条件格式、数据验证绘制的效果当成单元格格式；没有单独设置字体的单元格显示工作簿默认字体和字号。
- Mac 上选中图片或图表后，delete 与 fn+delete 都能删除（Univer 原本只绑定前者）。
- 表格样式：Excel 内置表格样式（浅色 1–21、中等色 1–28、深色 1–11）和工作簿自定义的表格样式按表格选项绘制表头、镶边行/列、第一列/最后一列、汇总行和边框，随插入删除行列、扩展后的表格范围更新。单元格自身的格式优先；与 Normal 样式相同的字体颜色、未加粗、无填充不算直接格式，因此表头白字不会被默认黑字盖住（与 Excel 一致）。样式只绘制，不写进单元格格式，文件中的表格样式保持不变。
- 表格编辑：在表格内部插入列会新增表格列，表头按 Excel 命名为“列1”“列2”（英文界面为 Column1），改表头即改列名；删除表格列时，如果有公式按列名引用它（如 `Fruit[数量]`、`[@数量]`）或要删掉表格的全部列，就拒绝并说明原因。在没有汇总行的表格正下方、或表格右侧的空单元格输入、粘贴或拖动填充柄填入内容，表格自动扩展（Excel 的“自动扩展表格”）：计算列的公式填入新行，新列按表头命名；撤销时一并撤回。结构化引用随列移动。
- 工具栏：边框改为 Excel 的边框菜单（下/上/左/右框线、无框线、所有框线、外侧框线、内部框线、粗外侧框线、双底框线、粗底框线）；新增格式刷（单击刷一次，双击连续使用，Esc 退出）和增加/减少小数位数。
- 复制工作表：带条件格式、数据验证、筛选、超链接、批注、图片和图表的工作表可以复制，副本写回为完整的工作表部件；副本中的图表引用副本自己的数据（与 Excel 相同）。工作表含表格、编辑器画不出的形状、设在数字上的超链接或扩展内容时仍拒绝，因为副本会丢掉这些内容。
- 工具栏（第四轮，对齐 Excel“开始”选项卡）：新增顶端对齐/垂直居中/底端对齐；字体颜色、填充颜色改为 Excel 的拆分按钮——按钮直接套用上次用过的颜色，箭头打开色板：自动/无填充、工作簿主题色（10 列，每列主题色及其 5 个浅色/深色变体，算法与 Excel 相同）、标准色、其他颜色（系统取色器关闭时应用一次）；合并按钮改为“合并后居中”，箭头提供跨越合并、合并单元格、取消单元格合并，合并会丢值时先提示（取消则不改动），合并与居中是一步撤销；边框改为拆分按钮，按钮重复上次的边框，图标随之变化；数字格式增加长日期、时间、分数、科学记数和“其他数字格式…”（Univer 的数字格式面板）；自动求和拆分按钮（求和、平均值、计数、最大值、最小值、其他函数…：选中空单元格时进入编辑并预填 `=SUM(C2:C7`，选中数据区域时在下方写入各列合计）；筛选开关（按下状态表示当前工作表有筛选）。1200 像素宽时工具栏为一行。（第四轮曾加入的“条件格式”菜单与“数据验证”按钮在第五轮按定位移除，见下文。）
- 数据验证对话框：第四轮加入的 Excel 三页对话框在第五轮移除（创建、修改规则属于低频的结构性操作，交给 AI 处理）；文件中已有规则的下拉选择、输入信息和出错警告照常工作。
- 输入信息与出错警告：选中设置了输入信息的单元格时，在单元格右侧显示 Excel 样式的淡黄色提示（标题加粗、内容换行），选中其他单元格即消失。键入的内容不符合规则时按 Excel 的三种样式询问（第五轮）：“停止”提供重试/取消，重试回到编辑状态并保留刚才键入的内容；“警告”问“是否继续？”，是/否/取消（默认按钮为“否”，即重新编辑）；“信息”提供确定/取消。标题使用规则中设置的错误标题（Univer 原本固定为“提示”）。与 Excel 一样不再在不合规的单元格角上画红色标记（红色角标在 Excel 里表示批注）。
- 快捷键（Excel 在 Windows 与 Mac 上各自的按键）：插入当前日期（Windows Ctrl+;，Mac ⌃;）与时间（Windows Ctrl+Shift+;，Mac ⌘;）——与 Excel 一样进入输入状态，回车后存为日期/时间序列号；常规、货币、百分比、科学记数、日期、时间、千分位数字格式（Ctrl+Shift+~ $ % ^ # @ !，Mac 用 ⌃⇧）；外侧框线与清除框线（Windows Ctrl+Shift+& / _，Mac ⌘⌥0 / ⌘⌥-）；设置单元格格式（Ctrl+1 / ⌘1，打开数字格式面板）；移到工作表开头（Ctrl+Home / ⌃Home，冻结窗格时为冻结区域右下的第一个单元格）、最后使用的单元格（Ctrl+End / ⌃End，与 Excel 一样把带格式的单元格计入）、本行开头（Home）；下一张/上一张工作表（Ctrl+PageDown/PageUp，Mac 另有 ⌥→/⌥←，跳过隐藏的工作表）。Univer 已有的 Alt+=（自动求和）、Ctrl+Shift+L（筛选）、F4、Ctrl+D/R、⌃Enter（输入填满选区）、⌥Enter（单元格内换行）、⌘⇧Z（重做）、双击列标或行号分隔线自动调整列宽/行高、双击填充柄向下填充等保持不变。这些快捷键只在表格获得焦点且不在编辑单元格时生效。
- 缩放：状态栏右下角显示缩放滑块（与 Excel 相同）；工作表的缩放比例随下一次保存写入 `sheetView` 的 `zoomScale`/`zoomScaleNormal`（与 Excel 保存缩放的方式一致），打开时按文件中的比例显示。

- 大文件编辑不卡界面：公式在 Worker 中计算（Univer 官方的 RPC 方式，`sheetFormula.worker.ts`），公式不足 2000 个的工作簿仍在主线程计算，结果即时显示。打开和保存由同一个“文件线程”完成（`sheetFile.worker.ts`）：解压、读取字体、导入、结构分析、表格样式和图表配色都在后台算好，主线程只加载字体、实测列宽和建立 Univer 模型；文件线程保留这份导入作为之后每次保存的基线，整个会话只导入一次。此前默认字体为等线、宋体、微软雅黑等中文字体的文件，因估算列宽与实测不符，会在主线程导入两次。Worker 启动失败或中途出错时，打开、保存自动改在主线程进行；公式 Worker 失败时，未编辑的工作簿改为在主线程计算并重新打开。

编辑器底部“暂不在此显示、但会原样保留”现在只列出：图表工作表、编辑器画不出的形状/组合/特殊格式图片、落在数字或公式上以及指向定义名称的超链接。

## 第五轮：聚焦 AI 协作编辑（2026-09-28）

定位（用户确认）：在 LobsterAI 里实时编辑 Word/Excel，是为了让 AI 辅助实时修改，以及需要小改动时可以直接改，而不是替代 Office。只保留高频功能，低频的完整对话框不做。

- 移除：本轮开发中的“设置单元格格式”五页对话框（数字/对齐/字体/边框/填充）在交付前撤回；工具栏的“条件格式”菜单、“数据验证”按钮及其对话框移除；单元格右键菜单末尾的“设置单元格格式…”（只打开数字格式面板）移除。Ctrl+1 / ⌘1 与工具栏数字格式的“其他数字格式…”仍打开数字格式面板。文件中条件格式、数据验证的显示、交互和写回不受影响，新建和修改这类规则交给 AI。
- 添加到对话（Excel）：用鼠标选中多个单元格后，选区右下角出现“添加到对话”；单元格、行号、列标的右键菜单第一项也是“添加到对话”（单个单元格同样可用）。点击后把 `文件名 · 工作表!区域` 和单元格显示的内容（制表符分隔，最多约 3600 字，超出时按整行截断并注明省略的行数；空区域写“（空白单元格）”）加入当前任务对话的草稿，与 Markdown、文本预览选中文字后的“添加到对话”走同一条路径；发给模型时带上文件路径，并提示可用 excel_read 读取公式等更多内容。单击单个单元格不出现按钮；开始输入、切换工作表、重新选择时按钮消失；没有可用的任务对话时两个入口都不显示。
- 添加到对话（Word）：在 Word 编辑器中选中文字后，选区上方出现同样的“添加到对话”（Word 引擎取消了 pointerdown，浏览器不再派发 mouseup，因此在 pointerup 时读取选区）；滚动、输入或点别处时消失。
- 倾斜文字方向：Univer 的旋转角度以顺时针为正，与 Excel 的 `textRotation`（1–90 逆时针、91–180 顺时针）相反；此前导入的倾斜文字显示成镜像（写回的数值不变），现在按 Excel 的方向显示和写回。
- 写回校验：导出的文件用 ISO/IEC 29500 过渡版 XSD（仓库 `SKILLs/docx/ooxml/schemas`）严格校验：先去掉 `ext` 之外的扩展命名空间，另查 count 属性、关系目标、内容类型和 sheetId。由此修复：新增的工作表子元素只按直接子元素定位插入点（此前可能写进 `extLst` 内部，例如数据验证进了数据条规则，WPS 因此不显示数据条）；向自闭合的空 `<definedNames/>`、关系和内容类型文件追加内容时不再生成重复元素；数据验证的日期、时间限值按 1904 日期系统换算。

### 流畅度核查（第五轮）

按“高频操作像原生一样顺”的标准，在隔离实例里用真实输入事件量化核查（`requestAnimationFrame` 帧间隔、`longtask`、按键到下一帧、回车到写入单元格）。两个样本：常见规模 500 行 × 12 列、大文件 2 万行 × 12 列（6 万个公式、筛选、冻结）。

| 场景 | 常见规模 | 大文件 |
| --- | --- | --- |
| 连续输入 10 行（每键 40 ms）并回车 | 60 帧、无卡顿帧、无长任务；按键到下一帧中位 23 ms；回车到写入 6 ms | 同左（中位 22 ms / 回车 4 ms），期间自动保存也无长任务 |
| 方向键连按 60 次 | 60 帧、无长任务，按键到下一帧中位 17 ms | 同左（中位 19 ms） |
| 触控板滚动 90 次 | 60 帧、无卡顿帧 | 同左 |
| AI 一次写入 500 个单元格 | 表格立即更新、无长任务；含保存共 0.66 s | 无长任务；含重算与保存共 2.6 s |
| 中文输入法（选中单元格直接输入拼音） | 组字过程显示在单元格中，上屏正确（“你好”“世界”），不丢字、不重复 | — |

由此修复两处：

- 大文件自动保存卡顿：保存时把整本工作簿一次性复制给文件线程，2 万行的工作簿每次主线程阻塞约 80 ms（掉 5 帧）。现在超过 2 万个单元格时按行分片发送（每片约 1.6 万个单元格、不到 6 ms），片与片之间让出主线程；分片期间若有新的编辑就整轮重来，保存的文件不会混入两个时刻的内容。修复后同一场景没有长任务，保存的文件经 openpyxl 与 ISO/IEC 29500 严格校验无误（`sheetSnapshotSlices.ts`、`sheetFileClient.ts`、`sheetFile.worker.ts`）。
- 在已有内容的单元格里编辑（双击或 F2 后输入，含输入法）时，Univer 的编辑器把主题默认文字颜色（`gray.900`）作为样式写进新输入的字，单元格因此变成带颜色的富文本：深色主题下新字几乎看不见，文件里也多出格式。现在在写入前去掉这种默认颜色，没有其他格式的单元格保存为普通值（`sheetCellInput.ts`，`AFTER_CELL_EDIT` 拦截器，先于数字格式与超链接处理）。

## 实现和文件边界

### 对 Univer 行为的修正

- 条件格式在插入行时被 Univer 拆成多条规则、绝对引用不随之移动：新增 `RuleReferencesPlugin`，让 `FormulaRefRangeService` 对行列插删不再改写规则，由结构跟踪器按 Excel 语义统一处理（剪切粘贴等单元格移动仍交给 Univer）。数据验证同理；列表类规则的范围仍由 Univer 移动，跟踪器的修正排在最后执行。
- 插入行列时 Univer 复制上一行的“显示样式”，条件格式的高亮会变成真实格式：在 `InsertRowByRangeCommand` / `InsertColByRangeCommand` 执行前改用源单元格自身的样式。
- 连续插删行后，其他工作表引用该表的公式会算成 0：结构编辑的计算结束后再做一次完整重算，保存等待重算完成。
- 常规格式的小数被显示成科学计数：`patches/@univerjs+engine-render+1.0.2.patch` 先尝试按列宽放下定点小数（通过既有的 `patch-package` postinstall 应用）。
- 数据验证下拉在深色模式下文字不可见：`sheetEditor.css` 补一条针对箭头样式的颜色；下拉中的“编辑”按钮关闭（规则编辑器可以生成 Excel 无法保存的类型）。
- 打开外部链接只允许 http、https、mailto，经 `window.electron.shell.openExternal` 打开，其他协议拒绝（工作簿内容不可信）。
- Univer 每次计算都会为全部公式重建依赖树（6 万个公式约 0.5–1 秒）：公式引擎放入 Worker。表格区域改用 `SetSuperTableMutation` 注册，以便同步到 Worker。
- 连续打开第 4 个工作簿时，缓存淘汰在 React 提交阶段销毁旧实例，Univer 自己的 React 根节点卸载冲突并报 `removeChild` 异常：淘汰改到提交之后执行。
- 浮动元素的数据更新后 Univer 不会把新数据传给已渲染的组件：图表组件每次重绘时从绘图模型读取最新描述。插入图表时的 `transform` 是包含表头的场景坐标，用 `drawingPositionToTransform` 从单元格锚点换算。
- 只改数据验证规则（新建、修改、删除）时文件不会自动保存：Univer 数据验证的 mutation 名为 `data-validation.mutation.*`，会话此前只把 `sheet.mutation.*` 视为编辑。现在也包括 `data-validation.mutation.*` 和超链接模型的 `sheets.mutation.*`。
- `FWorkbook.onSelectionChange` 只在鼠标或键盘移动选区结束时触发，Agent 定位等代码设置的选区不会刷新工具栏状态：改为订阅 `SheetsSelectionsService.selectionChanged$`（两者合并）。
- Univer 的服务通过懒加载代理提供，代理把方法绑定后缓存在自身上，给实例赋值替换不到调用方拿到的方法：替换拒绝输入提示框的标题时，用 `Object.defineProperty` 覆盖代理上缓存的方法。
- Univer 的工具栏入口（条件格式、数据验证、筛选、数字格式面板、自动求和）都在被隐藏的功能区里，右键菜单也没有：由 LobsterAI 的工具栏提供入口。

### 写回修正

- 删除计算链（`calcChain`）时曾用原文件的内容类型表覆盖当前版本：同一次保存中新建的部件（第一条批注的批注部件、新图表、新图片）会丢失内容类型。现在基于本次保存已有的内容修改。
- 带命名空间前缀（`x:`）的批注部件在编辑批注文字时曾写出 `x::t` 这样的元素名，已修正并补充测试。
- 新元素的插入位置：数据验证、条件格式、筛选、超链接、合并单元格、绘图、批注的写回按“下一个应出现的兄弟元素”定位插入点，此前按名称在整个工作表中查找，会命中嵌套在其他元素里的同名元素——Excel 写的数据条规则在 `<cfRule>` 内带有 `<extLst>`，于是在含数据条的工作表上首次添加超链接、图片/图表、批注，或改动数据验证时，新元素被写进 `<cfRule>` 内部，文件结构损坏（WPS 不显示数据条，下次打开时规则读不出来、再保存时被丢弃）。现在统一用 `xlsxXml.ts` 的 `childInsertionPoint` 只看直接子元素（`mc:AlternateContent` 按其包裹的元素计），样式表中新建 `dxfs` 同样处理；自定义视图中的 `autoFilter` 不会被当成工作表自己的筛选。
- 日期与时间验证：Univer 把日期规则的值规范为 `2026-09-28` 这样的文本，原样写入 `<formula1>` 会被 Excel 当作算式（得 1989）。现在按工作簿的日期系统（含 1904）写成序列号，时间写成一天中的比例。

## 已知限制与后续

- 排序区域内有设在数字或公式上的超链接（或跨多个单元格的链接）时拒绝排序：这些链接不在编辑器中显示，不会随排序移动。
- 剪切粘贴（移动单元格）不会改写文件中保留原样的引用（例如未显示的内容）；筛选、链接、批注随单元格移动。
- 新建图表只提供七种常用类型；数据区域只能整体替换（不能单独增删某个系列或改系列名引用），组合图与次坐标轴的新建、坐标轴刻度的设置暂不支持。改过设置的原有图表会按编辑器支持的属性重写，原图表中编辑器不认识的格式（如渐变填充、艺术字标题）会丢失。图表工作表不显示。两级分类的组分隔线只画在外层标签一行（Excel 从坐标轴一直画到外层）。
- 新图表创建之后若重命名它引用的工作表，引用不会跟随改名（图表数据显示为空，保存时保留原引用）。
- 数据验证不支持 Univer 的多选列表与复选框类型的写回（界面入口已关闭）；编辑器不提供新建、修改规则的界面（按定位交给 AI）。
- 前 N 项、高于平均值等条件按保存时的阈值显示，数据变化后不会像 Excel 那样重新取前 N 项；图标筛选与没有保存日期范围的相对日期按打开时显示的行换算为值列表。
- 批注编辑器只能输入纯文本：新输入的文字沿用相邻文字的格式，不能单独设置加粗等格式；批注框尺寸调整不写回。
- 打开大文件时 Univer 建模与首帧绘制仍在主线程（20 万单元格合计约 0.4 秒，最长一段约 0.14 秒）。
- 表格样式的颜色按主题色与色调换算，个别颜色与 Excel 相差一个色阶（如 `#DAE3F3` 与 Excel 的 `#D9E1F2`），肉眼不可分辨。
- 有汇总行的表格不会向下扩展（与 Excel 相同）。
- 复制含表格的工作表仍被拒绝（Excel 会为副本中的表格改名，这里还不支持）。
- 时间类型的数据验证规则编辑器不做校验（Univer 没有时间校验器），保存后在 Excel 中生效。
- 条件格式：编辑器不提供创建与管理界面（按定位交给 AI）；文件中的规则照常显示、随编辑更新并写回。
- 从色板选择的主题色保存为具体颜色值，不随工作簿主题切换变化（Excel 保存为主题色引用）。
- “设置单元格格式”（Ctrl+1 / ⌘1）只提供数字格式，对齐、字体、边框、填充使用工具栏（按定位不做完整对话框）。
- 只改缩放时不会触发保存，缩放随下一次编辑一起保存。
- 仍未在 Windows、Linux 和 Microsoft Excel 上人工核对（macOS 上的 WPS 与 Numbers 已核对；第五轮改用 ISO/IEC 29500 严格校验检查写出的文件结构，见验证记录）。
