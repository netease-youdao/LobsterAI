# 本地产物网格展开 / 收起控件中性色设计

## 1. 目标与边界

在[任务网格折叠方案](./2026-09-07-library-grid-session-collapse-design.md)上，仅调整展开、继续显示、收起、加载和重试控件的呈现。参考现有预览卡片的浅色背景、细边框和克制的悬停反馈，使控件作为次级操作，不抢占文件内容的视觉注意力。

不改变本地产物默认网格、按任务时间排序、固定预览 3 个、首次展开前 24 个、后续追加最多 24 个的规则。列表、云端、预览卡片、任务标题跳转、筛选和刷新行为不变；不新增持久化状态或配置项。此次仅涉及 Renderer，不修改 Main、IPC、数据库、服务器或 OpenClaw。

已确认的独立 Web Demo 保留在项目外；不将 Demo 源码、服务端脚本、合成数据或截图复制进项目。

## 2. 控件层级与文案

| 状态 | 底部左侧 | 右侧辅助信息 | 标题右侧 |
| --- | --- | --- | --- |
| 匹配文件不超过 3 个 | 无控件 | 无 | 无 |
| 折叠 | 浅灰描边按钮“还有 N 个文件” + 下箭头 | 无 | 无 |
| 展开且还有文件 | 浅灰描边按钮“继续显示 N 个” + 下箭头；透明“收起” + 上箭头 | “还有 M 个文件” | 透明“收起” + 上箭头 |
| 全部展示 | 透明“收起” + 上箭头 | 无 | 透明“收起” + 上箭头 |
| 初次或追加加载 | 禁用的浅灰按钮：灰色 spinner +“正在加载文件…”；可用的“收起” | 无 | 可用的“收起” |
| 局部加载失败 | 中性“重试”；已展开时保留“收起”；下方独立错误说明 | 无 | 已展开时保留“收起” |

- 折叠 N = 当前筛选匹配总数 - 3；继续显示 N = min(24, 剩余文件数)；展开后的 M = 匹配总数 - 已显示数量。
- 继续显示数量和剩余总数分开，避免长按钮挤占空间。宽屏辅助信息右对齐，窄屏允许自然换行，不截断数量或依赖 tooltip。
- 收起采用透明背景和透明边框；悬停仅出现浅灰底，边框仍透明。标题入口比底部入口更紧凑。
- 加载时移除下箭头，spinner 只作装饰；文字仍完整表达状态。保持收起可用，沿用旧请求失效机制。
- 失败时明确显示错误文字和重试，不用主题色或红色填充强调。重试只影响当前任务，保留已有卡片。
- 沿用禁用逻辑：加载或游标失效时阻止更多读取，不能因此禁止收起。
- 中文使用“继续显示 {count} 个”及“还有 {count} 个文件”；英文使用“Show {count} more”及“{count} files remaining”。其他已有双语文案不变。

## 3. 视觉规格

### 3.1 中性色板

| Token | 浅色 | 深色 |
| --- | --- | --- |
| 默认背景 | `#FAFAFA` | `#292929` |
| 默认边框 | `#DEDEDE` | `#484848` |
| 默认文字 / 错误说明 | `#626262` | `#C2C2C2` |
| 箭头 | `#797979` | `#B3B3B3` |
| Hover 背景 / 边框 | `#F1F1F1` / `#D3D3D3` | `#333333` / `#555555` |
| Hover 文字 | `#383838` | `#EEEEEE` |
| Pressed 背景 / 边框 | `#E9E9E9` / `#C9C9C9` | `#3B3B3B` / `#626262` |
| 键盘焦点 | `#858585` | `#A3A3A3` |
| 剩余数量 | `#707070` | `#AAAAAA` |

颜色使用控件作用域内的专用 CSS 变量，不引用 primary、accent 或皮肤的 surface-raised；后者在 daylight 等皮肤中可能带黄色。深色模式随应用 `.dark` 切换，但始终使用中性灰，不强行铺白色。

辅助数量文字比最初 Demo 的浅灰略深，保证在 classic-light、daylight、sakura 等实际浅色页面背景上的小字号文字对比度至少 4.5:1。

### 3.2 尺寸与状态

- 底部按钮最小高度 32 px、圆角 9 px、左右内边距 11 px、上下内边距 5 px、边框 1 px；文字与图标间距 7 px。
- 标题收起最小高度 28 px、圆角 8 px、内边距 3 px × 7 px；图标 14 px。
- 字号使用产品现有 `text-xs`，默认约 13 px，尊重应用字号设置；不机械照搬 Demo 的固定 12 px。
- 沿用卡片底部 12 px 间隔及控件行底部 28 px 间隔；动作组内部间距 8 px。
- 底部使用可换行的双层 flex，虚拟行继续测量真实高度。只改变样式，不添加会影响分页、收起定位的高度展开动画。
- 背景、边框和文字颜色过渡 140 ms；spinner 周期 800 ms。
- 禁用保留浅灰样式并降低透明度，不触发 hover/pressed 反馈。

## 4. 无障碍与兼容性

- 使用原生 button，保留 aria-expanded、aria-controls、任务级收起 aria-label、加载 aria-busy 和错误 role=alert。
- spinner 和箭头使用 aria-hidden，不重复朗读装饰内容。
- 焦点使用 2 px 中性实线轮廓、向外偏移 3 px；不能只去掉 outline。
- 粗指针设备底部及标题按钮最小高度 44 px；字号放大时允许控件增高和换行。
- prefers-reduced-motion 关闭控件过渡和 spinner 旋转，加载文字不受影响。
- forced-colors 使用系统按钮边框与焦点色；不禁止用户代理的高对比度调整。
- 保留独立任务展开状态、晚到响应取消、局部重试、收起后的标题锚点与键盘焦点恢复。

## 5. 实现与验收

- `src/renderer/components/library/LibraryVirtualizedGroups.tsx`：复用现有原生按钮和回调，增加局部样式 class、spinner、独立剩余数量。
- `src/renderer/components/library/libraryDisclosure.css`：专用浅深灰阶、交互、焦点、触控与减少动效适配；不扩大全局主题或预览卡片样式。
- `src/renderer/services/i18n.ts`：简化继续显示按钮，新增剩余数量双语文案。
- `LibraryVirtualizedGroups.test.ts`：覆盖中性 class、数量分离、中英文、加载/失败/禁用以及标题/底部收起语义。
