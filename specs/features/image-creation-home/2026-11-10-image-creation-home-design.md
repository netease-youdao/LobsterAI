# 首页图片创作入口设计文档

## 1. 概述

### 1.1 背景

用户需要在新任务页面直接发现图片创作能力，并能从具体作品理解可以完成的任务。作品入口同时承接专家广场中的图像创意搭档，避免两处维护不同的创作流程。

### 1.2 目标

- 首页增加默认展开的「图片创作」标签，用作品卡片展示创作场景。
- 点击作品后可预览、编辑提示词，使用示例参考图或上传自己的图片。
- 「做同款」准备专家会话草稿，由用户主动发送后执行。
- 样例内容、顺序及开关可动态配置；其余快捷标签保留原有交互。

## 2. 用户场景

### 场景一：从首页开始创作

用户进入新任务页面，浏览图片样例并选择作品。在预览弹窗中阅读或修改提示词，点击「做同款」，检查填入输入框的内容后发送。用户也可恢复选择样例前的草稿。

### 场景二：替换参考图

需要参考图的样例提供示例素材。用户可以使用示例素材，也可以点击「使用我的图片」或「选择图片」上传本地文件，再将图片和提示词一起带入草稿。

### 场景三：继续浏览专家作品

首页的「去专家广场，更多灵感」打开配置指定的专家详情。详情中的作品使用相同目录和预览组件，选择后进入同样的草稿准备流程。

## 3. 功能需求

### FR-1：首页展示

图片创作标签在目录启用时出现，新任务默认展开。输入区最大宽度为 720 px，作品区域最大宽度为 1040 px；窄窗口显示两列，较宽窗口显示四列。缩略图统一采用 16:10 容器，使用等比适配保留完整原图；允许按配置并排展示参考图和结果图。

切换到制作幻灯片、数据分析、文档写作、创建网站时，继续使用原有提示词面板。图片目录关闭或缺失时不展示新增入口。

### FR-2：预览与发送

预览显示生成作品、名称、说明、可编辑提示词和示例使用的模型名称。「做同款」不直接提交任务：先准备专家及附件，再填入首页输入框。提示词为空时禁用操作，准备期间防止重复点击；失败时允许重试。

`modelName` 仅用于说明示例的来源，不覆盖用户的生图模型选择。

### FR-3：参考图

支持 PNG、JPEG、WebP，单文件不超过 10 MB。示例参考图通过主进程下载并校验文件头及像素数量，最多 4000 万像素。WebP 在暂存时转换为 PNG，以兼容模型输入；原始展示素材保持不变。

附件经现有文件暂存接口保存到专家工作目录，并作为图片附件及媒体引用写入草稿，运行时可获取对应本地路径。

### FR-4：滚动提示

首页作品区域、提示词和专家详情在空闲时隐藏滚动条滑块，悬停、键盘聚焦或滚动时显示细滑块。内容未展示完时提供边缘渐隐及可点击的下翻提示；内容完全可见或滚动到底后隐藏提示。

提示词编辑时移除渐隐遮罩，保持固定高度并禁止原生拖拽缩放。专家详情的关闭按钮固定在内容滚动区之外。尊重减少动画和强制颜色模式。

## 4. 实现方案

### 4.1 配置协议

配置源为 Overmind 项目 `475` 的 `image-creation-examples` 键。主进程根据应用环境选取端点，测试与生产目录分别缓存。

| 字段 | 说明 |
| --- | --- |
| `schemaVersion` | 协议版本，当前为 `1` |
| `version` | 目录内容版本 |
| `enabled` | 是否展示图片创作入口及专家作品 |
| `expertPresetId` | 承接草稿的专家预设 ID |
| `examples` | 按展示顺序排列的样例，启用时为 1–24 个 |
| `examples[].id` | 唯一稳定 ID，使用小写字母、数字、下划线和连字符 |
| `title`、`description`、`prompt` | 各含非空 `zh`、`en` 文本 |
| `imageUrl` | 作品展示图地址 |
| `referenceImageUrl` | 可选的示例参考图地址 |
| `showReferencePreview` | 可选；是否在卡片中对照展示参考图与结果图，需要参考图地址 |
| `modelName` | 作品来源模型的展示名称 |

素材使用稳定 HTTPS 地址。允许的域名为 `ydhardwarecommon.nosdn.127.net`、`ydschool-video.nosdn.127.net` 和 `shared.ydstatic.com`；拒绝端口、账号信息、查询参数及片段。下载禁止跳转并限制响应大小，图片类型以文件头为准。

### 4.2 加载与刷新

`ImageCreationStore` 负责下载、解析、合并并发请求和持久化有效目录。渲染层在初始化、窗口聚焦以及每五分钟请求刷新；主进程控制刷新间隔。暂时失败时沿用当前环境的有效缓存，并在较短间隔后允许重试；无有效缓存时展示重试入口。

服务端明确缺失配置或返回关闭状态时隐藏功能。环境切换后不使用其他环境的目录兜底。

### 4.3 草稿准备与恢复

`prepareImageCreationDraft` 先记录当前草稿，准备专家及参考附件，再检查页面、账号代次及草稿是否仍保持不变。只有检查通过才切换专家并应用新草稿，避免异步准备覆盖用户的新操作。

恢复包含提示词、附件、选中文本、浏览器标注、套件、技能、协作模式及此前的 Agent。账号已切换或已进入会话时不恢复旧草稿。

### 4.4 组件复用

`HomeImageCreation` 管理首页入口和草稿反馈；`ImageExampleGallery` 与 `ImageExampleDialog` 同时用于首页和专家详情。`useScrollAffordance` 计算上下可滚动状态，`HomeScrollArea` 为首页提供滚动反馈。

## 5. 边界情况

| 场景 | 处理方式 |
| --- | --- |
| 配置缺失、关闭 | 隐藏图片创作标签与专家作品 |
| 目录格式错误、网络暂时失败 | 使用同环境有效缓存；首次加载失败提供重试 |
| 重复 ID、超出数量、非法地址 | 拒绝该目录，不应用部分内容 |
| 参考图无效、下载超时或暂存失败 | 显示错误并保留弹窗，允许重新选择或重试 |
| 准备期间切换账号、离开页面或修改草稿 | 放弃应用旧结果，保护当前草稿 |
| 空提示词或重复点击 | 禁止提交或重复准备 |
| 内容不溢出或已到底 | 隐藏下翻提示，保留正常布局 |
| 嵌套作品弹窗 | Escape 先关闭当前作品预览，再处理专家详情 |

## 6. 涉及文件

- `src/shared/imageCreation/`：目录类型、约束、IPC 常量和中英文文案。
- `src/main/libs/imageCreationStore.ts`、`src/main/ipcHandlers/imageCreation.ts`：目录缓存、参考图下载及 IPC 接口。
- `src/main/libs/endpoints.ts`、`src/main/main.ts`、`src/main/preload.ts`：环境端点与进程桥接。
- `src/renderer/services/imageCreationDraft.ts`：草稿准备、附件暂存和恢复。
- `src/renderer/components/imageCreation/`：首页、卡片、预览、滚动提示和目录加载。
- `src/renderer/components/cowork/CoworkView.tsx`、`src/renderer/components/quick-actions/QuickActionBar.tsx`：新任务页面与现有快捷标签衔接。
- `src/renderer/App.tsx`、`src/renderer/components/experts/ExpertPlazaView.tsx`：专家广场导航与共享作品入口。
