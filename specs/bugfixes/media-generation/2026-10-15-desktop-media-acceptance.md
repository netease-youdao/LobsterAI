# 媒体生成异常提示修复与桌面验收

## 1. 概述

2026-10-15 在 Windows Electron 应用中补做媒体生成的异常与恢复验收。使用独立验收数据目录，通过真实会话提交提示词、调用生成工具和操作实际组件；调试接口负责应用内操作及截图，不占用系统键鼠。

实机发现并修复三个端侧问题：

| 问题 | 根因 | 修复后 |
| --- | --- | --- |
| 视频确认缺少计费说明 | 内联确认组件未保留和显示问题的副标题 | 确认区展示按模型、时长与规格计费的说明 |
| 过小参考图提示残留占位符 | 同一占位符重复出现，而现有翻译入口只替换一次 | 提示“宽和高均需至少 2 像素”，中英文均无残留 |
| 提交回包丢失被称为失败 | 恢复逻辑保留原请求，但异常处理仍返回普通失败 | 提示正在核实原请求、不要重提，后台恢复后交付原结果 |

## 2. 用户场景

**Given** 用户确认生成视频。**When** 展示内联确认区。**Then** 可看到计费说明，并可以确认或取消，回答仍以原问题为键。

**Given** 用户选择 1×1 参考图。**When** 提交图片生成。**Then** 提前说明最低尺寸，不继续生成。

**Given** 生成请求已经发送，但确认回包中断。**When** 当前工具调用结束。**Then** 不宣称生成失败、不要求重新生成；恢复原意图后交付一次结果。

## 3. 功能需求与实现

- `questionDockModel` 仅保留非空副标题；`QuestionDock` 使用已有提示样式渲染，不改变选项、自由回答与答案键。
- 图片尺寸提示改用单个数值占位符，沿用中英文翻译入口。
- `mediaTaskStore` 按工具调用、账号和服务上下文查找未确认且未被拒绝的提交意图。主进程仅对这类生成请求提示后台核实，已拒绝、已确认、其他账号或其他调用不套用此提示。
- 沿用已有恢复、下载去重和终态处理，不改变媒体计费方式。

## 4. 边界情况

| 场景 | 验收边界 |
| --- | --- |
| 未登录、账号已变化 | 保留既有提示，不误称可恢复 |
| 已明确拒绝或已确认的意图 | 不归类为“受理结果未知” |
| 生成失败或超时 | 及时结束等待，显示具体原因及实际退款状态 |
| 停止会话 | 停止当前对话，已受理生成继续交付 |
| 文件下载失败 | 重试原文件，不重复生成 |
| 故障测试 | 真实桌面、真实会话和持久记录；部分上游结果与网络中断受控构造，不代表真实供应商发生故障 |

## 5. 验收覆盖

| 功能点 | 实机操作与结果 |
| --- | --- |
| 1. 具体错误 | 尺寸拒绝显示调整尺寸/参考图建议；视频审核失败显示具体原因 |
| 2. 前置校验 | 10 秒与 1080P 冲突、image-01 双参考图、1×1 图片均被提前拒绝 |
| 3. 终态结束等待 | 明确失败、图片超时、取消均结束等待并显示退款 |
| 4. 超时与慢提示 | 图片按实际 3 分钟期限结束；视频超过 5 分钟显示仍在处理，按实际 10 分钟期限结束并退款 |
| 5. 状态卡片 | 实测等待提交、生成中、核实结果、下载重试及完成/失败/取消/超时 |
| 6. 后台与依赖 | 普通等待让出会话后回答“2 加 2”；重启后收到原图片；显式等待先保存图片再写入文件路径和字节数 |
| 7. 幂等恢复 | 丢失首个确认回包后自动恢复同一任务，只有一次生成和完成通知 |
| 8. 下载恢复 | 暂停文件获取后显示自动重试，恢复后取回原文件 |
| 9. 取消与停止 | 排队取消显示退款；停止对话后原生成仍完成并交付 |
| 10. 视频计费确认 | 实际确认区展示计费说明，未出现固定每秒积分估算 |
| 11. 本地视频播放 | 在当前版本重播保留的真实视频，正常播放、跳转并到达结尾 |

此前真实生成覆盖 Seedream Lite/Pro 和 Hailuo 2.3。本轮异常测试使用受控故障，未声称所有供应商或所有时长组合均实测；显式等待验证的是通用依赖文件流程，不代表完整 AI skin 业务验收。每种模型的期限规则仍有自动测试覆盖。
