使用 LobsterAI 中已授权的 GitHub MCP 工具查询仓库、Issue、Pull Request 和 Actions。需要连接或重新授权时，引导用户打开「连接器 → GitHub → 连接」，在 GitHub 官方页面确认授权。

操作前确认目标仓库或组织。仅在用户要求时执行写操作。
