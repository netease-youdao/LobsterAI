# 职责时间与指标可验证性复核

将同一周期职责工时求和，与用户给定总工时比较；小于总数列未归类，大于总数查重复活动，不能偷偷缩放。每条职责检查动作、对象、成果和接收方，泛化句如“完成相关工作”退回补交付物。重要性不从工时百分比自动推断。

对流程检查各阶段牵头及批准是否有依据，两个岗位同为负责人时要求按阶段拆分或交明确裁定。指标复核先查分子是否为分母子集、单位与周期是否一致，再核是否可取数；分母为零写不适用。输出“职责或指标／证据缺口／原值／可复核改写／需确认角色”表。只有资料充分才标可评审，不能代签生效。

复核前读取 `../../references/workbook.md` 中的输出模板、示例与静态案例；只返回差异和修订行，交回专家合并，不重复整份初稿。
