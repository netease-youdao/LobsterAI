# 可复制决议底稿

将下面模板完整填写；不适用的写原因，未知的保留材料标记。

```text
会议信息：名称｜性质｜日期时间｜主持人｜记录人｜规则文件与版本
表决权成员：姓名或角色｜表决权｜到会方式（现场／线上／委托）｜签到时间
议程：议题编号｜一句话决定什么｜备选方案与代价｜表决方式｜通过比例｜计算基数｜材料｜预计时长
到会核对：有表决权总数｜到会人数｜到会要求｜是否满足｜回避后是否仍满足
计票核对：议题｜回避人与理由｜基数人数｜赞成｜反对｜弃权｜未投｜合计是否等于参与人数｜通过所需票数｜结果
决议记录：编号｜结论原文｜票数｜基数口径｜责任人｜完成时间｜验收标准｜附带条件
更正记录：版本｜原文｜修改后｜理由｜提出人｜确认人｜日期
执行跟踪：编号｜内容｜责任人｜截止｜状态｜上会回顾日期｜逾期原因与新计划
待确认：最多三项，每项写明会改变哪条结论
```

## 已填假设示例：产品评审委员会

以下成员、议题与票数均为演示假设。产品评审委员会有表决权成员九人，一人一票。假设规则为：到会须达全体三分之二以上；普通议题以出席且未回避成员为基数，过半数赞成通过；预算调整议题基数相同，三分之二以上赞成通过。

到会：2026年10月15日周四的会议到会八人，要求9×2/3=6人以上，满足。

议题一“是否采用A方案并在11月30日前上线”：一名成员与A方案供应商存在关联，申报回避，基数为8−1=7，回避后参与表决七人，仍不少于六人。赞成4、反对2、弃权1，合计7，与基数一致。过半数需多于3.5，即至少4票，本议题通过。同一组票数若规则写的是全体成员过半数，基数为9，至少需要5票，则不通过；若写的是有效票过半数，基数为4+2=6，至少需要4票，则通过。这说明基数必须在会前写进议程。

议题二“第四季度预算调整”：无人回避，基数8，赞成6、反对1、弃权1，合计8。6÷8=75%，三分之二以上需至少6票，本议题通过。

记录与跟踪：决议记录于10月16日周五发出，更正期为下一个工作日，即10月19日周一。决议R01截止日为11月30日，11月20日回顾时状态为“进行中”，距截止还有十天，以责任人回填的进展为依据，不写成已上线。待确认：一、回避人是否仍计入到会人数；二、预算议题的三分之二以上是否以出席为基数；三、线上参会者的表决截图由谁保存。
