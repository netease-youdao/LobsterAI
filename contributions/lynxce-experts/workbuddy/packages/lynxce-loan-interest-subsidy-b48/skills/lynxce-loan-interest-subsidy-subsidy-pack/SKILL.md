# 政策分流与贴息说明
本能力将适用政策、分段测算和证据写成企业可审阅的初报及补正正文。先识别设备更新、符合条件中小微民营企业固定资产或流贷、地方技改等不同分支，核本轮通知和时间，不把所有贷款统一套1.5个百分点或一律按已付利息比例。财金2026年第71号调整中小微范围及额度时，应与4号合读；2号设备更新是另一路，旧2024再贷款前提和旧期限不能直接照搬。官方文件政策有效不等于本地窗口此刻开放，也不保证某银行或企业已符合。
成稿至少包含借据与用途、适用来源和限制、实际本金变化、区间天数分母、利率及已付上限、总测算和仍待核、拟报送目录。摘要只是摘要，不能写原件已验证。已发贷款、已申报、已审核和到账分别记录，银行代财政贴息与企业单独收款不混用。未知窗口、用途认定或重复支持状态必须明确，不拿用户想申请当符合依据。材料不全先交已有事实稿和最多三项关键问题，不用空清单代替成稿。
收到第一段付息9000/6000冲突后，重出整个V2：本金2000000至1200000、还本800000、90/91天、360分母、利率3%/1%和第二段3000均保持；理论第一段7500不变，沿旧已付得总10500，沿新已付得9000，未定有效资料不选大额。写明原因未核、所需原始扣息组成和冲红记录，不代企业承诺到账日期。配套交接正文保留证据及拟附目录，真实附入与签章递交待证。拒绝编流水、改本金为利息或重复贴息，给真实差异说明。完成标准是所有数字、状态、法源与全文一致，用户能交财务和银行核实，不出审计、融资审批或保证性结论。
放款年度另设分流：2025年及以前旧贷款先核财金〔2024〕54号等历史政策及本地衔接，不因2026年仍有余额就追溯套新贷起息日或取消再贷款条件。旧贷历史规则、划付供应商日期和相关支持条件缺失时，保留资格与起息日待核，不照2026模拟样例算唯一金额。
