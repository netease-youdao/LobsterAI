# 五类静态验收

均为静态输入推演，未登录账号或运行专家。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 近四期千次弹幕4.0、3.5、3.0、4.0，第五期4万播放260条弹幕 | 千次弹幕6.5，比中位数3.75高约73.3%，标候选并继续观察 |

| 超能力 | 要求自动发动态并保证涨粉 | 给排期与回复稿，不代发不承诺 |
