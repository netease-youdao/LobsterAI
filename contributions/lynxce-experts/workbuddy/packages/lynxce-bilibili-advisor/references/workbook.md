# 可复制互动运营底稿

```text
账号分区／内容形式／更新频率／粉丝量级／材料编号：
诊断：可比期次数｜千次弹幕中位数｜千次评论中位数｜留存掉点｜结论（方向/可判断）。
每周动态：日期｜类型（预告/花絮/投票/转发/勘误）｜内容要点｜配图或片段｜兑现事项｜状态（计划/已发）。
单期互动设计：时间点｜类型｜画面提示文字｜停留秒数｜期望弹幕（六字内）｜兑现位置。
置顶评论：时间轴｜资料来源｜勘误（原说法/更正/影响）｜本期问题｜下期预告。
评论分级：编号｜类别（纠错/提问/建议/表扬/违规）｜处理动作｜进置顶或选题池｜截图编号。
月度复盘：视频｜统计时点｜播放｜弹幕｜评论｜点赞投币收藏分享合计｜千次弹幕｜千次评论｜互动率｜有效互动点｜下月调整。
关键问题：最多三项，并写明答案会改变哪项安排。
```

## 已填假设示例：数码测评区

以下全部为演示假设，不是真实账号数据。账号为数码测评区，每周日更新，视频约十二分钟，统计时点统一为发布后第七天。上月四期：第一期播放42000、弹幕168、评论210；第二期38000、133、190；第三期55000、165、330；第四期30000、120、150。千次弹幕依次为4.0、3.5、3.0、4.0，中位数3.75；千次评论依次为5.0、5.0、6.0、5.0，中位数5.0。弹幕偏低而评论正常，诊断为画面缺少可接的点。

本月第五期设一个互动点：一分十秒处画面提示"你猜续航能撑几小时？弹幕猜"，停留四秒，期望弹幕为"八小时"这类短答，结尾十分三十秒揭晓。假设留存曲线在一分十秒处仍有百分之七十二观众；该位置也在前四分钟即前三分之一之内。第五期播放40000、弹幕260，千次弹幕6.5，比中位数3.75高约73.3%，标为可复用候选；点赞2400、投币600、收藏900、分享100，互动率为4000除以40000即10.0%。只有一期数据，需再观察两期，且选题变化也可能影响结果。

置顶评论草稿："时间轴：00:00开箱｜01:10续航竞猜｜03:20屏幕｜07:45性能｜10:30续航揭晓。资料来源：参数取自厂商公开规格说明（发布时间【材料待确认】），续航为本期自测条件下的结果。勘误：暂无。下期预告：周二动态投票决定测评对象。"

本周动态：周二投票三选一决定下期测评对象，周四发拍摄花絮，周六发上线预告；投票结果在下期开头说明。评论区中"测试亮度多少"出现三次，补进置顶；一条辱骂评论删除并举报，截图编号存档。
