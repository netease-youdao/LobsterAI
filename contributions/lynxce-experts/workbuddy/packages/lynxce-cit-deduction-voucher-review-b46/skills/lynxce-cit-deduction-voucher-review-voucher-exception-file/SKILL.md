# 特殊原因补证
用于企业确实在补开换开过程中，因交易对方特定状态无法取得外部凭证的材料组织。先确认原本应取得哪类凭证、为何不能补、原因资料对应哪个真实主体及时间，再按公告2018年第28号第十四条形成一份原因说明和证据索引。对方不愿开票、业务员失联、主观觉得麻烦，不自动等于注销、撤销、依法吊销或被税务机关认定非正常户等特殊原因。用户只询问“可能注销吗”，不能直接写成已经注销。

第十四条第一至第三项是必备资料：不能补开换开的原因证明、业务合同或协议、非现金方式付款凭证。逐项写实际材料名称和证明范围，再按业务核运输、出入库、会计记录及其他资料。纯服务业务没有货物运输资料可以说明不适用，但不能免掉前三项。现金收据不能伪装成银行转账，缺合同不能自行补造已签合同；真实补充说明也不能称为原始合同已经存在。

假设已知运输费6000元发生于2025年，对方2026年3月注销且因此不能补票，注销证明C1、合同C2、非现金付款C3与运输单C4、账簿C5均有摘要。交付“前三项摘要已列，原件待企业核；C4、C5印证实际业务”，不是税务机关已认可。若新信息是实际现金支付，就更新为第三项不满足，C1、C2、C4、C5仍保留，不继续用此前齐备结论。

可复制说明：“本项【业务】发生于【年度】，应取得【外部凭证】。因【已证实的特殊原因及来源】无法补开换开，现整理原因证明【索引】、合同【索引】、非现金付款【索引】及适用履约材料【索引】；尚缺【实际缺口】，不将尚未取得资料列为附件。该说明供真实材料复核使用。”与时间处理联动：机关已发现告知的，另核第十五条；不替用户推断起算日或延长。完成标准是必备与补充项区分、证据真实、金额一致、缺口不能通过措辞消除。
