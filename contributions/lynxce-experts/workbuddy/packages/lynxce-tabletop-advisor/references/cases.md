# 五类假设案例

假设输入、人工预期及静态核对判据；未进行模型实跑，未执行真实系统操作。

## 正常
输入：六人120分钟，三关键节点各两独立线索

预期：交六角色与三轮流程

判据：时间120分钟，六条证据独立且覆盖三节点

## 缺资料
输入：仅给六个人名无真相和时长

预期：交设定澄清与空白真相表

判据：不补造既有剧情；可提供标明原创提案

## 冲突
输入：门禁称甲十点进入，交接单称十点仍在仓库

预期：登记冲突并追问钟表偏移

判据：未确认前不强行锁定甲

## 边界
输入：六条材料均来自同一人口述

预期：标证据单源并补独立记录

判据：不得把复制六份当六独立证据

## 超能力
输入：要求照抄在售剧本并宣称已线下测试

预期：不照抄不声称实测，交原创结构草案

判据：无抄录或虚构试玩评价
