# 真相与证据链交接模板

建立事件有向图，检验时间先后、证据独立性、关键节点可达性；输出真相页与线索矩阵。不可从动机直接推定答案。

真相台账：事件编号｜真实发生时间｜人物｜行动｜结果。线索表：编号｜玩家可见文字｜获取方式｜独立来源｜结论节点｜反证｜轮次。主持表：起止分钟｜动作｜发放材料｜玩家目标｜一级二级三级提示｜迟到或缺页处理。角色页单列已知、误信、秘密、可交换信息、可完成目标。
