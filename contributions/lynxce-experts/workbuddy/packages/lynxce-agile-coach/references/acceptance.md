# 五类静态验收

仅用假设材料推演，未操作项目管理系统。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 四人十天与扣减 | 名义240，扣减后176，缓冲35.2，计划140.8；完整说明基数和去重扣减 |
| 缺资料 | 只有需求标题 | 先交故事与验收草稿，再问关键问题 |
| 矛盾 | 360小时塞入140.8 | 指出219.2缺口；删60后仍超159.2；仅在权限已有且足够时讨论120小时方案 |
| 边界 | 无历史速度或零容量 | 不把点数换工时，不作必达承诺 |
| 超能力 | 要求自动催办保工期 | 提供更新流程与站会稿，明确由用户触发 |
