# 可复制主页底稿

```text
账号／平台／截图日期（含星期）／数据时间窗：
定位句：为［谁］解决［什么］，凭［证据］。
体检表：元素｜现状｜问题｜对应定位的哪一部分｜修改建议｜优先级。
  元素依次为头像、昵称、简介三行、置顶三条、封面网格。
昵称：识别名＋领域词；搜索自查结果【由用户填写】。
简介：第一行｜第二行｜第三行（站内动作）。
置顶候选：作品｜窗口｜播放｜新增关注｜转化率｜来意类型｜结论。
封面模板：模板名｜适用系列｜画布尺寸｜网格比例｜安全区｜标题位置｜字号层级｜主色｜角标。
改版记录：改版日（含星期）｜改动项｜负责人｜前窗口｜后窗口｜访问｜关注｜转化率｜同期事件。
关键问题：最多三个，写明会改变哪一项。
```

## 已填假设示例：职场表格教程账号

以下全部为假设。定位句为“为入职一年内的职场新人解决表格做得慢的问题，凭五年报表工作经历和两百条教程作品”。头像现状为半身照加杂乱书架背景，修改建议为胸像配纯色背景；昵称“小林的日常”看不出领域，建议换成“小林讲表格”。简介三行：“前财务，专讲职场新人用得上的表格技巧”“每周二、周五更新，一条视频解决一个函数问题”“新手先看置顶第一条：入门十个函数合集”。

置顶候选为同一三十天窗口的数据：V1播放48000、新增关注1440，转化率3.0%；V2播放12500、新增关注625，转化率5.0%；V3播放30000、新增关注600，转化率2.0%。V1播放最多，但V2转化最高，选V2作代表作，V1放入合集入口。

封面画布假设为1080×1920像素（9:16），主页网格假设按3:4居中裁切。可见高度1080×4÷3=1440像素，上下各裁去（1920−1440）÷2=240像素，可见区为纵向240至1680像素。四边再内收60像素，标题区为横向60至1020像素、纵向300至1620像素。两套模板：教程系列左上标题配深蓝色块，答疑系列居中标题配橙色角标。

改版日为2026年9月28日（星期一）。改版前窗口为9月14日（星期一）至9月27日（星期日），共14天，主页访问2400、新增关注168，转化率7.0%；改版后窗口为9月28日（星期一）至10月11日（星期日），共14天，主页访问2100、新增关注189，转化率9.0%，相差2个百分点。同期V2播放上涨，结论写“转化率上升，与改版和V2走热同时发生，不能单独归因”。
