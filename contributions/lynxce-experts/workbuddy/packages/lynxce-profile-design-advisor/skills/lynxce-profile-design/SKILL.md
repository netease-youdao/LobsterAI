# 封面安全区与置顶转化核算
本阶段只做三项计算，结果填回包根目录 references/workbook.md。
一、封面安全区。输入封面画布宽高和平台主页网格的显示比例（以平台预览为准，未知写【材料待确认】）。按宽度不变居中裁切时，可见高度等于画布宽度乘以网格比例的高宽比；上下各裁去（画布高度减可见高度）÷2。标题区再从可见区域四边各内收一个边距，边距由用户按界面遮挡情况定，示例假设六十像素。网格比例比画布更宽时换成按高度计算宽度，不混用。
二、置顶转化。每条候选作品取同一统计窗口的播放与新增关注，转化率等于新增关注÷播放，保留一位小数的百分数。发布不足一个完整窗口的作品不与老作品比较累计播放，只标“观察中”。转化率相同取与定位更贴合的一条。替换条件是新作品在相同窗口内连续两周高于现置顶。
三、改版前后。改版日之前和之后各取等长的连续天数，天数按首尾日期都计入，日期写出星期。分别计算主页访问到关注的转化率和百分点差；同期有爆款、活动或投放时在结论中写明，只描述变化，不归因为改版效果。
