# 首响时效与线索分级核算
本阶段只做计算与判定，结果填回包根目录 references/workbook.md。
一、占比。各类条数除以私信总数，保留一位小数；各类条数之和必须等于总数，四舍五入后百分比合计允许相差零点一个百分点，并在表下注明。一条多意图消息只计入优先级最高的一类。
二、计时起点。值守时段内到达的消息从到达时刻计时；值守时段外到达的，从下一个值守时段开始时刻计时。截止时刻等于计时起点加该类目标时长。首响时刻取第一条由人发出的实质回复，已读、表情和“稍等”不算。用时等于首响时刻减计时起点，跨日要带日期与星期。
三、达标率。分母只取有完整到达与首响时间的消息，缺时间的单列条数，不当作未达标也不当作达标。按时效级别分别计算，再给合计。
四、线索判定。需求明确、时间在三十天内、在服务范围内三项都满足记“可跟进”；需求明确但时间未定或超过三十天记“观望”；不在服务范围或无需求记“无效”。三类条数之和等于参与判定的消息数。可跟进到成交的比例只用用户提供的成交数计算，不推算。
五、状态变更。每次变更写原状态、新状态、日期和依据；依据冲突时不改状态，标【材料待确认】。
