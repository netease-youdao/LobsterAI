# 可复制私信承接底稿

```text
账号／复盘周（起止日期含星期）／值守时段与人员／各级时效目标：
分类表：类别｜条数｜占比｜典型原话（隐去昵称）｜第二意图备注。
时效表：级别｜目标｜完整记录条数｜达标条数｜达标率｜缺时间条数。
单条计时：到达时刻｜是否值守内｜计时起点｜截止时刻｜首响时刻｜用时｜是否达标。
回复模板：类别｜复述句｜可直接回答部分｜追问（≤2）｜下一步与时间｜禁用表述自查。
线索交接：日期｜来源作品｜平台昵称｜意图｜需求摘要｜判定｜下一步｜跟进人｜截止｜状态。
状态变更：线索编号｜原状态｜新状态｜日期｜依据。
周复盘：私信量｜各级达标率｜可跟进｜观望｜无效｜成交（用户提供）｜高频问题→选题。
关键问题：最多三个，写明会改变哪一项。
```

## 已填假设示例：办公技能课程账号

以下全部为假设。复盘周为2026年10月5日（星期一）至10月11日（星期日），值守时段9:00–21:00。私信共120条：价格咨询46条（38.3%）、使用与方法30条（25.0%）、售后与投诉14条（11.7%）、合作与商务6条（5.0%）、闲聊互动22条（18.3%）、风险消息2条（1.7%），条数合计120，百分比合计100.0%。

时效：三十分钟级（风险加售后）16条全部有记录，达标12条，达标率75.0%；两小时级（价格、使用、合作）共82条，其中10条缺回复时间，按72条计，达标61条，达标率84.7%；当日级闲聊22条全部达标。合计完整记录110条，达标95条，达标率86.4%，缺时间10条单列。

单条计时：一条价格咨询于10月9日（星期五）21:40到达，在值守时段外，从10月10日（星期六）9:00开始计时，两小时目标的截止时刻为11:00；10:25人工首响，用时85分钟，达标。

价格模板：“看到你在问表格入门课的价格。这门课标价199元，包含24节录播和每周一次答疑。想确认两点：你是自己学还是给团队报名？打算什么时候开始？我根据情况告诉你适合哪一档。”

线索判定只针对价格与合作的52条：可跟进11条、观望9条、无效32条，合计52条。用户提供本周成交3条，可跟进到成交的比例为3÷11=27.3%。高频问题“零基础能不能跟上”出现12次，列为下周选题候选。交接表中有一条显示“已成交”，但10月11日（星期日）的聊天记录里对方仍在问价，状态保持原值并标冲突，等跟进人确认。
