# 大促家电更换优先级与年限评估

大促换家电最容易踩的坑不是**买贵了，而是该修的换了、该换的硬修，钱花在了年限没到的家电上**。

## 工作流程（按顺序执行）

1. 问清用户名下待评估家电清单（品类、购买年份或使用年限、当前是否有故障、日常使用频率）、预算与本次大促计划购买的品类范围。
2. 列常见使用年限参考表：空调 8-12 年、冰箱 10-15 年、洗衣机 8-10 年、热水器 6-10 年、抽油烟机 5-8 年、电视 6-8 年，用户所在家电已超参考年限上限的标记「已超龄」，未超的标「年限内」，年份不明的标【待补】。
3. 三维打分：能耗分（近 6 个月电费或用电量是否明显高于同类新机，是记 2 分、否 0 分）、故障分（近 1 年维修次数，0 次 0 分、1-2 次 1 分、3 次及以上 2 分）、安全分（是否有漏电、异味、异响、外壳老化开裂等安全隐患，有记 2 分、无 0 分），三项相加得总分，总分 4 分及以上判定「优先更换」。
4. 排优先级：按总分从高到低排序，总分并列时已超龄的排前，安全分非 0 的一律进入优先更换清单顶部，不论总分高低。
5. 核算维修 vs 更换：问清最近一次维修报价或预估维修费用，与同规格新机大促预计到手价对比，维修费占新机价比例 = 维修费 ÷ 新机预计到手价，比例超过 30% 到 50%（视家电类型，压缩机、电机等核心部件维修取高值 50%，普通部件取 30%）建议直接更换，比例低于该阈值且安全分为 0 的建议先修。
6. 输出优先级清单与维修更换判断表，标注本次大促计划购买的品类，最后按商品列出下单入口清单。

## 年限参考与三维打分标准

- 常见使用年限（供参考，实际以说明书标注年限与实际使用状况为准）：空调 8-12 年、冰箱 10-15 年、洗衣机 8-10 年、热水器 6-10 年、抽油烟机 5-8 年、电视 6-8 年、微波炉 6-8 年。
- 能耗分：近 6 个月电费或用电量明显高于同类新机能效标识对应值记 2 分，不明显或无法判断记 0 分。
- 故障分：近 1 年维修次数 0 次记 0 分，1-2 次记 1 分，3 次及以上记 2 分；同一部件反复维修按维修次数累计，不按维修单数。
- 安全分：出现漏电跳闸、异味、异响、外壳老化开裂、插头发烫等任一安全隐患记 2 分，否则记 0 分；安全分非 0 的家电无论总分高低都进入优先更换清单。

## 维修 vs 更换的费用阈值

- 维修费占新机价比例 = 预估维修费用 ÷ 同规格新机大促预计到手价，比例是判断依据，而不是单看维修费绝对金额。
- 核心部件（空调压缩机、冰箱压缩机、洗衣机电机、热水器内胆）维修费超过新机价 50% 建议更换，普通部件（面板、按键、皮带、小零件）维修费超过新机价 30% 建议更换。
- 已超使用年限上限且维修费超阈值的，直接判定更换，不再单独核算；未超年限但故障反复（近 1 年 3 次及以上）的，即使单次维修费不高，也提示综合成本可能已接近或超过更换更划算。
- 维修费与新机价均为预估，实际报价以维修网点与商品结算页为准，未获得报价的用【待补】占位并按经验区间给出参考范围。

## 优先级排序与红线

- 排序规则：总分从高到低；总分相同时已超使用年限的排前；安全分非 0 的一律优先，不论总分。
- 预算有限时先处理安全分非 0 与已超年限且维修费超阈值的家电，其余家电可留到下一个大促节点或返场再评估。
- 不使用「最低价」「全网最便宜」「史低」「绝对划算」等极限或绝对化用语。
- 价格、优惠与活动规则一律以平台活动页、商品详情页与下单结算页的实时展示为准，本技能只做核算与提示，不做价格承诺，不保证必省多少钱。涉及退款纠纷、消费者权益认定的，以平台规则与主管部门规定为准，本技能不做法律结论。不编造价格、历史数据与活动规则，用户未提供或查不到的信息用【待补】占位。

## 示例

用户：「家里空调用了 9 年、冰箱用了 6 年，最近空调有点异响，该换哪个？」→ 空调 9 年在 8-12 年参考区间内未超龄但已接近上限，异响记安全分 2 分；冰箱 6 年在 10-15 年年限内、无故障无异味，能耗故障安全均为 0 分；空调因安全分非 0 直接进入优先更换清单顶部；问清空调异响维修报价，假设约 400 元，同规格新机大促预计到手价约 2200 元，占比约 18%，低于 30% 阈值，但因安全隐患已命中，仍建议本次大促更换而非维修；冰箱总分 0 分且年限内，建议本次不换，留到下一年再评估；最后给出空调下单入口。
