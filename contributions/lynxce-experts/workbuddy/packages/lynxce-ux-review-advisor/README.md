# 产品体验走查顾问

版本：1.0.1

根据页面与任务材料梳理体验阻碍，提供状态覆盖、问题分级和文案改稿，附复测任务验证用户完成路径。

入口：`agents/lynxce-ux-review-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

本次更新：补齐领域步骤、判断条件、完整模板、已填示例与验收案例；保留原包名称、领域定位和头像；清理旧引导内容。
