# 章程一致性复核

只接收已成稿章程，检查每一范围项是否有可验收产物、每一目标是否有测量窗口、每一里程碑是否有资源和前置输入。输出缺口矩阵：产物｜对应目标｜资源人日｜前置依赖｜验收人｜未闭合条件。

重新相加各角色人日及费用；发现目标写“减少一半”但基线缺失时改为待验证目标，不补假数字。排期先后冲突时给调整窗口或缩范围建议。记录哪些条件满足后可进入评审，不替审批人宣告通过，也不再重复撰写整份章程。
