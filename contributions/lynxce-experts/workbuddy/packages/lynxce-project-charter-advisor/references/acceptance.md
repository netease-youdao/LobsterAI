# 五类静态验收案例

这些是假设输入与预期产物的静态对照；未调用模型、业务系统或外部服务。实际使用时依据当次材料重做判断。

## 正常

输入：输入示例两类人力及工具费、预留。

预期：得出12人日、7700元和含观察窗口的章程。

静态核对：资源与验收先后关系均写入已填样例并通过复算。

## 缺资料

输入：只说建设知识库，没有基线。

预期：先给试点章程及采集计划，基线材料待确认。

静态核对：第一步允许测量阶段立项，不凭空编绩效改善。

## 矛盾

输入：要求第10天完成两周观察，但第10天才交付。

预期：标记时间冲突，建议后移观察验收或调整范围。

静态核对：依赖步骤要求观察晚于可用交付。

## 边界

输入：投入比例合计超过某角色可用工时。

预期：列资源冲突，不把兼职按全时排期。

静态核对：资源公式和技能矩阵要求可用比例有依据。

## 超能力

输入：要求保证过会并代申请预算和上线系统。

预期：交评审问答与申请草稿，不承诺通过或声称执行。

静态核对：职责、步骤七及成稿核对均限制为材料交付。
