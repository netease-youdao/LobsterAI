# 可复制邮件触达底稿

```text
项目／版本／负责人角色／数据时间窗：
名单体检：来源｜获取方式｜同意文字版本｜获取时间｜数量｜可否营销发送｜依据。
抑制名单：硬退信｜连续软退信｜投诉｜退订｜沉默超期；各自数量与处理日期。
认证核对：发信子域｜发件人策略记录｜域名签名｜对齐策略及阶段｜营销与通知是否分开。
放量计划：日期｜批次｜人数｜人群（按互动排序）｜放行条件｜实际结果（回填）。
单封复核：主题｜预览文本｜发件人名称｜唯一目标｜主按钮｜退订入口｜广告标注｜问题与改稿。
旅程表：旅程名｜触发事件｜进入条件｜节点（第几天／目标／主题草稿）｜退出条件｜优先级｜频次上限。
指标复盘：发送｜硬退｜软退｜送达｜投诉｜退订｜独立打开｜独立点击；各比率及分母。
结论：可配置／补材料后可配置／暂停发送待核；下一步责任角色；最多三个关键问题。
```

## 已填假设示例：线上课程月刊

以下数字全部是演示假设，不对应任何真实账号。名单共24000个地址：官网注册时勾选订阅的20400个有表单版本和时间；线下活动纸质登记的3600个找不到同意文字，标【材料待确认】，暂不纳入营销发送。20400个中有2400个超过一百八十天无点击、购买或登录，先进入确认意愿的小流程。首期可发地址为 `24000-3600-2400=18000`。

发信改用新的营销子域，订单通知仍走原通道。首期按最近互动从高到低分五个发送日：1000、2000、4000、8000、3000，合计18000；每批放行条件为上一批硬退率低于百分之二且投诉率低于千分之一。

首期结束后假设回填：发送18000，硬退180，软退90，送达 `18000-180-90=17730`。硬退率 `180÷18000=1.0%`，低于百分之二；投诉12次，投诉率 `12÷17730≈0.068%`，低于千分之一参考线；退订71个，约0.40%；独立点击532个，点击率约3.0%；独立打开6206个，打开率约35.0%，点击打开比 `532÷6206≈8.6%`，打开类指标只作方向参考。结论为“可配置”：放行条件满足，第二期按原频次发送，180个硬退地址当期加入抑制名单。

新用户培育旅程假设：触发事件为完成注册且勾选订阅；第0天欢迎信说明发送频率与退订方式，第2天上手指南，第5天学员案例，第9天体验课邀请；任一节点后购买、退订、硬退或投诉即退出，旅程总跨度9天。频次核对：第0至6天旅程已发三封，达到“任意七天不超过三封”的上限，月刊对该用户推迟到第7天；第9天邀请信时，第3至9天窗口内为第5、7、9天三封，仍未超限。下一步由运营负责人确认纸质登记名单的处理方式，由发信平台管理员按设计表配置。
