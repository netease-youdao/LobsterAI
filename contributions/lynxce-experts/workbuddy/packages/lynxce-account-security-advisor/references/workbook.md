# 可复制账号安全底稿

```text
平台／账号主体／事件编号／版本号：
分级：L1可疑｜L2已入侵仍可控｜L3失控；判定依据（能否登录、绑定是否被改、收款实名是否被改）。
止损清单：动作｜是否完成｜完成时刻｜执行人｜证据编号｜备注。
证据表：编号｜内容（登录记录/设备/授权/陌生内容/绑定信息）｜截屏时刻｜存放位置。
时间线：日期时刻｜事件｜证据编号｜记录人；可疑窗口起点｜终点｜时长；排查对象。
自查十项：检查项｜结果｜异常时间｜处理。
申诉跟进：入口（官方应用/官方网站/官方客服）｜提交时刻｜工单号｜所需材料名称｜平台回复时限｜跟进日｜进展。
权限表：成员｜角色｜实际需要｜当前权限｜处理（保留/降级/移除）｜处理日期｜离职或换岗日期｜逾期天数。
加固清单：独立密码｜二次验证｜备用验证｜绑定核对｜旧设备与授权清理｜收款实名核对｜恢复投放日期。
月度抽查：日期｜成员列表结论｜登录记录结论｜处理人。
```

## 已填假设示例：企业短视频账号

以下数据全部为演示假设。企业账号，所有者本人最后一次正常发布是10月10日18:30。10月12日09:15发现简介被改，并出现两条非本人发布的视频，发布时刻为02:10和02:40；登录记录显示01:55有一台陌生设备登录。账号仍能登录，绑定手机和邮箱未变，判为L2。

可疑窗口从10月10日18:30到10月12日09:15，共38小时45分钟；陌生登录到发现间隔7小时20分钟。授权列表中有一个10月8日新增的第三方剪辑工具授权，早于窗口，仍列为排查对象。

止损：09:15发现后先截屏，09:20完成证据E01至E06；09:22改密，09:24退出全部其他设备，09:28解绑该授权，09:35暂停定时发布与投放。从发现到止损完成用时20分钟。两条陌生视频在截屏后删除，简介恢复原文。

申诉：陌生视频触发了平台违规提示，于10月12日10:30通过官方应用的申诉入口提交说明和时间线，工单号按平台回执登记。平台告知三个工作日内回复，跟进日为10月15日（周四）。

权限：成员7人，所有者1人、管理员4人、运营1人、数据1人。其中一名管理员已于10月1日离职仍未回收，到10月12日逾期11天，当天移除；另两名管理员实际只做发布，降为运营。调整后成员6人：所有者1人、管理员1人、运营3人、数据1人。约定每月第一个工作日抽查成员列表和登录记录。
