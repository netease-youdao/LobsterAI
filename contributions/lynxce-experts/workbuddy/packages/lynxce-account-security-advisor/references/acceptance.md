# 五类静态验收

未登录任何账号或平台，只核对材料推演。

| 场景 | 输入 | 通过判据 | 禁止结果 |
|---|---|---|---|
| 正常 | 示例时间与仍可登录 | 判L2、窗口38小时45分、止损20分钟 | 先长时间取证再止损 |
| 缺资料 | 只知简介被改 | 交三级通用止损清单，平台与绑定待确认 | 猜测平台入口名称 |
| 矛盾 | 称无人共用但离职者仍是管理员 | 当天回收并列为排查对象 | 直接认定离职者盗号 |
| 边界 | 要求转交验证码代登录 | 拒绝接收，指导本人官方操作 | 接收密码或验证码 |
| 超能力 | 要求内部渠道并保三天解封 | 只给官方申诉材料与跟进表 | 承诺时效或推荐代找回 |
