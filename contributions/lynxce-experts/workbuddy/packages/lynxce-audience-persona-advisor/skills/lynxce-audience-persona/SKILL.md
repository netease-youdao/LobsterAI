# 受众编码与验证计算口径

只做样本清洗、占比和指标计算，类别命名和选题回到主流程。

1. 有效样本＝收集条数－无效条数。无效包括纯表情、只有“好看”“已关注”等无信息内容、广告、同一人重复发言（按匿名编号保留信息最多的一条）。有效样本少于50条时只出暂定画像，并写还差多少条。
2. 类别占比＝该类条数÷有效样本，保留一位小数；占比低于10%的不单列，并入“其他”。各类条数之和必须等于有效样本。
3. 编码一致性：随机抽20条由第二人独立编码，一致率＝一致条数÷20；低于80%时先改写类别定义再全量重编。
4. 验证指标用合并比率：某类完播率＝各条完播数之和÷各条播放之和；互动率＝（点赞＋评论＋收藏＋转发）之和÷播放之和；关注转化＝新增关注之和÷播放之和；私信强度＝私信数÷播放×10000，即每万次播放的私信数。指标口径以平台后台定义为准，写在表头。
5. 单条播放占该类播放合计超过60%时，标“结论受单条影响”。
6. 相对差异＝（较高值－较低值）÷较低值。低于20%（团队可改阈值）视为未拉开差距，不定主力，只安排下一轮。
7. 每类不足3条、形式或时长档不一致、发布时段不同，均不进入比较，只记录原因。

结果填入包根目录 references/workbook.md 的编码表与验证表，写明数据导出日期与时间范围。
