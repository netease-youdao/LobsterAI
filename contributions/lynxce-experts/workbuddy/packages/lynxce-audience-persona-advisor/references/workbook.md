# 可复制受众底稿

```text
账号／平台／领域／账号目标／版本与日期：
来源表：来源｜时间范围｜收集条数｜无效条数｜有效条数｜导出日期。
编码表：匿名编号｜来源｜场景｜诉求｜顾虑｜原话关键词｜所属类别。
一致性：抽查条数｜一致条数｜一致率｜是否需改定义。
类别表：类别｜一句话画像｜条数｜占比｜常用词｜后台属性对照与口径差异。
匹配表：类别｜选题方向｜开头一句｜形式｜依据的编码条数。
验证表：类别｜作品编号｜形式与时长档｜发布时段｜播放｜完播数｜互动合计｜新增关注｜私信数｜单条播放占比。
汇总：类别｜完播率｜互动率｜关注转化｜每万次播放私信｜相对差异｜结论（暂定/定版/下一轮）。
复核：下次复核日期（星期）｜触发条件。
待确认：最多三项。
```

## 已填假设示例：家装内容账号

以下全部为演示用假设。账号目标以涨粉为主，同时接少量设计咨询。后台显示25至34岁女性占比62%。取近九十天互动最高十条作品的评论180条，剔除表情、广告和重复发言36条，有效样本144条。

归类：A“刚交房要做全屋预算的人”58条，占40.3%；B“租房想低成本改造的人”43条，占29.9%；C“只翻新厨房卫生间的人”29条，占20.1%；其他14条，占9.7%，不单列。合计58＋43＋29＋14＝144。双人抽查20条一致17条，一致率85%，定义可用。

验证：三类各发3条“实拍加口播、50至60秒”，同一周、19点至21点发布。A播放12000、9000、9000，合计30000，完播6000、互动1500、新增关注240、私信18；B播放10000、8000、6000，合计24000，完播6000、互动1440、新增关注288、私信9；C播放7000、5000、3000，合计15000，完播3150、互动600、新增关注105、私信21。

计算：完播率A为20.0%、B为25.0%、C为21.0%；互动率A为5.0%、B为6.0%、C为4.0%；关注转化A为0.80%、B为1.20%、C为0.70%；每万次播放私信A为6.0、B为3.8、C为14.0。单条播放最高占比A为40.0%、B为41.7%、C为46.7%，都未超过60%。B的关注转化比A高（1.20－0.80）÷0.80＝50%，超过20%阈值，B暂列涨粉主力；C的私信强度最高，暂列咨询方向候选。只有一轮各3条，结论写“暂定”，下一轮每类再发3条复核，方向一致再定版。

复核：定版日假设为2026年10月19日（星期一），下次复核为2027年1月19日（星期二）。
