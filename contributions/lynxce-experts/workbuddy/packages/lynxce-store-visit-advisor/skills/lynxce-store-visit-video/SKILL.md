# 探店视频脚本与拍摄清单

观众看探店是为了**做决定：去不去、点什么、花多少钱**。每一段都要回答其中一个问题。

## 工作流程（按顺序执行）

1. 问清店铺类型、是否商家合作、城市与人均、视频时长与平台。
2. 按「钩子 → 环境与位置 → 招牌与点单 → 试吃/体验 → 价格与避坑 → 结论评分」写脚本。
3. 列必拍镜头：门头、动线、菜单价目、出品特写、第一口反应、环境细节、排队或人流。
4. 做信息卡：地址区域、营业时间、人均、推荐与不推荐、是否需要预约（以现场与商家公示为准）。
5. 合作内容按平台要求标注，体验评价如实描述，不隐瞒缺点。
6. 拍摄前与店家沟通拍摄范围，避开其他顾客正脸或做模糊处理。

## 脚本要点

- 开头 3 秒给决策信息：「人均 60 吃到撑的湘菜，但有一道千万别点」。
- 点单段说清点了什么、为什么点、多少钱。
- 试吃段描述具体口感与分量，少用「绝了」「巨好吃」这类空词。
- 结尾给明确结论：适合谁、不适合谁、值不值得专门去。

## 拍摄清单

- 门头与周边地标，方便观众找到。
- 菜单价目表清晰拍一遍，价格以现场为准并提示可能变动。
- 出品上桌特写、切开或拉丝等动态镜头。
- 人声口播靠近收音，餐厅嘈杂时后期配旁白。

## 客观与合规

- 商家合作或免单体验需按平台要求标注合作或体验性质。
- 不虚构排队、不夸大分量与价格优惠，不编造「本地人都来」这类无法验证的说法。
- 食品安全与卫生问题只描述所见，不做定性结论。
- 平台规则以官方最新公告与后台提示为准，本技能不代替平台审核结论。

## 输出模板

脚本：
| 段落 | 时长 | 口播要点 | 画面 | 字幕/信息卡 |
|---|---|---|---|---|
| 钩子 | 3秒 | | | |
| 环境与位置 | | | 门头/动线 | 区域、营业时间 |
| 招牌与点单 | | | 菜单价目 | 价格 |
| 试吃体验 | | | 出品特写/反应 | |
| 价格与避坑 | | | | 人均/不推荐 |
| 结论 | | | | 适合人群/评分 |

信息卡：区域 ____ / 营业时间 ____ / 人均 ____ / 推荐 ____ / 不推荐 ____ / 预约 □ / 合作标注 □

## 示例

用户：「商家请我免费体验一家新开的烧烤店。」→ 开头标注体验性质；钩子「新开的烧烤店人均 80，有两样值得点、一样劝退」；点单段拍价目表；结论段如实说明「羊肉串分量偏少」；信息卡注明价格以店内公示为准。
