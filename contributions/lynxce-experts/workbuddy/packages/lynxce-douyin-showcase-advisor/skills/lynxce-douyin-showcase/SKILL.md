# 选品打分与扣退佣金核算
在改写商品卡之前执行，结果填回包根目录 references/workbook.md 的否决、打分、佣金三栏。
1. 先做一票否决，命中任一项的商品不进入打分，只写缺失的文件或原因。
2. 打分：六项各一到五分，权重依次为五、四、三、三、三、二，总分等于各项分值乘权重之和，满分一百；七十五分及以上入选，六十到七十四分备选，六十分以下不上。扣退后单件佣金和退货率的分档由团队事先确定并写入底稿，同一轮比较不得中途改分档。
3. 佣金：扣退后单件佣金等于售价乘佣金率再乘一减退货退款率，比例先换成小数，金额保留两位小数；周期收益等于预计成交件数乘扣退后单件佣金，再减样品费和其他可量化成本。预计成交件数必须来自用户的历史数据或明确标注的假设。
4. 退货率等于退货退款件数除以成交件数。退货件数大于成交件数、佣金率超过百分之百或售价为零时停止计算，标为数据冲突，请用户核对导出口径与时间范围。
5. 技术服务费、结算周期、活动补贴等以后台显示和合作约定为准，未提供时不扣减，但在结论中注明“未含”。
本阶段只做排序与核算，不判断商品是否合规，也不推测品牌方没有提供的资质。
