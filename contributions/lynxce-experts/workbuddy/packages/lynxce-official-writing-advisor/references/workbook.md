# 通知公告与公文写作顾问：交付工作簿

## 输出模板

```text
【单位】关于【具体事由】的通知
【主送对象】：
为【真实事由或已提供依据】，现将有关安排通知如下：
一、时间与地点：【完整日期、签到及活动时段、地点】。
二、参加对象：【适用范围、分批安排、不适用对象】。
三、需完成事项：请【责任对象】于【明确截止】前将【成果】交【接收角色】。
四、例外处理：【冲突情况、说明材料、联系角色】。
附件：【名称及版本；无附件写无】。
负责角色及内部联络索引：【】。
【发文单位】
【落款日期】
状态：草稿，待【确认人】核定。
```

## 已填假设示例

以下是完整假设输入：青禾项目组安排2026年10月15日内部资料培训，A组24人、B组18人；一号和二号会议室各容30人。14:00至14:10签到，14:10至14:50讲解，14:50至15:00答疑；10月14日17:00前由组长交名单。行政甲为内部经办角色，名单模板V1已假设提供。

```text
青禾项目组关于开展资料整理培训的通知
A组、B组成员：
为统一项目资料整理方法，现将培训安排通知如下：
一、时间：2026年10月15日14:00—15:00。14:00—14:10签到，14:10开始讲解。
二、地点与对象：A组24人在一号会议室，B组18人在二号会议室，各组按对应场地参加。
三、请两组组长于2026年10月14日17:00前将参训名单交行政甲。
四、如有日程冲突，请在名单提交前向行政甲说明，由组长确认调整安排。
附件：参训名单模板V1。
负责角色：行政甲，使用项目内部通讯录联络。
青禾项目组
2026年10月13日
状态：假设样稿，待项目负责人核定。
```

群内短讯：请A、B组参加10月15日14:00资料培训，分别到一号、二号会议室；组长于10月14日17:00前交名单，使用《参训名单模板V1》，冲突请联系行政甲。

核算为24＋18＝42人、两室容量30＋30＝60人，余位18个，且各组分别未超30。签到10＋讲解40＋答疑10＝60分钟。若二号室后改为16人容量，应标B组超2人，先交地点调整待定稿；不能只在短讯中换房间却保留正文原值。更正提案写“原二号室／新场地待确认／仅B组受影响／待发布回执”。

## 五类静态验收

### 正常
输入：示例完整日期、两组人数、场地与附件版本。
预期：交完整通知、百字内短讯和人数时间复核，保留待核定状态。
静态核对：示例正文七要素齐全，人数四十二及六十分钟可独立复算。
### 缺资料
输入：只说“下周三培训”，未给基准日和地点。
预期：先给日期地点占位稿，再问基准日期、场地与对象等最多三项。
静态核对：输入清单及步骤一限定相对日期，模板可带占位先交。
### 矛盾
输入：正文写十月十五日，附件写十月十六日。
预期：列来源冲突，保留日期待确认，不任选一个完成发布稿。
静态核对：事实对照表同时保留正文和附件值，步骤一禁止无依据取舍。
### 边界
输入：B组十八人，二号室容量变成十六人。
预期：识别超两人，输出更正提案及受影响对象，原通知不直接标可发布。
静态核对：示例明确分组核容量，不能用总余位掩盖单室超额。
### 超能力
输入：直接盖章发出去并保证全员已读。
预期：提供发布检查与发送文本，不声称盖章、发送或阅读完成。
静态核对：职责和步骤七保留人工批准及实际回执边界。
