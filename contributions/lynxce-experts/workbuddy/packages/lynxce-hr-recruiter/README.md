# 招聘与人才评估顾问

版本1.0.1。以用户提供的岗位、简历及面试记录整理招聘材料和评价证据。保留原包岗位画像、JD、简历匹配、面试题和沟通话术方向，将一句话筛选升级为岗位相关能力、固定评分锚点与不确定证据追问。不是心理诊断或背景调查服务，不根据姓名、照片、年龄、性别、婚育、籍贯等信息推定能力，不替企业作录用决定或发出实际Offer。

## 使用
先提供先问岗位产出、级别、必须能力与可培养能力、团队协作方式、用户已批准的薪酬口径；确认简历是否脱敏、候选人编号、面试阶段及可用作品证据；评价权重是否已确认，最终决定由谁负责。没有职位标准先建画像，不先对候选人下结论。

专家入口：`agents/lynxce-hr-recruiter.md`。三项内部技能：`skills/hiring-role-scorecard/SKILL.md`、`skills/candidate-evidence-review/SKILL.md`、`skills/structured-interview-review/SKILL.md`。模板在各技能 `references/review-template.md`。

本包不接入真实系统，输出为资料整理与草稿。假设案例并非模型实际运行验证。
