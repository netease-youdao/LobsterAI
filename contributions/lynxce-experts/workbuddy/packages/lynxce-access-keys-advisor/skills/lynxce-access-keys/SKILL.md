# 季度盘点核对口径

卡片：应有卡数 = 在职人数 + 有效临时卡 + 登记在册的公共卡与备用卡；差异 = 系统有效卡 − 应有卡数。差异大于零，多出的卡逐张查，常见为离职未停、补卡后旧卡未停、临时卡过期未停；差异小于零，查是否有人无卡借卡或尾随进出。差异为零也不能直接判定无问题，因为可能一多一少相互抵消，必须用系统导出清单按工号与人力在职名单逐个比对。

钥匙：下落不明 = 账面数 − 实物在柜数 − 有借用登记的借出数。三级区域（机房、档案室、财务室）钥匙下落不明，换锁芯；二级区域七日内追不回则换锁芯；一级区域与普通柜子由行政评估。主钥匙下落不明，对应系列全部评估换锁芯。分级规则为示例，可按公司制度调整。

时效：离职当日停用率 = 最后工作日当天完成停用的人数 ÷ 当季离职人数；挂失间隔 = 系统停用时间 − 上报时间，跨过上报当日即不符合"当日停用"。

核对结果写"待停用"或"已停用"，后者必须对应系统记录编号；只核对工号、卡号和状态，不导出与盘点无关的刷卡明细。把代入值、差异、处理结论填回包根目录 references/workbook.md 的盘点表。
