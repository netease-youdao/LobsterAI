# 可复制门禁钥匙底稿

```text
单位／盘点期间／门禁类型（有效期、分时段是否支持）／材料编号：
区域等级：区域｜等级（一/二/三）｜区域负责人｜是否分时段。
权限矩阵：角色｜大门｜办公区｜部门区域｜仓库｜机房｜档案室｜财务室｜有效期｜审批人。
发放登记：卡号或钥匙编号｜类型｜持有人工号｜部门｜权限组｜发放日期｜签收｜有效期止｜状态（在用/待停用/已停用/挂失/已回收）。
离职调岗：工号｜最后工作日｜停用时间｜系统记录编号｜钥匙交回｜未交回处理。
挂失：卡号｜上报时间｜停用时间｜间隔小时｜是否当日｜新卡号｜经办人。
卡片盘点：系统有效卡｜在职人数｜有效临时卡｜公共与备用卡｜应有数｜差异｜逐人比对结果。
钥匙盘点：编号｜等级｜账面｜实物｜有登记借出｜下落不明｜处理（追回/换锁芯/评估）。
关键问题：最多三项。
```

## 已填假设示例：一百六十余人办公室

以下均为演示假设。第三季度盘点：系统有效卡186张；在职162人；有效临时卡15张，其中外包9张、实习6张；登记的公共卡与备用卡5张。应有卡数为162加15加5，共182张，差异4张。按工号逐人比对后，3张属于离职未停用，1张是补卡后旧卡未停用，全部列入待停用清单，管理员停用后补记系统记录编号。

离职时效：本季度离职9人，最后工作日当天完成停用6人，当日停用率约66.7%；其余3人正是上面盘点发现的未停用卡。原因是离职交接清单里没有门禁项，整改为把"门禁停用、钥匙交回"加入清单并由行政签字。

挂失时效：一次上报为9月11日周五17:50，系统停用为9月14日周一09:00，间隔约63.2小时，跨过上报当日，不符合当日停用要求，补充下班后接报的值班停用安排。另一次上报09:40、停用15:10，间隔5.5小时，符合要求。

钥匙盘点：账面48把，实物在柜45把，差3把；其中2把有借用登记，已追回，下落不明1把，为财务室备用钥匙。财务室属三级区域，按规则换锁芯，并检查备用钥匙封袋是否有未登记的启封。
