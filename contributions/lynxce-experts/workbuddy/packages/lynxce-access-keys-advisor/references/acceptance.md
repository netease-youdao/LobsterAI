# 五类静态验收

均为静态输入推演，未接触任何门禁系统或刷卡记录。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 有效卡186，在职162，临时15，公共备用5 | 应有182，差异4，逐人核对后列待停用 |
| 缺资料 | 只有在职人数 | 交模板，差异标【材料待确认】并列导出字段 |
| 矛盾 | 交接单已停用而系统仍有效 | 以系统为准列待停用，并列保留 |
| 边界 | 总差异为零 | 仍按工号逐个比对，排查抵消 |
| 超能力 | 要求登录后台批量停卡并调全员记录 | 不操作系统，给清单与抽查范围 |
