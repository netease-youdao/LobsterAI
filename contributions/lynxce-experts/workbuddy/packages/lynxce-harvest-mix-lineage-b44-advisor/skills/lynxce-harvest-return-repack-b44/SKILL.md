# 退回果箱子箱映射

内部独立专项：核一只退回父箱重新分装后是否重复计出站或丢失来源。用户为分级站批次记录员。输入只需父箱码、退回事件、子箱码与重量、重新出站时点。此项按自己的证据键、方法和输出表工作，不以专家摘要替代专项交付，不依赖任何外部接入。

## 工作流程

1. 锁定本项任务：核一只退回父箱重新分装后是否重复计出站或丢失来源。最少输入为父箱码、退回事件、子箱码与重量、重新出站时点；先给材料范围和截止时点，超出本项范围的请求单独记录。

2. 按最少字段建立证据索引：先给父箱建立退回事件编号，只变更有效去向状态而保留原发出记录；口头说已退回而无记录时父箱状态待确认。

3. 建立对象与事件关系：子箱逐个引用父箱，父箱来自混合单时沿用来源集合；无法证明哪部分来自甲批时不填写甲批精确重量。

4. 执行专项推演：核父箱净重＝全部子箱净重＋拆包余料＋记录损耗，子箱码唯一；同一子箱引用两个父箱要有合并单。

5. 检查专属异常与边界：分别计算历史发出重量和当前有效出站重量，退回前后两次运输不能累计成当前在外数量。 对照缺资料与冲突案例，确认缺项没有被填成示例值。

6. 交付退回果箱子箱映射文本表与补证队列，逐格保留资料编号及状态。重新核正常与边界算式，给负责人确认入口；实际完成状态以用户后续反馈为准。

## 专项方法与证据顺序

- 先给父箱建立退回事件编号，只变更有效去向状态而保留原发出记录；口头说已退回而无记录时父箱状态待确认。

- 子箱逐个引用父箱，父箱来自混合单时沿用来源集合；无法证明哪部分来自甲批时不填写甲批精确重量。

- 核父箱净重＝全部子箱净重＋拆包余料＋记录损耗，子箱码唯一；同一子箱引用两个父箱要有合并单。

- 分别计算历史发出重量和当前有效出站重量，退回前后两次运输不能累计成当前在外数量。

## 专属异常和采用条件

- 退回部分重量与整箱退回分开，部分退回要保留仍在原去向的剩余量。

- 新包材皮重单列，父箱净重不能与子箱毛重相加。

- 拆包损耗未知时残差未解释，不能假设损耗率补齐。

- 映射结果交给来源主流程，不重复创建分级标准或客户问答。

## 资料状态与交付复核

- 引用材料使用资料代号、版本和行号，事实摘录与推演结果分栏。未知值统一写【待补】；补证问题指出缺什么、为什么影响本项判断，以及用户应返回哪一格资料，不能仅泛称完善材料。

- 所有统计注明对象、单位及截止时点，记录数、唯一对象数与关联边数分开。计算从原始值逐步列算式，残差保留符号；不通过四舍五入隐藏冲突，零分母写不适用而非百分之百。

- 文本表是材料审阅草案。建议动作、用户确认拟执行、用户反馈实际完成采用不同状态；无反馈时不得变为完成。这里只用已给文字与表格手工推演，不声称已查询系统、通知人员或操作实物。

- 收到新增材料后只重算受影响对象，保留旧值、采用版本和修改理由。冲突未解决的对象不能挤入已确认集合；结束时检查每条输入有去向、每条判断有来源、每个未决项有最少补证动作。
