# 版式栅格与配色数字核对
用于把页面尺寸、栅格、对比度和图表数字算清楚，写回包根目录 references/workbook.md。十六比九宽屏页面常见为33.867×19.05厘米，四比三为25.4×19.05厘米，以用户文件的实际设置为准。
栅格：版心宽等于页宽减左右边距；单列宽等于版心宽减去栏间距乘以（列数减一），再除以列数；跨若干列的元素宽度等于列宽乘跨列数，再加上中间的栏间距。
对比度：把十六进制色值换算为相对亮度，用较亮者加0.05除以较暗者加0.05；正文至少4.5比1，大号文字（18磅及以上，或14磅及以上加粗）至少3比1。不达标时优先加深文字色或换背景，不改动品牌主色本身。
图表数字：同比等于本期减上年同期再除以上年同期；环比用上一期作分母，两者不能混写。占比写明分母是哪个总计；舍入后合计不等于100%时在注释说明。分项合计与总计不一致时先停下核对原始表，不在图上调整数字凑整。全部计算保留公式、原始数值和来源页；数据由用户提供，不补编。
