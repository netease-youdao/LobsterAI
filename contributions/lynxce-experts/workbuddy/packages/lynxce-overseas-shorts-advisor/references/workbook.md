# 可复制本地化底稿

```text
目标市场／语言变体／平台／原视频编号／版本：
对标调研：账号｜主题｜时长｜开场类型｜文字密度｜常用表达｜播放｜点赞｜评论｜分享｜互动率｜采集日期与地区。
本地化对照：时间码｜原文｜本地化文案｜处理类型（保留／替换／换算／删除）｜原因｜母语复核人角色与结论。
术语表：原词｜译法｜备注。
时长核算：字幕编号｜字符数｜最短显示秒数｜分配秒数｜是否通过；旁白可用秒数｜词数预算｜草稿词数。
文化合规：手势｜数字｜颜色｜动物与食物｜宗教｜地图旗帜｜音乐授权｜广告标注｜个人信息；各项结论与待复核人。
测试记录：版本｜唯一变量｜发布时段｜播放｜三秒留存｜完播｜是否达门槛｜结论。
结论：可发布前复核／补材料／暂缓；最多三个关键问题。
```

## 已填假设示例：收纳盒视频改美国英语版

以下为演示假设，不是真实账号数据。原视频30秒，原文“双十一囤的收纳盒终于派上用场：40厘米宽的抽屉分隔盒，全家袜子一格一类，到手价39.9元”。对标样本之一播放120000、点赞6000、评论300、分享900，互动率 `(6000+300+900)÷120000=6.0%`；前20条中多数开场直接展示整理前后对比，作为开场假设而非定论。

改写：“双十一囤的”发布日期不临近当地大促，处理类型为删除；“40厘米”换算为 `40÷2.54≈15.7` 英寸并保留厘米；“39.9元”不按汇率换算，用户提供的美国售价假设为8.99美元，注明发布时的价格。旁白：总长30秒，首尾各2秒无旁白，可用26秒，词数预算 `26×150÷60=65` 词。英语旁白草稿如下，共53词，按每分钟150词约需21.2秒，在预算内：

```text
Sock drawer: before and after. This 15.7-inch, 40-centimeter organizer fits the whole family's socks. One row per person, so nobody digs through a pile in the morning. The dividers slide, so baby socks and winter socks both fit. It is $8.99 at the time of posting. Would you try it in your drawer?
```

字幕核对（每秒15字符，竖屏每行不超过32字符）：初稿第一条“My sock drawer, before and after.”为33字符，超限，缩写成“Sock drawer: before and after.”30字符，最短显示2.0秒，分配2.5秒，通过。第二条“This 15.7-inch (40 cm) organizer”32字符，最短约2.13秒，分配2.5秒，通过。第三条“fits the whole family's socks.”30字符，最短2.0秒，分配2.5秒，通过。第四条拆成两行“One row per person.”与“No more digging.”，共35字符，最短约2.33秒，初稿只分配2.0秒，不通过，延长到2.5秒。

文化合规：画面无手势、旗帜和宗教元素；配乐改用可商用授权曲；无品牌合作，不需要合作标注。测试假设：A版先展示整理结果，播放3200，三秒留存1696，留存率53.0%，完播448，完播率14.0%；B版先提问“袜子总配不成对吗”，播放2800，三秒留存1736，留存率62.0%，完播504，完播率18.0%。两版都超过1000次门槛，B版两项都更高，但只有一轮，结论为“B版开场暂优，再复测一轮后定模板”。
