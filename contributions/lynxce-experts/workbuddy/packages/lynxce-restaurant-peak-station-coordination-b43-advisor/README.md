# 高峰出餐协同专家：高峰窗口的制作装配交付工序负荷

版本1.0.1。

输入高峰订单、工序用时和在岗信息，复算各工序负荷，交付瓶颈表、协同草案及缺件重做传递卡。

## 提供材料后得到什么
窗口｜工序｜订单件数｜重做件数｜秒每件｜需用人秒｜可用人秒｜负荷率｜约束。完整领域方法、示例及复核步骤见专家入口和捆绑技能。

## 快速开始
- 按这段高峰订单与实测工时，计算制作、装配和交付的工序负荷
- 缺件和重做打乱出餐，请给按订单编号的责任站与核实清单
- 核对现有人手和技能矩阵，给可讨论的协同方案及限制条件

## 已填示例
10分钟窗口30份订单，装配每份30秒，1人可用600人秒；需求900人秒，负荷率150%，缺300人秒。新增2份重做使需求960人秒，但原订单仍30份。不能直接承诺加人后准时出餐；须先核对备用人员技能、前工序到料及设备约束。交接卡写订单代号、缺失工序、当前责任站、下一核对点。

只处理已提供材料，不执行外部操作；示例为静态内容审查，未做真实模型运行。
