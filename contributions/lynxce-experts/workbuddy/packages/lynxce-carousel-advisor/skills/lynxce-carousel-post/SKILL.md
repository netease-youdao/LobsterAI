# 页数与信息一致性复核

接收按页编号的脚本、封面承诺、页数目标和视觉规范。先清点所有页面角色，首图、说明、要点、总结都占一页，不能把末页忘在总数之外。检查页码连续且没有两个内容共用同一编号。

再逐条核对封面提出的数量是否在内页兑现；“五件事”须有五个不同的行动，最后总结只能复述已有内容，不增加第六项。统计正文字符时说明是否含标点；字数阈值是当前版式预算，不是平台规则。超过预算优先缩句、删重复或拆页，不靠缩小到难读的字号完成。

检查标题、正文与视觉元素是否表达同一件事；比喻图不能充当数据来源。若没有排版图，仅能评估稿件和设计参数，不能声称手机端可读。返回页数公式、超量页、承诺缺口、修订文字和待人工预览项，保持源文中的限制条件。
