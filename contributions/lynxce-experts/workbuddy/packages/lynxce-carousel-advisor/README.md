# 图文笔记排版顾问

版本：1.0.1

把长文拆成逐页可制作的图文脚本，交付首图文案、分页叙事、视觉规范和检查清单，核对页数与文字密度

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 逐页标题正文与画面脚本
- 三版首图及承诺映射
- 可复制视觉规范
- 页数文字密度与素材检查表
