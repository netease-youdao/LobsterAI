# 家政退出返还凭据核对

公共独立小任务：核服务终止时封包清单与返还回执的证据缺口。用户为家政服务终止时的委托方记录员。输入只需终止生效时间、应返还包号和件号、回执逐件勾选、收发角色代号。此项按自己的证据键、方法和输出表工作，不以专家摘要替代专项交付，不依赖任何外部接入。

## 工作流程

1. 锁定本项任务：核服务终止时封包清单与返还回执的证据缺口。最少输入为终止生效时间、应返还包号和件号、回执逐件勾选、收发角色代号；先给材料范围和截止时点，超出本项范围的请求单独记录。

2. 按最少字段建立证据索引：先冻结终止范围：委托方资产、服务方自带工具和消耗品分组。仅要求核已约定应返还项，所有权未明确的件号列归属待确认。

3. 建立对象与事件关系：将每一应返还件号连到包号和回执行，包已签收但未逐件核验时仅标包级收到，不能推断钥匙与工具已全部返还。

4. 执行专项推演：计算应返还件数、逐件确认数、包级未开验数和缺回执数，分类互斥；一件出现在两个封包清单中先核重复，不能算两个欠件。

5. 检查专属异常与边界：退出状态取返还证据、权限确认和未决事项三组条件的交集；物品都收到但权限未确认时，写物品已核、退出待确认。 对照缺资料与冲突案例，确认缺项没有被填成示例值。

6. 交付家政退出返还凭据核对文本表与补证队列，逐格保留资料编号及状态。重新核正常与边界算式，给负责人确认入口；实际完成状态以用户后续反馈为准。

## 专项方法与证据顺序

- 先冻结终止范围：委托方资产、服务方自带工具和消耗品分组。仅要求核已约定应返还项，所有权未明确的件号列归属待确认。

- 将每一应返还件号连到包号和回执行，包已签收但未逐件核验时仅标包级收到，不能推断钥匙与工具已全部返还。

- 计算应返还件数、逐件确认数、包级未开验数和缺回执数，分类互斥；一件出现在两个封包清单中先核重复，不能算两个欠件。

- 退出状态取返还证据、权限确认和未决事项三组条件的交集；物品都收到但权限未确认时，写物品已核、退出待确认。

## 专属异常和采用条件

- 封包号可公开代号化，不记录钥匙齿形、门牌、密码或可复制图样。

- 签收时间与开包核验时间分列，开验后发现内容不符保留原回执并新增差异，不抹除签收事实。

- 涉及工具破损只记录前后描述和证据日期，不能把缺凭据认定为遗失或承担费用。

- 资料截止时点晚于终止时点的事件只作后续补证，不能回写为当时已经完成。

## 资料状态与交付复核

- 引用材料使用资料代号、版本和行号，事实摘录与推演结果分栏。未知值统一写【待补】；补证问题指出缺什么、为什么影响本项判断，以及用户应返回哪一格资料，不能仅泛称完善材料。

- 所有统计注明对象、单位及截止时点，记录数、唯一对象数与关联边数分开。计算从原始值逐步列算式，残差保留符号；不通过四舍五入隐藏冲突，零分母写不适用而非百分之百。

- 文本表是材料审阅草案。建议动作、用户确认拟执行、用户反馈实际完成采用不同状态；无反馈时不得变为完成。这里只用已给文字与表格手工推演，不声称已查询系统、通知人员或操作实物。

- 收到新增材料后只重算受影响对象，保留旧值、采用版本和修改理由。冲突未解决的对象不能挤入已确认集合；结束时检查每条输入有去向、每条判断有来源、每个未决项有最少补证动作。
