# 计征期间与税额勾稽
先将每个对象按真实用途和责任期间切片，再决定从价、从租或土地单位税额计算。自用房产按原值与属地减除比例的余值计算，出租依据租金口径；同一对象同一期间不能把全额从价和全额从租同时叠加。房产税全国条例的一点二与十二个百分点不等于各类住房与优惠都可机械套用，个人住房试点不纳企业普通经营房产示例。土地税以实际占用面积乘属地等级年税额，分期只按已确认起止及当地征管口径处理。
原值一千万元、上海减除百分之三十条件下余值七百万元，全年普通自用房产税八万四千元。全年不含增值税应计租金六十万元、普通企业出租百分之十二条件下七万二千元；面积一万平方米、已确认上海三级每平方米年税额六元时土地税六万元。示例两房加一地一般计算合计二十一万六千元，仍需独立核资格优惠和实际缴款，不称最终应补税。租金是否含增值税、免租期及合同变更不明时不得拿银行到账当全年应计租金，也不把押金一概当租金。
本年转租、免租、停用、拆除、权属转移等要核实际事件、适用规则和起止；缺时间不能自行按六个月或全年算。记录原申报、一般计算、已证实减免、已缴与未解释差异，优惠资格未知独立留空，不等于没有优惠也不等于自动减半。没有缴款凭证，税额减去零不是应补。计算表每行只一个对象期间，汇总及算式移到表外，百分比与金额单位清楚。完成标准是房产与土地分别能对账，未确认面积和税额参数只给条件结果，不用邻区税率或账面折旧猜测。
