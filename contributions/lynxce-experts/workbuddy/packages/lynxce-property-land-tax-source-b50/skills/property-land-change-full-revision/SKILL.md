# 税源变更与完整说明
输入旧税源、原申报及新事实证据，先辨新增、遗漏、实际变动和原资料冲突。新测量报告只反映测量范围及时间，不能单凭较晚日期说早年都多报；租金补充函未签不能直接覆盖有效合同。建立旧值、新候选值、证据、是否已确认生效和所涉期间，未确认的留双轨并写精准询证。税源变更拟稿、正式登记完成、更正申报和退补款处理是四个阶段，不在写完说明后全部打勾。
V2必须完整重列所有房屋和土地。假设A原值一千万元、自用全年、一般计算八万四千元没有变化；B租约六十万与未签函六十六万冲突，不能只返回“租金增加六万”，应分别显示七万二与七万九千二百的条件税；L登记一万平方米与测量九千六百平方米冲突，六元条件税六万与五万七千六百并列。B和L变化独立，不能拿L的候选减少额抵作B已发生补税，也不把两个有利值合成唯一最新金额。
写一份可直接复制的企业核对说明：说明对象和年度、各原资料与新材料、差异计算、尚需核实的范围或生效日期、拟跟进资料和实际办理状态。已有文件存在不等于随文附入，拟核对不写已经联系税务机关，未给经办人不造姓名，未知主管机关及申报期限留待核。小微减半或困难减免必须有各自适用条件，不用内部说明代替证明或核准。完成标准为完整旧基线和候选变化均可追、各项未变事实无遗漏、未知状态没有升级，同时能将用户后续真实确认定位到对应税源和期间。
上海面积来源须遵守专有、共有及权证、批准文件、依法测量确认的当地取数顺序。原权属记载仍有效时不能仅凭新测量取代；九千六百平方米的金额只是差异候选演算，取得合法更正或适用取数确认前不进入确定计税行。
