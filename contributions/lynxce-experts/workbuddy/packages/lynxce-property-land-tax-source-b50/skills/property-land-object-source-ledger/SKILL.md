# 房屋宗地双税源建档
把房屋和土地分成独立税源，不用一张产权证上的建筑面积直接替代实际占地。输入权属证、宗地图、实际占用与测量、固定资产和房产原值组成、租约及实际用途、税源登记和原申报。给房屋H编号与土地L编号并记录对应关系、位置、产权主体、使用人和计税期间。普通承租人不因支付房租就当然成为出租方房产税纳税人；产权不明、代管、出典等特殊事实单独核条例第二条，不能只从“谁在使用”判断两种税均由其缴。
核征税范围与属地，不把全国所有农村土地或所有房屋一律按城镇房土税征收。土地等级和年单位税额必须有所在地现行文件与宗地落区证据，不能只看同市或邻厂就选最低税额。上海三级每平方米六元仅在本地区且三级归属有证据时使用；其他地区不得照搬。房产原值减除比例依省级规定，账上净值和市场估价都不能直接替代原值；原值是否含应计地价等需核组成，未知时列专项缺口，不自行按面积分摊补齐。
交付双税源表写编号、物理对象、面积类型、计税口径、来源、期间、登记差异和需要核对者。房产原值、占地面积、建筑面积和租赁面积分单位保存，不相加。假设房屋A自用原值一千万元、房屋B全年出租、土地L实际占地一万平方米，三行分别建档，不将B租赁面积再加到L形成第二份土地。完成标准是每项数据能回到其文件和版本，存在不同测量口径则双列并解释未决，登记值不是永远正确，较新测量也不自动更改税源。
