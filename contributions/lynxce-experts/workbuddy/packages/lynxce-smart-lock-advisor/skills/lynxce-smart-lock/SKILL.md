# 大促智能门锁选购核算

买智能门锁最容易吃亏的不是功能少，而是**没量门厚和锁体就下单装不上、只看开锁花样不看应急开锁、没核安全认证和锁芯等级**。

## 工作流程（按顺序执行）

1. 问清门的类型（防盗门、木门、防火门）、门厚、原锁体导向片长宽与锁舌位置、开门方向、是否租房、家庭成员（老人、儿童）与常用开锁习惯，以及预算。
2. 核门厚与锁体：门厚在商品标注的适用范围内（常见约 40–120 mm）才可装；原锁体导向片长宽与商品支持的锁体规格逐项比对，国标 6068 锁体导向片常见 240×24 mm，企标锁体需拍照给官方客服确认；防火门、租房的先征得物业或房东同意。
3. 选开锁方式：常用指纹加密码作为基础，老人与儿童指纹较浅的优先半导体指纹或人脸识别，人脸款看是否为 3D 结构光；密码支持虚位密码防偷窥。
4. 核续航与应急：干电池款续航常见 6–12 个月，人脸或猫眼款多为锂电池需定期充电；须有低电量提醒、外部应急供电口与机械钥匙，机械锁芯优先 C 级。
5. 核安全认证与安装价：看是否提供电子防盗锁相关公安行业标准检测报告，未提供的标【待补】；官方安装费、改孔费、上门费逐项列出，以官方公布收费为准。
6. 输出门锁匹配核对表与到手价对比表，写明判断与结论，最后按商品列出下单入口清单。

## 门厚与锁体匹配

- 门厚量门扇最厚处，含门框饰面，须落在商品标注的适用范围内，超出的需要加长配件或无法安装。
- 拆下原锁侧面导向片量长宽，国标 6068 锁体导向片常见 240×24 mm，大多数智能锁直接支持；企标锁体尺寸不一，拍照给官方客服确认能否兼容。
- 开门方向（左开、右开、内开、外开）与天地钩联动情况一并确认，需要改孔的由官方师傅评估。
- 防火门改装可能影响防火性能，须先征得物业同意；租房换锁须先征得房东同意。

## 开锁方式与续航应急

- 指纹加密码为基础配置，老人与儿童指纹较浅的优先半导体指纹或 3D 结构光人脸识别，虚位密码可防偷窥。
- 干电池款续航常见 6–12 个月，人脸或猫眼款多为锂电池，充电周期以说明书为准，频繁开锁会缩短续航。
- 必须有低电量提醒、外部应急供电口与机械钥匙三重应急，机械锁芯优先 C 级，钥匙备份另放。
- 远程开锁、临时密码等联网功能需要网关或联网模块，按实际需要选择，不需要的不必为此加价。

## 安全认证安装与红线

- 看是否提供电子防盗锁相关公安行业标准的检测报告与锁芯等级说明，商品页未写的标【待补】并问客服。
- 官方安装费、改孔费、上门费、远程费逐项列出，以官方公布收费为准；防盗门结构改动由官方师傅操作，不指导用户自行拆改。
- 不使用「最低价」「全网最便宜」「史低」「绝对划算」等极限或绝对化用语。
- 价格、优惠与活动规则一律以平台活动页、商品详情页与下单结算页的实时展示为准，本技能只做核算与提示，不做价格承诺，不保证必省多少钱。涉及退款纠纷、消费者权益认定的，以平台规则与主管部门规定为准，本技能不做法律结论。不编造价格、历史数据与活动规则，用户未提供或查不到的信息用【待补】占位。
