# 可复制收音底稿

```text
场景／设备／录音格式／发布平台／记录日期：
选麦与摆位：麦克风类型｜位置｜距嘴距离｜防风防喷｜多人间距（≥3倍距嘴距离）。
录前检查：噪声源已关｜自动增益已关｜试录峰值（dBFS）｜耳机监听｜环境音时长（秒）｜电池与存储。
噪声诊断：现象｜可能类型｜判断依据｜录前对策｜后期对策｜是否建议重录。
后期链：步骤｜工具类型｜参数起点｜复听结论（外放／耳机）。
响度核算：当前综合响度｜当前真峰值｜目标响度｜需调整dB｜调整后真峰值｜需压低dB｜处理方式。
关键问题：最多三个，写明会改变哪一步。
```

## 已填假设示例：室内口播有嗡嗡声

以下全部为假设。单人室内口播，领夹麦接相机，男声；用户描述有持续嗡嗡声，试录峰值−2 dBFS，麦克风接收器与补光灯插在同一插排。

诊断：嗡声持续不随说话变化，频谱上在50、100、150赫兹有尖峰，判为电源哼声；录前把接收器换到另一路插座，并把音频线与灯的电源线分开。电平：目标峰值定为−8 dBFS，需调整−8−（−2）=−6 dB，幅度约为原来的10^(−6/20)≈0.501倍，即约一半。环境音录20秒，在10到30秒区间内。

后期链起点：高通80赫兹；在50、100、150赫兹窄带陷波；用环境样本降噪约8分贝；压缩比率3比1，峰值压缩约4分贝；最后统一响度。

响度核算：用户从响度表读到综合响度−19.5 LUFS、真峰值−3.2 dBTP，目标−14 LUFS，需提升−14−（−19.5）=5.5 dB；直接提升后真峰值为−3.2+5.5=+2.3 dBTP，高于−1 dBTP上限3.3 dB，必须先由真峰值限制器压住这3.3 dB再交付。若改选−16 LUFS，需提升3.5 dB，真峰值为+0.3 dBTP，仍超上限1.3 dB，同样要限幅。

若加一位嘉宾对谈，两支领夹麦距嘴各约20厘米，两人座位上麦与麦间距至少20×3=60厘米，并分两轨录制。
