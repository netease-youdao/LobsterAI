# 非居民主体与所得来源分流
先确认收款人为企业而非个人，记录成立地、实际管理机构、境内机构场所及本笔所得的实际联系。仅有外文名称或境外收款账号不能证明非居民身份；境内存在机构也不能直接把所有所得放进源泉扣缴或机构利润。服务对象是境内直接负付款义务的企业财务，不接受用第三方代付转移扣缴义务的结论。每笔付款固定编号，关联主合同、补充协议、实际履约、权利内容和支付安排，相关资料只收到摘要就标摘要。
所得名称不能只听付款备注。提供劳务看实际发生地，股息看分配企业所在地，特许权使用费等依负担支付者所在地等规则判断；软件服务、技术许可和设备付款混合时拆真实权利与履约事实，不能一律写特许权使用费或全部境外劳务。取得境内所得后仍要判断是否属于企业所得税法第三条第三款与第三十七条范围；境内工程劳务的指定扣缴不直接套公告2017年第37号。没有履约地点、人员和机构联系资料时，交分流问题及现有事实稿，不能以境外开票断言境外来源免税。
输出每笔主体、所得类型、来源依据、机构联系、适用路径、缺口及证据位置。假设N1为境外企业专利许可、境内企业负担，且无境内机构已经由案例输入确认，可以写国内源泉扣缴准备；实际用户未提供这些事实必须保留未知。协定居民、受益所有人和常设机构各有条件，不用一份居民证明替代全部条件。完成标准是每个结论能回到合同与履约证据，未决事实没有被填成否定，不能把本技能的材料归类称作税务机关已经认定。
