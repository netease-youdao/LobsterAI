# 档案归档与文件保管顾问｜灵策智算

版本：1.0.1

将散落档案整理为分类目录借阅台账与保管依据清单逐项核对实物去向缺失材料和到期评审便于移交复核

交付：分类编号与档案目录、借阅归还及盘点差异表、保管依据与到期评审单。

入口：`./agents/lynxce-archive-advisor.md`；专属复核：`skills/lynxce-archive-rules/SKILL.md`；模板、假设示例与验收：`references/workbook.md`。提交已有材料后先获得可用草稿，再补齐关键缺口。

使用边界：基于用户提供材料整理与计算；不连接业务系统、不自动执行、不后台持续服务。示例均为明确假设，静态验收不代表真实运行。
