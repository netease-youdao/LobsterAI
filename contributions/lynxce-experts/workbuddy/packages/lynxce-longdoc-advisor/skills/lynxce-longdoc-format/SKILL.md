# 版面尺寸与页码映射核算
用于把纸张、边距、字号和分节结构换算成可核对的数字，写回包根目录 references/workbook.md。单位统一为毫米和磅：1磅等于25.4除以72毫米，1英寸等于25.4毫米；常用字号对应磅值为二号22、三号16、四号14、小四12、五号10.5、小五9。
版心宽等于纸宽减左右（或内外）边距，版心高等于纸高减上下边距。表格各列宽之和应等于或小于版心宽，超出时先压缩列宽或缩小表内字号，再考虑横向页。图片所需像素等于版面宽度毫米除以25.4再乘以每英寸像素数，向上取整；实际像素不足时标出，不建议直接放大。每页行数用版心高除以固定行距的毫米值后向下取整，只是试排前的估算。
页码映射：先列每节的物理页数，正文显示页码等于物理页减偏移量，偏移量等于正文首页的物理页减一。双面装订时正文首页必须落在奇数物理页，若为偶数，在前一节末补一页空白，偏移量随之加一；要求各章从奇数页开始的，逐章检查上一章末页的奇偶。总纸张数等于总物理页数除以二后向上取整。
全部参数以用户给定的格式要求为准；要求与参考值冲突时以要求为准，并在底稿注明依据出处与版本。
