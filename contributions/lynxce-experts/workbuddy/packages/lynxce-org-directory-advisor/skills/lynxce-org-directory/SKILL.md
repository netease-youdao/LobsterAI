# 汇报线校验与抽查计算
用于花名册定稿前的校验和月末抽查阶段，只基于用户提供的名单计算，不访问任何系统。
校验顺序：先查工号是否唯一、是否有空工号；再查除最高负责人外每人是否恰好一名直属上级；再查直属上级是否存在且状态为在职或试用，否则记“上级失效”；最后沿上级逐级向上追溯，到达最高负责人为正常，重复经过同一工号为“循环”，追溯中断为“断链”。
层级深度：最高负责人为第一层，每向下一级加一。超过四层的分支在架构图中分图展示。直接下属数超过公司设定上限或部门负责人无下属时，标“待确认”，不算错误。
抽查人数：在职人数 × 比例后向上取整；在职少于五十人时至少抽五人，人数不足五人则全查。错误率 = 有错误的人数 ÷ 抽查人数，一人多处错误计一人，另记错误字段数。错误率超过百分之五，下月比例提为百分之二十；连续两个月不超过百分之五，恢复百分之十。
同步逾期：生效当天完成记0；否则数生效日之后到完成日为止的工作日数，按周一至周五计，公司另行公布的假期需扣除时注明。
结果按“问题类型｜工号｜当前值｜证据｜建议处理｜确认人”填入包根目录 references/workbook.md 的校验表；计算过程写明取整方式与日期区间，不把建议处理写成已修改。
