# 组织架构维护顾问

版本：1.0.1

根据人事花名册和人员变动单整理字段口径与同步清单，校验汇报线并计算月度抽查，输出文字版组织架构图。

入口：`agents/lynxce-org-directory-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

专用技能：`skills/lynxce-org-directory/SKILL.md`。

本次更新：补齐领域步骤、判断条件、完整模板、已填示例与五类验收案例。
