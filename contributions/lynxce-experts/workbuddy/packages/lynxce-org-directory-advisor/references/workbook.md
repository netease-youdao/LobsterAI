# 可复制维护底稿

将以下模板完整填写；不适用项写明原因，未知项保留【材料待确认】。

```text
数据源：花名册版本／导出日期／维护人／截止日期：
字段字典：字段｜口径｜可选值｜维护方｜是否对外展示。
变动同步单：单号｜工号｜类型｜生效日｜变动前｜变动后｜下游清单（花名册／通讯录／架构图／审批流／群组权限）｜完成日｜逾期工作日｜原因。
校验表：问题类型（上级缺失／上级失效／循环／断链／超层级／待确认）｜工号｜当前值｜证据｜建议处理｜确认人。
抽查记录：月份｜在职人数｜比例｜抽查人数｜有错误人数｜错误字段数｜错误率｜下月比例。
架构图（文字版，注明截止日与版本）：
最高负责人
├─ 部门（负责人）
│  └─ 小组（负责人）
关键问题：最多三项，写明答案会改变哪条汇报线或哪项同步。
```

## 已填假设示例：小型销售与客服团队

以下为演示假设，不是真实人员数据。花名册节选八名在职人员：E1001总经理，无上级；E1002销售总监，上级E1001；E1003销售一部经理，上级E1002；E1004销售代表，上级E1003；E1005客户成功经理，上级E1001；E1006客服专员，上级E1009；E1007与E1008均为产品专员，分别以对方为上级。另有E1009，状态为离职。

校验结果：E1006记“上级失效”，因E1009已离职，建议由人事确认新上级；E1007与E1008记“循环”，两人都追溯不到E1001，需确认真实上级；共两类问题、涉及三人。E1004的链路为E1004、E1003、E1002、E1001，位于第四层，未超过四层。

变动同步：单号T-1102，E1004由销售一部调至客户成功部，上级由E1003改为E1005，生效日2026年11月2日（周一）。下游五项为花名册、通讯录、架构图、审批流审批人、群组权限，全部完成于11月4日（周三），晚于生效日两个工作日，记逾期2个工作日，原因写“审批流审批人待管理员排期”。调整后E1004链路为E1004、E1005、E1001，位于第三层。变动前后值与单号同时保留。

月度抽查：在职126人，按百分之十抽查，126×10%=12.6，向上取整为13人；其中2人汇报线有误，错误率2÷13≈15.4%，超过百分之五，下月比例提为百分之二十，抽查126×20%=25.2，向上取整为26人，并优先追查近三十天的调岗单。
