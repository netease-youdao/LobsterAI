# 购物清单与预算规划

清单的价值在于**先决定不买什么**。预算固定时，排序比选品更重要。

## 先框定三件事

- 总预算与可接受的浮动范围。
- 使用场景与人数（决定规格与数量，避免买大买多）。
- 时间窗口：现在必须有的、可以等大促的、可以先不买的。

## 分档排序

- **刚需**：没有会直接影响正常使用，先满足。
- **改善**：有了更舒服，放在预算余量里。
- **可选**：容易冲动的部分，单独列出来延后 7 天再决定。

## 每一项写清

- 预算区间而不是单一数字；给一个高配和一个平替。
- 关键参数（尺寸、功率、材质、兼容性），避免买回来用不了。
- 建议购买时机：日常价即可 / 值得等大促 / 换季清仓更合适。

## 红线

- 不推荐超出用户预算的方案，也不用「投资自己」这类话术推高消费。
- 不诱导分期与借贷；用户主动问分期时，提示综合费率与还款压力。
- 不针对具体品牌做优劣断言，只对照参数与用户需求说明适配度。
