# 可复制证明开具底稿

将以下模板完整填写；不适用项写明原因，未知项保留【材料待确认】。

```text
公司简称／模板版本号／生效日期：
受理登记：编号｜申请人｜部门｜类型｜用途｜接收方｜所需字段｜份数｜委托书（如代办）｜受理日期（星期）。
字段来源：字段｜填写内容｜来源文件｜核实人｜核实日期。
收入口径：税前或税后｜统计期间｜是否含奖金补贴｜金额小写｜金额大写｜财务复核人。
时限：类型｜工作日数｜受理日｜逐日列出的工作日｜出具期限（星期）｜是否顺延及原因。
介绍信：持信人｜职务｜前往单位｜事由｜出具日｜有效天数（含出具当日）｜有效期至（星期）。
用印登记：日期｜文件名称｜编号｜份数｜用途｜审批人｜用印人｜是否骑缝。
外发记录：编号｜方式（本人领取／指定渠道）｜是否加密码｜发送日期｜签收。
作废记录：原编号｜作废原因｜收回日期｜重开编号。
季度对账：出具份数｜作废份数｜用印份数｜差异｜追查结果。
待确认：最多三项。

在职证明骨架：兹证明【姓名】（证件号码【按接收方要求，允许时仅后四位】）自【入职日期】起在我公司工作，现任【部门】【岗位】，截至出具日在职。本证明仅用于【用途】。出具日期【日期】，加盖公章。
介绍信骨架：兹介绍我公司【姓名】【职务】前往【单位】办理【事由】，请予接洽。本信有效期至【日期】，逾期作废。
```

## 已填假设示例：房贷收入证明与介绍信

以下为演示假设，人员与金额均非真实。员工甲于2026年11月12日（周四）申请收入证明，用途为个人房贷，接收方书面要求“近12个月税前月均收入”。受理当日不计，第1至第3个工作日为11月13日（周五）、11月16日（周一）、11月17日（周二），期间无法定节假日，出具期限为11月17日（周二）。

财务按发放记录确认：近12个月税前合计216,000元，其中年终奖24,000元。若接收方口径含奖金，月均为216,000÷12＝18,000元，大写壹万捌仟元整；若不含奖金，月均为（216,000−24,000）÷12＝16,000元，大写壹万陆仟元整。接收方未写明是否含奖金，列为待确认，由员工向接收方确认后，财务按确认口径签字复核。员工希望写成25,000元，与发放记录不符，不予填写。

介绍信：员工乙于11月16日（周一）开具介绍信，前往某合作单位办理资料交接，有效期含出具当日15天，有效期至11月30日（周一），注明逾期作废。

季度对账（7至9月）：出具台账46件共52份，作废收回3份，合计55份；用印登记56份，差1份。追查到编号JS-2026-0088的介绍信盖章后未登记出具台账，补登后出具53份、作废3份，合计56份，与用印登记一致。
