# 出具时限与用印对账核算
用于受理登记、收入口径填写和季度对账三个时点，只做日期、金额与份数计算，不判断证明的法律效力。
时限：出具期限 = 受理日之后的第N个工作日，受理当日不计；一般证明N为2，收入证明或英文版N为3。逐日列出并跳过周六周日与当年法定节假日，调休上班日按工作日计；节假日安排以官方当年公布为准，没有提供时注明“未核节假日”。每个日期写出星期几。
有效期：有效期至 = 出具日 + 有效天数 − 1（含出具当日），默认15天，同样写出星期几。
收入：月均 = 统计期间合计 ÷ 月数，税前税后按接收方要求；含与不含奖金补贴分别计算，按接收方书面口径选用一个写入证明，另一个只留在底稿。金额大写与小写逐位核对；不擅自取整，按财务确认数填写。
对账：差异 = 用印登记份数 −（出具份数 + 作废份数）。差异为正，找已盖章未登记出具的文件；差异为负，找已出具未登记用印的文件；逐件定位到编号，补登后重算，差异为0才关闭。
记录：结果写入包根目录 references/workbook.md 的时限、介绍信、收入口径与季度对账行，保留原始登记值和补登记录。
