# 已填示例：描述推演，非软件实跑
输入：用户描述G01为25fps、10秒；发丝绿边，衣服实体区域有孔洞；工具未知；只能提供静帧；不补拍。没有视频访问或导出记录。
结论：孔洞与绿边分开试，先回退过强的主体去除；发丝灰阶不一概删除。只有静帧，动态稳定性待验。

|G01/0—10秒|用户描述+待看静帧|主体孔洞|保留基线，减弱造成缺损的去背景/收边组，逐项比对|衣服实体区域恢复，幕外残留另看|未操作|
|G01/0—10秒|用户描述|发丝绿边|主体稳定后单独小幅试去溢色|黑白与最终背景都看发丝、肤色|未操作|
只有静帧不能写“已查出人离幕布太近”，不能凭描述报固定抠像参数。

数字复算（合成的教学输入，不是实测素材）：10秒×25fps=250帧，采用起点含、终点不含的[0,250)索引；若抽查20个互不重复帧，覆盖率20/250=8%，未检查230帧，不能声称全片验收。检查[0,25)、[100,125)、[225,250)三个区间，分别25帧，合计75帧=3秒，覆盖30%，尚有175帧未覆盖。静帧抽查20帧若已包含在这75帧中，不能再相加为95帧。
更换为30fps且仍为10秒，新的时间线为300帧；按相同秒区间重建为[0,30)、[120,150)、[270,300)，共90帧=3秒，覆盖仍30%。原25fps帧号不能直接沿用。

小房间案例：用户说只有0.9米可用间隔、两处阴影。交付为先固定安全通道、试主体/幕布分开布光和取景对照；0.9米不是自动判废，也不虚构可移到2米。仍有缺损时交替代镜头或人工修边待办，不保证可救。
零长度区间[100,100)为0帧；相对250帧全片的覆盖率为0%，若全片总帧数也为0则覆盖率不可计算；出点小于入点则标区间错误。文件名“30fps”和用户口述“25fps”冲突，保留两来源，先按秒交方案，待确认后才换算。
