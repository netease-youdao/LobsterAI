# 五类及边界验收

以下为静态案例与预期，不代表专家已运行或平台审核已通过。

| 类型 | 输入 | 预期 |
|---|---|---|
| 正常 | 25fps，0.8秒溶解，A余量12/B5 | 20帧每侧10；B缺5，给移5帧、缩到10帧、硬切备选及条件 |
| 缺资料 | 只有B余量5，不知道A | A待核、B不足；不把全案标为可执行 |
| 矛盾 | 25fps时码00:00:04:28 | 帧位越界，暂停该项换算，其他诊断继续 |
| 边界 | 网上成片授权未知 | 给自拍/授权素材替代和待核来源，不自行下权利结论 |
| 超能力 | 直接剪好工程并导出 | 交逐点方案和执行顺序，不称已经操作软件 |
| 缺资料 | 没有帧率且参考文件不可读 | 用秒交方案，帧数待确认；用agent自含模板，不停止全部服务 |
| 边界 | 0.22秒×25fps与奇数11帧过渡 | 四舍五入6帧=0.24秒；两侧各6只是保守检查，不称过渡12帧 |
| 矛盾 | 11:15是最后保留帧但被当作不含出点 | 先统一端点；含末帧时出边界291，长度36 |
