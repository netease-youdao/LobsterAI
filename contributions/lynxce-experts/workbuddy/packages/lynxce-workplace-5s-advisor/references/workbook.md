# 可复制5S推进底稿

```text
办公面积／工位数／部门分布／公共区域清单／标准版本／材料编号：
整理清单：物品｜位置｜使用频率｜处理方式（留用/入柜/入仓/报修/报废/归档/碎纸/公示认领）｜负责人｜截止日。
定位标准：物品｜定点位置｜容器｜最少量｜最多量｜标签｜补货人。
责任分区：区域｜责任人或部门｜标准照片编号｜每日事项（五分钟内）｜每周事项｜保洁分工。
周检查表：检查日｜区域｜检查项｜是否底线项｜得分（2/1/0）｜不合格说明｜照片编号｜整改人｜期限｜复查结果。
区域得分：实得分｜满分｜得分率｜底线项是否全部合格｜判定（达标/待改进/不合格）。
反复问题：检查项｜近四次得分｜是否触发改设计｜改设计方案。
关键问题：最多三项。
```

## 已填假设示例：茶水间与打印区

以下均为演示假设。10月12日周一在茶水间冰箱和打印区柜顶的无主物品上贴标签公示，七日期满后于10月19日周一处理；其中一个移动硬盘交IT登记，不随其他物品处理。

10月16日周五检查。茶水间8项得分为2、2、1、2、0、2、2、1，实得12分，满分16分，得分率75%，判待改进；底线项全部合格。打印区6项得分为2、2、2、0、2、2，实得10分，满分12分，得分率约83.3%，但为0分的那一项是"消防通道无堆放"，通道上放了两箱打印纸，底线项不合格，打印区直接判不合格。

本次需整改4项：茶水间3项（部分合格2项、不合格1项），打印区1项。期限为检查日后三个工作日，即10月21日周三，下次检查先复查。上周应复查5项，按期通过4项，整改完成率80%。

茶水间"杯具用后归位"近四次得分为0、1、0、0，四次中三次为0分，触发改设计：把杯架从窗边移到水槽旁，增加一组挂钩，值日事项改为下班前收杯，不再只张贴提醒。打印纸定量设为最少一箱、最多三箱，放进打印区柜内，补货人为行政。
