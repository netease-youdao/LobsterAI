# 周检查评分与整改复查口径

每个检查项三档计分：合格2分，部分合格1分，不合格0分。区域得分率 = 实得分 ÷（检查项数 × 2）。分档：得分率不低于百分之八十五为达标，百分之七十到八十五之间为待改进，低于百分之七十为不合格。底线项（消防通道、安全出口、灭火器和配电箱前无堆放，电源线不横跨通道）任一项为0分，该区域直接判不合格，不看得分率。区域项数不同时只比较得分率，不比较总分。

整改：得分低于2分的项都要写整改人和期限，示例期限为检查日后三个工作日；下次检查先复查。整改完成率 = 按期复查通过的项数 ÷ 应复查项数。没有复查照片的写"待复查"，不算完成。

反复问题：同一检查项在最近四次检查中有三次为0分，触发改设计，提出位置、容量或流程的调整方案，不能只继续提醒。

标准修改后记录版本和生效日期，新旧版本的得分率不直接比较。阈值是示例，可按公司要求调整。把每项分数、得分率、判定和整改项填回包根目录 references/workbook.md 的周检查表与区域得分表。
