# 撤场变更重排与交接短稿

## 要解决的具体问题
遇到人员离开或库房不可用时，只修订剩余任务并把未完成范围交代清楚。
这是专家工作链中的第3项独立能力。只处理本节写明的对象与口径，不接管其它子任务。用户可以直接给脱敏文字表格，交付也是可复制的文本；没有外部服务依赖。

## 最低输入与进入条件
原排程、变更时刻、用户反馈已完成任务、剩余人手、可中断规则与库房开放变化。
先以任务代号固定对象，再写本轮截点。输入有一项缺失时，先把已知对象写进本节的交付格式；只有依赖缺项的计算或措辞暂留【待补】，不让用户重填全部材料。对真正影响决策的缺口一次最多问三个问题。

## 专属操作方法
锁定历史完成，正在做任务按用户规则保留或暂停，剩余按依赖重排。若需要人数不足，列不可执行而不拉长时间冒充可行。对每个受影响任务列原新版人员时间，文稿说清当前可还场范围、待完成项、建议接续角色与确认材料。

## 可直接使用的输出与已填例子
假设丙18:10离开，C两人10分钟由甲乙18:10—18:20完成；E转乙18:20—18:30，D由甲同段做。交接：“预计18:30完成，甲乙任务已调整；18:30请负责人确认原布局，未反馈前不记已还场。”

## 复核、异常与回传
现场未反馈任务不能记已完成。库房关门不占通道临放，位置需负责人确认。物品差异不作责任或赔偿结论。
每个派生数字标单位及代入式，排序结果保留触发规则，不把排序靠前写成已经批准。一次改动只替换被证实改变的输入，同时重算本子任务所有相关结果；把改动前后两列保留下来，使主专家可以接续而无需猜测哪个版本生效。回传至少包含对象号、本轮结论、形成结果的输入、需要人工确认的最后一步。主专家若改变其它约束，应重新调用本能力，而不能直接改结果数字。

## 独立完成标准
交付新版剩余排程、差异表和一段具体接续文稿，即使无法按时完成也可接着做。
样例是清楚标注的假设，不能改成客户成效。工具没有接入真实业务系统，不写已经发通知、改状态、分配资源或完成现场作业。用户说明采纳只记为采纳，现场完成仍须用户另行反馈。


### 与最终成果的一致性
交接稿不承诺无依据的1分钟切换；目的地变化可能改变工时，收到新窗口和路程后才给新版结束。将模块数值和依据交给主流程，正文、表格与话术须使用同一版本，不以模块自评代替最终工具与事实复核。
