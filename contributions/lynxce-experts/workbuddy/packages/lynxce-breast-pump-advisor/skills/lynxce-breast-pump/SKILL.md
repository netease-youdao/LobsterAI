# 大促吸奶器选购

吸奶器最容易买错的不是牌子，而是**没按每天要吸几次来选，上班背奶每天三四次却买了手动单边，一次吸完手腕酸、时间翻倍，只看「最大吸力」大小不看档位能不能从很低调起，喇叭罩口径和自己不匹配，吸着疼还以为是机器不好，配件和储奶袋另算后到手成本比主机贵一截**。

## 工作流程（按顺序执行）

1. 问清使用场景（居家偶尔吸/上班背奶/纯吸奶喂养）、预计每天吸奶次数与使用月数、是否需要在通勤或工位使用、是否夜间使用怕吵、是否已在医生或哺乳顾问处量过乳头直径、有无不适史、预算，以及候选款的类型（手动/电动单边/电动双边/穿戴免手扶）、最大负压标注值与单位（mmHg 或 kPa）、吸力档位数量与模式（按摩模式/吸乳模式）、标配喇叭罩口径与可选尺寸、是否为防回流闭合系统、与奶接触部件材质及执行的食品接触材料标准、整机噪音分贝、供电方式与电池容量、单次满电可用次数、集奶瓶容量、需清洗的零件数量、配件单价与更换周期、质保期。
2. 按次数选类型：每天 1 次以下或只是偶尔应急，手动款即可；每天 2 次以上或上班背奶，参考选电动款；每天 3 次以上且两侧都要吸的，参考选双边款；每天吸奶总时长＝每天次数×单次时长×（单边轮流吸两侧为 2，双边同时吸为 1）；单次时长以用户实际情况或哺乳顾问建议为准，用户没给的标【待补】，不自行设定吸多久。
3. 读吸力与档位：最大负压只是上限，不代表越大越好；单位换算 1 kPa≈7.5 mmHg，按同一单位比较；更重要的是最低档够不够低、档位间隔是否细，档位多且起步低的便于从舒适档开始调；使用时从低档起步，调到感觉舒适且不疼的档位即可，不追求开到最大档；只写「强劲吸力」无数值的标【待补】。
4. 量喇叭罩与核卫生结构：喇叭罩口径参考乳头根部直径加约 2–4 毫米，常见 21、24、27 毫米等规格，两侧直径不同的分别配；吸奶时乳头在管道内摩擦明显或乳晕被大量吸入，都提示口径可能不合适，需复测或咨询哺乳顾问；看是否为防回流闭合系统，与奶接触的部件材质（PP/PPSU/硅胶）及是否标注符合食品接触材料国家标准，未标的标【待补】；零件越多清洗越费时，背奶族把可拆零件数量列入对比。
5. 核噪音电池与到手成本：夜间或办公室用的看噪音分贝，同条件下数值越低越安静，未标的标【待补】；背奶族看电池容量与满电可用次数，满电次数需不少于一个工作日内的吸奶次数；到手成本＝主机券后价＋另购口径喇叭罩＋备用鸭嘴阀与导管等易耗件＋储奶袋，按月成本＝到手成本÷预计使用月数，易耗件按说明书更换周期计入，未写的标【待补】。
6. 输出对比表，写明计算过程与结论；用户需要下单时，按商品整理下单入口（商品、规格、预计到手价、下单入口）。

## 参数怎么读

- 最大负压是上限值，比较时统一换算成 mmHg 或 kPa，再看最低档与档位间隔。
- 按摩模式与吸乳模式的节奏不同，看说明书写明的模式切换方式，不按宣传词判断效果。
- 标配喇叭罩口径只是一个规格，是否另售其他口径、单价多少要一起核。
- 满电可用次数与噪音分贝要在同一测试条件下比较，条件没写的标【待补】。

## 使用清洁与安全

- 每次使用后按说明书拆洗与奶接触的部件，晾干或按说明书方式消毒，主机与电机部分不进水。
- 鸭嘴阀、导管、硅胶垫等易耗件出现变形、发黄或漏气时及时更换。
- 吸出的母乳按储存时间与温度要求存放，具体以医生、哺乳顾问或权威育儿指引为准。
- 吸奶时出现明显疼痛、皮肤破损、红肿发热或硬块，停止使用并及时就医，吸奶器不能替代医生或哺乳顾问的建议。

## 售后与红线

- 下单前确认主机质保期限、易耗件单价、拆封后是否支持七天无理由（个人护理类拆封后常有限制）。
- 本技能只做选购与成本核算，不做增加奶量、缓解堵奶、改善健康等功效结论，喂养与哺乳问题以医生与哺乳顾问意见为准。
- 不使用「最低价」「全网最便宜」「史低」「绝对划算」等极限或绝对化用语。
- 价格、优惠与活动规则一律以平台活动页、商品详情页与下单结算页的实时展示为准，本技能只做核算与提示，不做价格承诺，不保证必省多少钱。涉及退款纠纷、质量争议与消费者权益认定的，以平台规则、国家标准与主管部门规定为准，本技能不做法律结论。不编造价格、参数、历史数据与活动规则，用户未提供或查不到的信息用【待补】占位。
