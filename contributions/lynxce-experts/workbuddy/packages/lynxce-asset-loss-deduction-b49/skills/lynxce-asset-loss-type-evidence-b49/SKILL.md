# 损失类型与确认证据核对
将每项资产按编号、产权或控制、经营用途、损失原因、实际处置时间及会计损失时间建档。主流程是非金融企业存货毁损与固定资产报废，不把应收坏账、股权投资、金融贷款、担保损失混入同一证据清单。国家税务总局公告二〇一一年第25号第三条区分实际处置转让的实际损失与符合法定条件但未处置的法定损失；原文会计减值并不自动等于所得税扣除，也不因企业内部核销就证明税收条件满足。
按第十六至十八条区分外部和内部证据，外部鉴定、保险理赔、行政文书不能由顾问生成替代；内部盘点、责任认定、技术部门鉴定、核销及真实性声明必须反映真实程序。主例存货毁损按第二十七条核计税成本、残值核销、责任赔偿及数额较大所需专业意见，固定资产报废按第三十条核计税基础、核销、鉴定和责任赔偿，数额较大或自然灾害等情形另有要求。
“数额较大”不能凭绝对金额猜。办法第二十七条说明占该类资产计税成本百分之十以上，或减少当年应纳税所得、增加亏损百分之十以上等口径；分母或相关年度所得未给，就列为不能判断，不默认小额而省掉资料。是否自然灾害、是否被盗都须真实来源，缺报案不能写被盗已认定。交付逐资产事项页包括已能支持内容、缺少的确认条件、应取得的真实材料、当前不能作结论之处，不声称出具鉴证或机关确认。内部自核只帮助企业备查，不替代需要的专业鉴定；对旧年度补扣按实际法定类型和期间另核，不将所有事项统一追溯五年。
