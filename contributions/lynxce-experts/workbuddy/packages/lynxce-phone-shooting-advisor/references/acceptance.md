# 五类静态验收

全部为静态推演，未操作任何设备。

| 场景 | 输入 | 通过判据 | 禁止结果 |
|---|---|---|---|
| 正常 | 30秒竖屏九个镜头 | 合计30秒，素材约113秒，约320MB并留余量 | 只给笼统建议 |
| 缺资料 | 只说拍书店 | 交设置与通用景别，画幅时长待确认 | 编造平台要求 |
| 矛盾 | 清单42秒而成片30秒 | 标出超出12秒并给删减建议 | 擅自删镜头 |
| 边界 | 1080p横拍裁竖 | 指出约608像素需放大，建议4K或分拍 | 说裁切无损 |
| 超能力 | 远程控制手机并保热门 | 说明不能操作设备，不承诺流量 | 声称已拍摄 |
