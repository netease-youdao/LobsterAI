# 可复制拍摄底稿

```text
主题／平台／画幅／成片时长／版本：
参数设置：分辨率｜帧率｜快门（如可调）｜对焦曝光锁定｜白平衡｜美颜与自动切镜头关闭｜动态范围｜收音方式。
镜头清单：镜号｜景别｜运镜及动机｜成片秒数｜画面内容｜声音｜拍摄条数｜备注。
时长存储：清单合计秒数｜目标秒数｜差额｜每条实拍秒数｜素材总秒数｜每分钟占用｜存储需求｜含余量需求。
画幅裁切：原视频高度｜裁出宽度｜目标输出宽度｜是否需放大。
开拍检查：镜头｜水平线｜曝光｜对焦｜白平衡｜收音｜存储｜电量｜勿扰｜试拍回看。
结论：可开拍／补信息后可开拍／需重排；最多三个关键问题。
```

## 已填假设示例：咖啡店30秒竖屏介绍

以下为演示假设，不是真实拍摄记录。参数：竖屏9:16，4K、30帧，锁定对焦曝光与白平衡，关闭美颜和自动切镜头；店内为暖色灯加窗光，关掉吧台顶灯避免混合色温；店主说话段用领夹麦。

镜头清单九个：1门头远景，固定，交代地点，3秒；2推门进入中景，跟，带观众进店，3秒；3吧台中景，摇，从门口跟随视线到吧台，4秒；4研磨特写，固定，3秒；5萃取特写，推，强调油脂，4秒；6拉花特写，固定，4秒；7顾客中景侧拍，固定，3秒；8杯子近景摆拍，推，3秒；9店内远景，拉，揭示整体环境收尾，3秒。合计 `3+3+4+3+4+4+3+3+3=30` 秒，与目标一致。

拍摄条数：特写4、5、6各拍三条，其余各两条。每条实拍时长为成片时长加起落幅2秒，素材合计 `(5+6+6)×3+(5+5+6+5+5+5)×2=51+62=113` 秒，约1.88分钟。假设设置页标注4K30每分钟约170MB，存储需求约 `1.88×170≈320` MB，留一倍余量需约640MB以上可用空间。

若店主后续要求再出横屏版：本例是竖拍，横屏版需单独补拍门头、吧台、店内三个环境镜头，在清单中新增镜号10至12并标版本，不从竖屏素材硬裁。
