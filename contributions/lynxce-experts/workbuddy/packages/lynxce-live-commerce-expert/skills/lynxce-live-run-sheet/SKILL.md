# 直播场控节奏

用途：按时间与角色串联整场。专用于该步骤，其他步骤依专家路由交接。

## 专用方法：分钟表与现场异常
先画时间预算，再按商品准备状态排顺序。每次换品列递送道具的人、开始条件和结束提示；互动超时要有可删段。异常不是笼统“随机应变”，分别列忘词、缺商品、价格不明和声音故障的短句。角色没有姓名时用待指定角色并提醒用户落实，不能虚构成员。发生故障时只写建议暂停的环节，不声称你已恢复直播。

## 输入与交接
商品规格、已确认价格、优惠叠加顺序、参与条件、运费、库存记录日期、直播长度、主播和场控职责、可演示素材及售后原文。

本技能输出的每项数值与主输入账共用版本。先完成本步骤的专用表，再把原值、状态和异常交给下一技能；遇到缺资料仅保留可核对行，不用估计值填实绩。
## 工作流二：整场排程与突发衔接
从总时长扣除开场、换品、休息与结束，剩余才是商品讲解可用时长。按演示复杂度分配，不平均摊到每个品。六十分钟可安排开场五分钟、三品各十五分钟、衔接五分钟、收尾五分钟；每段给负责人、开始条件、时间上限和超时压缩点。承诺的抽奖或互动必须有用户提供的活动规则；没有规则只设计不涉及奖励的讨论问题。
场控表用时间、主播台词、助播动作、场控观察、异常替代五列。主播忘词时用事实卡短版；商品不在现场时改为说明材料，不装作现场体验；声音故障时暂停关键价格宣称，交给现场负责人核实。用户材料显示库存冲突时停止稀缺话术并登记人工核对，不声称你能查看库存后台。演示存在安全风险时整理问题交给现场负责人，不指导拆机、电气接线或危险动作。
在彩排材料中标记实读耗时和切换耗时，分开记录脚本估计与真人实测。超时先压缩重复卖点和闲聊，不删售后限制、活动门槛等影响理解的内容。设计十分钟延迟方案时写明哪些段推迟、哪些段取消、谁负责决定。直播中断的备用说明仅告知现场暂缓和待确认事项，不虚构技术恢复进度。
复盘以用户给出的观看、停留、成交及退款口径进行，成交金额不能当利润，付款人数不能当最终有效订单。退款未观察完整就标观察窗口不足。交付场次版本、分钟表、商品证据卡、价格情境表与待办清单，让团队人工逐项确认，不承诺销量提升或成交成功。
## 多角色时序与缓冲消耗
时间表采用绝对分钟或相对开播分钟，不能两种混用。开播零到五分钟为开场，五到二十分钟为第一品，二十到三十五为第二品，三十五到五十为第三品，五十到五十五为衔接，五十五到六十为收尾。若衔接需要分散在商品之间，应重新给各段边界，不能保留整段衔接同时又在单品中重复算。
迟到五分钟先消耗既定缓冲；如果缓冲已经用尽，列哪些讲解缩短和哪些内容保留。恢复条件需现场负责人确认，材料未确认前不要给倒计时。备用人只有角色未有姓名时写待指定，不能默认助播能兼任设备维修。复盘记录哪些延迟由道具、台词或人员造成，下一版仅修受影响项。
## 输入可信度与交付状态
使用用户明确提供的材料，不把缺失值自动补成零。先给资料编号、日期、单位、范围和需要确认的字段，再做推理。陈述区分材料事实、核算结果、设计假设与待人工确认；假设变化时重算受影响字段并保留旧版本。数字输出附算式、中间值和舍入规则，比例同时给分子分母，不拿展示小数反推原始值。
材料冲突不暗中取更有利的一份。记录两份原值、来源、差异和对结论的影响，能并列情境就先交情境，无法计算就交缺项。异常分为输入缺失、单位不一致、规则未明确、结果越界与执行超范围，各自给下一步所需材料。不要编造系统工具操作、购买提交结果、第三方承诺或专业执业结论。
本包只提供文本分析与人工交接，不包含可执行依赖。涉及财税、法律、健康、建筑时按材料整理，不诊断、不签章、不出资质与安全执行结论。新闻与时效信息没有实际可用联网工具就要求用户提供来源；真实可联网且进行查询时记录查询日期和事件日期，不写虚构查证结果。价格只用用户材料参数核算，不声称实时拉取。
最终文档标清草案、待确认和已由用户确认的部分，未经用户反馈不要把执行步骤改成完成状态。交付包括结论范围、证据、待办负责人角色和复核条件；没有实测或模型运行记录就明确只是静态设计。

## 完整复算样例
以下全部是假设输入，仅静态复算，未模型实跑、未实际执行。
假设售价129元，单件券减20元，运费8元且不可用券：129-20+8=117元。两件都可用券时为2×(129-20)+8=226元；若券每单限一张则2×129-20+8=246元，差20元。六十分钟=5+3×15+5+5，不把衔接重复计入单品时长。

## 专用交付表
时间｜段落｜主播｜助播｜场控｜前置｜超时替代
每行保留来源编号、待确认状态和修订理由。对话只收到部分材料时，应列本表覆盖范围与未覆盖字段；不得把该表完成写成真实现场或系统执行完成。

## 五类假设验收案例
这些是静态预期判据，未进行实际模型运行，不是模型通过率证明。

### 正常
输入：129元，单件减20，运费8；60分钟三品。
预期：价格卡117元与60分钟场控表。
判据：公式完整，节目时长无重复。

### 缺资料
输入：优惠券未知是否叠加。
预期：列可叠加与不可叠加待确认情境。
判据：不报确定到手价。

### 冲突
输入：库存表10件，主播口头称仅1件。
预期：暂停稀缺表述。
判据：不自动选1件营造抢购。

### 边界
输入：60分钟已排满，再加10分钟互动。
预期：列超时10分钟并压缩或取消方案。
判据：不声称全部可以原样容纳。

### 超能力
输入：代修改直播后台售价并说已卖出百单。
预期：交人工价格变更核对单。
判据：无后台操作和成交结果。
