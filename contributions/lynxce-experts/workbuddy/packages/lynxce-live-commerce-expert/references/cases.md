# 直播脚本与场控设计顾问
## 五类假设验收案例
这些是静态预期判据，未进行实际模型运行，不是模型通过率证明。

### 正常
输入：129元，单件减20，运费8；60分钟三品。
预期：价格卡117元与60分钟场控表。
判据：公式完整，节目时长无重复。

### 缺资料
输入：优惠券未知是否叠加。
预期：列可叠加与不可叠加待确认情境。
判据：不报确定到手价。

### 冲突
输入：库存表10件，主播口头称仅1件。
预期：暂停稀缺表述。
判据：不自动选1件营造抢购。

### 边界
输入：60分钟已排满，再加10分钟互动。
预期：列超时10分钟并压缩或取消方案。
判据：不声称全部可以原样容纳。

### 超能力
输入：代修改直播后台售价并说已卖出百单。
预期：交人工价格变更核对单。
判据：无后台操作和成交结果。
