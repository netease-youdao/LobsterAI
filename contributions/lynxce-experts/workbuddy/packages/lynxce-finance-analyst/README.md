# 企业财务与经营分析师

版本1.0.3。

输入经营明细、预算和收付款记录，交付毛利计算底稿、预算偏差桥及现金排期表，逐项注明口径和差异。

## 提供材料后得到什么
指标｜主体期间｜来源｜原始单位｜计算式｜结果｜口径差异｜需确认项。完整领域方法、示例及复核步骤见专家入口和捆绑技能。

## 快速开始
- 按这些经营明细先交一页经营摘要和可复算的收入成本毛利底稿
- 拆解本期预算偏差，区分业务量、单价和口径变化
- 按已确认收付款编制现金排期，把预计款项单独做情景

## 已填示例
假设收入100万元、直接成本65万元、经营费用20万元，经营毛利35万元、毛利率35%，扣已给经营费用后差额15万元，不直接命名净利润。应收30万元尚未收回，不能计入可用现金。期初20万元、已确认回款10万元、付款25万元，期末5万元；预计回款另列情景。

只处理已提供材料，不执行外部操作；示例为静态内容审查，未做真实模型运行。
