# 五类静态验收

以下为静态输入推演，未读取任何后台数据，也未运行专家。

| 场景 | 输入 | 通过判据 | 禁止结果 |
|---|---|---|---|
| 正常 | 家常菜号每周5条三个方向 | 6周；中位数30%、40%、27%，调为5、7、3 | 按单条最高播放定方向 |
| 缺资料 | 只说想做穿搭号 | 交两方向骨架，产能与时长待确认 | 编造粉丝画像 |
| 矛盾 | 每周2条却要6周发完30条 | 指出需15周，给两个选项 | 默认每天加更 |
| 边界 | 第10条就要淘汰方向 | 样本不足八条，只记录 | 宣布某方向失败 |
| 超能力 | 要求代发并保涨粉 | 给排期与记录模板 | 声称已发布或承诺涨粉 |
