# 可复制冷启动底稿

逐栏填写，不适用写原因，未知写【材料待确认】。

```text
账号定位／目标观众／每周条数／是否出镜／时长档／开始日期／发布时段／数据导出日期：
测试方向表：方向｜选题类型｜形式｜目标观众｜前十五条条数｜后十五条条数
排期表：序号｜日期｜方向｜标题｜测试元素｜是否时段异常
数据表：序号｜72小时播放｜平均播放时长｜视频时长｜平均播放占比｜完播率｜互动数｜新增关注｜关注转化‰｜备注（2小时异常、违规提示）
中期调整单：方向｜五条占比中位数｜五条关注转化中位数｜排名｜后十五条条数｜理由｜版本
终期结论：方向｜总条数｜占比中位数｜关注转化中位数｜主方向｜固定栏目｜取舍理由｜下一阶段计划
待确认问题：最多三个，各写清会改变哪一项
```

## 已填假设示例：家常菜账号

以下数字全部是假设，用于演示计算口径，不是真实账号数据。账号做家常菜，目标观众为双职工家庭，每周5条，视频统一在60秒档，2026年10月19日（周一）开始，每周一至周五发布。三个方向：甲为十分钟快手菜，乙为一周带饭，丙为老人小孩都爱吃。30条按每周5条需6周，第30条在11月27日（周五）发布；第15条在11月6日（周五）发布，11月9日满72小时后做中期判断。

单条口径：乙方向某条72小时播放2400，平均播放时长24秒，新增关注6。平均播放占比为24÷60=40%，关注转化为6÷2400×1000=2.5‰。

中期五条平均播放占比：甲为31%、28%、35%、30%、26%，中位数30%；乙为42%、38%、45%、40%、36%，中位数40%；丙为25%、33%、29%、27%、24%，中位数27%。关注转化中位数假设为甲1.8‰、乙2.6‰、丙1.2‰。乙两项均第一，丙两项均最后，后十五条调整为甲5条、乙7条、丙3条，三个方向三十条内总数为10、12、8，都不低于八条。

终期假设乙方向12条的占比中位数为41%，关注转化中位数为2.7‰，仍是两项最高，定为主方向，固定栏目为“周日备好五天带饭”。甲方向留存居中，保留为每周一条的补充栏目；丙方向两项最低，停测并记录原因。若同一账号每周只能做4条，30条需7.5周，取8周排期。待确认问题：是否能长期保持60秒档、周末能否发布、是否有带货计划。
