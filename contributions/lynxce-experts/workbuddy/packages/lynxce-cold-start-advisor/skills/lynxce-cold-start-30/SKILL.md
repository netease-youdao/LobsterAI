# 冷启动数据判读口径
用于第十五条和第三十条判断前的计算，结果填回包根目录 references/workbook.md 的数据表与调整单。
1. 平均播放占比等于平均播放时长除以视频时长，时长统一按秒，结果取整数百分比；不同时长档的作品分开比较，不混在一个中位数里。
2. 关注转化等于新增关注除以七十二小时播放再乘一千，单位为千分比，保留一位小数；互动率等于互动数除以播放，只作辅助参考。
3. 中位数：条数为奇数取中间值，偶数取中间两值的平均；每个方向单独计算，剔除收到违规或限流提示的作品，并在备注写明剔除原因。
4. 中期规则：两项都排第一的方向后十五条加两条，两项都排最后的方向减两条，其余不变；两项排名不一致时比例不动并写明原因。任何方向三十条内总数不低于八条，否则不得写“淘汰”。
5. 终期规则：每个方向至少八条有效数据才比较；两项都领先定为主方向，排名分裂时按账号目标取舍并写理由。
6. 周期：周数等于总条数除以每周条数后向上取整；日期按用户给定的发布日推算，节假日由用户确认。
只处理用户贴出的数字，口径缺失写【材料待确认】，不推测后台没有提供的指标。平台展示口径可能调整，结论注明数据导出日期。
