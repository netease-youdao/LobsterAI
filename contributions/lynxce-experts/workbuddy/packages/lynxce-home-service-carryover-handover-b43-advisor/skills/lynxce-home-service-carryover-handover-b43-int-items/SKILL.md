# 家政物品状态交接卡

内部专项任务：家政物品状态交接卡。只处理物品数量与可用状态交接记录，不替代公开任务的完整交付。核心方法为：数量账与状态账双列核查，数量守恒后再核可用、待检查和损坏，位置仅用代号；缺物不直接认定遗失，要求提供移出、归还记录与双方确认时间。

## 工作流程

1. 确认专项输入为上次服务记录、遗留事项、家庭授权范围与本次时段，锁定所用版本及本次范围，仅抽取与家政物品状态交接卡有关的字段；缺项标【待补】，不要套用演示例子作为事实。

2. 建立物品数量与可用状态交接记录的原始证据列，记录资料编号、原文片段与目前状态；将事实与经办人的解释分栏，矛盾内容保留两种记录。

3. 数量账与状态账双列核查，数量守恒后再核可用、待检查和损坏，位置仅用代号；缺物不直接认定遗失，要求提供移出、归还记录与双方确认时间。每项都说明判断顺序、触发条件和例外，缺关键条件时不强行给确定结论。

4. 逐项采用专属方法核查：任务使用房间、对象和动作三层编号，厨房清洁不能一项覆盖所有设备；记录上次做到哪一步和为什么停止，接班人员只承接明确动作，避免重复清洁或遗漏。保留原始值和推演值，让复核人能够独立重现过程。

5. 用专项示例检查数量守恒及分类互斥：假设工具期初6件，移出2件，归还1件，期末5件；5件中4件可用、1件待检查，4＋1＝5，下一次可用容量只按4件记录。遇到不闭合结果，先找遗漏与重叠，不能为了闭合改写事实。

6. 输出物品数量与可用状态交接记录并列待补项、影响范围、复核人及下次更新条件；没有用户反馈的条目不变更为已完成，专项结果交由主流程采用。

## 专项证据方法

- 任务使用房间、对象和动作三层编号，厨房清洁不能一项覆盖所有设备；记录上次做到哪一步和为什么停止，接班人员只承接明确动作，避免重复清洁或遗漏。

- 上次问题区分服务范围之外与范围内未完成，追加动作须有新的授权记录；没有明确约定时写待确认，不能把未授权任务自动计成服务方的遗留欠项。

- 用户观察、服务人员记录和共同确认分栏，出现矛盾时引用原表述并给最少核查动作；不依据单方印象认定损坏发生时间或承担费用的一方。

- 家庭私人物品用代号与授权边界描述，资料不需要列真实门牌或密码；钥匙交接只核数量、代号和确认状态，不把具体开锁信息写入公开可复用模板。

## 专项模板与决策

- 数量账与状态账双列核查，数量守恒后再核可用、待检查和损坏，位置仅用代号；缺物不直接认定遗失，要求提供移出、归还记录与双方确认时间。

- 每一行以专项对象编号为主键，与公开成果只通过资料编号关联，不复写公开交付全文；表头固定包含原状态、证据位置、专项判断和待核动作。

- 分支状态采用已确认、待证据和存在冲突三类；待证据不是否定，存在冲突不能合并为已确认，后续反馈到来后再记录原状态和新状态。

- 复核意见必须包含可观察依据与采用版本，确认人没有提供时标【待补】；文字建议与实际执行分栏，避免专项草案被误读为已经完成的业务。

## 复核与版本

- 资料入口采用最小必要字段，先核用户提供的版本、时间与适用范围；原始记录和解释意见分别保存，缺项统一写【待补】。存在两份冲突资料时并排列出，不擅自选更有利的一份，也不把演示数字补成真实业务事实。

- 输出每条判断对应的资料编号、所用方法和状态，记录谁需要确认以及确认后会改变哪一项结果。所有数量注明单位，计算保留分子分母和逐步算式；舍入只用于展示，原值与修正值均保留以便复核。

- 表格是根据给定资料编写的文本草案，计划、人员自报、资料核对通过和实际完成分开记录。没有实际反馈就维持待确认，不能声称已经读取业务系统、发送通知或执行现实任务；也不提供任何资格认定或虚构外部验证。

- 完成前先检查每条输入是否有去向、每条输出是否有来源、每个异常是否有承接动作。后续更新只改有新证据的条目，保留旧版本与变更理由；超出本任务的请求列具体缺项或交接建议，不把未核实事实写进结论。

## 假设案例

以下为专项假设，非真实业务结果：假设工具期初6件，移出2件，归还1件，期末5件；5件中4件可用、1件待检查，4＋1＝5，下一次可用容量只按4件记录。该示例只演示专项判断的分类与数值核对。实际使用时先把资料对象逐行编号，保留原始证据，再执行所列方法；不符合前置条件的对象必须单列待核，不能放入已确认数量。若用户补充记录导致判断改变，记录新增依据、原状态和新状态，重新计算受影响的分母与合计。最终只输出文本对照表和复核建议，不宣称已执行外部任务。复核时逐项检查对象总数、已确认数和待核数是否闭合，注明所用资料版本与计量单位；发现输入修订时只重算受影响条目，并在输出中保留旧值、修订值和差异原因，交由业务负责人确认后再更新主流程记录。

## 能力边界

根据用户提供的资料整理和分析；未知项填【待补】，区分事实、假设与建议。没有实际连接工具时不声称读取或修改业务系统，不编造实时数据或已完成的操作。
