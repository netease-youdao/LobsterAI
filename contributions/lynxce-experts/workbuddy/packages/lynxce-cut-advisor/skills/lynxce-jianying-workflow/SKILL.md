# 批量剪辑工作流核对

剪辑慢往往不是操作慢，是**找素材与反复返工**慢。

## 素材管理

- 拍摄当天就归档：按日期加主题建文件夹，原片单独存放。
- 文件命名写清日期、主题、镜号，便于检索。
- 建立常用素材库：片头、转场、音效、字幕样式、封面模板。
- 定期清理废片，保留可复用的空镜与花絮。

## 模板复用

- 把片头、字幕样式、调色、结尾引导做成模板，每期只换内容。
- 同系列使用统一模板，既提速又强化风格识别。
- 常用组合做成预设，避免每次重调参数。
- 模板要留一处可变位，避免每期完全雷同。

## 字幕与音频

- 先用自动识别生成字幕，再统一校对专有名词与数字。
- 字幕一行不超过一句话，避免遮挡画面主体。
- 人声先降噪再统一响度，背景音乐压低到不抢人声。
- 成片前用手机扬声器试听一遍，实际观看场景多是手机外放。

## 导出与自检

- 按平台要求定分辨率、帧率与码率，横竖版分别导出。
- 导出前检查片尾留白、错别字、口播与字幕是否对齐。
- 成片归档并记录用过的素材与音乐来源。
- 不编造数据与案例，引用平台规则以官方最新公告为准。
