# 商品短视频脚本顾问

版本：1.0.1

把商品资料转成可拍摄的展示脚本，交付卖点证据表、逐镜口播字幕与道具清单，标明适用条件和缺失材料

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 商品卖点与证据矩阵
- 30秒逐镜口播字幕稿
- 15秒压缩稿与镜头复用表
- 拍摄道具及待确认材料清单
