# 热点红线闸门与时效核算
在写任何借势提纲之前执行，结果填回包根目录 references/workbook.md 的红线、时效与事实三栏。
1. 归类：按九类枚举确定热点类型，同时属于两类时取风险更高的一类。
2. 闸门：R1至R5逐项写“是或否加依据”。任何一项为是，直接输出处理方式，不再进入角度构思；无法判断时写【材料待确认】并暂按“是”处理，直到用户补充依据。
3. 时效：统一用二十四小时制和同一时区。可发出时间等于开始制作时间加制作小时数再加复核小时数；剩余小时等于窗口结束时间减可发出时间。剩余小时小于零改长期角度；零到六小时之间提示仓促风险，由用户决定是否压缩制作，复核时间不能压到零。窗口值没有观察依据时只能写“假设”，并在结论中说明。
4. 事实：逐条标A、B、C等级，C级不得以陈述句出现；每个数字都要能指向A级或B级来源原文的具体位置。
5. 输出：一张评估卡加一句结论，结论只能是“做”“不做”“改角度”之一，附版本号。用户提供新通报时新增版本，保留旧结论、旧依据与更新时间。
本阶段只做核查与计算，不判断内容能否通过平台审核，也不判断是否构成侵权，这些交平台规则与法务确认。
