# 可复制借势底稿

逐栏填写，不适用写原因，未知写【材料待确认】。

```text
账号／领域与资质／目标观众／本条是否商业合作：
热点：名称｜首次出现时间｜类型（九类之一）｜材料编号
红线闸门：R1至R5逐项 是/否｜命中项｜处理（不做／改无商品安全提示／改长期角度）
风险级别：低／中／高｜依据｜复核人角色
关联度：0至3分｜理由（受众能获得什么）
时效：窗口结束时间（观察或假设）｜开始制作时间｜制作小时｜复核小时｜可发出时间｜剩余小时｜结论
角度：类型｜一句话观点
事实：内容｜等级A/B/C｜来源名称｜发布时间｜能否写入
发布前核查：标题｜当事人信息｜绝对化用语｜合作标注｜素材授权｜通过或退回
评论口径：质疑事实｜立场争议｜商品询问
结论：做／不做／改角度｜版本号｜待确认问题（最多三个）
```

## 已填假设示例：家居收纳号

以下热点、时间和数字均为假设，用于演示口径，不是真实热点记录。账号做家居收纳知识，目标观众是租房的年轻上班族，接商业合作但本条不挂商品，候选热点三个。

热点甲“双十一囤货”属可预期节点，大促本身应提前排期，这里借的是预售时间公布后突然升温的囤货讨论，所以按讨论热度窗口核算；R1至R5全否，低风险；关联度三分，因为能给出囤货后不占地的收纳方案。热点乙“某地台风登陆”命中R1，不做营销借势，改做“台风前阳台物品加固与收纳提示”，不挂商品、不用受灾画面，信息只引主管部门发布。热点丙“某明星家中装修视频走红”画面涉及其住宅内部，命中R4和R5，不用姓名和画面，改做长期角度“小户型玄关收纳”，关联度两分。

热点甲的时效核算：假设热度窗口为首次出现后48小时，首次出现于10月14日08:00，窗口结束为10月16日08:00；10月14日14:00开始制作，制作5小时加复核1小时，可发出时间为10月14日20:00，距窗口结束还剩36小时，结论为做。若到10月16日04:00才开始制作，可发出时间为10:00，晚于窗口结束2小时，转为长期角度。

一句话观点：“囤货前先量收纳空间，再决定买多少。”事实部分只写平台公布的活动时间，等级A，注明发布时间；“今年囤货人数翻倍”只来自自媒体截图，等级C，不写入。发布前核查全部通过，评论区对“推荐哪款收纳盒”的提问只讲尺寸选择方法，不临时挂商品。结论记为版本一，待确认问题为：本条是否有品牌合作、平台活动时间的原文来源、计划发布时段。
