# 可复制联动底稿

```text

选题分层：主题｜类型（文章优先/视频优先/两边都做）｜理由
改编对照：原内容｜原形态｜改编要点｜新标题｜口播字数与时长｜状态
入口清单：内容｜入口位置｜入口说明文案｜数量（文章不超过两个）
联动日历：日期｜星期｜主题｜节奏｜视频号内容｜公众号内容｜入口位置｜负责人｜状态
月度复盘：主题｜视频播放｜文章阅读｜文章中来自视频的阅读｜视频中来自公众号的播放｜视频带文章率｜文章带视频率｜评论占比｜结论
口径说明：来源数据取自｜替代口径｜截图日期
关键问题（不超过三个）：
```

## 已填假设示例：财税科普双号

以下全部为演示假设，不代表真实账号或数据。公众号写财税科普长文，视频号播放偏低。十一月排四个联动主题，采用视频预热节奏：11月3日、10日、17日、24日（均为周二）发视频，同周周四即5日、12日、19日、26日发长文，每组间隔两天。每条视频取文章里一个常见误区，目标六十秒，按每秒四字约60×4=240字。

十月复盘（假设数据）：
主题A视频播放8000、来自视频的文章阅读240，视频带文章率3.0%；文章阅读3000、来自公众号的视频播放150，文章带视频率5.0%。
主题B播放12000、阅读来源180，比率1.5%；文章阅读2500、视频来源75，比率3.0%。
主题C播放5000、阅读来源50，比率1.0%；文章阅读2000、视频来源20，比率1.0%。
主题D播放6000、阅读来源210，比率3.5%；文章阅读4000、视频来源160，比率4.0%。

视频带文章率中位数为(1.5%+3.0%)÷2=2.25%，一半为1.125%；文章带视频率中位数为(3.0%+4.0%)÷2=3.5%，一半为1.75%。主题C两项都低于一半，十一月减少同类主题；主题B只是视频带文章率偏低但高于阈值，保留并改写视频结尾的入口说明。

扩写候选：视频评论A为96条、B为60条、C为15条、D为54条，评论占比分别为1.2%、0.5%、0.3%、0.9%，中位数(0.5%+0.9%)÷2=0.7%，A与D高于中位数，列为扩写长文候选。口径说明：来源数字假设取自后台来源统计截图，十月与十一月口径一致。待确认：两个号是否已完成关联，答案决定视频能否挂文章入口。
