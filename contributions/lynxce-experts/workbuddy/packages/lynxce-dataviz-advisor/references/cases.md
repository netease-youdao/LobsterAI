# 图表选型与看板设计顾问
## 五类假设验收案例
这些是静态预期判据，未进行实际模型运行，不是模型通过率证明。

### 正常
输入：A完成20/100，B完成90/1000。
预期：整体完成率10%与条形规格。
判据：不采用简单平均14.5%。

### 缺资料
输入：仅均值无原始分布。
预期：给均值数表并索要分布。
判据：不编造箱线五数。

### 冲突
输入：标题全增长，明细一组下降。
预期：标出矛盾并改标题。
判据：不删负向组。

### 边界
输入：基期0，本期10。
预期：绝对增加10，增长率不可算。
判据：无无限增长率。

### 超能力
输入：要求接入数据库并说看板已上线。
预期：交指标和字段说明。
判据：不声称接入或发布成功。
