# 大促车蜡与镀晶养护选购

车蜡镀晶最容易买错的不是牌子，而是**把门店宣传的「三年镀晶」当成实际持久期去比价，没算一瓶够车身用几次，大太阳下在发烫的漆面上施工留下一块块花斑，漆面有铁粉和柏油没清干净就直接上镀晶，钱花了效果撑不过一个月**。

## 工作流程（按顺序执行）

1. 问清车型与车身大小（轿车/SUV/MPV）、车龄与漆面状况（新车、轻微划痕、发乌失光、有鸟屎或树胶腐蚀印）、停车环境（地库/露天/树下）、洗车频率与方式（自己洗/洗车店/自助洗车）、是否愿意自己动手、可用的施工场地（是否有遮阴处）、预算，以及候选产品的类型（喷雾快蜡/液体蜡/固体蜡/DIY 镀晶/门店镀晶或镀膜服务）、容量（毫升或克）、商家标注的单次用量与持久期及测试条件、是否需要配套洗车液或除铁粉剂、是否赠送海绵与超细纤维毛巾、门店服务是否包含洗车、去铁粉、抛光与质保条款、券后价。
2. 按停车与洗车频率定类型：只想快速补亮、每次洗车顺手喷的选喷雾快蜡，持久期参考 2–4 周；每一两个月愿意花一两个小时打一次的选液体蜡或固体蜡，持久期参考 1–3 个月；露天停车、想减少打理次数、能接受较严格施工条件的选 DIY 镀晶，持久期参考 3–6 个月；漆面已有明显划痕失光、自己不想动手的再考虑门店抛光加镀晶；商家宣称的年数多为理想条件，计算时按质保条款写明的期限或宣称值的一半保守估算。
3. 核单次用量与可用次数：可用次数＝容量÷单次用量并向下取整；单次用量商家未标的，轿车参考按液体蜡 20–30 毫升、DIY 镀晶 15–25 毫升估，SUV 与 MPV 按轿车用量×1.3 估，标【待补】并提示以说明书为准；年施工次数＝12÷持久月数并向上取整；年需瓶数＝年施工次数÷可用次数并向上取整。
4. 看施工前处理与条件：施工前先洗车并擦干，漆面有铁粉黄点、柏油点的用除铁粉剂或除胶剂清理，粗糙处可用洗车泥处理；在阴凉处、漆面不烫手时施工，环境温度与湿度范围以说明书为准；镀晶类施工后通常需一段时间不淋雨、不洗车，具体时长以说明书为准；镀晶与车蜡一般不叠加在同一层上随意混用，维护顺序按产品说明。
5. 算每月养护成本：DIY 年成本＝年需瓶数×单价＋配套洗车液、除铁粉剂与毛巾等耗材年费；门店年成本＝服务价÷保守持久年数＋按需维护费；每月成本＝年成本÷12；同时记录每次施工所需时间，供用户权衡时间投入。
6. 输出对比表，写明计算过程与结论；用户需要下单时，按商品整理下单入口（商品、规格、预计到手价、下单入口）。

## 参数怎么读

- 「持久 X 年」「硬度 9H」等宣称无测试条件的标【待补】，按质保条款或保守值核算。
- 容量单位为毫升或克，只在同类型产品间比单次用量。
- 门店套餐要拆开看是否含洗车、去铁粉、抛光、镀晶层数与复检次数，各项未写明的标【待补】。
- 持久期判断可看洗车后漆面水珠是否仍成圆珠、滑落是否顺畅，明显变差即进入下次养护周期。

## 施工与注意

- 不在烈日下、漆面发烫或刚跑完长途发动机舱附近仍很热时施工，以免形成斑痕。
- 抛光会磨掉少量清漆层，频繁抛光不可取；门店施工前可询问是否先做漆膜厚度检测，以门店专业意见为准。
- 产品勿接触眼睛，施工时保持通风，敏感肌戴手套；剩余产品放在儿童接触不到的阴凉处。
- 玻璃、橡胶条与未喷漆塑料件是否可施工以说明书为准，误涂及时擦净。
