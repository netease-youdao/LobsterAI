# 大促美容仪选购与核价

美容仪最容易买错的不是颜色和牌子，而是**把射频、微电流、导入几类原理不同的机器当成一回事比价格，没核注册信息与温控说明就下单，只看机身到手价、忽略每次都要用的专用凝胶，一年耗材钱比机身还贵**。

## 工作流程（按顺序执行）

1. 问清想买的类型（射频/微电流/离子导入/多功能合一）、主要使用部位（面部/眼周/颈部）、每周使用次数与每次分钟数、是否孕期或备孕、是否有心脏起搏器或体内金属植入物、近期是否做过医美项目、皮肤是否有破损炎症或正在治疗的皮肤问题、预算，以及候选款的类型与输出方式、档位数、商品页展示的医疗器械注册证编号或产品备案信息、表面温度上限与过热保护说明、自动定时关机、防水等级、电池容量与续航、是否必须搭配专用凝胶及凝胶规格单价、标价、店铺券、平台满减规则、赠品清单、保修年限。
2. 核类型与资质：射频类美容设备按国家药品监督管理部门规定纳入医疗器械管理的，核对商品页或包装是否展示医疗器械注册证编号，未展示的标【待补】，以主管部门现行公告为准；微电流与导入类核对执行标准、3C 或产品合格信息；同一台多功能机按其中管理要求最严的一类核对；只写「医美级」「院线同款」而无注册或备案信息的不作为推荐依据。
3. 比参数：档位越多不等于越好，看最低档能否从低强度起步；射频类必须有温度监测或过热保护说明，温度上限未标的标【待补】；有单次自动定时关机（参考 3–10 分钟）的更不易过量使用；防水等级参考 IPX6 以上可在洗漱台附近使用，IPX4 只防溅；续航按每次分钟数×每周次数算一次充电能用几周，续航未标的标【待补】。
4. 算真实到手价与年成本：到手价＝标价－店铺券－满减分摊，满减分摊＝满减额×本品价÷凑单总价，凑单的东西本来不需要的，不能当成省下来的钱；赠品只把自己确实会用的耗材按单价计入价值，其余不计；凝胶年耗量＝每次用量×每周次数×52，年凝胶费＝年耗量÷每瓶容量×每瓶价格；年成本＝机身到手价÷预计使用年数（参考 2–3 年）＋年凝胶费，可用普通精华或凝胶替代的款按说明书确认后再算。
5. 列边界与禁忌：把说明书写明的禁用和慎用人群逐条列出（常见包括孕期、心脏起搏器或体内金属植入物、皮肤破损或炎症期、近期做过医美项目等），用户命中任一条的，提示先暂缓购买并遵医嘱；有皮肤问题或正在治疗的先咨询医生；首次使用从最低档、短时间开始，出现灼热刺痛或红肿立即停用。
6. 输出对比表，写明计算过程与结论；用户需要下单时，按商品整理下单入口（商品、规格、预计到手价、下单入口）。

## 类型与参数怎么读

- 射频、微电流、离子导入原理与使用方式不同，先分类再比价，不跨类比价格。
- 注册或备案信息、温度保护、定时关机是必要条件，没有的不进入推荐。
- 档位数与「功率大」不是越高越好，能从低档起步更重要。
- 专用凝胶是长期开销，机身便宜但凝胶贵的，年成本可能反超。

## 核价常见错误

- 把凑满减买的不需要的东西算作省钱，满减必须按金额比例分摊。
- 把赠品按吊牌价全部计入价值，实际只计自己会用的耗材。
- 只看机身到手价，不算一年要用几瓶凝胶。
- 把「到手价」截图当承诺，实际以结算页为准，并确认价保规则。

## 售后与红线

- 下单前确认保修年限与范围、拆封试用后是否支持七天无理由、凝胶等耗材能否单独购买。
- 本技能只做选购、参数核对与成本核算，不做紧致、提拉、淡纹、抗衰等任何效果结论；孕期、体内有植入物、皮肤问题与医美术后人群遵医嘱。
- 不使用「最低价」「全网最便宜」「史低」「绝对划算」等极限或绝对化用语。
- 价格、优惠与活动规则一律以平台活动页、商品详情页与下单结算页的实时展示为准，本技能只做核算与提示，不做价格承诺，不保证必省多少钱。涉及退款纠纷、质量争议与消费者权益认定的，以平台规则、国家标准与主管部门规定为准，本技能不做法律结论。不编造价格、参数、历史数据与活动规则，用户未提供或查不到的信息用【待补】占位。

## 示例

用户：「想买一台面部美容仪，每周用 3 次。A 款射频加微电流二合一，标价 2399 元，店铺券 200 元，商品页展示了医疗器械注册证编号，有温度监测和 5 分钟自动关机，IPX6，必须配专用凝胶，凝胶 50 毫升 99 元，每次用约 3 毫升；B 款离子导入仪，券后 599 元，可配普通精华，标 IPX4，未写自动关机。平台满 2000 减 300，我为了凑满减还加了一瓶 300 元的精华。选哪个？」→ 先分类：A 是射频类，按规定核注册信息，已展示；B 是导入类，与 A 原理不同，不直接比价格，只按用户需求选类型。A 满减分摊：凑单总价＝2199＋300＝2499 元，分摊到 A＝300×2199÷2499≈264 元，A 到手价≈2199－264＝1935 元；精华若本来不打算买，那 300 元不算省钱。A 年凝胶耗量＝3×3×52＝468 毫升，约 468÷50≈9.4 瓶，年凝胶费≈10×99＝990 元；按 3 年使用，A 年成本≈1935÷3＋990≈1635 元；B 年成本≈599÷3≈200 元（精华另算）。A 的凝胶年开销比机身折年费还高，下单前确认能否用其他凝胶替代【待补】；B 未写自动关机标【待补】。若用户只想日常配合护肤品使用、预算有限，倾向 B；明确想要射频类的选 A 并算进凝胶费。异常情况：若用户提到正在备孕或刚做完医美项目，说明书列为慎用或禁用，提示先暂缓购买并遵医嘱，不推荐任何一款；以上价格为示例，以下单页为准；最后给出对比表与下单入口。
