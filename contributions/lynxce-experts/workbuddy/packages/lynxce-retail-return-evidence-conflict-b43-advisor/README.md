# 退换货事实沟通专家：退换货双方陈述中的证据冲突

版本1.0.1。

整理退换货双方陈述、订单和收寄凭据，交付事实分歧表、事件时间线与待核问题，生成不擅自归责的回复。

## 提供材料后得到什么
争议ID｜客户陈述｜商家陈述｜来源时点｜已知事实｜待核实项｜授权角色｜中性回复。完整领域方法、示例及复核步骤见专家入口和捆绑技能。

## 快速开始
- 整理这起退换货双方陈述，区分已知事实、分歧和待补凭据
- 根据订单及收寄记录生成事件时间线，标出物品身份和时间冲突
- 把这段回复改成事实、分歧和下一核实动作，保留用户原诉求

## 已填示例
客户称10日寄回2件，商家11日签收1件，物流凭据只记1箱。1箱不等于1件，数量争议保持待核。时间线分别登记寄件、签收及开箱记录，不能仅凭签收时间判责任。回复可写已核到1箱签收记录，仍需核对箱内件数和物品身份；没有授权不承诺退款金额和时限。

只处理已提供材料，不执行外部操作；示例为静态内容审查，未做真实模型运行。
