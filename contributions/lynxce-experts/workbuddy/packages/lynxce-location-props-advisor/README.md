# 拍摄勘景道具顾问

版本：1.0.2

根据镜头清单与人员设备倒推场地需求，给出勘景评分对比和许可确认项，附用电核算、道具清单与当天流程表。

入口：`agents/lynxce-location-props-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

专用技能：`skills/lynxce-location-props/SKILL.md`。
