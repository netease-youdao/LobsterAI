# 可复制店铺诊断底稿

```text
平台／类目／比较期间（起止日期与天数）／成交口径（支付、是否含退款）／材料版本：
口径核对：访客×转化×客单｜报表成交额｜差额｜差额占报表比例｜是否超过2%。
三因素拆解：因素｜基期｜本期｜相对变化｜贡献金额｜计算式；合计＝成交额变化。
渠道拆分：渠道｜基期访客｜本期访客｜变化｜占总变化比例。
定位清单：环节｜现象｜数据证据｜待验证假设｜验证所需数据｜负责人。
活动方案：阶段｜日期与星期｜主推款｜权益｜库存保障｜价格底线｜满减力度。
复盘：目标｜实际｜差异｜三因素拆解｜同期其他因素｜下次动作。
待确认：最多三项，写明各自会改变哪项判断。
```

## 已填假设示例：家居店前后两期对比

以下全部为假设数据。基期为2026年8月17日（周一）至9月13日（周日），本期为9月14日（周一）至10月11日（周日），各28天，口径为支付金额、不含退款。基期访客50000、转化3.0%、客单120元，成交额180000元；本期访客42000、转化2.8%、客单125元，成交额147000元，减少33000元，降幅18.33%。

拆解：访客影响 (42000−50000)×3.0%×120 = −28800元；转化影响 42000×(2.8%−3.0%)×120 = −10080元；客单影响 42000×2.8%×(125−120) = +5880元；合计−33000元。访客相对变化−16%，超过15%，优先追查；转化相对−6.67%，客单+4.17%。

渠道：搜索30000降到22000，减8000，降幅26.67%；推荐15000升到15500；付费5000降到4500，降幅10%；本期合计42000。推荐渠道小幅上升，主图与内容素材暂无同步下滑迹象，暂不列为优先项。搜索减少量等于访客净减少量，下一步核对主推款在搜索渠道的关键词排名与库存，库存截图显示主推款两个热门尺码在本期中段缺货，列为待验证假设，需导出该商品分日访客与库存记录。

活动价格底线：某款成本60元、履约8元、扣点5%，保本活动价 68÷0.95 ≈ 71.58元；目标毛利率15%时活动价不低于 68÷0.80 = 85元。满200减30力度15%，满150减20力度13.33%；当前客单125元，满150需凑单25元，先测算加购配件后的连带率再定门槛。
