# 可复制操作手册

```text
手册首页：系统｜适用版本｜读者角色｜维护角色｜更新日期｜材料状态。
任务目录：编号｜用户目标｜起始页面｜成功标志。
任务页：
任务编号与标题：
前提：权限／资料／起始状态／不可执行条件。
步骤表：序号｜动作与控件原文｜输入说明｜预期反馈｜图号或待补图。
分支：触发条件｜替代步骤｜回到主流程的位置。
完成标志：可见状态／记录标识／仍在处理时的判断。
恢复：结果未知怎么查／失败怎么回到可继续状态／需要的责任角色。
截图索引：图号｜任务步骤｜文件或待补图｜界面版本｜标注要求｜脱敏状态。
常见问题：报错原文｜步骤｜可能原因｜核对动作｜升级角色及材料。
试做记录：参与者编号｜任务｜独立/协助/未完成｜耗时口径｜卡点｜证据。
修订表：版本｜触发材料｜影响任务和图片｜修改说明｜待复测。
```

## 已填假设示例：差旅报销单

示例界面与规则均是假设，不代表用户实际软件。手册首页为“演示报销系统，界面版本演示一版，读者普通申请人，维护角色行政支持，日期由实际交付时填写”。任务T01是提交差旅单，前提为已获申请权限、两张测试票据和行程说明，起点是示例的“我的报销”页。两笔费用假设86元和120元，合计206元；金额仅用于算例，不作为截图中的真实私人数据。

步骤一点击假设控件“新建报销”，看到草稿页；步骤二选择“差旅”并填写行程；步骤三逐笔填86和120并附测试票据，核对合计206；步骤四检查日期与票据对应后点击假设控件“送审”；步骤五在“我的报销”核对记录状态为“待审核”且获得编号 `DEMO-001`。完成标志是单据已送审，不是已经报销到账，审批通过及到账是后续任务。

截图索引为图T01-1展示新建入口、图T01-2展示明细与合计、图T01-3展示状态与编号，全部状态写“待补图”，标注序号分别对应步骤一、三、五。没有真的生成这三张图片。若实际按钮是“提交”而非“送审”，必须核对版本后同步修改步骤和图注。

常见问题示例为“附件缺失”：先核对对应明细是否已附测试票据，具体文件格式和大小要求待材料确认。提交后断网则先查是否已有 `DEMO-001` 或相应记录，不立即重复送审。撤回能力未确认，所以恢复栏写交行政支持核对单据状态，不宣称普通申请人一定能撤回。

假设试做四人中三人独立完成，一人需要说明附件位置，独立完成比例3/4为百分之七十五；三名独立完成者耗时4、5、6分钟，中位数5分钟。不能由此保证所有新人能完成。修订行动为在步骤三补充附件定位和上传完成反馈，并对同一任务重新试做；真实试做仍由用户组织并带回记录。
