# 五类静态验收

只做材料推演，未联系任何管理方、未查询天气或日落时间。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 11月7日周六公园商业短片 | 10月30日周五截止，集合14:40，电池6块，书面答复前不写获批 |
| 缺资料 | 只说下周去海边 | 给报备问题和通用核对项，潮汐点位待确认 |
