# 可复制外景底稿

```text
项目／版本／拍摄日（星期）／备选日／用途：
场地表：机位｜性质｜管理方｜对接人角色｜报备触发项｜提交日期｜答复状态｜条件｜书面凭证文件名。
报备截止：管理方口径｜N个工作日｜倒推截止日（星期）｜节假日扣除说明。
光线表：日期｜日出｜日落｜暖光窗口｜主拍时段｜机位顺序与光线方向｜数据来源与查询时间。
天气决策：前一天傍晚｜出发前｜降水概率｜风力等级｜预警｜阈值｜决定（维持/调整/备选）。
风险核对：类别｜位置｜风险描述｜控制措施｜负责人｜确认人｜状态。
时间表：集合｜路程｜搭建｜彩排｜缓冲｜主拍｜拆收｜离场。
器材表：物品｜数量｜开机分钟｜单块续航｜所需块数｜备用｜携带人。
应急：最近医院与路程｜撤离点｜现场安全负责人｜场地对接人角色。
收工清点：出发数量｜收工数量｜差异与处理｜场地恢复照片。
待确认：最多三项，写明影响哪一行。
```

## 已填假设示例：城市公园产品短片

以下全部为演示用假设。2026年11月7日（星期六）在某城市公园草坪区拍产品短片，备选日11月8日（星期日）同一时段；3人：导演兼摄影、灯光兼场务、出镜；两盏LED灯配灯架，不用无人机，不接市电；用途为商业短片。

报备：公园管理处书面告知“商业拍摄需提前5个工作日提交计划”。按提交日与拍摄日之间至少5个完整工作日倒推，11月2日至6日为5个工作日，最晚提交日为10月30日（星期五）；申请中同时写入备选日。截至方案日期仅“已提交，未答复”，通告状态写待获批，不安排出发。

光线：用户查得当日日落为17:10（假设值），暖光窗口约16:10至17:10，主拍定为16:10至17:10共60分钟，逆光人像排在16:40以后。倒排：集合14:40，步行到机位15分钟到14:55，搭建40分钟到15:35，走位彩排20分钟到15:55，缓冲15分钟到16:10开拍，各段合计90分钟。拆收清点30分钟，17:40离场，日落后拆收需带两只头灯。

天气：前一天傍晚预报降水概率30%、风力3级、无预警，未触发阈值，维持原计划；出发前复查一次。电池：每盏灯开灯时间为彩排20分钟加主拍60分钟共80分钟，单块续航50分钟（假设取自说明书），预报气温8至14摄氏度，不打折扣；每盏需向上取整80÷50＝2块，加1块备用为3块，两盏共6块。

风险核对节选：草坪边步道为人流主通道，灯架只放草坪内侧并离步道至少一个灯架高度，各压一只沙袋，由灯光兼场务负责并担任现场安全负责人；草坪东侧人工湖无护栏，机位背向湖面且不后退取景；路人入镜镜头后期模糊。应急：最近医院名称与车程由用户补充【材料待确认】，撤离点为公园北门。
