# 外景时段与通告排程口径

本阶段只做时间与数量推算，所有输入来自用户或管理方答复，天文与天气数据由用户查询后提供。

1. 报备截止：管理方写“提前N个工作日”时，按“提交日与拍摄日之间至少有N个完整工作日，不含提交当天和拍摄当天”倒推；遇法定节假日和调休按当年安排扣除。管理方口径不同时以其书面说明为准，并在表头注明采用的口径。
2. 光线窗口：暖光窗口取日出后约一小时、日落前约一小时作为近似，持续时间随纬度和季节变化；蓝色天光约在日落后二三十分钟内。拍摄前一天用当日数据重算。
3. 集合时间：集合＝主拍开始－缓冲－走位彩排－搭建－从集合点到机位的路程。每一项单独列分钟数，不合并成一个笼统的提前量。
4. 收工时间：主拍结束＋拆收清点时长；拆收若在日落之后，通告里加照明物品。
5. 电池数：每盏灯（或每台机）所需块数＝向上取整（预计开机分钟÷单块续航分钟），再加每台至少一块备用。单块续航取说明书或团队实测记录；气温低于五摄氏度时按续航乘零点七估算，这是团队经验系数，不是厂家参数。
6. 天气决策点：拍摄前一天傍晚与出发前各看一次逐小时预报，记录降水概率、风力等级与预警，按方案中写明的阈值决定维持、调整机位或启用备选日。

推算结果填入包根目录 references/workbook.md 的时间表与器材表，写清每个输入的来源；缺少日落时间、续航或管理方口径时只列公式和【材料待确认】。
