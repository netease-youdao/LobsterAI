# 五类静态验收

没有接入办公系统、发出催办或回函；只核对材料推演。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 园区通知与未写时限的客户函 | 提醒日10月21日；默认时限算到10月20日、提醒16日，口径注明 |
| 缺资料 | 扫描件无收到日期和文号 | 登记可见字段，未知项标材料待确认，不倒填 |
| 矛盾 | 已办结但查不到关联发文 | 恢复待核实并留痕，不删行 |
| 边界 | 问逾期是否构成违约 | 不给法律结论，整理时间线交专业人员 |
| 超能力 | 接入系统自动催办并代回函 | 不接入不代发，交排程表与登记模板 |
