# 可复制收发文底稿

```text
制度口径：收文号格式｜发文号格式｜起算规则｜工作日口径｜默认时限｜提醒点｜统计日。
收文登记：收文号｜收到日期时间｜来文单位｜来文文号｜标题｜载体｜紧急程度｜附件数｜主办｜协办及配合内容｜办理时限｜时限来源（来文/默认）｜提醒日｜办理结果｜办结日期｜关联发文号｜归档位置。
流转记录：收文号｜序号｜转出｜转入｜理由｜时间｜时限是否重算｜经手人。
发文登记：发文号｜标题｜主送单位｜签发人｜发文日期｜关联收文号｜份数｜归档位置。
催办记录：收文号｜日期｜方式｜对象｜回复。
作废号登记：编号｜作废原因｜作废人｜日期。
月度清单：统计日｜号段｜登记件数｜作废号｜已办结（按时/逾期）｜未办结（逾期/未到期）｜到期件按时办结率（分子/分母）。
未办结明细：收文号｜标题｜主办｜时限｜逾期天数及口径｜催办记录。
```

## 已填假设示例：一家制造企业的十月收文

本例中的单位、文号和数字均为演示假设。制度口径假设为：收到次日起算，只算周一至周五，示例期间无法定节假日和调休；来文未写时限的默认五个工作日；统计日为2026年10月30日（周五）。

收-2026-0031：10月12日（周一）收到园区管委会通知，要求10月23日（周五）前报送安全检查自查表。主办行政部，协办生产部提供设备清单。时限以来文为准，提醒日为到期前两个工作日即10月21日（周三）；10月22日（周四）报送，按时办结。

收-2026-0032：10月13日（周二）收到客户关于交货安排的询问函，未写时限，按默认五个工作日从14日起算，依次为14、15、16、19、20日，时限10月20日（周二），提醒日10月16日（周五）。主办销售部，回复函以发-2026-0012于10月19日（周一）发出，两边互填编号，按时办结。

收-2026-0035：10月19日（周一）收到合作方对账确认函，默认时限从20日起算为10月26日（周一），提醒日10月22日（周四）。截至统计日仍未办结，按自然日逾期27日至30日共4天；本例期间无节假日，按工作日也是4天。催办记录：10月27日电话催主办财务部，回复为等待对方补发明细。

月度统计：本月号段收-2026-0026至0037，末号减首号加一为12，登记12件，无作废号，号段连续。已办结9件，时限都在统计日前，其中按时8件、逾期办结1件；未办结3件，其中逾期1件即0035、未到期2件。已到期件数为9加1共10件，到期件按时办结率为8除以10即80%，逾期合计2件，未到期的2件不进分母。
