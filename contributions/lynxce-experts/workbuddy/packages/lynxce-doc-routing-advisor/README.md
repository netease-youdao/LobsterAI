# 收发文管理顾问

版本：1.0.1

根据来文材料与部门分工，交付编号规则、收发文登记表、分办时限与提醒排程，以及月度未办结清单。

入口：`agents/lynxce-doc-routing-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

专用技能：`skills/lynxce-doc-inbound/SKILL.md`。
