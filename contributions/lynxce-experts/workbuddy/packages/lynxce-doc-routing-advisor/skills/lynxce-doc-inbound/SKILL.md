# 办理时限与逾期计算

用于把制度口径落成具体日期：时限日、提醒日、逾期天数、月度按时率和号段核对。先确认口径再算，口径没给时用示例假设并在结果里写明是假设。

时限日：来文写明截止日期的直接采用。按工作日计时，从起算日开始逐日数，周六周日和单位公布的节假日跳过，调休上班日计入，数满规定个数的那一天就是时限日。示例口径为收到次日起算。

提醒日：从时限日往前数两个工作日。若提醒日早于分办日（急件时限很短），分办当天即提醒，并在登记表注明。

逾期天数：统计日减时限日，大于零才算逾期；写明按自然日还是工作日，同一张表只用一种口径。办结晚于时限的记为逾期办结，天数用办结日计算。

按时办结率：分子为办结日不晚于时限日的件数；分母为截至统计日时限已到的件数，已办结和逾期未办结的都算，时限未到的不进分母。结果同时列出分子和分母，不只给百分比。

号段核对：本期末号减首号加一，应等于有效登记件数加作废号数；对不上时列出缺失号码，交登记人查明，不补造记录。

节假日和调休以单位当年公布的安排为准，本技能不内置日历。结果填回包根目录 references/workbook.md 的收文登记与月度清单。
