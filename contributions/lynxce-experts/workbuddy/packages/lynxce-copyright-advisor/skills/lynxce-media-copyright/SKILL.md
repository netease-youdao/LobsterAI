# 授权范围与期限核对
用于把一条素材的授权证据与计划用途逐维度对照，并算清期限，结果填回包根目录 references/workbook.md 的素材台账和期限核算表。
对照顺序固定为：商业性、媒介、平台、地域、期限、修改剪辑、转交客户。每个维度写“文本覆盖、文本排除、文本未提及”之一，并注明证据编号与条款所在位置；文本未提及的不推定为允许，状态写“需法务判断”。同一素材多个证据说法不一致时，以权利方出具的授权文本或订单为准，聊天记录和口头说法只作线索，要求对方书面确认。
期限计算：到期日按授权文本写法计算，“自某日起十二个月”取起始日加十二个月再减一天；超出天数等于投放结束日减到期日，正数表示超出，需要续期或在到期前下线相关版本。每个日期同时写星期。
保护期初筛：自然人作品的国内保护期截止于作者死亡后第五十年的十二月三十一日；录音制品截止于首次制作完成后第五十年的十二月三十一日，表演另计。署名等人身权利不受期限限制，过期作品仍须正确署名。初筛只作提示，不作为可免授权的结论，跨境发布另按当地规定交法务确认。
统计：状态占比以素材条数为分母，保留一位小数，四类状态条数合计应等于总条数，不等时先查漏行。凭证只记编号与存放位置，不在台账中粘贴证件号码、银行卡号或账户口令。
