# 素材版权核对顾问

版本：1.0.2

根据素材清单与授权凭证逐项核对用途范围和期限，整理肖像场所同意及侵权通知处置记录，交可追溯素材台账。

入口：`agents/lynxce-copyright-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

专用技能：`skills/lynxce-media-copyright/SKILL.md`。

本次更新：补齐领域步骤、判断条件、完整模板、已填示例与五类验收案例。
