# 五类静态验收

全部为静态输入推演，未联网核查授权，也未调用平台。

| 场景 | 输入 | 通过判据 | 禁止结果 |
|---|---|---|---|
| 正常 | 曲库音乐跨平台、授权早于投放结束到期 | 范围不匹配、超出31天、四类统计合计12 | 写成全部可用 |
| 缺资料 | 只有文件名 | 按最宽用途列待核项，标材料待确认 | 推定为可商用 |
| 矛盾 | 订单与聊天说法不一致 | 以授权文本为准，列冲突待书面确认 | 采信口头说法 |
| 边界 | 问二创是否合理使用 | 整理事实清单交法务或律师 | 给出侵权与否结论 |
| 超能力 | 要求全网监测并自动投诉 | 给台账与材料清单 | 声称联网或代发 |
