# 可复制素材核对底稿

```text
项目／成片版本／核对日期／核对人：
计划用途：商业性｜媒介｜平台｜地域｜投放起止（含星期）｜修改剪辑｜转交客户。
素材台账：编号｜类别｜出处与截图编号｜权利方｜授权类型｜证据编号｜获取日期｜使用位置｜七维度逐项对照｜状态｜待办。
音乐两层：曲目｜词曲授权｜录音授权｜平台限制｜署名要求。
人物同意：出镜人｜是否未成年｜同意书版本｜范围｜期限起止｜撤回约定。
场所许可：地点｜许可方｜形式（书面／口头补记）｜日期｜限制条件。
期限核算：授权起始｜期限｜到期日｜投放结束日｜超出天数｜处理。
保护期初筛：作品｜作者卒年或录制年份｜截止日｜仍需取得的授权层。
投诉处置：收到时间与渠道｜涉事素材｜下线时间｜授权链条｜交法务时间｜答复期限｜复盘。
状态统计：范围匹配待抽检／不匹配／凭证缺失／需法务判断；条数与占比。
关键问题：最多三项，每项说明答案影响哪条素材的状态。
```

## 已填假设示例：门店新品宣传短视频

以下全部为演示用假设。成片为品牌新品宣传，计划2026年10月28日（周三）在甲、乙两个短视频平台发布，同步在门店屏播放，投放至2027年3月31日（周三），属于商业用途。台账共12条素材：

- M01背景音乐来自甲平台内置曲库，授权限于甲平台站内；乙平台与门店屏不覆盖，状态“范围不匹配”，替换或另行取得授权。
- M02商用音乐订单显示自2026年3月1日（周日）起12个月，到期日为2027年2月28日（周日）；投放结束日比到期日晚31天，状态“范围不匹配”，需续期或在到期前下线门店屏版本。
- F01商业字体只有桌面授权，用于视频字幕是否覆盖需看授权文本，状态“需法务判断”。
- P01图库照片为编辑类授权，不能用于宣传片，状态“范围不匹配”。
- R02出镜顾客为未成年人，缺监护人书面同意，状态“凭证缺失”，发布前移除该镜头或补签。
- L01商场拍摄只有口头同意，状态“凭证缺失”，补书面确认。
- 其余6条（开源字体、带模特授权的商业图片、员工同意书等）证据齐全，状态“范围匹配待法务抽检”。其中员工同意书自2026年9月1日（周二）起两年，至2028年8月31日（周四），覆盖投放期。

状态统计：范围匹配待抽检6条占50.0%，范围不匹配3条占25.0%，凭证缺失2条占16.7%，需法务判断1条占8.3%，合计12条。

保护期初筛：片尾一段古典乐，假设作曲者1975年去世，国内词曲保护期截止于2025年12月31日；但所用录音为某乐团2019年录制，录音制作者权利截止于2069年12月31日，仍需取得录音授权。

投诉处置演练：假设2026年11月3日（周二）10:20收到乙平台转来的投诉，内部规定两小时内下线，即12:20前下线涉事版本；通知要求5个工作日内答复，期限为11月10日（周二），期间无法定假日。答复内容由法务审定。

结论写法：12条中6条可进入法务抽检，另6条处理完成并补齐凭证后再进入发布评审；是否发布由项目负责人在法务意见后决定。
