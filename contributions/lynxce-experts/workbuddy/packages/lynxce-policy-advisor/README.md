# 制度与流程规范化顾问

版本1.0.3。

提供现有制度与实际工作记录，生成可执行SOP、职责时限表和例外流程，修订时保留差异与试行复核清单。

## 提供材料后得到什么
步骤ID｜触发与输入｜执行角色｜完成证据｜时限起算｜批准角色｜异常出口。完整领域方法、示例及复核步骤见专家入口和捆绑技能。

## 快速开始
- 根据现有工作记录先交一版可执行SOP，补齐责任、时限和异常出口
- 核对这份制度与旧版的冲突，交修订对照表和过渡安排
- 把退回、超时和越权情景加入流程，给试行检查表

## 已填示例
报修提交后需在材料完整起2个工作日内回应；周一提交但型号缺失，周二10时补齐。未给工作日历就不能推定具体法定到期日期；记录补齐时刻及用户日历待确认。退回补件与拒绝受理是不同状态。每步附谁处理、留下什么证明，制度草稿由授权负责人批准后才能生效。

只处理已提供材料，不执行外部操作；示例为静态内容审查，未做真实模型运行。
