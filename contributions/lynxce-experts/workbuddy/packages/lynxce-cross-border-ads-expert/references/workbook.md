# 可复制广告调整底稿

```text
站点／币种／报表类型／日期范围／排除的归因未完成天数：
成本：售价｜产品与头程｜佣金｜配送｜退货及其他｜广告前利润｜盈亏平衡ACOS｜目标利润率｜目标ACOS。
整体：曝光｜点击｜花费｜订单｜广告销售额｜ACOS｜ROAS｜转化率｜店铺总销售额｜TACOS。
无单点击门槛：广告组转化率｜1÷转化率｜向上取整。
搜索词分层：搜索词｜点击｜花费｜订单｜销售额｜ACOS｜分类（否定候选／观察／降低竞价／加量／精准候选）｜依据。
竞价：投放｜当前CPC｜实际ACOS｜参考出价｜本次建议出价（单次不超30%）｜状态。
预算：活动｜现日预算｜分类｜调整后日预算｜原因｜状态。
复盘：调整日期｜前后同长周期指标｜同期其他因素｜结论。
待确认：最多三项，写明各自影响哪项动作。
```

## 已填假设示例：竹制砧板美国站

以下全部为假设数据。售价30.00美元；产品与头程7.50、佣金15%即4.50、配送5.20、退货及其他0.80，广告前利润12.00美元，盈亏平衡ACOS为40%；目标利润率10%，目标ACOS为30%。报表覆盖某30天，最后3天归因未完成，以下只用前27天数据；店铺同一27天总销售额4600美元。

搜索词A点击400、花费320、订单40、销售额1200，ACOS 26.67%，CPC 0.80，转化率10%。B点击150、花费165、订单6、销售额180，ACOS 91.67%，CPC 1.10。C点击15、花费12、零订单；D点击8、花费6、零订单。合计点击573、花费503、订单46、销售额1380，ACOS 36.45%，ROAS 2.74，转化率8.03%，TACOS 10.93%。

分层：无单点击门槛 = 1÷(46÷573) = 573÷46 ≈ 12.46，取13次。C点击15次达到门槛仍零单，列否定候选；D仅8次，继续观察。A、B平均订单金额均为30美元，B的ACOS可拆为 1.10÷(4%×30) = 91.67%，转化率只有A的四成，先核对该词与商品的相关性，再处理竞价。B高于盈亏平衡，参考出价 1.10×30%÷91.67% = 0.36美元，降幅超过30%上限，本次先调至0.77美元，下一周期再评估。A低于目标ACOS，所在精准活动日预算20美元，假设27天中有22天在18点前耗尽，列放量，日预算上调20%至24美元。B、C、D所在广泛活动花费183、销售额180，ACOS 101.67%，列收缩，日预算15美元下调20%至12美元。整体ACOS介于目标与盈亏平衡之间，维持总体策略。以上全部标“待执行”，用户执行后按相同27天长度复盘。
