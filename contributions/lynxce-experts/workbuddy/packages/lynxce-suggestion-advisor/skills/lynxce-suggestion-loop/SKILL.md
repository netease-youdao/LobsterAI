# 回复时限与闭环指标计算
用于建议登记后的时限计算和月末统计阶段，只基于用户提供的登记表计算，不代为分派或回复。
起算：时限从收到日次日起算。工作日按周一至周五计，公司公布的假期需扣除时必须写明依据；没有假期表时注明“未扣假期”。受理确认为2个工作日；立即类1个工作日内响应，本月类10个工作日内给结论，规划类30个自然日内给评估结论或计划。
逾期：回复日期晚于截止日即为逾期，记录晚了几个工作日和原因；到期日在统计月之后的议题不计入本月分母。
按时回复率 = 本月到期且按时给出结论的议题数 ÷ 本月到期议题数。采纳占比 =（采纳 + 部分采纳）÷ 已出结论议题数，“已有方案”和“转其他渠道”单列，不混入采纳。百分比保留一位小数，并写出分子分母。
一致性检查：汇总数必须等于明细逐条计数；各级别议题数之和等于议题总数；原始条数之和等于收到条数。不一致时停止公开，列出差额。
季度高频：同一议题季度累计不少于三条，或来自不少于两个部门，即转改进项。公开前检查涉及人数少于五人的部门是否已合并到上级部门。
计算过程与结果填入包根目录 references/workbook.md 的登记表与月度统计。
