# 可复制建议闭环底稿

将以下模板完整填写；不适用项写明原因，未知项保留【材料待确认】。

```text
渠道与规则版本／公示日期：
分流：类型（建议／投诉／违规举报／安全隐患／个人争议）｜去向｜负责人角色。
收集表字段：地点｜频率｜影响人数｜建议做法｜是否匿名｜选填回访方式。
登记表：编号｜收到日期｜原始条数｜议题｜类别｜级别｜责任人｜受理确认截止｜结论截止｜结论｜理由或改变｜回复日期｜是否逾期。
月度统计：收到条数｜议题数｜本月到期议题｜按时数｜按时率｜采纳｜部分采纳｜不采纳｜已有方案｜转其他渠道｜逾期部门。
公开清单：问题｜结论｜已做改变或理由｜完成时间（不含提议人，小部门已合并）。
季度改进项：议题｜季度累计条数｜涉及部门数｜责任人｜完成时间｜验收标准｜复发检查。
关键问题：最多三项，写明答案会改变哪条分级或哪项公开。
```

## 已填假设示例：11月建议闭环

以下为演示假设，不是真实公司数据，工作日按周一至周五计、未扣假期。11月共收到31条，合并重复后为24个议题，其中立即类2个、本月类15个、规划类7个，合计24个。

时限：一条本月类建议“打印机常卡纸”于2026年11月3日（周二）收到，受理确认截止11月5日，结论截止为10个工作日后的11月17日（周二）。一条规划类建议“增设午休区”同日收到，30个自然日后为12月3日（周四），届时给评估结论或计划。

月度统计：截止日落在11月内的议题共20个（含10月收到、11月到期的），均已出结论，其中按时17个，按时回复率17÷20=85.0%；逾期3个，行政部2个、信息部1个，在月度公开中点名部门并写明原因。20个结论中采纳9个、部分采纳5个、不采纳6个，采纳与部分采纳占比（9+5）÷20=70.0%。11月新收但截止日在12月的议题不计入本月分母，计入到期月份。

公开清单示例：“会议室预订冲突”结论为采纳，已改为预订须填结束时间，11月20日起执行；“延长下午茶时段”结论为不采纳，理由是该时段与客户接待重叠且已有茶水间全天开放的替代做法。法务部仅3人，其议题合并到职能中心名下公开。

季度高频：“食堂午餐排队久”10月4条、11月3条，季度累计7条，来自三个部门，转为改进项，由行政部负责，12月31日前给出错峰或增窗方案，验收标准为午高峰排队时长的抽样记录。
