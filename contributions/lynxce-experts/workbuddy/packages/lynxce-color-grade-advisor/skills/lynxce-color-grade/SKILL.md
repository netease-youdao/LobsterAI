# 调色与画面风格统一

调色翻车通常是**一上来就套滤镜**。先把白平衡和曝光校正准确，再加风格，系列视频才能统一。

## 工作流程（按顺序执行）

1. 问清拍摄设备与拍摄模式（普通/Log）、剪辑软件、账号风格参考、是否有人物出镜。
2. 一级校色：按「曝光 → 白平衡 → 对比度 → 饱和度」顺序把每段素材校正到正常。
3. 镜头匹配：以主镜头为基准，让同场景其他镜头的亮度与色温一致。
4. 二级风格：统一加风格（色调偏向、暗部与高光色彩、颗粒或暗角），强度适度。
5. 保护肤色：检查人物肤色是否偏绿偏紫，必要时局部调整。
6. 在手机上预览并保存为账号预设，输出参数记录表。

## 一级校色

- 曝光：看波形或直方图，高光不过曝、暗部不死黑。
- 白平衡：找画面中本应是白或灰的物体校准。
- Log 素材先做色彩空间转换或使用对应还原 LUT，再进入后续调整。
- 同一场景的镜头先匹配再统一加风格。

## 风格与 LUT

- 风格 LUT 放在校色之后，强度通常 40%–80% 起调。
- 一个账号固定 1–2 套风格，系列内容不随意更换。
- 暖色调适合生活美食，偏冷偏青适合科技与城市，但以内容为先。
- 付费或下载的 LUT 与预设确认授权范围。

## 检查清单

- 肤色自然，没有明显偏色。
- 转场前后两个镜头亮度、色温无跳变。
- 手机端预览：暗部是否太黑、字幕是否仍清晰。
- 导出设置与平台推荐参数一致，避免二次压缩发灰。

## 示例

用户：「探店视频室内灯光发黄，每个镜头颜色都不一样。」→ 先以白色餐盘校准白平衡，统一曝光；以主机位镜头为基准匹配其他镜头色温；再叠加 50% 强度的暖色风格；检查人物肤色不过橙；保存为「探店-室内暖光」预设供后续复用。
