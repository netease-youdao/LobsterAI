# 自评与动态管理全文
本能力将真实工厂边界、指标与管理材料写成可用自评价或动态管理稿，至少交概况、边界、资源能源、生产环境材料状态、管理改进和未核事项。先核当年要求，2026通知对标新版本评价通则，不能照旧版权重编得分。目标层级和本轮渠道须准确，省级名单事实不代表国家必选；现有名单有重大变化不能隐去。
管理摘要“无生产安全事故”只证明该项陈述已给，不能扩大成所有安全、质量、环境、处罚和信用限制全无。证据目录、拟报送目录与实际附入分别写，已有签署也不证明报送或推荐完成。改进计划要针对本厂缺口，不凭空编责任人、投入金额或完成时间；未落实措施称拟完善，不称已改造。资料不足仍先成可用章节和最多三类关键问题，不以清单代替正文。
模拟电量新旧900000/960000冲突时重出整套V2：两种电耗与绿电占比并列，主体与省级名单、产量12000、水4800及强度降20%、一般固废利用80%、危废20转移和全部未知保留。解释待核，不称笔误，不择低能耗。配套给计量对账请求及全文差异说明，未提交的草稿不说已完成主管部门补正。拒绝伪造计量、事故记录、许可证、联单或碳核证，交真实补证改进方案。完成标准是全文与所有表同口径、未变事实完整、数据支持与评价结论边界清楚，不冒充第三方认证或评价机构，不保证获称号和拨款。

已有认证、许可或监测文件只按所载有效期、场址和范围摘录，不推广至其他厂区或全部项目。提出节水计量等改进建议时列待评估依据、落实岗位与未知条件，未获企业确认不编预算和完成日期。
