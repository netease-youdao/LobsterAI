# 能源、水与固废分别计算
本能力把能耗、水、绿电和固废数据转为可核对的自评指标，输入是同一已确认边界内的源单、分母、计量单位及评价表原文。先统一千瓦时、立方米、吨和件等单位，保留原数再计算绝对变化与单位强度变化；不因单位能耗下降就写总量下降相同比例。没有碳系数或标煤系数不自行换算，不出碳核证结果，也不把绿电合同容量当实际消费电量。
新鲜水、循环水、排水和耗水分别识别，不能把循环利用率与单位取水混为一项。一般工业固废综合利用率按实际适用表和同范围分子分母核，危险废物合法转移只是去向事实，不自动并入一般固废利用。全部数据出自账单摘要时仍留原件待核，不能声称法定检测和许可已合规。
模拟基期电1000000除10000件为100，本期900000除12000为75，强度降25%、绝对量降10%；水5000至4800、单耗0.5至0.4，强度降20%、绝对降4%。本期绿电180000除900000为20%，一般固废80除100为80%，危废20转移另列。新增电960000有效时单耗80、降20%、绝对降4%、绿电18.75%，水与废物不随电量改写。输出全指标表、逐算式和可复制指标说明，不只丢一串比例。完成标准是每个指标单位和分母一致、绝对与强度清楚、基期未知占比不补0，所有假设结果不升级为行业领先分数、合格认定或补贴数。

总账与分项表合计不一致时先保留未分配差额和表计位置，不能按各部门产量比例摊成已测量值；产量来自内部统计就标内部统计，未给审计证明不加“经审计”。不同产品、不同能耗品种未提供可比系数时分列，不先硬合为综合单耗。能源计量数据与金额账单有税费和价格影响，电费下降不能直接代替电量下降。
