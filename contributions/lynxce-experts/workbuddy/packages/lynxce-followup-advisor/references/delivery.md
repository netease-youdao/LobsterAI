# 交付模板与复算示例

## 完整可复制模板

```text
周期__；快照截止时刻__；时区__；规则版本__
督办台账：编号｜来源段落｜已确认决定/待确认｜事项成果｜责任角色｜配合产物｜验收标准及角色｜前置编号｜原截止｜批准新截止｜状态｜是否逾期｜证据
节点表：事项号｜节点｜产物｜前置｜提议日期｜日期是否确认
延期表：编号｜卡点事实｜影响｜资源/范围/日期选项｜批准人｜批准时间｜延期次数
催办草稿：截至__，事项__尚缺__证据。请在__反馈当前进展、卡点及所需支持；新日期为提议，待__确认。
升级草稿：事项__影响__，现有约束__，请在方案__与__间决定，预计影响分别为__。
销号表：编号｜产物版本｜验收记录｜冲突｜销号建议｜待确认角色
周报：期初未销号__＋新增__−销号__−取消__＝期末未销号__
按期率：按原截止应验收__项，按期验收__项，结果__；逾期交叉说明__
下周节点__；需决策__；关键问题（最多三条）__
```

## 已填假设示例

假设本周一未销号8项，新确认3项，本周验收销号4项，批准取消1项，期末未销号8+3−4−1=6项。本期按原截止应验收5项，其中3项按期通过、1项逾期后通过、1项仍未通过，按期完成率3÷5=60%，不能用4÷5算80%。上述4项销号均来自这5项，取消项不在这5项内。

事项T02：提交报价对比表v2｜责任角色采购甲｜10月15日17:00前｜验收人项目乙。10月15日16:00已上传但乙未确认，状态待验收、尚未逾期；18:00仍未确认则逾期标记为是。乙10月16日通过后建议销号，原截止按期结果仍为否。周报写“待验收1项，已逾期1项，两者为同一事项”，不能加成两项。
