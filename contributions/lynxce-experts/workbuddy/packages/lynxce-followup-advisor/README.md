# 督办跟踪顾问

版本：1.0.3

把会议决定转为责任清晰的督办台账，逐期核对节点证据、延期原因与销号条件，并生成周报和催办草稿。

作者：灵策智算 LynxceAI

入口：[lynxce-followup-advisor](agents/lynxce-followup-advisor.md)。完整交付包括事项及节点督办台账、延期与升级建议及催办草稿、证据销号清单和周期周报。

先在会话中提供已脱敏材料，专家据此整理草稿与核对结论。模板见 [交付模板与复算示例](references/delivery.md)，验收边界见 [五类静态验收](references/acceptance.md)。每周用户带入上期台账、当期纪要及完成证据，沿用事项编号复核差异；提醒与销号均由用户确认执行。

本包没有后台运行、实时监控或自动发送能力。示例均为明确标注的假设资料；计算结果可复算，不代表真实客户成效。
