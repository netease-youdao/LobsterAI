# 可复制评优底稿

将以下模板完整填写；不适用项写明原因，未知项保留【材料待确认】。

```text
方案名称／版本／统计期间／资格截止日：
目的与覆盖范围：
名额：参评人数｜比例｜向下取整名额｜不足一名而并池的部门。
预算：奖励形式｜单人金额｜合计｜余额用途｜财务确认人。
奖项设置：奖项｜鼓励的行为｜名额｜参评资格｜一票否决项｜限得规则。
评分细则：维度｜分值｜类型（数据／评委）｜口径或档位锚点｜来源｜取数人。
分值核对：各维度合计＝满分？
回避矩阵：评委｜候选人｜关系｜是否回避｜声明编号。
汇总表：候选人｜数据分｜有效评委数｜原始分｜去极值规则｜平均分｜分差｜是否复议｜总分｜排名。
并列与递补：比较顺序｜递补名单。
公示清单：奖项｜姓名或团队｜部门｜事迹（百字内）｜公示期｜异议提交方式。
异议登记：编号｜收到日期｜是否实名｜异议事实｜核实方式｜结论｜答复日期｜是否更正。
留档：文件｜版本｜保管人｜保存期限。
关键问题：最多三项，并写明答案会改变哪条规则。
```

## 已填假设示例：年度业绩突破奖

以下全部为演示假设，不是真实评审记录。统计期为2026年1月1日至11月30日，资格为期末在岗满六个月，符合资格者240人；个人奖比例5%，名额240×5%=12，分为业绩突破5名、客户口碑4名、协作之星3名。某部门参评14人，14×5%=0.7，不足一名，并入跨部门评选池。预算30000元，单人奖金2000元，12人合计24000元，余6000元用于证书与颁奖，发放与个税处理由财务确认。

业绩突破奖满分100分：数据分50分由取数人计算，达成率≥120%得50分，100%≤达成率<120%得40分，80%≤达成率<100%得25分，低于80%不具备本奖项资格；事例分50分由七名评委打分，复议线为50×30%=15分。

候选人甲目标300万元，实际345万元，达成率115%，数据分40分。评委中一人是甲的直属上级，回避后有效评委六人，分数41、43、44、45、39、48；去掉48和39后平均（41+43+44+45）÷4=43.25，总分83.25；分差48−39=9，不复议。候选人乙目标200万元，实际250万元，达成率125%，数据分50分；七份分数30、33、35、36、34、31、38，去掉38和30后平均169÷5=33.8，总分83.8；分差8，不复议。候选人丙目标150万元，实际114万元，达成率76%，不进入本奖项。排名乙在甲前。

公示期为2026年12月14日（周一）至12月18日（周五），共五个工作日。12月15日收到实名异议，称甲的业绩含一笔已退款的30万元订单。财务核实后甲的实际业绩为315万元，达成率105%，仍在40分档，总分不变，维持结果，并把公示事迹中的金额更正为315万元；按受理后三个工作日内答复的规则，最迟12月18日书面答复。原值345万元、更正依据和核实人写入异议登记，异议人身份不出现在任何公开材料中。
