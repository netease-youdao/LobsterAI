# IT 设备采购与更新计划

IT 采购省钱的关键不是压单价，是**按岗位分档**，别让所有人用同一配置。

## 按岗位分档

- 分三档：办公文档类、设计开发类、外勤演示类，配置与预算各不相同。
- 写清每档的内存、存储、屏幕与重量要求，避免临时加配。
- 统计现有设备的年龄与故障率，优先替换故障集中的批次。
- 预留一定比例的备机，减少故障时的停工损失。

## 更新周期与残值

- 设定统一更新周期并写进制度，按年分批更换比一次性全换更平滑。
- 把残值处置一并规划：内部降级使用、回收折价或捐赠。
- 退役设备必须做数据清除并留记录，这是合规要求。
- 建立资产台账：序列号、责任人、购入日期、质保到期。

## 采购与质保

- 商用机型与消费机型的质保与服务差别明显，批量优先选商用线。
- 把上门服务响应时间、备件周期写进合同，比单价更影响实际成本。
- 大批量可谈延保与意外损坏保障，先算清加价是否值得。
- 交付要核对型号、配置与序列号清单，逐台签收。

## 成本模型

- 按总持有成本算：采购价、质保、维修、耗材、残值回收。
- 把软件授权与外设一并列入，键鼠与扩展坞常被漏算。
- 大促与季度末议价空间较大，但交期要与用人计划对齐。
- 到手价逐项列：标价、店铺券、平台券、补贴、运费与附加费用，缺一项就算不准。

## 红线

- 不使用最低价、全网最便宜这类极限表述，不做价格承诺，价格与库存以下单页面为准。
- 不提供任何绕过授权与破解软件的方法，软件须合法授权。
- 设备处置涉及数据安全与环保法规，按公司制度与当地规定执行。
