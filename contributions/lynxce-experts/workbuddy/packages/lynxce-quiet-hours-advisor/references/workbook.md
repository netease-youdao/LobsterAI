# 可复制公约底稿

将以下模板完整填写；不适用项写明原因，未知项保留材料标记。

```text
区域／人数／公约版本／记录周期：
盘点表：日期｜时间｜来源类型｜具体情形｜持续分钟｜是否必要｜记录人编号。
统计：记录人数｜回收率｜记录人日｜总次数｜人均每天次数｜总分钟｜平均单次时长｜同时通话峰值。
分类：类型｜次数｜次数占比｜总分钟｜分钟占比｜次数排序｜分钟排序｜处理方式（公约、设备、观察）。
分区：区域｜位置｜到最远工位的距离与步行秒数｜位数｜用途｜使用规则。
专注时段：时段｜时长｜合计占工作时长比例｜例外岗位与替代做法。
公约：序号｜规则｜适用时段｜适用区域｜替代做法｜例外。
表决：应到｜实投｜赞成｜门槛｜结果｜主要反对意见。
复盘：指标｜试行前｜试行后｜变化率｜成功线｜判断｜下一步。
待确认：最多三项，每项写明会改变哪条规则。
```

## 已填假设示例：销售与研发同一开间

以下数字均为假设，只演示口径。研发二十人与销售十二人同在一个开间，研发投诉电话吵。研发区16人连续记录5天，回收率16÷20=80%，记录人日16×5=80。共记录打断480次，人均每天480÷80=6.0次。

分类：电话216次、讨论120次、外放72次、走动48次、设备24次，合计480次，占比依次为45%、25%、15%、10%、5%。平均单次时长假设为电话3分钟、讨论6分钟、外放1分钟、走动1分钟、设备2分钟，总分钟依次为648、720、72、48、48，合计1536分钟；平均单次1536÷480=3.2分钟，人均每天被打断1536÷80=19.2分钟。按次数电话、讨论居前两位，按分钟讨论、电话居前两位，因此先治电话与讨论，外放进观察名单。

分区：销售区盘点中同时通话峰值为4人，通话区设4个位。候选位置甲距最远销售工位22米，约22÷1.2≈18.3秒，符合二十秒线；候选位置乙30米，约25秒，不采用。专注时段定为9:30至11:30和14:30至16:00，合计3.5小时，占8小时工作时长的43.75%，未超过一半。公约六条，研发区应到20人、实投18人、赞成15人，赞成比例15÷18≈83.3%，达到三分之二门槛。

复盘：试行第四周研发区15人记录5天，记录人日75，打断270次，人均每天270÷75=3.6次，较试行前下降（6.0−3.6）÷6.0=40%，达到三成成功线。总分钟600，人均每天600÷75=8.0分钟，较19.2分钟下降约58.3%。回收率15÷20=75%，高于六成。结论写“试行达标，继续执行并每季度复盘”；外放类次数若在下一季度升到前两位，再补一条提示音规则。
