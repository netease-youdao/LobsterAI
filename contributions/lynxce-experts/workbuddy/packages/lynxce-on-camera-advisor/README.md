# 出镜表现顾问

版本：1.0.1

把出镜稿改成便于表达的口语脚本，交付停顿标记、分段练习、十分钟训练表和回看记录，比较同口径变化

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 逐句口语改写与停顿标记
- 提词与分段录制准备表
- 完整十分钟练习安排
- 按相同时长单位比较的回看记录
