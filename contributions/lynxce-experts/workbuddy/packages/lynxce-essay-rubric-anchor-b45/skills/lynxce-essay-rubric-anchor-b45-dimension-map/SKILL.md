# 评分维度与部分分拆解

## 何时调用与最低输入
输入题干、教学目标和总分；最适合在首次阅卷前或发现同一证据重复给分时调用。
只围绕本项任务制作一个可以被上层专家直接引用的中间成品。用户没有给出的条件以待补标记；可先按写明的假设生成样稿，再提出不超过三个会改变结果的问题。给每次输入分配材料编号，同一编号在本轮中保持含义不变，不能把推测写成材料事实。

## 具体制作方法
把题干动词拆为判断、解释、举例、核查四类动作。为每项写“出现什么原句即可确认”，再分总分。先用空答案检验零分定义，再用完整答案检验满分是否可达；中间档必须写清缺了哪个动作，不能只用较好、一般、较差。把每条作答证据只分配到一个主要维度，必要的交叉关系写在说明中但不重复记分。遇到不连续档位，应说明为何没有二分而只有零、一、三分。

## 可复制的已填示例
假设十分题：判断二分、解释三分、反例三分、核查二分。已填证据行：句一“平均不代表每个人”归判断；句二“个人有增有减”归解释；句三两人数据归反例；句四配对记录归核查。合计二加三加三加二为十分。空模板为“维度／最高分／零分证据／中间分证据／满分证据／不能重复计入的内容”。

## 修订与完成判据
若教学目标不要求数据反例，先把三分的去向交给教师确认，不能自行删掉总分。交付必须包含完整量规表、一次满分与一次部分分演算，以及尚未确认的范围。
交付时同时给可直接使用的正文和一段使用说明，指出哪个条件变更会触发重做。引用本项成品时保留版本号和适用范围，不能只复制结论丢掉假设。遇到用户要求跳过必要输入，仍给可编辑草案，并把受影响位置显式标注，不扩展成未经授权的执行。完成意味着输入可以逐项映射到输出，示例能够手算或逐句核验，所有占位都已有用途说明；不把纸面设计写成已经获得现实反馈。

档位与证据分别核验。判断中“不能推出”或直接回答“不一定”均为明确否定计2，只有未作立场的犹疑计1，避免量规表与中档锚例冲突。反例档位0/1/3可枚举，组合的和不能证明原文满足该档。


第四轮数值复用：按本轮原始值实际调用包内scripts/lynxce-essay-rubric-anchor-b45/round5/format_exact.py；复制同次精确/显示text。循环小数用≈，精确等式逐值相等；未知或零分母不可算，不能把真实算错简单换≈。本项原有证据定位、完整文本及版本修订职责保持。


第五轮完整成品门槛：此能力应交实际可用正文，不是只交统计附件或“已保留”声明。维度能力须给实际维度/全部档位证据；锚例能力须给三份完整作答与逐维原句理由；校准能力须给每段实际活动、产物、版本及重评边界。把本项正文纳入本轮sections，由同JSON数值占位替换后与整包一并渲染。
