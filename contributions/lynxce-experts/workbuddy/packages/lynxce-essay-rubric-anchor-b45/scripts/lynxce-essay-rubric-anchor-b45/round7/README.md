# 完整评分包＋精确数值附件
本工具不自动判学生原句证据，也不是批卷系统。它做原有Fraction算术与显示复核，并把专家制作的完整正文sections与计算字段合并渲染。数值附件不是完整产品。

运行 `python3 scripts/lynxce-essay-rubric-anchor-b45/round7/format_exact.py 本轮输入.json`；同输入加 `--format markdown` 得整份评分包。专家任务输入必须documentRequired:true，并列requiredSections的完整业务章节id。sections逐项给id/title/text；text中{{计算id}}被同一JSON本次实际结果替换。缺必需正文、只有数值页、引用未知计算id均退出2，不能以有数值表冒充完成量规与锚例。章节存在检查不代表语义质量自动通过，仍须独立审完整文本。

正常正文至少有题干范围、实际量规维度/所有档位/证据、三份完整作答锚例及逐维理由、合理异解、15分钟真实校准活动与产物、可执行反馈、未知项/版本修订。争议正文至少保留原分与版本、原句逐维证据表、数值与证据边界、分歧处置/权限/重评范围、15分钟校准活动、反馈与待补。不能把这几项写成标签或声明“已保留”。

calculations支持sum/mean/difference/absoluteDifference/ratio/percent/constant。values用有限十进制/分数字符串或null；precision默认2、允许0–12。percent精确基础值是比例2/3，显示为200/3%≈66.67%；有限7/2=3.5，循环11/3≈3.6667。主稿内数字使用{{id}}占位直接引用，而不是手抄。原始事实与档位是输入，不是自动评分结果，必须有原句/用户或明确假设来源。

claims给calculationId/value/relation，精确等式完全相等才过；近似也须在显示末位半单位容差内，0.93≈0.77拒绝。零分母/未知返回不可算，断言null不称通过。错误断言退出2。既有正常10/4/0、均值2/3、议程15，以及争议原4/8、均值6非裁决、证据4/无反例上限7、反例1可到8的条件边界全部保留。实际量规版本与正式权限未知不补造。

整份Markdown先输出完整sections，最后是同次精确数值附件；“直接采用脚本Markdown”指整包，不能只复制附件。边界算术样例没要求完整文档时仍能单独运行，但标题明确仅数值附件。所有样例为本地验证，不是新模型试跑或真实教学结果。
