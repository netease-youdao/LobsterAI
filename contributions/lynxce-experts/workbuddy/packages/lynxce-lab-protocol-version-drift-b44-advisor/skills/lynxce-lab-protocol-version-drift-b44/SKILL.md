# 实验记录版本偏差表

公共独立小任务：核已形成实验记录所引用方案与用户批准适用版本之间的资料偏差。用户为研究组实验资料管理员。输入只需执行记录号、执行开始时间、引用方案号、生效时点、批准过渡条件。此项按自己的证据键、方法和输出表工作，不以专家摘要替代专项交付，不依赖任何外部接入。

## 工作流程

1. 锁定本项任务：核已形成实验记录所引用方案与用户批准适用版本之间的资料偏差。最少输入为执行记录号、执行开始时间、引用方案号、生效时点、批准过渡条件；先给材料范围和截止时点，超出本项范围的请求单独记录。

2. 按最少字段建立证据索引：为每个执行记录锁定开始时点和引用版本，按用户给定生效与过渡规则选应引用版本；不能凭文件修改时间认作方案批准时间。

3. 建立对象与事件关系：逐条并列实际引用版本与适用版本，版本不同先记资料偏差候选，不把实验结果直接判为无效。

4. 执行专项推演：版本相同还需核关键字段摘录，附件被覆盖导致同版本内容不同时列内容冲突；没有方案正文不能判断参数差异。

5. 检查专属异常与边界：按记录号去重统计匹配、偏差与未知，保留适用依据及原始数据索引，把需要研究负责人判断的科学影响单列。 对照缺资料与冲突案例，确认缺项没有被填成示例值。

6. 交付实验记录版本偏差表文本表与补证队列，逐格保留资料编号及状态。重新核正常与边界算式，给负责人确认入口；实际完成状态以用户后续反馈为准。

## 专项方法与证据顺序

- 为每个执行记录锁定开始时点和引用版本，按用户给定生效与过渡规则选应引用版本；不能凭文件修改时间认作方案批准时间。

- 逐条并列实际引用版本与适用版本，版本不同先记资料偏差候选，不把实验结果直接判为无效。

- 版本相同还需核关键字段摘录，附件被覆盖导致同版本内容不同时列内容冲突；没有方案正文不能判断参数差异。

- 按记录号去重统计匹配、偏差与未知，保留适用依据及原始数据索引，把需要研究负责人判断的科学影响单列。

## 专属异常和采用条件

- 生效时点用含下界区间明确，批准允许旧版完成的既有运行按开始时点处理，不擅自按结束时点换版。

- 时间只有日期而边界精确到小时的记录列未知，不能猜执行在上午还是下午。

- 不推荐剂量、反应条件、危险试剂操作或临床判断，只整理提供的文字差异。

- 将记录用错版与方案缺签批分开，缺签批不能算已确认适用版本。

## 资料状态与交付复核

- 引用材料使用资料代号、版本和行号，事实摘录与推演结果分栏。未知值统一写【待补】；补证问题指出缺什么、为什么影响本项判断，以及用户应返回哪一格资料，不能仅泛称完善材料。

- 所有统计注明对象、单位及截止时点，记录数、唯一对象数与关联边数分开。计算从原始值逐步列算式，残差保留符号；不通过四舍五入隐藏冲突，零分母写不适用而非百分之百。

- 文本表是材料审阅草案。建议动作、用户确认拟执行、用户反馈实际完成采用不同状态；无反馈时不得变为完成。这里只用已给文字与表格手工推演，不声称已查询系统、通知人员或操作实物。

- 收到新增材料后只重算受影响对象，保留旧值、采用版本和修改理由。冲突未解决的对象不能挤入已确认集合；结束时检查每条输入有去向、每条判断有来源、每个未决项有最少补证动作。
