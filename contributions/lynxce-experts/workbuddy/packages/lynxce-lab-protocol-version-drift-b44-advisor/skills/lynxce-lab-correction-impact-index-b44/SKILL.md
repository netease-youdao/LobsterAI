# 实验更正受影响索引

内部独立专项：核一条资料更正传播到哪些派生表与引用记录。用户为研究组实验资料管理员。输入只需更正单、被更正字段位置、引用关系及派生稿版本。此项按自己的证据键、方法和输出表工作，不以专家摘要替代专项交付，不依赖任何外部接入。

## 工作流程

1. 锁定本项任务：核一条资料更正传播到哪些派生表与引用记录。最少输入为更正单、被更正字段位置、引用关系及派生稿版本；先给材料范围和截止时点，超出本项范围的请求单独记录。

2. 按最少字段建立证据索引：更正单保留原值、新值、更正理由及批准状态，未批准更正只列候选，不修改原始记录。

3. 建立对象与事件关系：从被更正位置沿用户提供引用边列直接及间接派生稿，重复路径只计同稿一次；缺引用关系不能假定全部报告受影响。

4. 执行专项推演：区分字段引用与仅引用文献标题，只有实际取用此字段的稿件进入待更新集合；科学解释影响交负责人判断。

5. 检查专属异常与边界：输出应复核、已反馈更新和缺版本三类，更新须有用户提供新稿证据，不把拟修改写成已更正。 对照缺资料与冲突案例，确认缺项没有被填成示例值。

6. 交付实验更正受影响索引文本表与补证队列，逐格保留资料编号及状态。重新核正常与边界算式，给负责人确认入口；实际完成状态以用户后续反馈为准。

## 专项方法与证据顺序

- 更正单保留原值、新值、更正理由及批准状态，未批准更正只列候选，不修改原始记录。

- 从被更正位置沿用户提供引用边列直接及间接派生稿，重复路径只计同稿一次；缺引用关系不能假定全部报告受影响。

- 区分字段引用与仅引用文献标题，只有实际取用此字段的稿件进入待更新集合；科学解释影响交负责人判断。

- 输出应复核、已反馈更新和缺版本三类，更新须有用户提供新稿证据，不把拟修改写成已更正。

## 专属异常和采用条件

- 环形引用通过已访问稿号停止重复扩展，列环路供用户核，不无限增加数量。

- 同稿不同版本分别关联，历史稿保留原值不无痕替换。

- 数值改动只演示差额和引用传播，不自动推导实验结论变化。

- 更正记录与异常解释分开，记录员不能替作者签批或补写原因。

## 资料状态与交付复核

- 引用材料使用资料代号、版本和行号，事实摘录与推演结果分栏。未知值统一写【待补】；补证问题指出缺什么、为什么影响本项判断，以及用户应返回哪一格资料，不能仅泛称完善材料。

- 所有统计注明对象、单位及截止时点，记录数、唯一对象数与关联边数分开。计算从原始值逐步列算式，残差保留符号；不通过四舍五入隐藏冲突，零分母写不适用而非百分之百。

- 文本表是材料审阅草案。建议动作、用户确认拟执行、用户反馈实际完成采用不同状态；无反馈时不得变为完成。这里只用已给文字与表格手工推演，不声称已查询系统、通知人员或操作实物。

- 收到新增材料后只重算受影响对象，保留旧值、采用版本和修改理由。冲突未解决的对象不能挤入已确认集合；结束时检查每条输入有去向、每条判断有来源、每个未决项有最少补证动作。
