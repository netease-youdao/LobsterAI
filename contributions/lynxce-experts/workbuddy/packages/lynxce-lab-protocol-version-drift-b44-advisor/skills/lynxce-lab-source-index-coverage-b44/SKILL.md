# 实验原始资料索引覆盖

内部独立专项：独立核记录号能否定位到用户提供的原始资料索引。用户为研究组实验资料管理员。输入只需记录号集合、原始资料代号、数据文件标签、页码或行号及引用关系。此项按自己的证据键、方法和输出表工作，不以专家摘要替代专项交付，不依赖任何外部接入。

## 工作流程

1. 锁定本项任务：独立核记录号能否定位到用户提供的原始资料索引。最少输入为记录号集合、原始资料代号、数据文件标签、页码或行号及引用关系；先给材料范围和截止时点，超出本项范围的请求单独记录。

2. 按最少字段建立证据索引：以实验记录号为核对集合，每条原始资料引用须含文件代号和页行位置；只有目录名时不可定位。

3. 建立对象与事件关系：一个记录引用多个原始资料分别建边，共享资料允许多条记录引用但要标共享范围；不能把引用边数当覆盖记录数。

4. 执行专项推演：统计至少有一份可定位资料的记录数，同时列资料缺失、索引不完整和标签冲突，区分类别互斥。

5. 检查专属异常与边界：记录重新编号时保存旧新号映射，只传索引不改原文件；定位成立仅指给定索引可查，不声称已读取文件。 对照缺资料与冲突案例，确认缺项没有被填成示例值。

6. 交付实验原始资料索引覆盖文本表与补证队列，逐格保留资料编号及状态。重新核正常与边界算式，给负责人确认入口；实际完成状态以用户后续反馈为准。

## 专项方法与证据顺序

- 以实验记录号为核对集合，每条原始资料引用须含文件代号和页行位置；只有目录名时不可定位。

- 一个记录引用多个原始资料分别建边，共享资料允许多条记录引用但要标共享范围；不能把引用边数当覆盖记录数。

- 统计至少有一份可定位资料的记录数，同时列资料缺失、索引不完整和标签冲突，区分类别互斥。

- 记录重新编号时保存旧新号映射，只传索引不改原文件；定位成立仅指给定索引可查，不声称已读取文件。

## 专属异常和采用条件

- 附件截图模糊的数值不能转录成精确数据；只列需提供清晰页号。

- 同标签两文件核日期与资料代号，不自动判定二者内容一致。

- 索引有地址或敏感信息时输出内部资料代号，不复制外部路径信息。

- 覆盖完整不表示数据真实、实验合格或可复现，科学判断由研究负责人作出。

## 资料状态与交付复核

- 引用材料使用资料代号、版本和行号，事实摘录与推演结果分栏。未知值统一写【待补】；补证问题指出缺什么、为什么影响本项判断，以及用户应返回哪一格资料，不能仅泛称完善材料。

- 所有统计注明对象、单位及截止时点，记录数、唯一对象数与关联边数分开。计算从原始值逐步列算式，残差保留符号；不通过四舍五入隐藏冲突，零分母写不适用而非百分之百。

- 文本表是材料审阅草案。建议动作、用户确认拟执行、用户反馈实际完成采用不同状态；无反馈时不得变为完成。这里只用已给文字与表格手工推演，不声称已查询系统、通知人员或操作实物。

- 收到新增材料后只重算受影响对象，保留旧值、采用版本和修改理由。冲突未解决的对象不能挤入已确认集合；结束时检查每条输入有去向、每条判断有来源、每个未决项有最少补证动作。

## 五种假设案例及预期

- 正常：假设四个记录，R1引用F1和F2，R2引用F3，R3引用F4，R4无索引。 预期：引用边4条，覆盖记录3条，覆盖3÷4＝75%，待补1条。 明确假设案例；已作静态算式复核，未作模型实测。

- 缺资料：假设只有目录实验资料，未给记录号和位置。 预期：记录集合与位置待补，覆盖率不可计算。 明确假设案例；已作静态算式复核，未作模型实测。

- 资料矛盾：假设同资料标签F1有两份不同日期文件，记录未注明采用哪份。 预期：F1引用冲突，不能计为可定位已确认，补资料唯一代号。 明确假设案例；已作静态算式复核，未作模型实测。

- 异常边界：假设零条执行记录、提供三份附件。 预期：记录分母0，覆盖率不适用，不写100%；三份附件列未关联。 明确假设案例；已作静态算式复核，未作模型实测。

- 超出能力：假设要求恢复丢失数据并证明没有篡改。 预期：仅整理索引缺口，不恢复文件、不出真实性鉴定。 明确假设案例；已作静态算式复核，未作模型实测。
