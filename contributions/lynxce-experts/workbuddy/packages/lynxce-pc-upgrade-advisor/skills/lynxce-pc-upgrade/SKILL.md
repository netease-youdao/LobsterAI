# 大促旧电脑加内存换固态核算

给旧电脑升级最容易吃亏的不是配件买贵了，而是**没查插槽买回来的内存代际不对插不进、M.2 口只支持 SATA 却买了 NVMe 不识别、CPU 已是瓶颈花几百元升级后仍然卡**。

## 工作流程（按顺序执行）

1. 问清电脑类型（台式机或笔记本）、品牌型号与购买年份、CPU 型号、现有内存容量与条数、现有硬盘类型与容量、主要卡在哪些场景（开机慢、开网页多了卡、剪视频卡）、预算，以及是否还在保修期。
2. 先查硬件底数：用系统信息或硬件检测工具查主板型号、内存插槽总数与已占用数、主板支持的最大内存、内存代际（DDR3/DDR4/DDR5）与频率；笔记本需确认内存是否板载焊死、有无空闲插槽，以官方规格或拆机图为准。
3. 定内存方案：代际必须一致，DDR3、DDR4、DDR5 金手指缺口不同不能混插；笔记本用 SO-DIMM 短条、台式机用 DIMM 长条；新条频率高于主板或旧条时自动降到较低频率运行；组双通道选同容量两条，日常办公 16GB、剪辑修图 32GB 为常见档位。
4. 定固态方案：先看 M.2 插槽是否存在及支持的协议（NVMe 还是仅 SATA）与长度规格（常见 2280）；无 M.2 的用 2.5 英寸 SATA 固态；SATA 固态顺序读取约 550MB/s，PCIe 3.0 NVMe 约 3500MB/s，老主板对 PCIe 4.0 固态会按 3.0 速度运行，不必多付钱。
5. 判升级还是换新：升级总成本＝内存＋固态＋系统迁移工具或上门服务费；CPU 为 7 年以上的双核或低压双核、或需要运行的软件对 CPU 有更高要求的，升级改善有限；升级总成本超过同等使用需求新机到手价的 40% 时，建议对比换新方案。
6. 输出硬件底数表、升级清单与升级对换新对比表，提醒升级前备份数据、确认拆机是否影响保修，最后按商品列出下单入口清单。

## 先查插槽与接口

- 内存插槽数、已占用数、最大支持容量与代际是升级前必须查清的四个数，缺一个就标【待补】，不凭型号猜。
- 笔记本常见板载内存加一个空槽，或全部板载焊死无法升级，以官方规格为准。
- M.2 插槽分 NVMe 与 SATA 两种协议，外观相同，买错会不识别；部分老机型只有 mSATA 或 2.5 英寸盘位。
- 主板 BIOS 过旧可能影响新硬件识别，更新 BIOS 有风险，需按厂商说明操作或交由专业人员处理。

## 内存与固态怎么配

- 双通道需两条容量相同，单条 16GB 与两条 8GB 相比，后者组成双通道在集成显卡机型上表现通常更好。
- 混插不同频率时整体按较低频率运行，不必为主板不支持的高频多付钱。
- 系统盘从机械硬盘换成固态是提升开机与软件打开速度的主要手段，容量按系统加常用软件留 30% 余量，常见 512GB 起。
- 换固态需迁移系统或重装系统，迁移前备份重要数据，旧机械硬盘可作为资料盘继续使用。

## 升级还是换新与红线

- 升级总成本＝内存到手价＋固态到手价＋工具或服务费，与同等需求新机到手价比较，超过 40% 建议换新。
- 升级后仍卡的常见原因是 CPU 或显卡瓶颈、散热积灰降频，必要时先清灰换硅脂再判断，由专业人员操作更稳妥。
- 拆机前确认保修条款，拆机是否影响保修以厂商规定为准。
- 不使用「最低价」「全网最便宜」「史低」「绝对划算」等极限或绝对化用语。
- 价格、优惠与活动规则一律以平台活动页、商品详情页与下单结算页的实时展示为准，本技能只做核算与提示，不做价格承诺，不保证必省多少钱。涉及退款纠纷、消费者权益认定的，以平台规则与主管部门规定为准，本技能不做法律结论。不编造价格、历史数据与活动规则，用户未提供或查不到的信息用【待补】占位。

## 示例

用户：「2018 年买的笔记本，i5 八代四核，8GB 内存一条，1TB 机械硬盘，开机要两分钟，开十几个网页就卡，预算 500 元。」→ 先查：假设检测结果为 DDR4 2400、两个插槽占用一个、最大支持 32GB、有一个支持 NVMe 的 M.2 2280 插槽；八代四核 CPU 日常办公不是瓶颈，值得升级；内存加一条 8GB DDR4 SO-DIMM 组双通道共 16GB，买 2666 或 3200 的会降到 2400 运行，不影响使用；固态选 512GB PCIe 3.0 NVMe，买 PCIe 4.0 也按 3.0 运行不必多付钱；假设内存 120 元、固态 230 元，升级总成本 350 元，远低于同需求新机到手价的 40%，建议升级，系统迁到固态、机械硬盘作资料盘。异常场景：若检测发现 M.2 插槽只支持 SATA，则改买 M.2 SATA 固态，买 NVMe 会不识别；最后给出硬件底数表、升级清单与下单入口。
