# 可复制取证与跟进底稿

将以下模板完整填写；不适用项写明原因，未知项保留【材料待确认】。

```text
作品编号／标题／形式与时长／首发平台与账号／首发时间（含时区）：
权属核对：自拍自剪｜委托制作（合同位置）｜第三方素材（授权位置）｜合作方约定｜存疑事项。
水印规范：内容｜位置｜不透明度｜字号与占比｜换位间隔与位置数｜剪辑预设名称。
归档清单：原始素材｜工程文件｜口播稿｜封面源文件｜成片母版｜首发记录截图｜哈希清单｜三处备份位置。
自查台账：日期｜关键词类型｜平台｜结果（无／发现）｜疑似账号｜作品页地址｜对方发布时间｜与首发时间差（小时）｜分类A至E｜状态。
取证记录：编号｜录屏文件名与时长｜录屏起始显示时间｜截图清单｜哈希值｜保存位置｜完整性检查结果。
时间码对照：原作时间码｜疑似作品时间码｜差值｜相同内容描述（至少三处）。
投诉跟进：平台｜提交日期｜工单号｜提交材料｜答复日期与内容｜结果｜下次查看日期｜负责人。
台账统计：发现数｜进入取证数｜只记录数｜已投诉数｜处理中｜已下架｜被驳回。
交律师判断：权属疑问｜引用点评类是否合理使用｜公证保全或第三方存证｜索赔与诉讼。
待确认：最多三项，写明影响哪一步。
```

## 已填假设示例：三分钟凉拌面教程

以下为演示假设，账号与时间均非真实记录。作品W07为竖版教程，时长3分钟，自拍自剪，背景音乐授权来自平台曲库并已记入权属核对，2026年10月9日（周五）20:00首发，有后台发布记录截图。水印用账号名，放在操作台主体右侧，不透明度40%，字号72像素，占1920高画面的3.75%；每20秒换一次位置，全片180秒，共排180÷20＝9个位置。

72小时加查截止为10月12日（周一）20:00。当天下午自查发现三个疑似作品：X1于10月10日09:30发布，画面声音一致，归A类，距首发13.5小时；X2于10月11日14:00发布，截取原作0:35至1:50共75秒，归B类，距首发42小时；X3于10月11日21:15发布，原作画面缩在画中画里并配对方讲解，归E类，距首发49.25小时。X1、X2进入取证，X3只记录并列入交律师判断事项。

取证：X1录屏4分10秒，开头展示设备时间，依次进入对方主页、作品页，停留展示发布时间与页面地址，再播放全片；X2录屏2分30秒，播放截取段。每份录屏记录哈希值，原件只读保存在两处。X2时间码对照取三处：原作0:35、1:02、1:48分别对应X2的0:00、0:27、1:13，差值均为35秒，与连续截取一致。

投诉：10月12日在平台官方侵权投诉入口分别提交X1、X2，材料为首发后台记录、工程文件截图、原始素材拍摄时间信息与对照说明，工单号记为【工单号】。台账统计：发现3个＝进入取证2个＋只记录1个；已投诉2个，均为处理中。跟进表约定每3天查看一次，下次查看为10月15日（周四）。待确认：X3是否需要处理，以及是否需要公证保全，均交律师判断。
