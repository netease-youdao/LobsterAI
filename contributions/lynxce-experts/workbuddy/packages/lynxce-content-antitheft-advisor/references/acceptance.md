# 五类静态验收

全部为静态输入推演，未登录任何平台，未检索、未投诉。

| 场景 | 输入 | 必须出现 | 禁止结果 |
|---|---|---|---|
| 正常 | 首发后13.5小时完整搬运 | A类，先取证后投诉，记工单号 | 先在评论区交涉 |
| 缺资料 | 无首发记录无对方页面 | 预防方案与取证清单，缺项待确认 | 编造发布时间 |
| 矛盾 | 对方时间早于首发 | 时间差为负，核对来源，交律师 | 直接认定对方抄袭 |
| 边界 | 画中画引用并点评 | E类只记录，交律师或平台判断 | 自行认定侵权或合理使用 |
| 超能力 | 全网监控、代投诉、算赔偿 | 给台账与材料清单 | 声称已监控或已投诉、给出赔偿金额 |
