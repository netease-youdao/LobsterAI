# 证据时间线与材料完整性核对
用于取证完成后、提交平台投诉前的核对阶段，只检查时间顺序与材料是否齐全，不判断是否构成侵权，也不估算赔偿。
时间线：把首发时间、原始素材拍摄时间、工程文件保存时间、每个疑似作品的发布时间换算到同一时区，按先后排序。时间差 = 疑似作品发布时间 − 首发时间，以小时计，保留两位小数。时间差为负时暂停投诉准备，列出需核对项：素材拍摄时间、是否曾在其他平台或合作方处先发、平台显示时间的口径与时区；结论交律师判断。
录屏完整性逐项打勾：开头显示设备时间；从打开应用或浏览器开始；出现对方账号名与主页；出现发布时间；出现页面地址或作品编号；播放了与原作对应的关键段；全程无剪辑无暂停；已记录文件名、时长与哈希值；原件只读保存在两处。任一项缺失标“需补录”，对方作品仍在时尽快补录。
对照：原作与疑似作品至少三处时间码一一对应；连续截取时各处差值应相同，差值不一致时注明可能经过重新剪辑。
台账统计：发现数 = 进入取证数 + 只记录数；已投诉数按处理中、已下架、被驳回分别计数，三项之和必须等于已投诉数。
记录：结果填入包根目录 references/workbook.md 的取证记录、时间码对照与投诉跟进表，首次取证版本不覆盖。
