# 升级批次与回滚时限计算
用于把样本测试、试点工单和回滚演练换算成每批人数上限与关键日期。只使用用户回传的实测数据；没有数据时保留公式并标【材料待确认】，不填估计值冒充实测。
1. 样本通过率 = 完全通过份数 ÷ 测试份数。任何一份关键业务样本失败，即使总通过率高也单独按风险分级处理，不用比例抵消。
2. 工单率 = 试点批前两个工作日工单数 ÷ 试点人数。支持上限 = 值守人数 × 每人每日处理量 × 2 ÷ 工单率，结果向下取整。
3. 回滚上限：已演练的单轮台数 n、单轮用时 t 分钟、回退时限 T 分钟，可回滚台数 = floor(T ÷ t) × n。每批人数取支持上限与回滚上限中的较小值，再扣除冻结期内的部门。
4. 日期：预告日为升级日往前数第3个工作日，提醒日为前1个工作日；问题汇总日为升级当日起第3个工作日；旧版保留截止不早于全员完成日后一个自然月的同一日；复盘日为全员完成后第14个自然日，遇休息日顺延。工作日要扣除用户提供的节假日与调休安排。
5. 每个结果写明代入值、取整方式与材料来源，填回包根目录 references/workbook.md 的批次上限栏；回滚演练没有记录时，回滚上限写“未验证”，该批不放行。
