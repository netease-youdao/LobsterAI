# Vlog 叙事与素材清单

流水账 Vlog 的问题不是拍得不好，而是**没有一个贯穿全片的问题**。先定主线，再决定拍什么。

## 工作流程（按顺序执行）

1. 问清主题（旅行/日常/探店/工作）、预计时长、拍摄设备、是否出镜、发布平台。
2. 定一句主线：「我想在【场景】里完成【目标】，过程中遇到【变化】」。
3. 按「开场钩子 → 目标 → 过程与变化 → 结果 → 感受或信息总结」列分段。
4. 为每段列必拍镜头：远景交代环境、中景动作、特写细节、第一人称视角、口播或旁白。
5. 列收音与现场注意事项，并提醒拍摄他人时的肖像与隐私边界。
6. 拍完后按分段结构给剪辑顺序与时长分配。

## 镜头怎么拍

- 每个场景至少拍全、中、近三种景别，剪辑才有得选。
- 每个镜头拍够 5–8 秒，动作开始前与结束后各多留 2 秒。
- 空镜头（环境、手部、物件）多拍，转场与压缩时间全靠它。
- 同一个动作换角度拍两遍，方便剪出节奏。

## 收音与光线

- 口播优先用领夹麦或靠近嘴边的收音，环境噪声大时先录旁白后配。
- 背光拍人脸会黑，顺光或侧光更稳。
- 室内优先靠窗自然光，夜景提高感光度前先稳住机身。
- 重要口播现场回放检查一次声音。

## 剪辑结构

- 开头 5 秒放全片最好看或最有悬念的画面。
- 过程段用「目标—阻碍—解决」推进，删掉不推动主线的片段。
- 背景音乐按段落换情绪，音乐与素材版权确认可商用范围。
- 拍摄路人与未成年人时注意隐私，必要时打码或取得同意；不编造数据、案例与来源，用户未提供的信息用【待补】占位。

## 输出模板

主线一句话：我想在【____】里完成【____】，过程中遇到【____】。

分段镜头清单：
| 段落 | 目标时长 | 必拍镜头（远/中/近/主观/空镜） | 口播或旁白要点 | 已拍 |

| 开场钩子 | 5秒 | | | □ |
| 目标 | | | | □ |
| 过程与变化 | | | | □ |

出门前检查：电量 □ 存储卡 □ 麦克风 □ 备用电池 □ 天气 □ 拍摄许可 □

## 示例

用户：「周末去一个古镇，想拍 3 分钟 Vlog。」→ 主线：「我想用 100 元预算在古镇吃遍当地小吃，过程中发现最火的店反而不好吃」；开场放排队长龙与一句「这家排了 40 分钟，值吗」；过程段每家店拍门头远景、制作特写、第一口表情；结尾给出预算表与推荐排序。
