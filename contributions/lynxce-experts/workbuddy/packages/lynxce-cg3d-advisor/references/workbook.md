# 可复制资产规范底稿

```text
项目／规范版本／平台与引擎／单位约定／材料编号：
分级预算：类别｜三角面上限｜贴图尺寸上限｜纹素密度目标与偏差｜依据。
资产行：名称｜类别｜真实尺寸｜是否形变｜LOD0三角面｜占预算比｜结论。
UV与贴图：表面积｜UV利用率｜贴图边长｜实际纹素密度｜是否在范围内｜显存。
贴图清单：后缀｜通道｜色彩空间｜压缩格式｜尺寸。
LOD表：档位｜三角面｜减面比｜切换屏幕占比（实测）｜碰撞体。
验收单：检查项｜通过/不通过/待确认｜证据截图编号｜复验日期。
异常排查：现象｜排查步骤｜观察结果｜结论或待确认。
关键问题：最多三项，写明答案会改变哪一项规范。
```

## 已填假设示例：仓储木箱道具

以下数字为演示假设。某第三人称游戏的普通道具档：三角面上限1500，纹素密度目标每米512像素，允许偏差正负百分之二十，即每米409.6到614.4像素。木箱真实尺寸为0.8米立方体，不形变，LOD0为1200个三角面，占预算百分之八十，通过。

六个面总表面积为6×0.8×0.8=3.84平方米，UV利用率按百分之七十。所需边长约为512×√（3.84÷0.7）≈1199.2，相邻的二的幂次为1024和2048：用1024时实际纹素密度=1024×√（0.7÷3.84）≈437.2像素每米，在范围内；用2048时约874.4，超出上限，故选1024。三张贴图为BaseColor、Normal、ORM，压缩后按每像素1字节估算，每张1024×1024字节即1MiB，三张3MiB，含多级渐远乘以三分之四约4MiB。

LOD按减半起步：LOD0为1200，LOD1为600，LOD2为300；作为小件也可只保留两档，由实测屏幕占比决定。碰撞体用一个长方体。验收时发现导入后一侧面发黑：该面所在部件在源文件中缩放为负一，修正为一并重算法线后需在三种光照下复查，记为待复验，等美术提交新导出文件后再标为通过。
