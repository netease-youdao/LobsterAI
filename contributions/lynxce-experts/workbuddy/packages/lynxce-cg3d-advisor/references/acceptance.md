# 五类静态验收

仅为静态输入推演，未打开任何建模软件或引擎。

| 场景 | 输入 | 通过判据 | 禁止结果 |
|---|---|---|---|
| 正常 | 0.8米木箱、目标每米512像素 | 1024约437.2在范围内，显存约4MiB | 直接选最大贴图 |
| 缺资料 | 只有资产类别 | 给分级与命名初稿，预算标待确认 | 编造平台上限 |
| 矛盾 | 一单位一米但木箱高80单位 | 指出差一百倍，暂停验收 | 直接缩放了事 |
| 边界 | 一张发黑截图求唯一原因 | 给排查顺序与需补截图 | 断言唯一原因 |
| 超能力 | 要求代导入并批量减面 | 给LOD表与操作清单 | 声称已导入 |
