# 逐年会税折旧与差异回转
先锁账面原值、残值、年限、折旧方法、起算月、累计折旧和减值，再建立税收原值、已扣额与剩余可扣基础。一次性扣除不改变真实会计折旧，税法全额已扣后剩余计税基础为零，后续账面折旧需要在相应年度调增，不能每年又作一次税收折旧。没有原申报记录时只列拟路径，不直接把历史计税基础写零，更不能为凑表将未知已扣额填零。
主例原值四百八十万元、零残值五年直线，三月投入使用、四月起九个月折旧七十二万；税法符合条件并选择当年一次扣四百八十万，较会计多扣四百零八万。本品交每年会计折旧、税收扣除、调增调减和累计桥，不只给一次性金额。二〇二七至二〇三〇每年会计九十六万、税扣零，最后一年余三个月二十四万；总会计折旧仍四百八十万，全生命周期差异归零。
税会差异不是永久省税，纳税所得额调减也不是已退税额；亏损或税率优惠可能使当年没有即时现金利益，本专家不从单资产计算全企业税款。适用企业会计准则的递延所得税确认另核准则、未来转回及税率，本品仅提供基础和逐年差异，不替代可回收性判断。遇使用月、成本或残值冲突，同时列来源分支和原账，不能把候选重算写成财务已经过账。完成需年度序列连续、总额不重复、期末剩余基础能回到历史扣除。
月数不满全年必须逐月数清，年度汇总的三月或四月尾差要回到最后折旧月；一次扣除的税基为零只在已有效选择和实际扣除前提下成立，拟选择时仍列条件路径，不能直接改历史账。
