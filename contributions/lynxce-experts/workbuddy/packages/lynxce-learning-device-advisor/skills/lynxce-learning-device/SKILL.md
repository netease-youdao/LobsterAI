# 大促学习机词典笔配置与内容核算

学习机最容易花冤枉钱的不是硬件，而是**买回来才发现核心课程要单独续费、宣传的护眼没有任何可核对参数，孩子年级用不上一半的内容**。

## 工作流程（按顺序执行）

1. 问清孩子年级与学段（学前、小学低年级、小学高年级、初中、高中）、主要用途（查词翻译、同步课程、作业辅导、英语听说）、预算、是否已有平板或电脑、每天预计使用时长与家长最关心的问题。
2. 按年级用途匹配形态：只需查词翻译与英语点读的优先词典笔（通常数百元）；需要同步课程与分科练习的看学习机；学前与小学低年级优先点读与绘本内容，初高中优先看教材版本覆盖与分科内容；用途不明确的先按查词需求起步，不一步到位买高配。
3. 核内容资源与续费：逐项确认教材版本是否覆盖孩子所用版本、哪些内容终身免费、哪些是会员或按年续费、续费价格与自动续费开关，商品页未写明的标【待补】；3 年总成本 = 到手价 + 3 年内容续费，续费年费超过到手价 20% 的单独提示。
4. 核护眼参数只看可核对指标：屏幕尺寸、分辨率、是否有第三方检测机构出具的低蓝光或无频闪认证编号、亮度调节范围，宣传中的「护眼」「防近视」等描述没有可核对参数的一律不计入评分，并提示用眼时长与距离以家长管理为主。
5. 核家长管控：是否支持应用白名单、使用时长限制、远程查看学习记录、禁止自行安装娱乐应用、防沉迷设置，逐项打勾，缺 2 项及以上的标「管控偏弱」。
6. 输出匹配建议、内容续费核算表、护眼参数核对表与家长管控清单，结论不承诺任何提分或成绩提升效果，最后按商品列出下单入口清单。

## 按年级与用途匹配

- 词典笔适合查词、翻译、英语点读，通常覆盖小学高年级到高中的查词需求，不能替代同步课程。
- 学习机适合需要同步课程、分科练习与作业辅导的家庭，核心看教材版本是否覆盖孩子所用版本与年级。
- 学前与小学低年级优先看点读、绘本与拼音识字内容；初高中优先看分科内容深度与题库覆盖，年级跨度越大越要核对内容是否持续更新。
- 已有平板或电脑的家庭，先评估用现有设备加内容会员是否能满足，避免重复购买硬件。

## 内容续费与护眼参数

- 逐项区分终身免费内容与会员内容，写清会员年费、是否自动续费、到期后已下载内容是否还能用，未写明的标【待补】。
- 3 年总成本 = 到手价 + 3 年内容续费，续费年费超过到手价 20% 的，单独提示长期成本并与其他型号对比。
- 护眼只看可核对指标：屏幕尺寸与分辨率、第三方检测机构的低蓝光或无频闪认证编号、亮度调节范围，没有认证编号的宣传描述不计入评分。
- 屏幕参数再好也不能替代用眼习惯，用眼时长、距离与休息安排以家长管理为主，有视力方面问题的以眼科医生建议为准。

## 家长管控与红线

- 家长管控五项：应用白名单、使用时长限制、远程查看学习记录、禁止自行安装娱乐应用、防沉迷设置，缺 2 项及以上标「管控偏弱」。
- 核对是否需要绑定家长账号、学习记录与个人信息如何存储，隐私政策未说明的标【待补】。
- 本技能不承诺任何提分、成绩提升或升学效果，宣传中的提分承诺不作为选购依据。
- 不使用「最低价」「全网最便宜」「史低」「绝对划算」等极限或绝对化用语。
- 价格、优惠与活动规则一律以平台活动页、商品详情页与下单结算页的实时展示为准，本技能只做核算与提示，不做价格承诺，不保证必省多少钱。涉及退款纠纷、消费者权益认定的，以平台规则与主管部门规定为准，本技能不做法律结论。不编造价格、历史数据与活动规则，用户未提供或查不到的信息用【待补】占位。

## 示例

用户：「孩子四年级，主要想查英语单词和同步课程，A 学习机 2999 元含 1 年会员续费 699 元/年，B 学习机 3499 元核心课程终身免费。」→ 四年级需要同步课程，学习机形态合适；先核两款教材版本是否覆盖孩子所用版本；A 款 3 年总成本 = 2999 + 699 × 2 = 4397 元，续费年费占到手价约 23%，超过 20% 单独提示；B 款 3 年总成本 3499 元，比 A 款低约 20%；护眼只比两款是否有第三方低蓝光认证编号与分辨率，只写「护眼」无编号的不计分；家长管控逐项打勾，缺 2 项以上标管控偏弱；不承诺提分效果；最后给出两款下单入口。
