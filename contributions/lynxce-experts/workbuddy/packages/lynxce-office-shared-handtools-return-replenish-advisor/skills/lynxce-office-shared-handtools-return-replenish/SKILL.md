# 共享手工具借还盘点与补损补货

聚焦办公室螺丝刀、扳手等共享手工具及其配件，先对互斥状态和借还流水，再决定补损补货；逾期不直接等于遗失。

## 工作流程（按顺序执行）

1. 收集工具唯一编号、规格和成套配件、期初数量、借还流水、批准期限、在借与在库清点、维修待查记录、批准移出和目标可用数。
2. 按在库完好、在借、维修、待查分互斥状态，一件只落一处；归还核工具规格与配件，损坏先隔离，不把返库数量直接记完好。
3. 核期末保有＝期初保有＋合格入库－批准移出，应等于各互斥状态之和；盘差保留待查，未经核实不标丢失，不以采购冲销差异。
4. 同规格可覆盖数＝在库完好＋经确认可在需求日前归还的完好工具，维修与待查不计；净需＝max(0,批准目标可用数－可覆盖数)，按包规取整。
5. 配件按套内实缺规格独立核算，采购不重复补整套与配件；记录包价税运日期和余量，核验到货规格、配件及完好状态后入库。
6. 输出借还事件、状态平衡、补货和未关闭异常表；超期按用户已有提醒流程处理，损坏责任与赔补由内部授权确认，不作法律或扣款结论。

## 逐件借还

- 套装编号关联配件清单。
- 借出和归还事件记录经办人与时间。
- 在借返还时间须有确认依据。
- 维修和待查不可同时计为可用。

## 平衡与补货

- 批准移出与暂时维修分开。
- 待查盘差先核事件再核实物。
- 补购按同规格需求日覆盖数计算。
- 整套与单件补配不能重复核算。

## 异常与交付边界

- 未关闭异常保留原始值和处理人，复核后再关闭。
- 未确认适配或条件不足的候选列待核。
- 采购包规余量与用户批准备用分开，避免重复加算。
- 先给适配与净购结论，再列带单位算式、取整依据、信息来源和办公表格。缺失信息标【待补】，示例数字不是用户事实。仅在用户要求采购比价时使用已连接的灵策优惠比价工具，先核规格再比较同口径到手价；无工具仍可整理用户数据，不编造参数、库存、实时价格或链接。用户明确要求购买入口且工具返回时才原样提供，不强制附链，不添加外链或邮箱。报价注明日期、包规、税费与运费，实际结算为准，不承诺最低价或节省额。余量、观察周期和验收条件来自用户确认、厂家说明或接收方要求，不自行设置通用标准。不作医疗、财税或法律结论。保留异常、负责人、时限和复核证据，不把采购完成当作现场通过。

## 示例

假设某规格螺丝刀期初12把，本期合格入库2把、已批准报损移出1把，期末保有12＋2－1＝13把。现场为在库完好7、在借3、维修2、待查1，7＋3＋2＋1＝13平衡。批准需求日目标10把，其中在借仅2把确认届时完好归还，可覆盖7＋2＝9把，净需10－9＝1把。2把/包购1包，假设包价24元、运费6元，到手30元，采购后可覆盖11把，目标余量1把。异常：若已确认归还的2把中1把回库发现刀头崩损，应转维修，可覆盖变8把，净需2把仍购1包但余量变0；若待查1把后来查到重复借出登记，应修正事件和状态，不再为它另购1把。以上数量价格为示例，损坏责任保持待内部确认。
