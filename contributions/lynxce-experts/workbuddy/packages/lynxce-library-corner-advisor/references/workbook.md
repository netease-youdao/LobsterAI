# 可复制图书角管理底稿

将以下模板完整填写；不适用项写明原因，未知项保留【材料待确认】。

```text
图书角名称／藏书总数／读者人数／规则版本号与生效日期：
分类编号：类别｜缩写｜流水位数｜示例编号｜复本后缀规则。
书目台账：编号｜书名｜作者｜类别｜入库日期｜来源（采购／捐赠及捐赠人）｜可否外借｜状态。
借阅规则：借期｜续借次数与天数｜在借上限｜预约规则｜休息日顺延规则｜暂停借阅规则及批准人。
借阅登记：编号｜书名｜借阅人｜部门｜借出日期（星期）｜应还日期（星期）｜提醒日期（星期）｜续借后应还日｜实还日期｜逾期天数｜标记。
催还话术：到期前｜逾期第一次｜逾期第二次｜转遗失流程。
季度盘点：类别｜在册｜在借｜在架｜待处理｜差异｜逐条处理结果。
下架候选：编号｜最近两季借阅次数｜是否不外借类｜入库日期｜处理建议｜公示日期。
采购征集：书名｜提名人｜推荐理由｜票数｜单价｜累计金额｜是否入选｜原因。
变更记录：日期｜修改项｜原值｜新值｜修改人。
待确认：最多三项。
```

## 已填假设示例：236册图书角

以下为演示假设。图书角236册，分8类，读者约150人；借期14天、续借一次7天、在借上限2本，休息日为周六周日。

借阅：编号GL-012于2026年11月2日（周一）借出，应还日为11月16日（周一）；提醒日原为11月14日（周六），提前到11月13日（周五）。借阅人续借一次，新应还日为11月23日（周一）。实际11月27日（周五）归还，逾期4天，台账标黄并记一次逾期。

到期前提醒话术：“您借阅的《【书名】》（编号GL-012）应还日期为11月16日（周一），如需继续阅读可续借一次7天，回复本消息即可办理。”逾期话术只写书名、编号、原应还日和续借或归还方式，不写评价。

盘点：台账在册236册；清点在借41册、在架183册、待处理9册（修补3册、遗失待处理6册），合计233册，差3册。逐条查：1册借阅漏登记，补登为在借；1册错放在相邻类别，归位计入在架；1册仍未找到，转为遗失待处理。更新后在借42册、在架184册、待处理10册，合计236册，差异为0。
