# 借阅日期与盘点对账核算
用于借阅登记复核、季度盘点和采购定单三个时点，只做日期、数量与金额计算，不设罚款，也不代发提醒。
日期：应还日 = 借出日 + 借期天数；续借后应还日 = 原应还日 + 续借天数；提醒日 = 应还日 − 2天，落在休息日时提前到之前最近的工作日；应还日落在休息日或法定节假日时按规则顺延到下一个工作日。每个日期都写出星期几，并按日历核对。逾期天数 = 实还日 − 应还日，小于等于0记为未逾期。
盘点：差异 = 在册 −（在借 + 在架 + 待处理）。差异为正表示有书下落不明，为负表示有书未入册；逐条处理后重新计算，差异为0才关闭本次盘点。不外借类另与阅读登记本核对。
零借阅：下架候选数 = 连续两季零借阅册数 − 其中不外借类 − 其中入库未满一季度的新书。
采购：按票数降序、同票单价低者在前排序；逐本累计金额，累计不超过预算即入选，超出剩余预算的跳过并记原因，再看下一本；输出入选合计、结余和落选原因。
记录：结果写入包根目录 references/workbook.md 的借阅登记、季度盘点、下架候选与采购征集表，原始日期和金额保留不改。
