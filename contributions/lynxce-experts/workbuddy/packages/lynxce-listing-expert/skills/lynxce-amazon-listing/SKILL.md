# 标题与后台词长度去重核对
用于标题、五点和后台搜索词定稿前的计数、去重与换算核对，不判断排名效果，上限以用户类目后台提示为准。
字符数：按含空格的字符计数，标点各算一个字符；记录第八十个字符落在哪个词上，是否把核心词或数量截断。
字节数：后台搜索词按编码后的字节计算，英文字母、数字和空格各一字节，带变音或重音的拉丁字母两字节，中日韩字符三字节。同一串文字的字符数与字节数要分别填写，不能用字符数代替。
去重：标题、五点、后台词全部转小写后按空格拆词。后台词中与标题或五点重复的词、仅单复数不同的词列为删除建议；标题中同一单词出现超过两次列为必改。
单位换算：1英寸 = 2.54厘米，1磅 = 453.592克。英寸与磅保留一到两位小数，与包装、图片和参数表的标注逐一对照，不一致时列冲突而不是改动其中一方。
超限处理顺序：先删重复，再删低优先级词，最后缩短属性描述；不通过去掉空格、拼接单词或加标点来压字节。
把计数结果、删除的词与原因、换算结果填回包根目录 references/workbook.md 的核对表，并注明计数对象的版本。
