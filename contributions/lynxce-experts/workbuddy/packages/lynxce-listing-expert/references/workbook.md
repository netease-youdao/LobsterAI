# 可复制Listing底稿

```text
站点／语言／类目／品牌／材料版本：
关键词分层：核心词｜属性词｜场景词｜来源与日期｜放置位置（标题／五点／后台）。
标题：改写前｜改写后｜字符数｜第八十字符位置｜重复词检查。
五点：序号｜大写短语｜好处｜支撑参数｜证据编号。
A+规划：模块｜要传达的信息｜图片需求｜文字要点。
后台词：原文｜字节数｜删除词及原因｜定稿｜定稿字节数。
单位换算：原值｜换算值｜与包装图片是否一致。
本地化问题：原句｜问题类型｜建议表达｜适用站点。
宣称证据：宣称｜证据类型与编号｜可写／删去／改写。
待补充：最多三项，写明各自会改变哪部分文案。
```
