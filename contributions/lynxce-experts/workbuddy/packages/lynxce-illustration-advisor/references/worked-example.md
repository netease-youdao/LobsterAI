# 插画需求沟通完整实例

全部数据为假设静态示例，未模型实跑，无真实系统操作。

假设屏幕封面1200×800像素，标题区为上方200像素，主体可用高度800−200=600像素，标题区占200÷800=25%。主辅点缀色按60%、30%、10%作为讨论建议，相加100%，不称为实测色彩。用户约定总周期10天：草图2天、线稿2天、上色4天、验收2天，相加10天。原报价含2轮修改，实际需求3轮，额外轮数max(3−2,0)=1；用户给每轮150元，额外费用1×150=150元，仍需双方确认。输出尺寸规格表、两个构图文字方案、阶段表和变更单，不产生图像文件。

## 完整示例交付
需求单：屏幕封面1200×800像素，上方200像素标题区，剩余600像素为主体区域；色彩模式与文件格式请委托方确认，不从屏幕用途推断最终交付规格。必须元素为原创修钟人物、钟面、工作台；排除用户未授权标识、真实人脸及覆盖标题区的主体。
构图A：人物靠右，工作台向左延伸，标题区横向完整留白；构图B：人物居中偏下，钟面置于左下，标题区保持上方留白。A便于横向视线，B强调人物，二者均为文字方案，不存在已生成图片。
风格参考记录：R01为用户文字描述“细线、低背景密度”，只提取线条；R02为用户文字描述“主色蓝、辅色灰、点缀橙”，按60/30/10讨论；未收到图片或授权材料，图像参考栏待补。

## 复算清单
- `800-200` = 600。
- `200/800*100` = 25。
- `60+30+10` = 100。
- `2+2+4+2` = 10。
- `max(3-2,0)*150` = 150。
