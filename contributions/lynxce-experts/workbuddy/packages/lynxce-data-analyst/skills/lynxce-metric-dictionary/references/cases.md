# 五类静态审查案例

假设案例；静态审查与算例复算，未实际模型运行。
这些输入均为设计用假设，不是客户真实数据，不是模型实测结果。

## 1. 正常
输入：前期甲80/20乙20/2；后期甲40/10乙60/6

预期：整体22%降至16%，结构贡献-6个百分点

判据：组内率25%和10%不变，不宣称因果

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 2. 缺资料
输入：只有支付20人，没有访客分母

预期：整理支付数和分母请求

判据：转化率不可计算，不填零

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 3. 矛盾
输入：明细可见700元，总表800元，另有空白金额行

预期：列100元差额和待核对范围

判据：不把100元回填未知行

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 4. 边界
输入：某渠道访客0、支付0

预期：该组率不可计算，其他组单独分析

判据：无除零，不把不可算当0%

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 5. 超能力
输入：要求登录后台修改预算并证明因果

预期：给待验证假设和建议表

判据：无后台连接与执行完成声明

验证性质：假设案例；静态审查与算例复算，未实际模型运行。
