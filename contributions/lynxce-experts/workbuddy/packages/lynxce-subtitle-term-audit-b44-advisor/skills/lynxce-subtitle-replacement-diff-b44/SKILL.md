# 字幕替换前后差异复核

本任务服务字幕校对员与内容审稿人，独立交付“字幕替换前后差异复核”。只以用户提供材料完成下列核查，最小输入见第一步。这是专门中间成果，可单独使用；不重复公开技能整套输出。资料不足时先交可确认部分和精确补件问题。

## 工作流程

1. 接受原字幕、候选新字幕及批准替换编号，最少同一行原句和新句，缺原文不宣称完成对比。

2. 按行号关联，不用行排序位置代替身份；合并拆行需给旧新映射，否则标不可定位。

3. 逐行提取实际改变词段，与批准词段比对，区分批准改动、越界改动和批准未改。

4. 检查否定词、数值单位和专名是否受损，时间码若变化另列超范围，不自动修正。

5. 统计批准改动完成数与越界数，撤回草稿写恢复到哪一原词，不能仅说恢复原样。

6. 交付差异审稿表和待确认撤回，不覆盖字幕文件；每次补件仅复核有映射的受影响行。

## 任务专属规则

- 术语替换应只动批准词段，数字与单位的改变必须独立获确认。

- 一行多处替换按词段计数，行数用于定位而非完成率分母。

- 原新行号失配时停止语义对比，避免把正常拆行误报删除。

- 越界改动与遗漏分别保留，即使总字符数相同也可能改变句意。

## 资料定位与事实等级

- 每条原始材料分配来源编号，保留原文与采用版本。示例是假设资料，不写入实际输入空白；用户只需提供会影响本项成果的字段，未知值统一填【待补】，空白与零区别处理。

- 每条结论明确是用户记录、计算结果、候选判断还是待人工确认。原材料状态与建议动作分开列，不用已处理、已通过等用语替代缺失证据；没有反馈的环节保留待核状态。

- 同一对象出现两份互斥记录时并列原值和来源，不按较新日期自动取舍。指出哪一个字段会改变结果，并给出需补充的最小证据；不平均文本冲突，也不删除不利记录。

- 复算前确认计数对象、单位及分母，所有比率同时提供分子和分母。零分母写不可计算，展示百分比保留两位小数；不同范围的数量不能为了凑合计而直接相加。

## 交付复核与变更

- 表格中每个异常给出具体受影响行、待补字段、经办角色与解除条件，建议只到文本资料层。用户没有实际系统记录时不假称已执行、读取后台或联系其他人。

- 收到补证后先确认对应对象和版本，再重算受影响行及汇总，旧版与新值都保留。对未受影响行维持原证据范围，避免局部补充被误读为全量验证或全流程成功。

- 输出前核对原记录数、可分析范围、排除原因和结论状态之间是否一致，每个输入都有去向。资料质量检查只支持本份草稿，不证明实际业务效果或第三方认可。

- 超出任务范围时交付可完成的资料部分，并写需要用户指定人员处理的具体事项。不提供医疗诊断、财税或法律专业结论，不虚构账号接入、现场观察或外部工具能力。

## 五类假设验收案例

- 【假设案例，未模型实测】正常：输入批准4处，完成3处，另有未批准否定词改动1处。 预期：完成75%，遗漏1、越界1，具体撤回否定词。

- 【假设案例，未模型实测】缺资料：输入仅新字幕，没有原稿。 预期：差异不可核，收原稿与批准号。

- 【假设案例，未模型实测】矛盾：输入批准清单说保留专名，新稿改了专名。 预期：列越界与对应批准证据。

- 【假设案例，未模型实测】边界：输入批准替换0处，新稿1处改变。 预期：完成率不可计算，新增1处待批准。

- 【假设案例，未模型实测】超出能力：输入要求直接替换剪辑工程并上传成片。 预期：仅给差异与撤回建议，不操作工程或上传。

## 假设案例

本例全部为假设，未作模型实测。假设批准4处替换，新稿仅完成3处，另有1处未经批准将“不支持”改为“支持”。批准完成3÷4＝75%，遗漏1，越界1。实际改动4处不等于批准全部完成；撤回建议是把“支持”恢复“不支持”，不能以改动次数相同放行。

## 能力边界
