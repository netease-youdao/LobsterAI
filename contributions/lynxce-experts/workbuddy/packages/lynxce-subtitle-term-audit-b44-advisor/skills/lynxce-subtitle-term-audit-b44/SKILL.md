# 字幕术语逐行一致性核对

本任务服务字幕校对员与内容审稿人，独立交付“字幕术语逐行一致性核对”。只以用户提供材料完成下列核查，最小输入见第一步。成果用于代课、演练、仲裁、审稿或申请的人工决策，不替代实际执行。资料不足时先交可确认部分和精确补件问题。

## 工作流程

1. 收行号字幕、时间码、术语规范及允许别名，最少字幕文本和一条已批准术语，不从音频猜缺字。

2. 按完整词和词组定位候选，先匹配长词，再核短词；子串命中只列疑似而非直接替换。

3. 逐个检查产品名、引用原话、否定语境及豁免范围，规范词不能覆盖别的概念。

4. 将已规范、可替换异写、豁免与待辨义四类分开，保留原句、候选句及术语条号。

5. 统计有效术语出现次数和待改次数，复查替换后数字单位与句意是否改变，不改时间码。

6. 交付逐行建议与未定问题，审稿确认前只是文字草案；不声称听过原音、改过字幕文件或完成渲染。

## 任务专属规则

- 同一个简称可能属于不同产品，须用局部语境或用户确认辨义。

- 口播引用可保留原话并备注规范写法，不能静默改变发言者原意。

- 英文大小写按术语表核，不将所有拉丁字母统一大写。

- 两行断开词组先按用户提供相邻行核整词，再分别保留行号定位。

## 资料定位与事实等级

- 每条原始材料分配来源编号，保留原文与采用版本。示例是假设资料，不写入实际输入空白；用户只需提供会影响本项成果的字段，未知值统一填【待补】，空白与零区别处理。

- 每条结论明确是用户记录、计算结果、候选判断还是待人工确认。原材料状态与建议动作分开列，不用已处理、已通过等用语替代缺失证据；没有反馈的环节保留待核状态。

- 同一对象出现两份互斥记录时并列原值和来源，不按较新日期自动取舍。指出哪一个字段会改变结果，并给出需补充的最小证据；不平均文本冲突，也不删除不利记录。

- 复算前确认计数对象、单位及分母，所有比率同时提供分子和分母。零分母写不可计算，展示百分比保留两位小数；不同范围的数量不能为了凑合计而直接相加。

## 交付复核与变更

- 表格中每个异常给出具体受影响行、待补字段、经办角色与解除条件，建议只到文本资料层。用户没有实际系统记录时不假称已执行、读取后台或联系其他人。

- 收到补证后先确认对应对象和版本，再重算受影响行及汇总，旧版与新值都保留。对未受影响行维持原证据范围，避免局部补充被误读为全量验证或全流程成功。

- 输出前核对原记录数、可分析范围、排除原因和结论状态之间是否一致，每个输入都有去向。资料质量检查只支持本份草稿，不证明实际业务效果或第三方认可。

- 超出任务范围时交付可完成的资料部分，并写需要用户指定人员处理的具体事项。不提供医疗诊断、财税或法律专业结论，不虚构账号接入、现场观察或外部工具能力。

## 五类假设验收案例

- 【假设案例，未模型实测】正常：输入8处术语含5规范2异写1豁免。 预期：适用7、待改2、28.57%，输出两行候选。

- 【假设案例，未模型实测】缺资料：输入只有字幕无术语表。 预期：列潜在异写，规范词与替换待补。

- 【假设案例，未模型实测】矛盾：输入术语表两版对同一简称规范不同。 预期：列版本冲突，不以更新时间自动决定。

- 【假设案例，未模型实测】边界：输入“云盘”出现在不同产品专名中。 预期：核完整专名与豁免，不全局替换子串。

- 【假设案例，未模型实测】超出能力：输入要求听音校对并自动渲染发布视频。 预期：只核给定文字，不声称听音、渲染或发布。

## 假设案例

本例全部为假设，未作模型实测。假设10行字幕中出现8处已定位术语：5处规范、2处明确异写、1处引用豁免。适用核对分母8－1＝7，待改2÷7≈28.57%；不按2÷10行计算术语错误率。两处改动必须给原句和候选句，若用户只有文本，发音是否正确仍待音轨人工核查。

## 能力边界

根据用户提供的资料整理和分析；未知项填【待补】，区分事实、假设与建议。没有实际连接工具时不声称读取或修改业务系统，不编造实时数据或已完成的操作。
