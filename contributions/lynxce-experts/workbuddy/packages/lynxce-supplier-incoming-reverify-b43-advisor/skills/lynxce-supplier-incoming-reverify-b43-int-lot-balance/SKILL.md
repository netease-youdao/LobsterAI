# 来料隔离数量守恒核对

本内部能力只处理来料隔离数量守恒核对，输入为收货台账、隔离移转记录、退回与报废记录；输出为批次数量守恒与差异清单。独立保留依据，不代替公开任务的完整交付。 依据仅限用户提供的业务资料。每项事实注明资料编号、版本与日期，缺项写【待补】，推测与确认事实分栏。对冲突输入保留原值和来源，不用示例填补真实空白。只交付可复制的文本和表格；不声称已联网取得数据、连接系统、发送消息、修改记录或执行现场操作。不作资质、认证或签章结论。

## 工作流程

1. 接收收货台账、隔离移转记录、退回与报废记录，明确本轮对象、截至时刻、资料版本与用户希望解决的问题；缺少核心资料先给待补表，保留能够核对的部分。

2. 按任务对象建立唯一记录键，拆分事实、声明与未知条件；逐条关联原文及原值，重复、缺漏与来源冲突单列，不静默覆盖。

3. 以物料与批次为键追每笔状态转移，隔离转退回必须同时减少隔离、增加退回，禁止只增目的状态。使用表格保存比较口径、数量单位和适用范围，方法无法实施时说明具体缺少哪一项输入。

4. 样本台账独立于整批库存台账，测量件重复抽测不重复算来料数量；破坏性检验移出按用户记录核对。对存在分歧的条目提出可回答的确认问题，条件足够才推进，不把未确认的假设转成决定。

5. 结合领域方法复核异常和变更影响，给出待核、补证后可继续或需重新对齐的分支；把责任、期限与验证证据逐项列入。

6. 交付批次数量守恒与差异清单，逐行复算数字与单位，检查来源、版本、状态和未闭环项；由用户负责角色复核后使用，后续资料按新版本续接。

## 对象与口径方法

- 以物料与批次为键追每笔状态转移，隔离转退回必须同时减少隔离、增加退回，禁止只增目的状态。

- 样本台账独立于整批库存台账，测量件重复抽测不重复算来料数量；破坏性检验移出按用户记录核对。

- 差异按遗漏、重复、错批次和时点错位分类，保留期初与截至时刻，不用倒推差额伪造收货记录。

- 给出原账、修正建议与需补证据，不能声称已调整库存；返工可用状态只能依据确认验收记录。

## 证据与决策方法

- 用供应商、物料号、批次与检验版本建立批次键；一个回复覆盖多个批次时先拆分适用范围，不能把某批已整改自动扩展到所有在途与在库批次。

- 将收到、未检、已检合格、隔离、退回与报废按互斥状态登记，同一件不能同时计入隔离和退回；样本量不等于全部来料量，保留检验范围。

- 出现原缺陷复发、新缺陷或复验未完成时分别列后续动作；整改措施针对A缺陷不能关闭B缺陷，复验样本不足时输出尚需补足的样本数。

- 恢复来料节奏、让步接收与继续隔离分别列需确认人和依据，文本不代签放行，也不将供应商整改承诺当成企业批准记录。

## 异常与交付复核

- 核对表中每项判断必须能回指输入记录，不同来源相互矛盾时列出冲突双方与待确认问题；输入没有证明完成的事项保持待核，不能写为事实。

- 检查每行单位、分母、时间窗口与版本是否一致，先复算再解释；零值、空白、未发生是三种不同状态，不把缺失字段默认为零。

- 输出时先列影响与未满足条件，再给逐行证据与下一步动作；责任人与复核人没有提供就留待补，不自行捏造人员或补上批准结论。

- 新资料到来时更新差异与有效范围，保留原表版本和修改原因；旧记录仅作历史依据，不把之前的假设结果当本次真实业务数据。
