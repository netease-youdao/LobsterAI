# 可复制选题与长文底稿

```text
账号定位／目标读者／文章目的／更新频次／材料版本：
选题评分：选题｜相关度｜信息增量｜证据可得性｜时效｜定位匹配｜加权分｜是否入选｜补素材项。
月度日历：发布日期与星期｜栏目｜主题｜目的｜素材负责人｜截稿日与星期。
大纲：开头场景｜小标题一至N（观点／证据／例子）｜结尾下一步。
事实核对表：编号｜原文位置｜数据或引语｜来源｜年份口径｜状态（已核／待核实）。
标题组：排序｜标题｜类型｜兑现位置。
摘要：一句话。
复盘：送达｜公众号消息阅读｜总阅读｜分享｜新增关注｜打开率｜分享率｜关注转化｜近十篇中位数｜偏离｜原因假设｜验证动作。
待确认：最多三项，写明各自会改变哪部分内容。
```

## 已填假设示例：职场效率类账号十一月

以下全部为假设。账号面向入职一到五年的办公室职员，每周二、周五各更新一篇。选题评分：A“周报怎么写才会被看完”为5、4、4、3、5分，加权4.25，入选；B“效率工具清单”为4、3、2、4、4分，加权3.35，未达3.5，暂不排期；C“年终述职提纲”为5、4、3、5、5分，加权4.35，入选；D“同事协作冲突”为4、5、1、4、4分，加权3.65，但证据可得性只有一分，先补两段真实采访再排期。

日历：11月3日（周二）发A，截稿10月30日（周五）；11月6日（周五）发读者问答，截稿11月4日（周三）；11月10日（周二）发D，前提是11月6日（周五）截稿前补齐采访，否则用备选题替换；11月13日（周五）发C，截稿11月11日（周三）。每个截稿日都比发布日早两个工作日。A的首选标题为“周报写三段就够：结论、进展、需要谁帮忙”，三段写法在正文第一节兑现。

复盘假设A发布后：送达20000，来自公众号消息的阅读1600，打开率8%；总阅读2800，近十篇总阅读为1800、2100、1650、2400、1950、2200、1700、2600、2050、1900，中位数2000，本篇高出40%，超过30%，原因假设为分享带来的阅读较多，验证动作是下次对比阅读来源中分享占比。分享140次，分享率5%；新增关注56，关注转化2%。只记录本篇表现，同类题材累计三篇后再判断题材效果。
