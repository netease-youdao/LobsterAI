# 铺位保本与回收期测算

用于把候选铺位与同品牌样本店的数据换算成保本点、回收期和悲观情景。客单价、日均营业额与转化率只用同类门店实际数据，并写明店数与时间窗；没有样本时停在公式层，不用行业平均值代入。

月固定成本 = 租金 + 物业费 + 固定人工 + 装修设备折旧（金额 ÷ 摊销月数） + 其他固定费用。租金按租约正常月租计入，免租期只作为开业初期的现金缓冲，不降低保本点；有递增条款时分年计算。

变动成本率 = 食材成本率（含损耗，不只算净料） + 包装率 + 外卖占比 × 平台佣金率 + 其他按营业额计的费用率；边际贡献率 = 1 − 变动成本率。

保本月营业额 = 月固定成本 ÷ 边际贡献率；保本日营业额 = 保本月营业额 ÷ 月营业天数；保本日客数 = 保本日营业额 ÷ 客单价，向上取整。到店客数 = 保本日客数 × 堂食占比，向上取整；所需进店转化率 = 到店客数 ÷ 日有效客流，与样本店实测转化率对照。

租金占比 = （租金 + 物业费） ÷ 预期月营业额，警戒线由品牌自定，超过即标红。月经营利润 = 月营业额 × 边际贡献率 − 月固定成本；月现金结余 = 月经营利润 + 折旧。回收月数 = 不可退投资（装修设备、转让费、开办费，不含押金） ÷ 月现金结余，保留一位小数；结余不大于零时写“不适用”。悲观情景按预期营业额的七成重算。

结果写区间与敏感性，标“测算不构成盈利承诺”，把代入值和舍入方式填回包根目录 references/workbook.md。
