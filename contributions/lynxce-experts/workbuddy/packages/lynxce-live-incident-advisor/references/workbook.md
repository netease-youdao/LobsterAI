# 可复制直播应急底稿

```text
直播名称／日期（星期）／时段／类型／预案版本：
团队：角色｜姓名或代号｜负责事项｜替补｜同时段是否另有关键任务。
网络：推流码率｜主网络上行｜备用网络上行｜1.5倍核对｜降级码率档｜结论。
风险表：风险｜类别｜概率｜影响｜分值｜等级｜是否写处置卡｜责任人。
处置卡：触发信号｜第一个动作（谁、点哪里、时限）｜话术三句内｜责任人与替补｜升级条件｜恢复条件｜记录项。
开播检查：T-60网络与电量｜T-30商品价格库存优惠截图｜T-10分工与处置卡｜检查人。
事故时间线：发现时刻｜第一个动作时刻｜恢复或暂停时刻｜首个动作用时｜中断时长｜目标值｜达标与否。
价格类记录：错误价｜正确价｜错误期间成交单数｜差额（仅评估）｜商家处理决定（待填）。
预案更新：版本｜修改项｜原因｜待执行事项｜负责人。
待确认：最多三项。
```

## 已填假设示例：周五晚间三小时直播

以下全部为演示用假设。2026年10月23日（星期五）20:00至23:00带货直播，主播、助播、场控三人。推流码率6兆比特每秒，主网络实测上行20，备用手机热点上行8。核对：6×1.5＝9，主网络20大于9通过；备用8小于9不通过，预设降级码率4兆比特每秒，4×1.5＝6，备用8大于6通过，切备用时同步降码率。开播检查节点为19:00、19:30、19:50。

风险定级：断流，概率2、影响3，分值6，高；价格或库存设置错误，概率1、影响3，分值3，按影响3规则升为高；平台警告，概率1、影响3，升为高；恶意刷屏，2×2＝4，中；一般口误，3×1＝3，中；备用设备电量不足，1×2＝2，低，并入检查单。合计高3项、中2项、低1项。

断流复盘：20:41:10推流软件显示码率归零；20:41:35助播用另一网络的手机在评论区置顶说明，首个动作用时25秒，目标30秒内，达标；20:42:05场控切到备用网络并降码率重推；20:43:20画面恢复，中断130秒即2分10秒，目标3分钟内，达标。

价格错误复盘：21:15:00发现一款商品标价29元，正确价为89元；21:15:40暂停该商品售卖，用时40秒；错误期间成交6单，差额（89－29）×6＝360元，仅作影响评估，订单处理待商家依平台规则决定。预案更新为第2版：开播前三十分钟价格核对调整为双人复核并截图，标注为待执行，下一场开播前由场控确认。
