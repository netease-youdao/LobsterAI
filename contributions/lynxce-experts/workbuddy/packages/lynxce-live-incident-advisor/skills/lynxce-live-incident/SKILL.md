# 风险定级与事故时间线口径

只做评分、带宽核对和时间计算，处置话术回到主流程。

1. 概率分三档：1为过去十场以内未发生过，2为发生过一到两次，3为三次以上或每场都可能发生；没有历史记录时按团队判断填写并标“估计”。
2. 影响分三档：1为观众稍有感知、不影响成交与合规；2为影响观看或讲解节奏；3为涉及消费者权益（价格、库存、质量安全）、平台违规警告，或直播中断超过团队设定时长。
3. 分值＝概率×影响。6至9为高，3至4为中，1至2为低。影响为3的风险无论分值都按高等级写处置卡。
4. 带宽核对：主网络和备用网络的实测上行都应不低于推流码率的1.5倍（团队经验值）。备用网络达不到时，预设一个降级码率档，使备用上行不低于降级码率的1.5倍；两档都达不到，记为开播阻断项。
5. 时间线：每次事故记录发现时刻、第一个动作时刻、恢复或暂停时刻，精确到秒。首个动作用时＝第一个动作－发现；中断时长＝恢复－发现。与处置卡中的目标值逐项比对，写达标或未达标。
6. 价格类事故另记：错误价、正确价、错误期间成交单数，差额＝（正确价－错误价）×单数，只用于评估影响，不代表处理方案。

结果填入包根目录 references/workbook.md 的分级表与复盘表；历史记录不足时注明估计依据。
