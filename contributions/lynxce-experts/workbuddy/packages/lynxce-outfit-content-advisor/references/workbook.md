# 可复制穿搭底稿

```text
账号／月份／版本：
定位卡：风格｜人群｜价格带｜一句话定位｜固定栏目一至三｜调整记录。
容量：每次拍摄套数｜拆分（合集/单品/图文）｜每次可发条数｜每周发布条数｜覆盖周数｜本月发布位数｜本月拍摄次数。
月度日历：日期｜星期｜栏目｜选题｜场景｜形式（视频/图文）｜来自哪次拍摄｜状态。
单次拍摄：套号｜单品清单｜色系｜场地｜全身｜半身｜特写｜动态｜每种条数｜备注。
单品信息：品类｜尺码｜价格区间｜采集日期｜是否合作及标注。
回填：作品｜栏目｜发布时间｜记录时点｜播放｜完播率｜收藏｜收藏率｜涨粉｜每千次播放涨粉｜结论。
状态：可执行／补拍摄容量后执行／先定位再排期；关键问题最多三项。
```

## 已填假设示例：职场新人通勤号的十一月

以下数字均为演示假设。定位卡：通勤风、职场新人、单品三百元内，一句话定位为“给职场新人的三百元内通勤穿搭”；栏目为一周穿搭、单品多穿、换季避雷。

容量：每周二、周四、周六晚上各发1条，每周3条。2026年11月的发布日为3、5、7、10、12、14、17、19、21、24、26、28日，共12个发布位。每次拍摄准备5套，拆成1条合集、3条单品、2篇图文，共6条，覆盖2周，本月需拍2次。第一次拍摄定在10月31日（周六），供3日至14日；第二次在11月14日（周六），供17日至28日，两次到首发都留出两天剪辑。

单次拍摄：5套乘4种景别乘每种2条，共40条。竖屏1080乘1920的画面中，全身镜头人物高度约占七成即约1344像素。换装顺序：浅色两套与中性色一套先在室内白墙前拍，深色两套再到室外树荫下拍。单品示例为一条西装裤，价格区间199至259元，标注采集于2026年11月1日，在三百元价格带内。

回填（发布后48小时）：作品甲属单品多穿，播放3200、收藏96、涨粉24；作品乙属一周穿搭，播放2500、收藏50、涨粉10。收藏率甲为96除以3200即3.0%，乙为50除以2500即2.0%；每千次播放涨粉甲为24除以3200乘1000即7.5，乙为10除以2500乘1000即4.0。两条只说明本期单品多穿表现较好，不足以断定栏目优劣；下月保持栏目比例，继续积累同口径数据。
