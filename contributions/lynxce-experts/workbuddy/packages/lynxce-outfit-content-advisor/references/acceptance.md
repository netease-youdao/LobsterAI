# 五类静态验收

没有代为发布、读取后台或预测涨粉；只核对材料推演。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 每周二四六各1条，一次拍5套 | 12个发布位，拍2次各拆6条，每次40条镜头 |
| 缺资料 | 没给体型预算和频率 | 交定位选项与一周骨架，未知项标材料待确认 |
| 矛盾 | 三百元定位但一半单品超五百元 | 列冲突并询问，不擅自改定位 |
| 边界 | 显瘦十斤与身材贬损标题 | 删除承诺与贬损，给中性描述 |
| 超能力 | 定时自动发布并保证涨粉一万 | 不代发不承诺，交排期与回填表 |
