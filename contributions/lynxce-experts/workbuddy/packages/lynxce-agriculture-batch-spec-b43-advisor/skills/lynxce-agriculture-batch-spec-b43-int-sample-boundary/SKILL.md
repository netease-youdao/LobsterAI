# 农产品抽样规格边界核对

逐样本应用明确边界并核净毛重，保持抽样限制。。输入范围仅限用户给定的农业业务材料；与公开技能分工，独立完成此项中间成果再交专家复核。

## 工作流程

1. 收集批次与逐样本原始测量，注明抽样方式、时间、工具记录及规格边界来源。

2. 同维度同单位转换后保留原值，克转千克除1000，重量不推断直径。

3. 逐个样本应用上下界包含规则，边界缺失时只报区间不计算符合比例。

4. 计算样本总量、均值、极值和边界内数，异常值保留并提出复测要求。

5. 核箱毛重中包含哪些包装与附加物，再用同配置皮重求净重。

6. 输出统计表及样本限制说明，不外推全批品质或认证结论。

## 专属核查方法

- 规格下界是否包含与上界是否包含分别记录，避免边界分类歧义。

- 测量精度依据用户工具记录，不能用更多小数伪装更高精度。

- 皮重来自同箱配置，换箱或新增衬垫后旧皮重不能照用。

- 没有抽样方法或数量时仅做资料整理，不称代表性抽检。

## 证据与状态控制

- 先按本任务的复合业务键标记每条材料，保留原值与来源日期，关键字段缺失时只输出可确认部分及补证问题。

- 将输入事实、计算中间值与建议动作分列，复算结果需要能够回到对应单据或记录，不能靠结论倒填来源。

- 用户给定规则只在明确范围内使用，规则变更需记录版本；冲突时列适用条件，不将其他批次或其他任务的规则直接迁移。

- 输出给经办与复核角色审阅，确认资料齐全并不等于业务执行完成，任何现场结果须由用户补充反馈及验证记录。

## 交付与异常

- 输出本任务的领域表格与逐行问题，单位、时间、状态必须写全；没有依据的字段填【待补】，不以零代替缺失。

- 对异常记录给出最小补证动作及其预期证明的条件，不能仅写需要核查，必须说明核哪一项以及结果如何影响表格。

- 先列矛盾与未确认条件，再给条件式建议；存在反证时修订相关行并保留旧版，避免相互矛盾的承诺或计算同时有效。

- 收尾检查表头、合计、状态及来源索引一致，交付文本草案和人工处理清单；不声称联网检测、自动派发或修改系统记录。

## 假设案例

假设横径样本为60、65、70、75毫米，用户规格为65毫米含下界至75毫米不含上界，则65与70两枚满足，样本比例2÷4＝50%，75不计满足。总径长270毫米、均值67.5毫米只描述这4枚。毛重3.2千克、同配置皮重0.3千克，净重2.9千克。若样本75毫米复测为74毫米，必须保留原值与复测依据，修订后的满足数3枚、比例75%，不可覆盖旧记录。

## 能力边界

根据用户提供的资料整理和分析；未知项填【待补】，区分事实、假设与建议。没有实际连接工具时不声称读取或修改业务系统，不编造实时数据或已完成的操作。
