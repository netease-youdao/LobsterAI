# 农产品批次规格与客户问答整理

面向农业的明确小任务：批次规格表、抽样与承诺边界、客户需求匹配矩阵和待确认问答草稿。只依用户提供资料核对，将事实、假设与待确认条件分开；本技能不自动执行任何业务操作。

## 工作流程

1. 收集经营者提供的品种、产地、批次编号、采收或装箱日期、规格标准及客户使用场景。每个字段注明用户材料来源与记录时点，产地与包装地分列；客户要求的认证、检测或特殊声明列待证，不依据图片、口述或品种名称给出质量等级与资质结论。

2. 统一规格单位，单果重量、横径、箱净重、箱毛重和果数分别整理，不用一个维度替代另一个。用户自定义规格需写上下界和边界是否包含，缺分级依据时只呈实测区间不套外部等级；多批次分别列表，包装变化后的皮重必须重新确认。

3. 整理抽样记录的抽样时间、样本数量、测量方法与极值，样本平均值和范围仅描述已给样本。按用户给定阈值统计样本内满足数与比例，不能从少量样本推断整批全部符合；异常测量保留原值及复核要求，不将异常样本删除以使结果更好看。

4. 将客户希望的大小、净重、用途、包装和交付条件映射至批次资料，逐项标已证实、待确认和不匹配。客户要求同箱均一且只有均值数据时，须补单箱分布或筛选记录；实测净重与宣称值不一致时先提出补证或调整说明，不承诺自动分选或替换货品。

5. 编写规格说明与客户问答草稿，采用事实值、适用批次、样本限制和待确认条件的表达。对于自然色差、个体差异和采收日期变化只根据给定材料解释；储运条件、保质期和损耗处理仅使用用户确认依据，未知项不凭经验给天数、农药剂量或品质保证。

6. 交付批次规格资料、需求匹配、缺项与条件沟通表。复核净毛重减法、样本比例、单位及边界，确认草稿没有把抽样数据写成全批承诺；批次变更或客户新需求时更新版本。只给文本资料和沟通建议，不声称已检测、认证、联系客户或修改商品页面。

## 规格与包装口径

- 横径测量注明方向与单位，重量不能直接换算成直径规格。

- 单果净重与整箱净重不同，包材皮重、衬垫和冰袋按资料分别列。

- 产地、采收地与分装地分别表达，来源不明时保持待确认。

- 用户等级标准的上下界要明确，区间相邻时避免同一测量值归两类。

## 抽样与事实边界

- 样本数量和批次总量分列，样本结果不等于全批结果。

- 平均值之外同时给极值及异常数，避免均值掩盖超出客户边界的个体。

- 疑似测量错误先复核原记录，不擅自删除不符合项改善比例。

- 没有检测或认证材料只列待补，不用图片外观推断残留或认证资格。

## 客户条件沟通

- 客户必须条件与偏好条件分开，如净重底线与外观均一偏好。

- 只对资料可证实的字段写肯定句，其余用条件与确认问题表达。

- 客户要求变更要指明受影响的规格、包装和交付字段，而非只改介绍。

- 储运与售后条件引用用户给定版本，资料缺失不编适宜温度或天数。

## 资料与交付复核

- 建立资料目录：每条数值、日期、状态和规则都关联用户提供的来源编号与版本。原始记录、解释性备注及建议动作分栏；资料缺失写【待补】，不得以示例中的数值或常见经验填补真实记录。

- 同一字段出现矛盾时保留两种说法，写清分别来自何人、何时及哪份资料，再指定需要补充的验证材料。没有反证不能选较有利的一版，不将推测原因写成已确认事实，也不替用户判定业务责任。

- 所有数量先核单位、范围、截止时点和分母，再逐行计算并复算合计。四舍五入要注明精度；不适合相加的比例、不同单位或不同批次不直接合计，分母为零时标不可计算并说明需要补充什么。

- 交付文本表格、待补问题和人工确认清单，每个建议写触发条件、经办角色及可核查完成证据。建议、已获用户确认和用户反馈实际完成分状态；收到补证后保留原版及变更原因，不声称已经操作业务系统。

## 五类领域假设验证场景

- 内容设计假设，未作实际模型实测。正常：输入样本180、190、200、210、220克，需求190至210含边界。预期均值200克、样本符合3/5＝60%，不外推全批；专家核客户条件。

- 内容设计假设，未作实际模型实测。缺资料：输入有箱毛重5.4千克但缺包装及冰袋皮重。预期净重待补，不把毛重当净重，不承诺满足每箱5千克。

- 内容设计假设，未作实际模型实测。矛盾：输入两箱净重5.1与4.9千克，客户要求每箱至少5.0。预期一箱符合一箱不符，平均5.0不代表逐箱满足，输出差异问句。

- 内容设计假设，未作实际模型实测。异常边界：输入横径65含下界至75不含上界，样本60、65、70、75。预期仅65和70满足，2/4＝50%；75不误计符合，不套外部等级。

- 内容设计假设，未作实际模型实测。超出能力：输入要求认定有机认证、保证零残留并代发客户承诺。预期认证检测材料列待核，仅给事实与条件草稿，不作认证结论或代发。
