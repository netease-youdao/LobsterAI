# 农产品客户条件与承诺核对

把客户需求与批次事实逐字段对齐，控制承诺范围。。输入范围仅限用户给定的农业业务材料；与公开技能分工，独立完成此项中间成果再交专家复核。

## 工作流程

1. 摘录客户关于大小、净重、外观、用途和交期的原话，明确必须项和偏好项。

2. 逐条件关联批次规格与包装证据，只有均值不能证明每枚或每箱满足。

3. 将已证实、不匹配和缺证三类分开，缺证不应被标为默认符合。

4. 对不匹配项提出有资料支持的替代条件，缺分选能力时不承诺可按规格筛选。

5. 编写事实回应、差异说明和确认问题，所有质量及储运说法引用给定资料范围。

6. 交付条件矩阵与承诺待核表，客户同意或批次变更后保留版本重新核对。

## 专属核查方法

- 每项肯定表达必须指向证据号，证据只适用于指定批次和记录日期。

- 均一性要求核分布和允许范围，单一均值无法满足逐枚保证。

- 交付时窗与储存期是不同条件，不互相替代也不从日期自行推保质。

- 认证需求列材料待核，不作资质判断；未知指标不写零残留等绝对保证。

## 证据与状态控制

- 先按本任务的复合业务键标记每条材料，保留原值与来源日期，关键字段缺失时只输出可确认部分及补证问题。

- 将输入事实、计算中间值与建议动作分列，复算结果需要能够回到对应单据或记录，不能靠结论倒填来源。

- 用户给定规则只在明确范围内使用，规则变更需记录版本；冲突时列适用条件，不将其他批次或其他任务的规则直接迁移。

- 输出给经办与复核角色审阅，确认资料齐全并不等于业务执行完成，任何现场结果须由用户补充反馈及验证记录。

## 交付与异常

- 输出本任务的领域表格与逐行问题，单位、时间、状态必须写全；没有依据的字段填【待补】，不以零代替缺失。

- 对异常记录给出最小补证动作及其预期证明的条件，不能仅写需要核查，必须说明核哪一项以及结果如何影响表格。

- 先列矛盾与未确认条件，再给条件式建议；存在反证时修订相关行并保留旧版，避免相互矛盾的承诺或计算同时有效。

- 收尾检查表头、合计、状态及来源索引一致，交付文本草案和人工处理清单；不声称联网检测、自动派发或修改系统记录。

## 假设案例

假设客户必须每箱净重至少5.0千克，偏好每枚约200克。批次甲记录两箱净重5.1与4.9千克，平均5.0千克并不能满足每箱底线；一箱符合、一箱不符合，应说明0.1千克差额并请求用户确认装箱调整。样本均值200克只能回答抽样平均，不能保证每枚200克。若客户把底线改为4.8千克，两箱在已有记录中满足，但未来发货箱仍需对应批次记录，不把两箱样本当全批承诺。

## 能力边界

根据用户提供的资料整理和分析；未知项填【待补】，区分事实、假设与建议。没有实际连接工具时不声称读取或修改业务系统，不编造实时数据或已完成的操作。
