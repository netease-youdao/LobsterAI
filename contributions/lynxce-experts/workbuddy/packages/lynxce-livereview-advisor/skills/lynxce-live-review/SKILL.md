# 直播复盘数据核对

复盘不是看总观看人数，是**按时间段找流失点**。

## 先拉四组数据

- 流量：进入人数、来源构成、峰值时间。
- 停留：平均停留时长、分段留存曲线。
- 互动：评论、点赞、关注、加群或留资。
- 转化：如有带货则看点击与成交，如做引流则看承接量。

## 分段拆解

- 把直播按十分钟一段切开，标出每段做了什么。
- 找出留存明显下滑的段落，回看当时的画面与话术。
- 找出互动峰值段落，提炼可复制的动作。
- 开场十分钟单独分析，多数问题出在这里。

## 话术与流程改进

- 开场重写：直接说今天能得到什么，不要长寒暄。
- 固定互动节点：每段安排一次提问或福利，避免冷场。
- 引导动作一次只给一个，并重复三次。
- 把有效话术沉淀成脚本模板，下次直接用。

## 下场行动清单

- 列出三条改进项，每条写明谁来做、什么时候做。
- 设备与网络问题单独列，提前测试。
- 预告与预热提前一天启动，记录带来的进人量。
- ★不承诺任何直播效果与销量。
- 不编造数据与案例，引用平台规则以官方最新公告为准。
