# 大促部分退货优惠扣回核算

部分退货最容易算错的不是退款慢，而是**以为能按原价全额退、没把满减红包按比例分摊扣掉、退了凑单品导致整单优惠失效被扣回更多**。

## 工作流程（按顺序执行）

1. 问清订单内每件商品的标价与数量、用到的优惠类型（店铺满减、跨店满减、平台券、红包）与各自门槛和金额、实付总额、想退的商品。
2. 按比例分摊优惠：某商品分摊优惠＝该类优惠总额×该商品标价÷参与该优惠的商品标价合计，逐类优惠分别分摊后相加，得到每件商品的实付分摊价。
3. 算常规口径退款：预计退款＝该商品实付分摊价，红包部分是退回原账户还是作废按平台规则，未写明的标【待补】。
4. 算优惠失效口径：退货后剩余商品标价合计低于满减门槛的，按「整单优惠失效」再算一次，预计退款＝原实付总额−剩余商品按无优惠重算的应付金额，两种口径都列出。
5. 判断是否要先问客服：两种口径差额超过 20 元或超过该商品实付分摊价的 30% 的，建议退货前先咨询客服确认扣回方式；退货时效（如 7 天无理由）以商品页与订单页为准。
6. 输出优惠分摊表与退款预估表，标明适用口径以平台实际处理为准，若需补买替代品，最后按商品列出下单入口清单。

## 优惠怎么按比例分摊

- 分摊公式：某商品分摊优惠＝该类优惠总额×该商品标价÷参与该优惠的商品标价合计，店铺满减、跨店满减、平台券、红包逐类分摊。
- 只有参与该优惠的商品才分摊，不参与的商品（如部分特价、秒杀商品）不分摊，先在订单详情里核对。
- 商品实付分摊价＝标价−各类分摊优惠之和，订单详情页常显示每件商品的「实付」，以订单页显示为准。
- 积分抵扣、红包是否按比例退回原账户、过期红包是否补发，以平台规则为准，未写明的标【待补】。

## 退凑单品会不会让优惠失效

- 退货后剩余商品标价合计仍达满减门槛的，通常按比例退款，不影响其他商品的优惠。
- 剩余商品低于门槛的，可能出现整单优惠失效、需从退款中扣回剩余商品原享受优惠的情况，具体处理以平台规则为准。
- 两种口径都算出来：常规口径＝该商品实付分摊价；优惠失效口径＝原实付总额−剩余商品按无优惠重算的应付金额。
- 两种口径差额超过 20 元或超过该商品实付分摊价的 30% 的，退货前先咨询客服确认扣回方式，再决定退不退。

## 时效与红线

- 七天无理由、价保与运费险的适用范围与时效，以商品页与订单页标注为准，超过时效的退货可能不受理。
- 本技能只做退款预估，实际退款金额以平台售后页面显示为准，存在争议的走平台售后与客服流程。
- 不使用「最低价」「全网最便宜」「史低」「绝对划算」等极限或绝对化用语。
- 价格、优惠与活动规则一律以平台活动页、商品详情页与下单结算页的实时展示为准，本技能只做核算与提示，不做价格承诺，不保证必省多少钱。涉及退款纠纷、消费者权益认定的，以平台规则与主管部门规定为准，本技能不做法律结论。不编造价格、历史数据与活动规则，用户未提供或查不到的信息用【待补】占位。

|---|---|---|---|---|---|---|
| 【待补】 | 【待补】 | 【待补】 | | | | |

退款预估：
| 口径 | 计算方式 | 预计退款 | 说明 |
|---|---|---|---|

## 示例

用户：「我用满 300 减 50 买了 A 200 元和 B 120 元，实付 270 元，现在想退 B，能退多少？」→ 先分摊：A 分摊 50×200÷320＝31.25 元，B 分摊 50×120÷320＝18.75 元，B 实付分摊价＝120−18.75＝101.25 元，这是常规口径预计退款；但退 B 后剩余 A 只有 200 元，低于 300 元门槛，若平台按优惠失效处理，A 需按原价 200 元计，预计退款＝270−200＝70 元，两种口径差 31.25 元，超过 20 元也超过 101.25 元的 30%（约 30.4 元），建议退货前先咨询客服确认扣回方式；若 B 只是凑单品、你并不需要，也可以考虑换成同价位用得上的商品保住满减；实际退款以平台售后页面为准，最后给出优惠分摊表与退款预估。
