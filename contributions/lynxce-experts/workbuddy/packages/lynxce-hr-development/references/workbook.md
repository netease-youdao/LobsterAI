# 可复制培养与面谈底稿

```text
岗位／版本／日期／材料编号：
任务分级：任务编号｜产出标准｜新手｜熟手｜骨干｜知识技能。
课程地图：课程｜任务编号｜级别｜必修选修｜形式｜时长｜考核｜讲授或带教。
培养节点：入职日｜第30天｜第60天｜第90天（含星期与顺延）｜目标｜完成标准｜负责人。
四层评估：反应（满意度、回收率）｜学习（课前课后、通过率）｜行为（观察周与清单）｜结果（指标与干扰因素）。
面谈准备：周期｜目标值｜实际值｜达成率｜SBI事实（日期）｜首次反馈标记｜三条反驳与记录。
改进计划：目标｜周期起止｜检查点日期｜支持资源｜HR确认人｜员工意见。
制度核对：缺章｜程序记录｜签收率｜冲突条款｜分档缺格｜金额边界｜时限。
关键问题：最多三项，写明答案会改变哪一栏。
```

## 已填假设示例：电商客服岗

以下均为演示假设。新人2026年10月19日（周一）入职，劳动合同约定试用期三个月。节点：第30天为11月18日（周三），第60天为12月18日（周五），第90天为2027年1月17日（周日），顺延至1月18日（周一）。八名新人需要至少三名带教人。

岗前课程于11月6日（周五）结束。学习层：课前测验平均52分，课后平均81分，通过线80分，八人中六人通过，通过率百分之七十五；未通过的两人安排补训与复测。反应层问卷回收七份，回收率百分之八十七点五。行为层：结束后第六周即12月18日（周五），主管按十项行为清单观察，八人平均做到七项。结果层只记录同期一次解决率变化，并注明当月促销导致咨询量上升等干扰因素。

面谈示例（另一名在岗满一年的客服）：季度一次解决率目标百分之八十五，实际百分之七十八，低七个百分点，达成率约百分之九十一点八。SBI：“11月12日（周四）晚班，客户第二次来电询问退款进度时，你在未核实工单状态的情况下回复已经退款，客户次日即11月13日（周五）再次投诉并要求升级处理。”该问题此前已在10月的质检反馈中出现，不属于首次反馈。

改进计划（拟，待HR确认）：2026年12月1日（周二）至2027年1月29日（周五），含首尾共六十天；检查点为12月14日、12月28日、1月11日、1月25日，均为周一。目标为计划期最后四周一次解决率不低于百分之八十五，回复退款进度前必须查看工单状态，质检每周抽查二十单。

制度核对示例：报销审批写成“五千元以下部门负责人；五千元至两万元加财务负责人；两万元以上加总经理”，按常用理解五千元与两万元各落入两档，建议改写为不超过五千元、超过五千元且不超过两万元、超过两万元。手册应签收120人，已签收114人，签收率百分之九十五，六人待跟进。
