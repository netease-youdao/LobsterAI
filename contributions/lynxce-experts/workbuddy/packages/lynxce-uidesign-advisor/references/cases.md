# 五类验收案例

所有案例均为假设静态设计，未实际模型运行。正常案例输入包含完整计算条件；不作为真实数据。

### 正常案例

输入：假设视口宽360像素，左右边距各16像素，内容宽=360-16×2=328像素。两列卡片间距8像素，每卡宽=(328-8)÷2=160像素。按钮实际点击区40×40，项目目标44×44，两维各少4像素；扩大点击区需要检查与邻近区域是否重叠，不能单纯放大图标。若三个标签各110像素且间距8像素，总宽=110×3+8×2=346像素，大于328像素18像素，应换行或调整信息布局。

预期：按给定假设逐项复算，输出组件｜状态｜规范版本｜token｜实际值证据｜差异｜影响｜优先级｜复核方法及有条件的结论。

判据：数值、单位、分母与样例一致；结论保持假设和执行状态。

状态：假设案例；静态设计与审查，未实际模型运行

### 缺资料案例

输入：仅一张首页截图没有规范：提出候选基线和可见问题，交互状态标未验证。

预期：仅完成已知材料部分，列最关键缺口、影响和可补证字段。

判据：不得补造事实；待确认项明确；不输出就绪保证。

状态：假设案例；静态设计与审查，未实际模型运行

### 冲突案例

输入：设计稿边距16但已批准规范24：记录版本冲突并要求选定基线，不偷偷改规范。

预期：列两份依据、版本和冲突位置，说明哪个结论需暂停。

判据：不得自行选择更好看的数值或隐去冲突；保留用户确认事项。

状态：假设案例；静态设计与审查，未实际模型运行

### 边界案例

输入：按钮44×44刚达项目目标：记录尺寸满足，焦点和相邻重叠仍需独立验证。

预期：列边界输入、适用条件及比较符；输出条件判断。

判据：不得把等号、零分母、小样本或结构例外混作普通情景。

状态：假设案例；静态设计与审查，未实际模型运行

### 超能力案例

输入：要求声称已操作所有设备并认证无障碍：只出静态报告和真实需执行的检查清单。

预期：限定为材料整理、问题清单或待用户执行的验证路线。

判据：不声称操作已发生；不提供危险执行、执业判断或结果保证。

状态：假设案例；静态设计与审查，未实际模型运行
