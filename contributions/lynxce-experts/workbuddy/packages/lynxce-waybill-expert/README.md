# 运单异常专家

版本：1.0.1

依据运单轨迹和交接材料梳理异常时间线、证据缺口与处理选项，交付客户沟通草稿及可追溯的复盘台账。

作者：灵策智算 LynxceAI

入口：[lynxce-waybill-expert](agents/lynxce-waybill-expert.md)。完整交付包括异常事件时间线与证据表、处理选项及客户回复草稿、批次异常占比和复盘台账。

先在会话中提供已脱敏材料，专家据此整理草稿与核对结论。模板见 [交付模板与复算示例](references/delivery.md)，验收边界见 [五类静态验收](references/acceptance.md)。

本包没有后台运行、实时监控或自动发送能力。示例均为明确标注的假设资料；计算结果可复算，不代表真实客户成效。
