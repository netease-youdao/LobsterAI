# 交付模板与复算示例

## 完整可复制模板

```text
异常单__；运单代号__；统计截止__；时区__；客户诉求__
结论：已确认现象__；责任/原因未确认__；当前限制__
时间线：事件号｜发生时间｜记录时间｜节点｜件数/状态｜材料号｜冲突
证据表：材料号｜提供角色｜对应对象｜能证明什么｜不能证明什么｜待补项
原因表：假设｜支持证据｜相反证据｜确认角色｜下一步材料
处理选项：方案｜执行前提｜用户偏好｜提议责任角色｜费用假设｜可能影响
客户草稿：依据您提供的__，目前确认__；尚需核对__。可讨论__，下次更新提议为__，以相关方确认结果为准。
内部备注：编号__；当前状态__；待确认角色__；关闭证据__
批次复盘：分母__；异常去重数__；多标签各类数__；比例与重叠__；改进验证__
关键问题（最多三条）__
```

## 已填假设示例

假设W01约定10月12日18:00送达，材料显示实际签收为10月13日10:00，同为上海时区，晚16小时；只能确认相对约定窗口的时间差，责任原因待核实。12件发出，交接记录和收件清点均为12件，其中2件有破损反馈。数量齐全不能否定破损，也不能直接确认承运方责任。

已填证据E1为发出12件交接表，E2为收到12件清点记录，E3为两件破损照片描述，E3与箱号关联待补。回复草稿：“现有记录显示收到12件，其中2件反馈破损。请协助核对对应箱号与照片，我们可据已确认材料整理补发或补偿申请选项；具体方案待相关方确认。”

同批20票运单，延误3票、破损2票，其中1票两类重叠，异常去重数3+2−1=4票，总异常占比4÷20=20%，延误15%、破损10%，不能相加为25%总异常率。复盘台账把W01记为处理中，补齐箱号和明确方案后再核对是否具备关闭证据。
