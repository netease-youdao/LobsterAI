# 大促暖手宝与热水袋选购

暖手宝与热水袋最容易买错的不是牌子，而是**充电暖手宝只看「10000 毫安」以为能热一整天，不看发热功率与档位，三无电热水袋充电时抱在怀里、外壳鼓了还接着用，注水热水袋直接灌刚烧开的水、夜里贴着皮肤放一整晚，第二天才发现低温烫伤**。

## 工作流程（按顺序执行）

1. 问清使用场景（通勤户外暖手、办公室久坐、睡前暖被窝、老人或儿童使用、经期腹部保暖）、每天使用时长、是否需要兼作充电宝、所在地区冬季气温、是否有糖尿病或感觉迟钝等对温度不敏感的使用者、预算，以及候选款的类型（充电式锂电暖手宝/插电加热的电热水袋/注水式热水袋）、电池容量（毫安时）与标称电压或瓦时、发热功率与档位温度、标称续航及测试档位、充电方式与时长、认证标志（如 3C）与执行标准编号、外壳材质与是否有布套、电热水袋的加热功率与温控断电说明、注水式容量与材质及建议水温、券后价。
2. 按场景定类型：通勤户外随身暖手的选充电式锂电暖手宝，注意重量与续航；办公室或家中久坐、靠近插座的可选电热水袋，加热后拔电使用；睡前暖被窝、不想用电的可选注水式热水袋，放入被窝预热后取出；老人、儿童、对温度不敏感或行动不便的使用者，优先低温档与有温控保护的款，并由家人照看使用。
3. 核认证与标准：查看商品与包装是否标注认证标志、执行标准编号、生产厂名厂址与生产日期；锂电类产品可核对是否标注锂电池相关安全标准（如 GB 31241），电热类可核对是否标注家用电器安全相关标准（如 GB 4706.1 及对应的特殊要求部分）；属于强制性产品认证目录的产品应有 3C 标志，是否属于目录及证书真伪以国家认证认可监管部门公布的目录与查询结果为准；标注不全或无法核对的标【待补】，不作为首选。
4. 按瓦时算续航：电池能量（瓦时）＝毫安时×标称电压÷1000，锂电标称电压多为 3.6V 或 3.7V；续航估算＝瓦时×0.8（转换损耗）÷当前档位发热功率；双面发热或高档位功率更大，续航按对应档位计算；商家只写「超长续航」不写档位与功率的标【待补】；兼作充电宝的，给手机充电会占用暖手续航。
5. 算每季成本：充电式与电热水袋的电费＝每次充电或加热耗电（千瓦时）×电价×每季使用次数，通常很低，主要成本是购买价与使用年限；注水式成本＝购买价＋烧水能耗；每季成本＝到手价÷预计可用季数＋电费；橡胶或 PVC 注水袋老化变硬、出现裂纹时需更换，按商家标注的建议更换周期计入，未标的标【待补】。
6. 输出对比表，写明计算过程与结论；用户需要下单时，按商品整理下单入口（商品、规格、预计到手价、下单入口）。

## 参数怎么读

- 「10000 毫安」要换算成瓦时并结合发热功率看续航，不同标称电压的毫安数不能直接比。
- 「恒温」「智能温控」需看档位温度数值与断电保护说明，只写宣传语无数值的标【待补】。
- 电热水袋要看是否为加热后拔电使用，以及温控断电、防爆说明，以说明书为准。
- 注水式热水袋看材质、容量与建议水温，未标建议水温的不按开水使用。

## 使用与安全

- 长时间贴着皮肤使用较高温度的取暖物品可能造成低温烫伤，使用时套上布套、隔着衣物，不贴身放一整晚，入睡前从被窝取出。
- 电热水袋充电或加热时不抱在身上、不放在被褥里，加热完毕拔电后再使用；外壳鼓胀、漏液、有异味或异常发烫时立即停止使用。
- 注水式热水袋按说明书的水温与灌水量使用，灌水后排出空气拧紧盖子，倒置检查不漏水再用，不压不坐。
- 锂电暖手宝不在高温处充电，不用非配套或劣质充电器长时间充电，外壳破损或鼓包停止使用；糖尿病等感觉迟钝人群使用前咨询医生。
