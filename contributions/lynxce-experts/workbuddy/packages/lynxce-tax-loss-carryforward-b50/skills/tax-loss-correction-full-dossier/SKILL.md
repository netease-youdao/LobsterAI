# 历史更正与全量申报勾稽
收到历史亏损新数先核来源是草稿、真实更正申报、检查调整还是内部建议。未签复核稿不能覆盖有回执的原申报，不按较晚日期或较大可用余额选择。固定原年与候选年两个分支，从最早受影响年度向后逐年重跑所有分配，不能只修改本年余额一个单元格；有可能总弥补后所得相同但批次余额变化，仍需保留完整影响链。
假设2018原税务亏损六十万元与候选四十万元冲突，2019四十万、2020三十万、2021至2025可用所得二十、十、三十、十五、二十五万和2022科小资格不变。原分支2025年末仍余2020批三十万，候选分支则2023用2018十万和2019二十万、2024用2019十五万、2025用2019五万和2020二十万，2020余额十万元。两分支每年所得都可弥补完，但后续可用余额不同，不能因为当年所得均零就说更正无影响。
将逻辑数据映射到本期真实A106000等表单的对应年度、境内所得、企业类型、当年待弥补、本年度弥补和可结转字段，具体栏次及电子表关系按用户所供当期表核，不能把旧网页栏号写死。交完整原/候选年度表、批次表、可复制更正准备说明及证据缺口，所有未变日期金额和资格重新列明。更正稿形成不是已经申报成功，更不是补退税、期限重开或递延税资产可以确认；用户实际提供回执再更新对应状态。本技能不代鉴证，不将未核历史数字伪造成机关确认结果。
询证稿应写明具体哪一年度、原金额和候选金额、需要哪份支持明细或真实回执，不问泛泛的所有资料。新材料只解释一批时，其他两批的原发生额和截止年仍完整列入；不得将财务复核签字冒写成税务机关批准，更不能抹除原版本。
