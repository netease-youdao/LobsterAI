# 多年度弥补与余额滚动
把每个所得年度的可用于弥补口径与每个亏损批次交叉，先检查有效期及已用数，再依发生年度顺序分配，本年所得只能使用一次。每步可用余额取当年所得剩余与该批未过期亏损余额较小者；用后同时减少两个余额。所得不足时保留未弥补批次到其法定期限，不按“今年亏损”把所有历史批次合并成一个新亏损；即使中间没有收入，期限也不会停止。
输出一张按所得年度的分配表与一张按亏损发生年的余额表，原批次发生额减各年真实弥补、转出及到期等须与期末余额衔接。示例原三批六十、四十、三十万元，总一百三十万元，2021至2025分别二十、十、三十、十五、二十五万元可用境内所得，总一百万元。合法十年条件下按序弥补，2018批用六十万，2019批用四十万，2020批仍三十万，各年度弥补后所得为零。这些零只在完整输入及规则下得出，不表示企业其他税种无应纳或实际税款已退。
逾期、部分更正、查补所得、特定税收优惠或资产损失追补须另核适用规则与真实有效年度，不把本示例自动套所有情况。境外亏损不得随意冲境内盈利；重组承继损失要分流专门处理，不从合并报表亏损直接转入。完成标准是每一元只用一次，每年所得桥与每批余额桥同时闭合，金额单位清楚，表格只有数据行，汇总和公式在表外，尚未获得的回执及未知资格均保持未知。
若旧申报使用额与本次依法核算不符，应并列原使用和拟调整，不为了让余额桥看起来闭合而改动原记录。只在有完整年度数据时出确定数，缺额留未知并继续核其他可完成年度；表尾的整体合计不能取代逐批最后期限及每年分配的审阅。
