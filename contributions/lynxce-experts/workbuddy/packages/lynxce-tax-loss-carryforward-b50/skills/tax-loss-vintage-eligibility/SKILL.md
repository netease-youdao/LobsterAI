# 亏损批次与资格期限追溯
先确认是适用企业所得税的境内企业及正常纳税年度，区分账面亏损、纳税调整后境内亏损、已实际弥补和尚未弥补余额。利润表负数不能直接复制为税务亏损；股东借款、现金流缺口与广告费结转也不是同一个税务亏损批次。每一亏损发生年建唯一编号，记录原申报、更正回执、取数单位和是否涉及合并分立、境外机构或特殊行业。资料只有口述就标口述，不能称申报已经确认。
一般五年结转以亏损发生年向以后年度计，不能把发生当年算成第一年缩短一年，也不能按连续盈利五年延长。高新和科技型中小企业依财税2018年第76号和总局2018年第45号核资格年度之前五个年度尚未弥补亏损及十年总期限；不是从取证年度再起算十年。高新按证书注明有效期所属年度核，不能机械认为所有证书只覆盖三个自然年；科小按登记编号注明年度核，申请中不算已经取得资格。
假设2022年真实科小编号已核，2018、2019、2020亏损均属其前五年且尚未弥补，可各自对应十年总期限至2028、2029、2030年。后续不具资格不回退这些已合法延长期限，但不自动把其他后来亏损也变十年。资格未证实则双轨列一般期限与延长候选，不以市场宣传高新代替证明。完成是每批原年金额、资格覆盖、最后可用年度和当前余额都有来源；本技能不替企业认定高新，不宣称期限延长需先获一份不存在的税务审批。
对每一项延长结论另外列发生年、资格年、覆盖区间和原一般截止年，判断是已满足条件还是仅候选。对过期批次保留历史索引但不给可用余额，不能从复核日重新开始；用户尚未提交的更正只登记草稿阶段，真实资格取数争议交精准询证。
