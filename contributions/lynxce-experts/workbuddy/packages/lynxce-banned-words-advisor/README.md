# 短视频文案自查顾问

版本：1.0.1

根据标题口播字幕等全部文案逐句标出风险等级，提供改写方向与证据缺口清单，需法务判断事项单列移交。

入口：`agents/lynxce-banned-words-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。
