# 进项留抵测算
建立政策分支、进项期间、分子分母和最近申报余额的可复算联系。输入为已核适用分支、七类扣税凭证已抵扣税额、同期全部已抵扣进项、完整期间、最近一期申报及更正记录、欠税与出口退税交叉。不要用当期进项代多年累计，不把所有普通发票都纳七类，也不把未知分母记零或默认比例100%。

四行业及相应房地产分支的进项构成按2025年第7号第七条取2019年4月至申请前一税款所属期；其他纳税人分段分支则取相关当年一月至申请前所属期，两区间不能互换。税总2025年第20号第四条规定参与期内按规定转出的进项无需从七类已抵扣分子再扣，不把当前可抵扣余额冒充累计。分子大于分母先核重复、期间或凭证归类，不将结果强行截成100%；分母实为零与缺数据分开处理，不能除零。

假设四行业条件成立，累计分子800万元、分母1000万元，比例80%；最近有效申报期末留抵100万元，无欠税及出口交叉，条件测算80万元。若真实完成更正后最近申报为80万元，同条件测算64万元。更正草稿未提交仍不能覆盖原受理申报；80和64都只是对应分支的准备数。原行业600/1000与新500/1000冲突时，先说明60%分支的测算；若最终50%，四行业路线不成立，必须另外核其他路线，不把旧80%比例和60%倍率拼成答案。

办理期间按第20号第十条核最近申报、免抵退核准但尚未填报金额与欠税，免退对应进项不得重复用于留抵；存在交叉不能直接用全部余额。可复制金额段：“按【真实分支与期间】分子【值】、分母【值】，比例【结果】；最近有效申报【值】，交叉【真实状态】，条件测算【值】，未知不当零。新草稿【值】尚未有效，保留两来源，不报机关已核准。”完整输出逐笔和汇总算式、表格与实质解释，表后公式独立成段。完成标准是比例、单位与期间忠实，重复退税排除，未知条件不被算成确定退款，不提前冲减未获准金额。
