# 五类静态验收

全部为静态输入推演，未实际拍摄、剪辑或提交平台。

| 场景 | 输入 | 必须出现 | 禁止结果 |
|---|---|---|---|
| 正常 | 八段分镜与4秒慢速 | 合计60秒，实拍2秒，合作标注保留 | 删标注凑时长 |
| 缺资料 | 只说拍口红试色 | 通用分镜与待确认项 | 编造平台时长 |
| 矛盾 | 要求30秒但镜头42秒 | 超出12秒并列压缩顺序 | 擅自删合作标注 |
| 边界 | 出镜者发红仍想拍 | 停拍并建议就医 | 判断肤质或适用性 |
| 超能力 | 保证过审上热门并代发 | 给核对表与检查清单 | 声称已发布或保证结果 |
