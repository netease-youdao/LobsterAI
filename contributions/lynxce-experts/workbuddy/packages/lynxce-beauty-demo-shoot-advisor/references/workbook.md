# 可复制拍摄底稿

将以下模板完整填写；不适用项写明原因，未知项保留【材料待确认】。

```text
视频名称／版本／平台与画幅／目标时长：
定性：方法演示｜个人体验｜商业合作；合作标注方式：
产品：品类｜用量单位｜品牌宣称口径文件与版本：
出镜安全：局部试用日期与结果｜不适停拍规则：
布光：主光类型｜高度角度｜距离｜色温｜补光｜关闭的光源｜灰卡参照。
机位：半身占比｜特写对准区域｜质地俯拍底板｜统一参数。
分镜：段落｜动作｜用量｜景别｜成片秒数｜拍摄帧率｜实拍动作秒数｜字幕。
时长核对：各段合计＝目标时长？合作标注是否保留？
话术核对：序号｜原句｜类别｜处理｜改写句｜依据文件｜确认人。
对比条件：机位｜光线｜角度｜参数｜妆面｜间隔｜修图标注；任一不一致即取消对比。
待确认：最多三项，写明影响哪段镜头或哪句话。
```

## 已填假设示例：粉底液60秒竖屏合作视频

以下为演示假设，不是真实拍摄记录。品牌合作，出镜者为本人，拍摄前一天按产品说明在耳后局部试用，无不适。布光为环形灯正前方略高20度、距离70厘米，两侧反光板，色温锁定5400K，关闭顶灯，每个机位先拍3秒灰卡。

分镜时长：片头合作标注与用途说明4秒，质地俯拍8秒，取量一泵6秒，点涂额头、两颊、鼻尖、下巴五点8秒，由内向外推开14秒（含慢速4秒），收边8秒，半身整体7秒，结尾说明5秒，合计4+8+6+8+14+8+7+5=60秒，与目标一致。推开段以每秒60帧拍摄、每秒30帧播放，慢放倍率30÷60=0.5，成片4秒慢速需要实拍动作4×0.5=2秒，建议连续拍三遍再选一条。

口播五句核对：第一句“我全脸用一泵就够”属用量与个人感受，保留；第二句“遮瑕力最强”含最高级，改写为“这次我在鼻翼两侧泛红处点涂后推开”；第三句“用了能修复屏障”属功效判断，品牌未提供依据且带医疗暗示，删除；第四句“敏感肌放心用，零刺激”含绝对化和人群承诺，改写为“我本人局部试用没有不适，皮肤敏感建议先做局部试用”；第五句“持妆12小时”属数据宣称，列入需品牌依据清单，拿到测试条件与确认前不进入成片。结果为保留1句、改写2句、删除1句、待依据1句，合计5句。

本片不做前后对比：上妆前段落使用的是窗光，与上妆后5400K灯光条件不一致。若品牌坚持要对比，需在同光线、同参数下重拍两段，并标注未修图。
