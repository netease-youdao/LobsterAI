# 分镜时长与话术逐句核对
用于美妆演示视频的分镜定稿和口播字幕定稿阶段，只做时长计算与风险分类，不判定是否合规，也不代替品牌方或平台给结论。
时长：先列不可删段落，即合作标注、必要说明和四步演示，再分配其余段落。各段秒数相加必须等于目标时长；超出时按“半身整体、质地、结尾说明”的顺序压缩，压缩后仍超出，列出差额交用户选择删哪一步，不删合作标注。
升格换算：慢放倍率 = 时间线帧率 ÷ 拍摄帧率；成片慢速秒数 × 慢放倍率 = 需要实拍的动作秒数。拍摄帧率不高于时间线帧率时无法做顺滑慢放，标【材料待确认】并建议重拍。
逐句分类：每句只给一个主类别，按风险高者优先：需删除（医疗用语、诊疗暗示）高于需品牌依据（功效、数据、适用人群、时效），高于需改写（绝对化、最高级、承诺性用语），高于需标注（合作、修图），最后是可保留（用量、手法、步骤、个人当下感受）。改写只能降低说法强度，不能新增功效或扩大人群。
记录：原句、类别、处理、改写句、依据文件与版本、确认人，填入包根目录 references/workbook.md 的话术核对表。统计各类句数，合计必须等于总句数；需品牌依据的句子在拿到书面依据并由品牌方确认前，不得进入成片字幕或口播。
