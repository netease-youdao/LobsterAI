# 变更任务经费影响测算
输入有效任务书、真实进展和拟调整方案，分别核任务边界、技术指标、时间、支出分类、资金来源与已执行承诺。把每个拟变更动作追到受影响的里程碑及预算，不用只改结束日期来掩盖需要的测试时间。拟增加的样品、参与方、场景和成本必须显著标建议，用户未确认的不进入事实段。技术目标降低或研究内容改变应单列权限待核，不能当同额预算调剂自动处理。
建立原预算、拟预算、差额、已支出、已签未付、资料状态六列。分类支出合计与财政、自筹等来源分别求和，同一支付不能重复登记到两个来源。已支出是过去事实，拟预算是未来计划，不用拟预算减已支出就称银行可用余额；真实拨款到账与承诺额另列。来源短缺直接展示，不默认其他资金补齐。金额单位统一为万元或元，不能把含税合同和不含税允许成本直接相加成合规支出。
假设原设备四十、算法三十五、材料十五、试用十万元，共一百万元；拟设备三十五、算法四十、其他不变，总额仍一百。财政四十、自筹六十原计划不变；如新材料改自筹五十，则来源仅九十、缺十，不能为凑平把设备随意降十。原计划十二个月，拟十五或十八个月，延长三或六个月，都是条件方案。新旧版本未确认前分别展示，不同时将两个延长月份累加。交付影响说明必须保留原技术目标和已支付三十八万元的历史，明确调整是否能解决实际障碍仍取决于真实进度与权限核实。完成标准是每个变化都有传播范围、每个差额都有公式，不能借已发生费用反推申请已经获准。
