# 可复制预热底稿

```text
直播主题／类型／时长／T0（年月日、星期、时刻）：
价值句：适合［谁］，［时长］里得到［具体收获］。
倒排日历：节点｜日期（含星期）｜时刻｜动作｜渠道｜内容要点｜负责人｜状态（计划／已完成）。
预告脚本：编号｜唯一看点｜0–3秒时间与收获｜中段支撑｜留给直播的部分｜结尾预约引导｜合规自查。
提醒频次：渠道｜日期｜次数｜是否超上限。
一小时检查：网络｜电量散热｜收音画面｜封面标题一致｜商品资料｜场控分工｜违规词自查。
复盘：渠道｜预约数｜到场数｜到场率｜与总体一半比较｜连续偏低场次｜下一场调整。
十分钟在线：人数【用户提供】；数据来源。
关键问题：最多三个，写明会改变哪个节点。
```

## 已填假设示例：新手做账号直播

以下全部为假设。主题为新手做账号前三步，知识分享类，时长一小时，T0为2026年10月24日（星期六）20:00。价值句：“适合刚开号的新手，一小时里拿到账号定位、主页设置和前五条选题三份清单。”

倒排日历：T-3为10月21日（星期三），发预告一（看点是定位句怎么写），用户在后台创建预约并更新主页简介与置顶；T-2为10月22日（星期四），发预告二（看点是主页三处常见错误）；T-1为10月23日（星期五），粉丝群提醒一次；T0前一小时为10月24日（星期六）19:00，粉丝群最后提醒并完成检查；20:00开播时粉丝群发开播通知。粉丝群开播当天共两次，未超上限。

预告一脚本：开头“周六晚上八点，一小时帮你写好账号定位句”；中段展示一句模糊定位和一句清晰定位的对比；留下“清晰定位的三要素”在直播里讲；结尾口播并配画面文字引导预约。

复盘假设：短视频预告预约260、到场52，到场率20.0%；粉丝群预约80、到场30，到场率37.5%；主页置顶预约40、到场8，到场率20.0%。合计预约380、到场90，总体到场率23.7%，其一半为11.8%，三个渠道都不低于这条线，全部保留。开播后十分钟在线人数由用户从后台读取后填入，本示例不估算。下一场调整写“预告二提前到T-2中午发布”，状态为计划。
