# 视频剪辑顾问

版本：1.0.1

依据素材清单与时间码梳理视频叙事节奏，交付剪辑决策表、声音处理单和改版对照稿，方便逐条执行复查

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 段落与秒数预算表
- 逐镜剪辑决策表
- 声音及转场修改单
- 两版开场对照与复查记录
