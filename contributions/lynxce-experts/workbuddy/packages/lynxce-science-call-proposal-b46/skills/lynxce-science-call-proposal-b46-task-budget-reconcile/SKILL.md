# 任务预算平衡
本能力围绕申报阶段任务的成本依据和资金来源组织预算说明，不判断某类支出在所有政策下均可列支。输入为每项任务、成本测算、申请支持额、自筹及其他来源、通知资金条件与金额单位。先登记币种和单位，按任务分别列总预算、申请支持、自筹和其他资金，同一笔成本的各来源相加必须等于该行总额；再分别合计每个来源及总支出。金额资料未知就留待补，不使用无凭据的其他资金平差。

本假设例的设备集成四十、算法验证三十五、材料十五、试用十万元合计一百。财政来源分配二十、十二、四、四合计四十；自筹分配二十、二十三、十一、六合计六十。四行分别满足四十等于二十加二十、三十五等于十二加二十三、十五等于四加十一、十等于四加六，总来源四十加六十等于一百。资金计划不等于到账，成本测算不等于已付发票。支出科目是否允许、间接费用或包干制规则未给时只写待依据真实通知确认。

比例按原文分母计算。若模拟通知规定自筹不少于申请额一点五倍，四十乘一点五得六十，恰匹配。自筹变五十而申请和任务不变时，来源九十较总成本一百差十，自筹也较最低六十少十；这是两个不同的判断，即使数额相同也要分别说明。不能用降低申请额自动消除总成本缺口，也不能假定银行贷款已获批。原成本表未变则完整保留，不通过删一行任务伪造资金平衡。

最终交付包括已填预算表、逐项测算依据、资金来源状态、算术复核和一段可复制说明：“按【通知】及【资料版本】，本项目计划总投入【】，申请【】，自筹【】；与成本合计的差额为【】，资金比例【条件及分母】；【待补证明】确认后再定稿。”变更还需输出原值、新值、受影响章节和生效条件。完成标准是行列两向一致、来源不重复、计划与实际分开、全部限制只绑定本轮原文；没有计算程序也要在交付前独立逐式复算，不用笼统的已核验掩盖数字不一致。
