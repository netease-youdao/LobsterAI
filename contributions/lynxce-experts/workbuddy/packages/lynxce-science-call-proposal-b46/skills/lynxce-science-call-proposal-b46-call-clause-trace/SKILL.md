# 通知条款核对
本能力只处理本轮申报通知与企业资料之间的资格和受理要求，不负责推销政策或猜测成功率。输入为通知正文、附件清单、补充通知、主体资料及其版本。先把申报对象固定为一个项目编号和一个申请主体，再将一段复合条款拆成可判定的小项；保留条款连接关系、例外和不适用条件。例如“企业注册满两年且自筹不少于申请额一点五倍”需要登记主体和资金两个判断，不因为其中一项符合就输出总体符合。

材料表至少包含条款编号、原文位置、适用对象、所需证据、当前资料、状态和下一动作。状态只用满足、有缺口、无法判断、不适用，另设整体证据范围；“材料称满足”与已核到原始证明分开。截图缺上下文，不能把否定句中的数字截出当允许条件；附件明确“其他条件另行规定”则附件缺失是阻塞。没有证据的资料登记留空值或待补，不用无、零、符合替代未知。历年通知只作背景，不能覆盖本轮有效期。

已填假设示例：A01模拟条款为注册满两年，A02登记资料载明注册满三年且独立法人，结论是就该条款资料匹配。A01另有自筹不少于申请额一点五倍，A05载明申请四十、自筹六十万元，计算下限六十万元，本项恰匹配。不能由这两项推出未给出的信用、负责人限项或申报窗口均合格。假设地方通知没有负责人年龄条件，即使国家计划文件提过，也不得补入地方清单。

缺资料仍交可用稿：列已核实条款、材料缺口和影响章节，最多询问完整通知、缺失证明、生效版本三个优先问题。冲突时并列资料编号与各自原值，不默认后来的文件优先；用户指定有效版本后保留旧值作为修订记录。可复制结论为：“本次仅核对【通知版本】中已提供的【条款范围】；【已匹配条款】有材料支持，【缺口条款】需补充，整体受理资格尚待【关键事项】确认。”完成标准是每个判断都可回到用户材料或本轮原文，未提供条件明确未知，且不凭案例生成现实政策。
