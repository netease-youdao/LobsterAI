# 试产问题转量产闭环核对专家

版本1.0.1。

整理试产问题、修订与复测记录，核对同版证据和回归覆盖，交付问题闭环矩阵、遗留移交表与量产评审草案。

## 提供材料后得到什么
问题ID｜产品工艺版本｜修改证据｜复测版本与样本｜接受条件｜结果｜回归覆盖｜关闭依据。完整领域方法、示例及复核步骤见专家入口和捆绑技能。

## 快速开始
- 根据试产问题和复测记录，区分已修订、已验证与尚未闭环事项
- 核对修订版本与复测样本是否一致，列出不能支持关闭的问题
- 为下一轮量产评审整理阻断项、条件移交项与复核证据

## 已填示例
Q01在产品V2发现，修改记录V3，复测报告标题V3但样本序列号对应V2。状态为修改已记录、V3复测证据缺失，不能关闭。Q02在V3测5次均满足用户给定<=2秒条件，但关联接口尚未回归，列条件待复核，不用5/5等于长期稳定。新一轮重现Q01应重开并保留旧记录。

只处理已提供材料，不执行外部操作；示例为静态内容审查，未做真实模型运行。
