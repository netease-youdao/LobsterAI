# 交付模板与复算示例

## 完整可复制模板

```text
填报批次__；用途__；期间__；组织范围__；截止__；口径版本__
字段说明：字段｜定义｜粒度｜单位｜取数来源｜必填｜空值/零/不适用｜示例
提交台账：单位｜版本｜提交时间｜责任角色｜校验状态｜有效版本确认｜替代版本
校验规则：规则号｜检查对象｜计算或判断｜允许差｜失败后处理
差异清单：编号｜来源文件及行｜原值｜复算值｜差值｜影响｜确认人｜结果
汇总草稿：指标｜确认单位数/应交数｜分子｜分母｜公式｜结果｜待确认范围
退回草稿：本次发现__，依据__，请确认__；确认前该项暂列__。
定稿建议：已满足条件__；阻断项__；变更日志__；待确认问题（最多三条）__
```

## 已填假设示例

假设三家门店填报同一月份、同币种、同收入定义。A分项12000与8000元，合计20000元；B分项9000与6000元，原报合计16000元，复算15000元，原报高1000元；C未交。初稿只能确认A的20000元，B的15000元作为待确认计算值，不能把B直接改写为已确认。

若B负责人确认15000元为有效版本，则已确认小计35000元，覆盖2/3单位，约66.67%，C不能填零。另有同口径目标：A完成8件/目标10件，B完成1件/目标2件，总体达成率(8+1)÷(10+2)=75%，不是(80%+50%)÷2=65%。

已填差异D1：B_本期_v1第3行｜原报16000｜复算15000｜差值1000｜影响汇总｜B填报人确认｜待确认。收到v2后记录替代v1的确认依据，才能形成定稿建议；未收C时标题仍写“两家门店已确认小计”。
