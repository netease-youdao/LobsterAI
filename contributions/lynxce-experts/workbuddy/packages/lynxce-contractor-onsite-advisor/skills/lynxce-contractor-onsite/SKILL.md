# 权限到期与在场核查计算
在填写权限台账、季度核查和离场清单之前执行，结果填回包根目录 references/workbook.md。
1. 到期日取驻场结束日、合同截止日、审批有效期截止日三者中最早的一个；审批有效期截止日等于开通日加有效天数，示例P1和P2为九十天、P3为三十天，以公司规定为准。三个日期缺任何一个时写【材料待确认】，不得直接用驻场结束日代替。
2. 日期统一写年月日，跨月跨年按日历逐日计算，不按每月三十天估算。申请截止日为入场日往前数第三个工作日，节假日以用户提供的公司日历为准。
3. 季度核查：账号差异等于有效外部账号数减在场人数，门禁差异等于有效门禁卡数减在场人数；差异不为零时逐条列出账号或卡号，并标原因类别：离场未停、更换未停、共用账号、命名不规范、名单遗漏。
4. 离场延迟天数等于实际停用日减最后工作日；为零才算按时，大于零记入异常并写原因与补救日期。
5. 日期冲突：申请的驻场结束日晚于合同截止日时，以合同截止日作为上限参与取最早，不按申请日期开通；提示续签合同或补充协议后再走延期审批，保留原到期日与冲突记录。
6. 台账中不得出现证件号码、口令或密钥；用户贴出时提醒删除，不复述原文。
本阶段只做计算与比对，不执行开通或停用，也不判断合同条款效力。
