# 可复制驻场底稿

逐栏填写，不适用写原因，未知写【材料待确认】。

```text
供应商／合同截止日／驻场起止／人数／对接人／审批人／日历依据：
入场申请：姓名｜岗位｜驻场起止｜工作区域｜所需系统｜权限级别P1/P2/P3｜部门审批｜信息安全审批（P3）｜申请截止日
身份核验：姓名｜已核验或未核验｜核验人｜日期（不记证件号码）
权限台账：姓名｜外部账号｜系统｜权限级别｜开通日｜驻场结束日｜合同截止日｜审批有效期截止日｜到期日（取最早）｜门禁卡编号｜状态
安全须知：日期｜讲解人｜四项要点已讲（是或否）｜保密文件依据
月度核对：月份｜名单人数｜有效账号数｜差异｜处理
季度核查：核查日｜在场人数｜有效外部账号｜有效门禁卡｜差异明细与原因类别｜处理与完成日
离场清单：项目（门禁卡、钥匙、设备、纸质资料、账号、工作群、共享文件夹）｜编号｜已回收｜确认人｜日期｜实际停用日｜延迟天数
待确认问题：最多三个
```

## 已填假设示例：外包开发驻场

以下人员、日期与数量均为假设，用于演示口径；假设涉及日期没有节假日调整。供应商甲派外包开发12人，合同截止2027年6月30日，驻场2026年11月2日（周一）至2027年4月30日，全员P2权限（代码仓库、测试环境），其中1人另需P3只读查看生产日志。

申请截止日为入场日往前数第三个工作日，即2026年10月28日（周三）。P2到期日：开通日2026年11月2日加90天为2027年1月31日，与驻场结束日2027年4月30日、合同截止日2027年6月30日比较，取最早的2027年1月31日，届时复核续期。P3到期日：2026年11月2日加30天为2026年12月2日，早于另外两个日期，取12月2日，到期前由信息安全负责人复核。

人员更换：A的最后工作日为2026年12月18日（周五），接替的B于12月21日（周一）入场，B的申请截止日为12月16日。外部账号按统一身份账号计，每人一个。

季度核查日2026年12月31日：在场名单12人，有效外部账号14个，有效门禁卡13张。账号差异为14−12=2：A的账号未停用，属离场未停；另有一个“ext-test”被三人共用，属共用账号。门禁差异为13−12=1：A的门禁卡仍有效。处理为当天停用A的账号和门禁卡，关停共用账号，使用者各自重新申请单人账号。A的账号实际停用日12月31日，比最后工作日晚13天，记入异常，原因为人员更换时未同步关闭。待确认问题：公司是否已规定审批有效天数、门禁到期是否能在系统中设置、离场清单是否写入合同结算条款。
