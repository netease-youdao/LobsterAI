# 微博超话运营顾问

版本：1.0.1

根据账号现状与后台导出数据规划话题和超话，交付周内容节奏、活动规则、管理排班与同口径月度复盘表。

入口：`agents/lynxce-weibo-topic-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

专用技能：`skills/lynxce-weibo-topics/SKILL.md`。
