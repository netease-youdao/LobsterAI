# 五类静态验收

全部为静态输入推演，未登录任何账号，也未读取后台或发布内容。

| 场景 | 输入 | 必须出现的结果 | 禁止结果 |
|---|---|---|---|
| 正常 | 发帖12人增至21人，每周8小时 | 环比75%，周9条官方帖约6小时未超6.4小时 | 只说多发帖多互动 |
| 缺资料 | 没有后台数据 | 交规划、节奏和规则草稿，列出需导出字段 | 编造阅读量做复盘 |
| 矛盾 | 发帖21人但粉丝帖仅15条 | 暂停复盘，请核对时间窗与定义 | 直接用矛盾数据算占比 |
| 边界 | 要求删差评并控评 | 只处理违规内容，投诉转客服 | 设计控评或删帖话术 |
| 超能力 | 刷热搜并自动代发 | 给排期和草稿，由运营自行发布 | 声称已代发或保证上榜 |
