# 可复制超话运营底稿

将以下模板完整填写；不适用项写明原因，未知项保留材料标记。

```text
账号／超话名称／月份／版本：
话题规划：话题名｜类型（主、活动）｜导语｜主持人｜起止时间｜重名检索结果。
周节奏：日期｜栏目｜内容要点｜发布位置（话题、超话）｜互动方式｜负责人｜预计工时。
工时核算：周官方帖数｜单条工时｜周所需工时｜可投入工时｜八成上限｜是否减栏目。
活动规则：名称｜参与方式｜起止｜奖品｜名额｜评选方式｜公布时间｜兑奖期限｜授权说明。
超话规则：讨论范围｜禁止事项｜分级处理｜申诉方式。
排班：班次｜时段｜管理员｜上报对象｜交接记录。
健康度：帖子总数｜官方帖｜粉丝帖｜粉丝帖占比｜发帖人数｜一致性核对结果。
月度复盘：指标｜上月｜本月｜环比｜原因｜下月动作。
待确认：最多三项，每项写明会改变哪项安排。
```

## 已填假设示例：文创品牌超话

以下数字均为假设，不是任何账号的真实数据。某文创品牌超话开设三个月只有十几人发帖，运营一人，每周可投入8小时。计划：超话每天一条官方帖共7条，其中周五为“买家秀征集”；主话题周三“新品剧透”、周日“本周精选”各1条。周官方帖7+2=9条，按每条40分钟估算需9×40=360分钟即6小时；八成上限8×0.8=6.4小时，6小时未超，节奏可执行。

买家秀征集：名额10名，每份奖品为价值59元的文创周边，奖品合计10×59=590元，由市场确认预算；评选方式为管理员按规则初筛后粉丝投票，截止后三天内公布，兑奖期限十五天。假设收到有效投稿48份，获奖比例10÷48≈20.8%。排班为两名管理员，9:00至16:00和16:00至23:00各7小时，覆盖14小时。

月度复盘：上月帖子总数80条，其中官方帖62条、粉丝帖18条，粉丝帖占比18÷80=22.5%，官方帖占77.5%，超过七成。本月帖子总数110条，其中官方帖36条，与计划每周9条、四周9×4=36条一致；粉丝帖74条，36+74=110，口径一致；粉丝帖占比74÷110≈67.3%。发帖人数由12人增至21人，环比（21−12）÷12=75%；扣除1个官方账号后粉丝发帖20人，不多于粉丝帖74条，一致性通过。阅读由52000增至61100，环比17.5%。买家秀征集贡献了本月新增粉丝帖中的多少，需要按话题筛选后核实，暂写“待核实”；下月只调整一处：把周日“本周精选”改为粉丝问答。
