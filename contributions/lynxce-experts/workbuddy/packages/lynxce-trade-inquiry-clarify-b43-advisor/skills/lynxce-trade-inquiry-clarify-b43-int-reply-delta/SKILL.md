# 询盘二轮变更承诺核对

本内部能力只处理询盘二轮变更承诺核对，输入为首轮回复、客户二轮原文、业务员授权条件；输出为二轮变更表与承诺措辞复核。独立保留依据，不代替公开任务的完整交付。 依据仅限用户提供的业务资料。每项事实注明资料编号、版本与日期，缺项写【待补】，推测与确认事实分栏。对冲突输入保留原值和来源，不用示例填补真实空白。只交付可复制的文本和表格；不声称已联网取得数据、连接系统、发送消息、修改记录或执行现场操作。不作资质、认证或签章结论。

## 工作流程

1. 接收首轮回复、客户二轮原文、业务员授权条件，明确本轮对象、截至时刻、资料版本与用户希望解决的问题；缺少核心资料先给待补表，保留能够核对的部分。

2. 按任务对象建立唯一记录键，拆分事实、声明与未知条件；逐条关联原文及原值，重复、缺漏与来源冲突单列，不静默覆盖。

3. 按字段比较两轮原文，不按邮件长度判断变化；新增用途可能影响材质确认，即使数量未改也须重开有关问题。使用表格保存比较口径、数量单位和适用范围，方法无法实施时说明具体缺少哪一项输入。

4. 将被修改条件的相关句定位到双语段落，先修中文事实再更新英文，避免只换数字而保留旧交期保证。对存在分歧的条目提出可回答的确认问题，条件足够才推进，不把未确认的假设转成决定。

5. 结合领域方法复核异常和变更影响，给出待核、补证后可继续或需重新对齐的分支；把责任、期限与验证证据逐项列入。

6. 交付二轮变更表与承诺措辞复核，逐行复算数字与单位，检查来源、版本、状态和未闭环项；由用户负责角色复核后使用，后续资料按新版本续接。

## 对象与口径方法

- 按字段比较两轮原文，不按邮件长度判断变化；新增用途可能影响材质确认，即使数量未改也须重开有关问题。

- 将被修改条件的相关句定位到双语段落，先修中文事实再更新英文，避免只换数字而保留旧交期保证。

- 把客户已答、未答和新增三类问题分开；第二轮只追未答关键项与新问题，不重复询问已证实的信息。

- 检查样品承诺依赖哪些规格、包装和时间条件，任一依赖改变就改为重新确认，交付待发送的修订草稿。

## 证据与决策方法

- 把原文按规格、用途、数量、目的地、期望时间、样品要求分句编号；每个字段保留原句位置与解释，客户没说的条件保持空白，不以行业惯例替客户确定。

- 建立客户用词与产品资料术语对照，尤其区分尺寸外径与内径、额定与峰值、套与件；相似型号只能标为候选，不把用户资料没有写出的功能补进回复。

- 检查产品型号、单位、日期和否定词四类高风险翻译点；将每一个数字回指原文或用户资料，若资料冲突则同时列两种说法并请求业务员指定版本。

- 回复草稿与对外可发送版分别标注，客户隐私用客户代号；用户只给截图转录时说明可能存在识别缺漏，并要求核对关键型号与小数点。

## 异常与交付复核

- 核对表中每项判断必须能回指输入记录，不同来源相互矛盾时列出冲突双方与待确认问题；输入没有证明完成的事项保持待核，不能写为事实。

- 检查每行单位、分母、时间窗口与版本是否一致，先复算再解释；零值、空白、未发生是三种不同状态，不把缺失字段默认为零。

- 输出时先列影响与未满足条件，再给逐行证据与下一步动作；责任人与复核人没有提供就留待补，不自行捏造人员或补上批准结论。

- 新资料到来时更新差异与有效范围，保留原表版本和修改原因；旧记录仅作历史依据，不把之前的假设结果当本次真实业务数据。

## 假设案例

假设首轮300件、每箱30件，合10箱；二轮450件则15箱，增加5箱。客户同时把样品从1套改2套，必须单列样品变化，不能把增加5箱当作样品变化。原回复只有预计发出日期，修订时不得变成预计到达日期。

## 能力边界
