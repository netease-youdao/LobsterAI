# 画幅字号与对比度核算
用于海报规格定稿和已有稿复核阶段，只做尺寸、字号和对比度的计算与判定，不评价审美优劣，也不代平台给审核结论。
画幅：屏幕投放直接按像素填写；打印品像素 = （成品毫米 + 2×3毫米出血）÷ 25.4 × 300，四舍五入。例如A3成品297×420毫米，加出血为303×426毫米，约3579×5031像素。
可用区域：宽 = 画面宽 − 左右边距之和；高 = 画面高 − 上安全区 − 下安全区。另有裁切展示时，上下各取安全区与裁切让位中较大的值。
字号：主标题下限 = 画面高 × 6%，上限 = 画面高 × 9%；单行还须满足 字数 × 字号 ≤ 可用宽度，否则断行；副标题 = 主标题 × 45%到60%；1920高画面正文不小于48像素。断行后该层总高度 = 行数 × 字号 × 行距倍数，须放得进为该层预留的高度。
缩略：缩略字高 = 字号 × 缩略宽度 ÷ 画面宽。150像素宽时，115像素字号约剩16像素，主标题缩略字高低于此值判为可能读不清，须实际缩放复看。
对比度：色值每个通道先除以255，小于等于0.04045时再除以12.92，否则取（c+0.055）÷1.055的2.4次方；相对亮度 = 0.2126R + 0.7152G + 0.0722B；对比度 = （较亮者 + 0.05）÷（较暗者 + 0.05）。标题门槛3:1，正文与支撑信息门槛4.5:1。半透明黑色色块下的背景近似为 原色各通道 × （1 − 不透明度）。
