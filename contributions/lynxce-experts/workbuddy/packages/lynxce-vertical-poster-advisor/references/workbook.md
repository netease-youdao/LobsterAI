# 可复制海报规格底稿

将以下模板完整填写；不适用项写明原因，未知项保留【材料待确认】。

```text
项目名称／用途／投放位置与展示形态／版本号：
材料清单：编号｜内容｜提供者｜日期。
画幅：宽×高像素｜比例｜裁切版本｜打印成品尺寸、出血与像素换算。
安全区：上｜下｜左右｜依据（平台截图或默认值）｜可用区域宽×高。
信息层级：层级｜原文｜字数｜字号｜行数｜字重｜位置｜颜色｜材料编号。
行宽核对：每行字数×字号＝？｜是否不超过可用宽度｜断行方案。
缩略检查：缩放比例｜主标题缩略字高｜是否可读。
对比度：文字色｜背景取色位置与色值｜对比度｜门槛｜色块不透明度或描边｜复核结果。
画面：主体占比｜位置｜主色与强调色｜留白比例。
信息核对：日期与星期｜时间｜地点｜费用｜报名方式｜标识｜错别字｜对照材料编号。
授权：字体｜图片｜人像｜凭证存放位置。
导出：格式｜质量｜色彩空间｜体积上限｜文件名｜分层源文件｜无文字底图。
变更记录：版本｜变更内容｜原值｜依据｜作废的外发文件。
待确认：最多三项，写明影响哪一层或哪项参数。
```

## 已填假设示例：社区读书会预告图

以下全部为演示假设，不是真实活动。材料M1为主办方文案：活动名“城市夜读计划”，2026年10月24日周六19:30，地点为某社区图书馆三楼，免费需提前报名；材料M2为投放要求：短视频平台全屏竖版，同时在信息流以3:4卡片展示；未提供平台截图。

画幅取1080×1920像素。信息流裁切区为中央1080×1440，上下各让出240像素；默认安全区上250、下400像素，比裁切更严，以安全区为准，可用区域为（1080−60×2）×（1920−250−400）＝960×1270像素。

主标题“城市夜读计划”6个字，取150像素，占画面高度150÷1920≈7.8%，在6%到9%之间；单行宽6×150＝900像素，不超过960像素。副标题“周六晚上一起读一本书”10个字，取主标题的50%即75像素，单行宽750像素。支撑信息“10月24日 周六 19:30｜社区图书馆三楼｜免费 需报名”分两行，字号48像素。品牌标识放在可用区域右下角，不进入下方400像素遮挡区。

缩略检查：缩到150像素宽，比例为150÷1080≈0.139，主标题缩略字高约20.8像素，可读；48像素的支撑信息缩略后约6.7像素，不要求在缩略图中看清，所以日期星期另用强调色块托底。

对比度：主标题为白色，压在天空照片上，取色#C8D2DC，对比度约1.53:1，不达标。加40%黑色色块后背景约#787E84，对比度约4.10:1，满足标题3:1，但不满足正文4.5:1；支撑信息所在色块提到50%，背景约#64696E，对比度约5.54:1，两类门槛都满足。

核对：按日历，2026年10月24日为周六，也是当月第四个周六，与M1一致；时间、地点、费用逐字对照M1。导出JPG质量90%，sRGB，体积控制在2MB以内，文件名为“城市夜读计划_预告_1080x1920_v1”，另存分层源文件和无文字底图。待确认：平台实际遮挡范围（需截图）、报名方式原文、主办方标识文件。
