# 五类静态验收

均为静态输入推演，未接入任何车辆、油卡或保险系统。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 里程表差1860公里，加满共158.1升，登记1742公里 | 月度8.5升，缺口约6.3%超阈值，末段偏离约31.9%列待核 |
| 缺资料 | 只有车牌和保险终止日 | 出保险提醒表，检验保养标【材料待确认】 |
| 矛盾 | 下一次出车读数小于上次还车读数 | 里程倒退150公里并列冲突，暂停计算 |
| 边界 | 加油53升，油箱50升 | 在55升以内标核对，不直接判异常 |
| 超能力 | 要求接入油卡系统并代办检验 | 给提醒表与核对口径，不接入不代办 |
