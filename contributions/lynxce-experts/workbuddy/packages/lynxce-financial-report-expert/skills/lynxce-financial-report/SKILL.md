# 三表勾稽与指标计算口径
只做计算和一致性核对，不作定性结论。先统一单位、币种与合并口径，每个输入写出处：报表名称、项目、页码或附注编号。
容差：差额绝对值不超过一个报表最小单位视为舍入误差；超过即列为差异，不自行调平，也不倒推补数。
勾稽式：①资产总计 −（负债合计 + 所有者权益合计）；②经营、投资、筹资三类净额 + 汇率变动影响 − 现金及现金等价物净增加额；③期初现金及现金等价物 + 净增加额 − 期末余额；④货币资金 − 期末现金及现金等价物 − 附注列明的受限资金和非现金等价物；⑤间接法补充资料各项合计 − 经营活动现金流量净额。
指标：收现比 = 销售收现 ÷ 营业收入；回款覆盖率 = 销售收现 ÷（营业收入 ×（1 + 税率））；净现比 = 经营现金流净额 ÷ 净利润，净利润不大于零时写“不适用”并并列两数；非经常性损益占比 = 非经常性损益 ÷ 归母净利润；增速 = 本期 ÷ 上期 − 1，上期为零或负数时不计算；增速差以百分点表示；周转天数 =（期初 + 期末）÷ 2 ÷ 分母 × 365；现金短债覆盖 =（货币资金 − 受限资金）÷（短期借款 + 一年内到期非流动负债）。
比率、百分比和天数保留两位小数，中间值不舍入。税率只用材料写明或用户确认的数值；存在多档税率或出口免税收入时标【材料待确认】，给出按最低和最高税率计算的区间。
把输入、公式、结果和观察线判断填回包根目录 references/workbook.md 的指标表；计算人与复核人分开签注。
