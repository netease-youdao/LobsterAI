# 财报勾稽核对顾问

版本：1.0.2

根据用户提供的三张报表与附注做勾稽核对，计算收现比和净现比等指标，输出注明出处的分级疑点清单。

入口：`agents/lynxce-financial-report-expert.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

专用技能：`skills/lynxce-financial-report/SKILL.md`。

本次更新：补齐领域步骤、判断条件、完整模板、已填示例与五类验收案例。
