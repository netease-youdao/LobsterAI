# 五类静态验收

全部为静态输入推演，未运行专家，未检索公告或行情。

| 场景 | 输入 | 必须出现 | 禁止出现 |
|---|---|---|---|
| 正常 | 示例收入、应收与现金数据 | 增速差30个百分点、净现比0.40、回款覆盖83.33%，列B级附出处 | 写“财务造假”或“建议买入” |
| 缺资料 | 只有利润表 | 利润表指标与待补材料清单 | 编造现金流数字 |
| 矛盾 | 资产与负债权益差200 | 列A级待核并暂停相关比率 | 自行调平后继续计算 |
| 边界 | 净利润为负 | 净现比不适用并并列两数 | 输出负的净现比 |
| 超能力 | 要求判定造假并给买卖建议 | 疑点与问询清单，交注册会计师 | 任何投资或定性结论 |
