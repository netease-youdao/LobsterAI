# 可复制财报核对底稿

```text
主体／报告期／合并或母公司／准则／单位／审计意见类型／材料版本：
勾稽表：勾稽式｜左值｜右值｜差额｜容差内与否｜附注解释｜出处页码。
指标表：指标｜公式｜本期｜上期｜观察线｜是否越线｜出处。
营运资金：应收类增速｜收入增速｜增速差｜存货增速｜成本增速｜周转天数。
现金与偿债：三类现金流组合｜可动用现金｜短期有息负债｜覆盖倍数。
风险信号：项目｜观察到的事实｜出处｜需补材料。
疑点清单：编号｜等级｜事实与数值｜可能的正常解释｜问询问题｜确认人。
结论三句：现金转化｜偿债压力｜首要问询。
更正记录：日期｜原值｜新值｜依据｜受影响指标。
```

## 已填假设示例：某制造企业年度合并报表

以下数字均为假设，单位万元，主营收入假设全部适用13%税率。勾稽：资产总计20000，负债11500与所有者权益8500合计20000，差额为零。期初现金及现金等价物1800，经营600、投资−1500、筹资1100、汇率影响0，期末2000，与报表一致。货币资金2600与期末现金等价物差600，附注列示票据保证金600，可解释。

利润质量：营业收入12000，上年10000，增速20%；销售收现11300，收现比0.94，参照含税收入13560，回款覆盖率83.33%，低于90%。净利润1500，其中归母1400，经营现金流净额600，净现比0.40，低于0.5。非经常性损益500（政府补助300、资产处置收益200），占归母净利润35.71%，扣除后为900。毛利率本期25%、上年24%，变动1个百分点，未越线。

营运资金：应收账款期初3000、期末4500，增速50%，比收入增速高30个百分点；周转天数 (3000+4500)÷2÷12000×365 ≈ 114.06天。存货期初2000、期末2600，增速30%；营业成本9000、上年7600，增速18.42%，差11.58个百分点，未越线，周转天数约93.28天。可动用现金2600−600 = 2000，短期借款1800加一年内到期非流动负债700共2500，覆盖0.80倍。

疑点清单：B1 应收增速差、净现比、回款覆盖率三项同向，问询前五大客户信用期变化、期后回款与收入确认时点；C1 非经常性损益占比35.71%，问询政府补助是否持续；C2 现金短债覆盖0.80倍，问询授信额度与续贷安排。结论三句：现金转化弱于账面利润；可动用现金不足以覆盖短期有息负债；首要问询为应收增长快于收入的原因。以上仅为待核事项，结论交注册会计师确认。
