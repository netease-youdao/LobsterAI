# 人月生活费与补贴测算
以人员编号和年月为最小行，分别登记实际见习、出勤、生活费发放、保险覆盖、本轮允许的人月与已领取补贴。先核本轮地方标准是人月固定额、生活费比例、封顶还是按日折算，不能自行统一每月金额，更不能将给个人的生活费总额当企业本次应获补贴。国办法只明确支持用途和地方确定具体标准，本项按用户原文复算，不用其他城市标准补缺。
每个月份必须能回到原始考勤或指导记录、生活费银行流水及保险凭证。内部表写已发并不证明银行到账，银行转账也不能单独证明当月完整见习。月中开始、结束、请假、签劳动合同转就业、跨月发放等依本轮规则分流，缺规则只列两种待确认情境。未知保险和未给出勤不是零，也不是默认全勤；同一人同月不得重复计入两次，多个项目资金重复支持要逐项核原补贴范围。
假设当地规定每合格完整人月补贴一千八百元，甲六月至八月三个月，乙七月至八月两个月，合计五人月，候选九千元。甲每月生活费二千二百共六千六百，乙两个月四千四百，合计一万一千；每人月保险三十，五人月一百五十，是单位支出，不额外叠加到九千元补贴，除非本轮规则明写另给。甲八月出勤新旧冲突时，五或四人月对应九千或七千二百；乙资料未变继续计两个月。不能为了满足要求补造签到、流水和保险。交付人月表、算式和限制性说明，候选金额不称核准额或到账额，完成时每个计入或待核月份都有明确理由。
