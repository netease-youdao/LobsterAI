# 迁移标签拆分键与碰撞核对

本任务只处理迁移标签拆分键与碰撞核对。最少输入为逐行旧新标签、迁移子行编号、货物身份字段与批准拆分数量，独立交付子行守恒检查表与重复标签碰撞表。仅使用用户提供的记录、规则和人工确认。来源以资料代号、版本、时间定位，未知字段写【待补】。原始事实、计算结果、假设条件与建议分栏，不能以案例填真实空白。只交文本与表格，不声称已连接业务系统、修改台账、发送信息或执行现场操作；不索取账号口令。不作专业医疗、财税、法律结论，不判定设备安全或材料技术合格；需要专业处置时整理证据给用户指定人员。

## 工作流程

1. 确定本轮小任务为迁移标签拆分键与碰撞核对，接收最少事实资料：逐行旧新标签、迁移子行编号、货物身份字段与批准拆分数量。明确对象键、单位、版本和截点，关键字段不足先交局部事实表与待补问题。

2. 只处理映射唯一性与子行量，不决定标签切换时间。建立父迁移行及子行编号，子行编号在同一父行下唯一，不能因目标位置相同就删除不同批次的子行。原始值、解释值和未知分别记录，重复对象保留对应关系。

3. 将重复分为完全重复导出、同标不同目标和同目标不同标。完全重复必须有同一原始行号证据才能去重，同标不同目标是碰撞，后两类不能被同一个去重规则吞掉。列出逐行算式或证据配对规则，不以常识补齐必要数据。

4. 逐父行求子行数量加明确未迁量，超过原量标超配，不足标欠分配。负数或缺单位先退回核原值，不能靠减另一批次抵平；需要换箱件单位时先核给定系数。正常、缺资料、来源矛盾及端点边界走不同分支，只有输入满足前提才输出条件结果。

5. 输出影响父行和受影响标签集合，一项碰撞可涉及两行但仅一个标识。分别计问题标识数与涉及行数，方便用户修订编号，不把行数当错误标签数量。把专属异常、欠证对象、下一核实角色和关闭依据放进附件，处理超出能力请求时交证据而不执行。

6. 交付子行守恒检查表与重复标签碰撞表。逐行复算单位、分母与版本，按用户反馈登记人工确认和实际状态；新资料保留旧版并仅重核受影响行。

## 状态分支与证据方法

- 资料索引逐项保留原记录代号、发生时刻、记录时刻和版本；先判断是否覆盖当前对象，再引用数值。没有资料证明的动作保留待核，不能将上一轮示例、计划值或人员口述改写成实际完成证据。

- 补件按字段更新而非整表覆盖：记录旧值、新值、修改理由及受影响行，原始冲突保留双版本。用户尚未指定哪个版本生效时给条件式结果和一个可回答的确认问题，不能自行选择有利版本消除异常。

- 汇总前检查单位、对象范围和唯一键，整数件数不平均处理，缺失不等于零。每个公式保留输入值与结果，数量、时长和状态覆盖率分开；分母为零标不适用，比例不能充当所有对象已完成的证明。

- 交付时列当前可确认事实、阻塞条件、最少补证与人工复核角色。执行建议、人工批准、现场反馈和复核通过分别登记；收到反馈仍需逐对象检查关闭依据，资料只覆盖局部就明确保留局部范围。

- 从输入的逐行旧新标签、迁移子行编号、货物身份字段与批准拆分数量中筛选覆盖当前小任务的记录，逐条检查出处是否可回看。对任务之外的字段不强行推算；用户补充资料改变范围时明确新增核对行，原有已证实的行保持证据链接。

- 五类案例分别用于检查正常推进、关键字段缺失、来源互斥、恰好边界和执行权限边界。以当前资料确定对应分支，不能把假设中的数字复制到实际表内；案例结果仅说明方法可复算，不说明模型表现。

- 复核附件应让另一名经办人员从原值重算并找到欠证对象，发现分母、时间窗或版本不一致则返回原字段修订。交付时注明本小任务完成的是文本核对，现场动作和审批状态仍按用户反馈登记。

## 五类假设检查

- 正常案例（明确假设）：假设父行100件分为子行60与40，各用不同标识。预期处理：差额0件，无标识碰撞。复算：60+40=100；100-100=0

- 缺资料案例（明确假设）：子行写3箱但无该批次箱件系数，父行为100件。预期处理：单位待补，不计算3箱对应件数。复算：无可计算条件；保留原值和待核范围，不补数。

- 矛盾案例（明确假设）：父行100件，子行60与50，新标同为L8。预期处理：超配10件且1个标签影响2行，分别报告。复算：60+50-100=10；1标/2行

- 边界案例（明确假设）：父行0件且无子行，用户确认是空位只改位置标。预期处理：数量差额0，货物标签覆盖率不适用，位置标单独核对。复算：0-0=0；0分母不计算

- 超出能力案例（明确假设）：要求凭货号自动生成可用条码并写入扫描器。预期处理：只提供映射字段草案，不声称生成注册编码或接入扫码设备。复算：无可计算条件；保留原值和待核范围，不补数。
