# 可复制成本工作簿

```text
分析周期／币种／现金或摊销／含税口径：
材料索引：账单编号｜资源表｜利用率窗口｜业务量｜合同适用范围。
核对表：总账单｜分项合计｜税费折扣退款｜未解释残差。
归因表：服务资源｜归属及依据｜旧数量价格｜新数量价格｜量效应｜价效应｜总增量。
候选表：动作编号｜资源范围｜业务用途｜依赖及保留要求｜证据缺口。
收益表：动作｜可避免费用｜新增月费｜净月节省｜一次成本｜静态回收期｜互斥项。
变更单：范围｜执行角色｜窗口｜先决证据｜观察指标｜中止条件｜恢复方式与限制。
复测表：基线成本/业务量｜复测成本/业务量｜单位成本变化｜其他影响｜证据状态。
结论：首选组合／暂缓项／未解释残差／最多三个关键问题。
```

## 已填假设示例：测试环境计算费

假设两期都是三十天、同币种折后未税费用，没有阶梯价。旧期1000实例小时、每小时2元，共2000元；新期1200小时、每小时2.2元，共2640元，增加640元。先量后价得到用量增量200×2=400元，价格增量1200×0.2=240元，加总640元。标签材料只覆盖2200元，剩余440元列为未分配；不能直接按人数摊给团队。假设业务任务从10000次增到15000次，单位成本从0.20元降至0.176元，降低百分之十二，说明总额增长并不等于效率下降。

候选A为关闭已确认无夜间任务的测试实例时段，按当前价预计每月减少200小时，毛节省440元；新增调度维护费40元，净月节省400元，一次实施费800元，静态回收期为两个月。候选B是在完全相同的200小时范围降配，假设可节省220元；二者互斥，不能报告660元毛节省。示例首选A只因假设已确认夜间无需服务，真实任务和依赖未确认前应保持待评审。

变更稿填写“由测试环境负责人选择一个实例试行，先提供任务日历和恢复配置记录，观察任务完成率与次日启动情况，中止阈值材料待确认”。下一周期假设实际计算费减少420元而新增维护费40元，在等用量基准下净节省380元，比计划少20元；需核对实际关闭时长和单价，不能把预计400元写为已实现。三项问题依次是夜间任务依赖、真实折后单价和可接受恢复时间，分别决定能否停、节省多少与是否影响业务。
