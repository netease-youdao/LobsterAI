# 可复制排品底稿

```text
场次／日期／开播时段／排品表版本／数据导出时间：
商品角色表：编号｜商品｜角色｜价格｜毛利区间｜库存｜预警值｜退换规则｜角色依据。
排品时间轴：轮次｜起止时刻｜分钟｜商品｜角色｜购物车序号｜负责人｜核对勾选。
时长校验：各轮合计｜整场合计｜主推分钟与占比｜主推返场次数｜超出默认区间的说明。
上下架口令：时刻｜主播口播序号｜助播动作（置顶/开放购买/下架）｜后台核对项。
单品讲解卡：痛点｜演示动作｜规格参数｜价格与权益｜促成交｜资质依据。
场中记录：时刻｜在线人数｜正在讲的商品｜点击｜成交｜调整建议｜决定人。
逐品复盘：商品｜讲解分钟｜曝光人数｜点击人数｜点击率｜成交人数｜转化率｜成交金额｜讲解分钟产出。
下场重排：调整项｜依据｜是否连续两场同方向｜生效场次。
```

## 已填假设示例：两小时九品直播

以下数据全部为演示假设。直播20:00至22:00共120分钟，原计划20个品从头讲到尾，后半场在线下滑。精简为9个讲解品加1个赠品：福利品Y1、Y2，主推品Z1（199元）、Z2（159元），利润品L1（89元）、L2、L3，清仓品Q1、Q2，赠品G1挂在Z1权益里。

第一轮20:00至21:15共75分钟：开场福利6、Y1 5、Y2 4、Z1 12、L1 7、Z2 10、L2 7、L3 6、Y1返场5、Z1返场10、过渡福利3。第二轮21:15至22:00共45分钟：Y2 4、Z2返场9、L1返场6、Z1 8、Q1 4、Q2 4、收尾抽奖与下场预告10。两轮合计120分钟；开场三段共15分钟。主推Z1共30分钟、Z2共19分钟，合计49分钟，占整场约40.8%；主推返场3次。

库存预警：Z1库存300件，上一场讲解时段每分钟成交6件，预警值30件；Y1没有历史，库存200件，预警值取两成即40件。

场后复盘（假设每位成交人数买1件）：Z1讲解30分钟，曝光20000人，点击1600人，点击率8.0%；成交160人，转化率10.0%；成交金额31840元，讲解分钟产出约1061.3元。Z2讲解19分钟，曝光12000人，点击900人，点击率7.5%；成交63人，转化率7.0%；成交金额10017元，讲解分钟产出约527.2元。L1讲解13分钟，曝光8000人，点击640人，点击率8.0%；成交80人，转化率12.5%；成交金额7120元，讲解分钟产出约547.7元。Y1首次讲解开始时在线800人、结束时1100人，增加300人即37.5%，保留开场位置。

重排：Z2本场讲解分钟产出低于L1，但只有一场数据，下场保持Z2主推角色，把Z2返场从9分钟缩到8分钟，多出的1分钟给L1返场（6分钟改为7分钟），整场仍为120分钟，并复查Z2演示环节；若下一场仍低于利润品，再讨论角色调整。
