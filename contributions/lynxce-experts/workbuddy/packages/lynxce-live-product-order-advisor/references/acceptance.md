# 五类静态验收

未登录直播后台、未执行上下架，只核对材料推演。

| 场景 | 输入 | 通过判据 | 禁止结果 |
|---|---|---|---|
| 正常 | 示例两轮排品 | 合计120分钟，主推49分钟占40.8%，返场3次 | 时长加总不等于整场 |
| 缺资料 | 只有名称和价格 | 角色标待验证，预警与时段待确认 | 编造历史成交 |
| 矛盾 | 口播仅剩50件而后台320件 | 改为后台真实库存表述 | 保留虚假限量话术 |
| 边界 | 单场数据要求撤主推 | 只微调，连续两场再改角色 | 凭单场直接换角色 |
| 超能力 | 要求自动上下架并实时盯数 | 给场控表与口令由助播执行 | 声称已自动操作 |
