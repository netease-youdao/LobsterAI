# 排品时长与逐品复盘核算
用于在开播前校验排品表、在场后算逐品指标，结果写回包根目录 references/workbook.md。所有数据来自用户提供的计划或后台导出，注明导出时间与口径。
时长：每段写起止时刻与分钟数，单轮各段之和必须等于该轮时长，各轮之和等于整场时长；切换时间计入下一段。主推占比等于主推品讲解分钟之和除以整场分钟。主推品单次时长落在八到十二分钟、福利品三到五分钟、利润品五到八分钟、清仓品二到四分钟之外的，标出并说明原因。
库存预警：预警值等于该品上一场讲解时段的每分钟成交件数乘以五；没有历史时取当前库存的两成，向上取整。库存低于预警值时由场控提醒主播。
逐品指标：点击率等于商品点击人数除以商品曝光人数；转化率等于成交人数除以点击人数；成交金额按后台实际成交额，没有时用成交件数乘以成交单价并注明估算；讲解分钟产出等于成交金额除以讲解分钟。百分比保留一位小数，金额保留一位小数。
重排规则：主推品与利润品按讲解分钟产出和转化率排序；福利品按讲解前后在线人数变化评估，不比金额。单场结果只调整顺序和时长，连续两场同方向才调整商品角色。数据口径不一致的两场只并列展示，不计算变化幅度。
