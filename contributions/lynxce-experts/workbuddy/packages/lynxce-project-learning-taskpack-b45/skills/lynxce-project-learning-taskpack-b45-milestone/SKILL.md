# 项目分钟排程与缩课重排

## 何时调用与最低输入
输入总课时、单节长度、不可删学习动作和当前进度，输出可执行的分钟段与缩减方案。
只围绕本项任务制作一个可以被上层专家直接引用的中间成品。用户没有给出的条件以待补标记；可先按写明的假设生成样稿，再提出不超过三个会改变结果的问题。给每次输入分配材料编号，同一编号在本轮中保持含义不变，不能把推测写成材料事实。

## 具体制作方法
先保留个人思考、同伴比较、作品修改三个核心动作，再安排讲解、美化和展示。每个时间段写教师提示、学生动作和本段产物；把单组展示时间与整班总时间分开计算。缩课时沿依赖链删除可选扩展，不把四节课所有活动等比例压缩到两节。对等待其他组的时段安排同伴试读，避免隐藏空档。

## 可复制的已填示例
已填两节课重排：第一节导入五分钟、读材料八分钟、独立计算十分钟、比较九分钟、交核心草稿八分钟；第二节回顾四分钟、合稿十二分钟、互读八分钟、修改十分钟、个人反思六分钟。两节各四十，总八十分钟。删除精美海报和逐组长展示，保留一页建议单、个人计算与一次修改。

## 修订与完成判据
课时变更后重新逐段求和，不只改标题。若作品无法在现有课时完成，缩小受众或栏目，不以学生课外无偿补完当默认前提。完成时总分钟匹配、依赖顺序成立、每节末都有可见成品。
交付时同时给可直接使用的正文和一段使用说明，指出哪个条件变更会触发重做。引用本项成品时保留版本号和适用范围，不能只复制结论丢掉假设。遇到用户要求跳过必要输入，仍给可编辑草案，并把受影响位置显式标注，不扩展成未经授权的执行。完成意味着输入可以逐项映射到输出，示例能够手算或逐句核验，所有占位都已有用途说明；不把纸面设计写成已经获得现实反馈。

四组各10分钟串行加20讲解=60而非40。并行仅在场地与评价方式允许时用两批10分钟；每批8名巡读者。改第3节为5+10+13+7+5=40时，需把末5拆为回看2、修改2、收齐1；原回看修改17改4减少13，收齐10改1另减9，不把同1分钟归两处，也不声称只前移。总160与个人资源约束同时验证。


第四轮同次成品：复用包内schedule_ledger.py的具体人/动作/活动唯一ID与结果，正文、角色产物、议程和复制稿来自同一JSON。学习动作压缩、资源条件与未知执行回执分别保留，不把人分钟当课堂经过时间，不把本地测试当模型真实通过。
