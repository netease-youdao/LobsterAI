# 学生任务书与驱动问题收敛

## 何时调用与最低输入
输入学习目标、受众、课时与作品类型，输出能直接发给学生的任务书。
只围绕本项任务制作一个可以被上层专家直接引用的中间成品。用户没有给出的条件以待补标记；可先按写明的假设生成样稿，再提出不超过三个会改变结果的问题。给每次输入分配材料编号，同一编号在本轮中保持含义不变，不能把推测写成材料事实。

## 具体制作方法
先把宽主题缩成某个受众在某种场景需要的一件小作品。写清学生必须使用的材料与可自由选择的部分，再将目标对应到作品栏目。任务书采用学生能读懂的行动句：读两份材料、比较一个差异、提出两条建议、解释一个限制。每一步都给出要交什么，避免只写讨论、探索、创新。用一名第一次接触项目的学生视角走读，凡是必须猜老师意思的地方补上说明。

## 可复制的已填示例
已填任务：“给值日生制作一页洗手区用水建议单。使用材料甲，写问题、计算、两条行动和使用限制。先独立算出每天等待流水量，再与组员复算，最后合成一页稿。”任务书模板为受众／驱动问题／材料／作品规格／必须动作／可选扩展／提交节点。四十分钟单课不要求做实测调查与精美海报两项大任务。

## 修订与完成判据
材料条件改变时，先改任务动作和作品规格，再改时间表。完成必须有直接可发放正文和一份教师说明；不能把教师术语原样丢给学生，也不能把没有授权的实地活动写成必做。
交付时同时给可直接使用的正文和一段使用说明，指出哪个条件变更会触发重做。引用本项成品时保留版本号和适用范围，不能只复制结论丢掉假设。遇到用户要求跳过必要输入，仍给可编辑草案，并把受影响位置显式标注，不扩展成未经授权的执行。完成意味着输入可以逐项映射到输出，示例能够手算或逐句核验，所有占位都已有用途说明；不把纸面设计写成已经获得现实反馈。

资源硬约束：本纸笔案例的学生版必须只有纸、笔与给定材料；不能沿用常见模板新增计算器。不同版本资源分别写明。


第四轮同次成品：复用包内schedule_ledger.py的具体人/动作/活动唯一ID与结果，正文、角色产物、议程和复制稿来自同一JSON。学习动作压缩、资源条件与未知执行回执分别保留，不把人分钟当课堂经过时间，不把本地测试当模型真实通过。
