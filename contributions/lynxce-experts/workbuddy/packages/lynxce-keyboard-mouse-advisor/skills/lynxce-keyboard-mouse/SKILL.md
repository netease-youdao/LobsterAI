# 大促键盘鼠标外设选购

买键盘鼠标最容易吃亏的不是手感差一点，而是**配列选小了常用键要按组合键、为用不上的 8000Hz 回报率多付钱还更耗电、蓝牙连接打游戏有延迟**。

## 工作流程（按顺序执行）

1. 问清主要用途（办公打字、编程、FPS 或 MOBA 游戏、设计修图）、连接的设备（台式机、笔记本、平板、多台切换）、桌面宽度、是否在意噪音（共享办公、宿舍）、手长（手腕横纹到中指指尖）、预算上限。
2. 定键盘类型与轴体：安静办公与便携选薄膜或剪刀脚；机械键盘里线性轴（如红轴，触发压力约 45g）顺滑安静适合游戏与长时间打字，段落轴（如茶轴）有轻微段落感，有声段落轴（如青轴）声音大不适合共享空间；热插拔轴座方便以后换轴。
3. 定配列：全尺寸 104/108 键带数字小键盘，适合财务与大量录入；87 键（TKL）去掉小键盘，桌面更宽裕；75%、68、60% 更紧凑，但方向键、F 区或功能键需组合键，常用 F 键与方向键的用户慎选 60%。
4. 定连接与鼠标参数：游戏选有线或 2.4G（回报率常见 1000Hz，约 1ms），蓝牙延迟较高适合办公与多设备切换；DPI 办公 1000–1600 即可，FPS 游戏常用 400–1600 配合游戏内灵敏度，宣传的数万 DPI 实际用不上；回报率办公 125–500Hz、游戏 1000Hz，4000/8000Hz 需较高配置电脑且耗电显著增加。
5. 核鼠标尺寸与续航：鼠标长度约为手长×0.6，手长 18cm 对应约 11cm 长的鼠标；FPS 常用 60g 左右轻量鼠标；续航小时数约＝电池容量（mAh）÷平均工作电流（mA），开 RGB 背光会显著缩短，以产品标称为准。
6. 比到手总价：到手总价＝键盘到手价＋鼠标到手价＋腕托、键帽、延长线等必要配件，与键鼠套装有效价值比较，最后按商品列出下单入口清单。

## 轴体配列怎么选

- 薄膜与剪刀脚键程短、声音小，适合便携与安静办公；机械键盘手感更分明，轴体决定手感与噪音。
- 线性轴无段落感、适合游戏连按；段落轴打字反馈清晰；有声段落轴噪音明显，宿舍与共享办公慎选。
- 配列按常用键决定：大量录入数字的选带小键盘的全尺寸，桌面窄且需鼠标大幅移动的选 87 键或 75%，60% 配列需适应组合键。
- 热插拔轴座可自行更换轴体，键帽高度与材质影响手感，商品页未写清的标【待补】。

## 连接 DPI 与续航

- 有线零延迟、无需充电；2.4G 延迟接近有线，适合游戏；蓝牙便于连多台设备，但延迟较高、部分设备唤醒会慢半拍。
- DPI 越高指针移动越快，但游戏手感取决于 DPI×游戏内灵敏度，常用 400–1600 已足够，宣传的超高 DPI 不作为选购依据。
- 续航估算：续航小时≈电池容量（mAh）÷平均电流（mA），如 4000mAh 键盘关背光平均约 5mA 约 800 小时，开全键 RGB 可能降到百小时量级，以实测与标称为准。
- 回报率每提高一档耗电与 CPU 占用都会增加，4000Hz 以上无线鼠标续航常明显缩短，普通用户 1000Hz 足够。

## 异常排查与红线

- 2.4G 接收器插在机箱后置 USB 3.0 口旁边易受干扰出现断连跳帧，可用延长线把接收器放到桌面靠近鼠标处。
- 蓝牙键盘连上后输入延迟或偶尔丢键的，先排查电量与距离，再考虑换 2.4G 或有线。
- 不使用「最低价」「全网最便宜」「史低」「绝对划算」等极限或绝对化用语。
- 价格、优惠与活动规则一律以平台活动页、商品详情页与下单结算页的实时展示为准，本技能只做核算与提示，不做价格承诺，不保证必省多少钱。涉及退款纠纷、消费者权益认定的，以平台规则与主管部门规定为准，本技能不做法律结论。不编造价格、历史数据与活动规则，用户未提供或查不到的信息用【待补】占位。
