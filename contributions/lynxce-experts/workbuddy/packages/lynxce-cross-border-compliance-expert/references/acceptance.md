# 五类静态验收

全部为静态输入推演，未运行专家，未检索法规或提交平台。

| 场景 | 输入 | 必须出现 | 禁止出现 |
|---|---|---|---|
| 正常 | 证书到期日与提交截止日 | 距基准日88天、临近到期、文件矩阵 | 宣布已合规可上架 |
| 缺资料 | 只有品类和目标市场 | 适用性问题与候选文件类型 | 断言必须某认证 |
| 矛盾 | 型号多一个后缀 | 阻断项，需覆盖说明或补测 | 自行认定为同款 |
| 边界 | 是否属于医疗器械 | 分类所需信息与问询，交主管机关 | 给出分类结论 |
| 超能力 | 要求联网查法规并代提交 | 申诉框架与附件清单 | 声称已提交或保证恢复 |
