# 可复制认证资料底稿

```text
商品／型号／目标市场／平台站点／基准日（上架或提交日）／材料版本：
规则来源：要求｜原文摘录｜来源类型｜材料日期｜解释｜是否需复核。
文件矩阵：文件类型｜签发机构｜编号｜持证主体｜适用型号｜标准与版本｜签发日｜到期日｜距基准日天数｜状态。
一致性：项目（型号／主体／电压／功率／电池）｜证书｜报告｜标签｜商品页｜结论。
分级清单：编号｜阻断／待确认／提示｜事实｜需补材料｜负责人｜预计取得日。
侵权排查：位置｜内容｜疑似对象｜需检索的关键词或图片｜处理建议。
申诉框架：通知编号与日期｜问题复述｜原因｜已完成措施及证据｜预防措施｜附件清单｜截止日。
待确认：最多三项，写明各自影响哪项结论。
```

## 已填假设示例：蓝牙音箱补交文件

以下全部为假设。商品为蓝牙音箱，含锂电池，在欧盟某站已上架。平台通知日期为2026年10月12日（周一），要求7天内补交合规文件，截止2026年10月19日（周一），以此为基准日；整理日为10月14日（周三），剩余5天。

文件矩阵：电气安全与电磁兼容报告R1，签发2023年3月10日（周五），型号BT-200，无到期日，距基准日1319天，通知未写时限，只记录不判超期。无线电类证书C1，到期2027年1月15日（周五），距基准日88天，标“临近到期”，提示联系发证机构了解续证所需时间。

一致性：证书与报告型号为BT-200，商品页和标签为BT-200S，列阻断项，需机构出具覆盖说明或补测。标签电池为3.7伏、2000毫安时，能量3.7×2.0 = 7.4瓦时；电池测试摘要写3.7伏、2200毫安时，即8.14瓦时，参数不一致，列阻断项，需供应商说明实际电芯并统一文件。

申诉框架：问题复述引用通知原文；已完成措施只写“已向机构提交型号覆盖说明申请（证据：申请回执编号待填）”；未取得的文件写“计划于10月16日（周五）前取得”。若截止前无法取得，在提交说明中写明进度和预计日期，不把计划写成已完成。商标检索项：商品页出现某知名耳机品牌词一次，列入需检索并建议删除。
