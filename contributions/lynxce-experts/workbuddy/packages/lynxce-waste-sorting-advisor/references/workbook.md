# 可复制分类落地底稿

将以下模板完整填写；不适用项写明原因，未知项保留【材料待确认】。

```text
办公区名称／城市及目录版本／楼层／人数／方案版本号：
分类口径：类别｜当地名称｜桶色｜本办公室常见物品｜易错物与当地归类｜依据。
点位规划：楼层｜点位编号｜位置｜覆盖区域｜最远工位路线距离（米）｜步行秒数｜桶型组合｜清运频次｜责任人。
标识样稿：点位｜类别｜可投3例｜不可投3例｜照片是否本办公室实物。
回收台账：日期｜类别｜品类｜件数或重量｜回收方｜是否有资质｜凭证编号｜经办人。
台账对账：季度｜类别｜台账合计｜凭证合计｜差异｜逐笔核对结果。
电子设备移交：设备｜资产编号｜清除方式｜清除人｜复核人｜销账日期｜接收方｜凭证。
抽查记录：周次｜点位｜抽查件数｜错投件数｜错投率｜主要错投物｜改进动作。
改进判定：点位｜最近两轮是否下降｜动作（改标识／换桶型／调点位）｜目标值。
季度公示：回收量｜各点位错投率变化｜下季度重点。
待确认：最多三项。
```

## 已填假设示例：单层120人办公区

以下为演示假设。城市目录为四类；工位区沿一条54米主通道分布，另有茶水间和打印区各一处。工位区按通道长度÷36米向上取整设2个点位，分别在通道13.5米和40.5米处，每个点位覆盖两侧各13.5米，最远工位路线距离13.5米，按每秒1.2米为11.25秒，在15秒以内。茶水间点位放厨余、其他垃圾、可回收物；打印区放废纸箱和墨盒硒鼓专收盒；有害垃圾集中在前台一处。

抽查四周（抽查件数/错投件数）：工位东点位A为40/12、42/9、38/6、40/5，错投率30.0%、21.4%、15.8%、12.5%，逐周下降。工位西点位B前三周为35/7、36/8、40/9，错投率20.0%、22.2%、22.5%，连续两轮未下降，第3周后把B点位移到外卖取餐柜旁并加厨余桶，第4周为38/6，错投率15.8%。茶水间点位C为50/15、48/12、45/9、44/7，错投率30.0%、25.0%、20.0%、15.9%。

合计：第1周三个点位共125件错34件，错投率27.2%；第4周共122件错18件，错投率14.8%。四周合计抽查496件、错投105件，总体错投率21.2%，用件数总和相除，不取各周百分数平均。主要错投物为带残渣的外卖餐盒和奶茶杯，第二次培训只讲这两项。

季度台账：废纸三次42.5、38.0、45.5公斤，合计126.0公斤；塑料瓶两次6.2、5.8公斤，合计12.0公斤。回收方凭证废纸合计126.0公斤、塑料瓶12.0公斤，与台账一致，可公示。报废笔记本电脑3台，按资产编号逐台清除数据并双人签字，销账后交有资质单位，凭证编号记为【凭证编号】。待确认：当地目录对墨盒硒鼓的归类、物业清运频次、错投率目标值。
