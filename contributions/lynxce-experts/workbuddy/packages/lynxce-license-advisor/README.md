# 证照与资质台账管理顾问｜灵策智算

版本：1.0.1

根据现有证照材料建立主体台账续期倒排与借用记录逐项核对有效期办理依据原件去向及待确认事项便于复查

交付：主体证照台账与依据清单、续期节点及材料准备表、原件使用借还与季度差异表。

入口：`./agents/lynxce-license-advisor.md`；专属复核：`skills/lynxce-license-ledger/SKILL.md`；模板、假设示例与验收：`references/workbook.md`。提交已有材料后先获得可用草稿，再补齐关键缺口。

使用边界：基于用户提供材料整理与计算；不连接业务系统、不自动执行、不后台持续服务。示例均为明确假设，静态验收不代表真实运行。
