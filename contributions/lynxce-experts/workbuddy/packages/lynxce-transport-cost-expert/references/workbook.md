# 可复制运输成本底稿

```text
线路／材料编号／数据期间／税口径：
线路：起点｜终点｜单程里程｜回程是否有货｜时效｜装卸要求。
车辆：车型｜核定载重｜容积｜资料来源。
货物：每趟实重｜体积｜件数｜月趟数或月货量。
基准成本：燃油｜路桥（去／回）｜趟补｜维修轮胎｜固定分摊（月固定÷月趟数）｜合计。
单位成本：每趟｜每公里｜每吨公里｜计算式。
装载：重量装载率｜体积装载率｜约束项｜空驶率。
报价归一：承运商｜计价方式｜基础运费｜附加费｜条件费用及依据｜不含税合计｜含税合计｜偏离基准｜服务差异。
议价清单：编号｜差额｜对应成本项｜可交换条件｜确认人。
降本测算：措施｜前提｜测算值｜需确认环节。
待确认：最多三项，写明各自会改变哪个结论。
```

## 已填假设示例：A仓至B配送中心

以下全部为假设数据，不代表真实线路或承运商。单程420公里，回程空驶，往返840公里，空驶率50%。9.6米厢车核定载重18吨（假设，以行驶证为准）、容积55立方米；每趟实载12吨、40立方米，重量装载率66.67%，体积装载率72.73%，约束项为体积。月出车20趟，金额均为不含税。

基准测算：燃油 840×28÷100×7.5 = 1764元；路桥去程600元、回程450元，共1050元；司机趟补500元；维修轮胎 840×0.4 = 336元；固定分摊 24000÷20 = 1200元。合计4850元每趟，每公里约5.77元，每吨公里 4850÷(12×420) ≈ 0.9623元。

报价归一：甲为整车含税5450元、税率9%、含装卸，不含税5000元。乙为整车4600元加装卸300元，超过两小时的等待每小时100元，近三个月平均等待3小时，预计等待费100元，合计5000元；若等待压到两小时内则为4900元。丙为零担0.45元每公斤，换算系数每立方米250公斤，体积重10000公斤小于实重12000公斤，计费重12000公斤，运费5400元加提货200元共5600元，时效两到三天。甲、乙偏离基准均为3.09%；丙偏离15.46%且时效不同，列入议价并单列服务差异。

降本与联动测算：月货量800立方米，若仓库能把每趟装到50立方米，需16趟，每趟15吨未超核定载重，体积装载率90.91%；按每趟5000元，月运费由100000元降到80000元，前提是时效与出库节奏允许合并，需仓储确认。燃油联动：油价由7.5元升到8.1元，往返用油235.2升，成本增加141.12元，约为基准的2.91%；承运商条款为每满0.5元调整3%，加价150元，与成本变化接近，要求合同写明基准油价和取价来源。
