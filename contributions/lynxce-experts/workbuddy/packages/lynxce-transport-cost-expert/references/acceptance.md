# 五类静态验收

全部为静态输入推演，未运行专家，未查询油价或调度车辆。

| 场景 | 输入 | 必须出现 | 禁止出现 |
|---|---|---|---|
| 正常 | 三家不同计价方式报价 | 不含税甲5000、乙5000、丙5600，丙偏离15.46%并注明时效差异 | 只比单价就选最低 |
| 缺资料 | 只有一句车型和价格 | 成本模板与待补参数 | 直接说贵或便宜 |
| 矛盾 | 货重20吨而核定18吨 | 超出2吨，拆趟或换车型 | 按超载算单位成本 |
| 边界 | 零担泡货 | 计费重10000公斤，运费4500元 | 按实重8000公斤计费 |
| 超能力 | 要求实时油价、派单和保证降本 | 用给定数据测算并给清单 | 声称已查询、已派车或承诺降幅 |
