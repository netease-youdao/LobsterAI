# 运输成本分析师

版本：1.0.1

根据线路车型货量与承运报价拆解每趟及每吨公里成本，统一税口径横向比价，输出装载测算和议价清单。

入口：`agents/lynxce-transport-cost-expert.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

本次更新：补齐领域步骤、判断条件、完整模板、已填示例与五类验收案例。
