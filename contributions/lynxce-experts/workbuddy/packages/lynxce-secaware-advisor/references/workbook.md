# 可复制安全意识底稿

```text
企业／适用部门／版本日期／制度依据：
数据分级表：数据类型｜示例｜级别｜判定理由（命中哪一项）｜存放位置｜访问范围｜外发审批｜传输方式｜打印带出｜保存期限｜销毁方式。
行为手册：编号｜场景｜正确做法｜错误做法｜原因｜适用级别。
演练审批：批准人角色｜批准日期｜法务与人力确认｜信息技术放行｜禁用主题。
演练设计：难度要素组合｜难度等级｜落地页提示内容（无输入框）｜时间窗含星期。
演练结果：名单人数｜投递成功｜点击｜上报｜点击后上报｜点击未上报｜首次上报用时｜各项比例（分母为投递成功）。
事后跟进：微课截止日｜应完成人数｜按时完成｜完成率｜部门汇总。
事件上报单：编号｜发现时间｜上报时间｜用时｜数据级别｜数量估计｜已采取动作｜处置人角色｜法务评估状态。
关键问题：最多三项。
```

## 已填假设示例：260人软件服务企业

以下为演示用假设。客户联系人表（姓名、手机号）为第三级；客户开票资料含证件号码与银行账户，命中敏感个人信息中的特定身份与金融账户项，定为第四级，只能存放在指定加密目录，外发须经部门负责人和安全负责人双签。

演练于2026年11月2日（周一）经管理层书面批准，时间窗为11月10日（周二）至11月12日（周四）。名单240人（全员260人中剔除安全团队与长假人员20人），投递成功236人，4封退信。点击38人，点击率38÷236约16.1%；上报71人，上报率71÷236约30.1%；点击后又上报9人，点击且未上报29人，占12.3%。点击者须在演练结束后七天内即11月19日（周四）前完成微课，按时完成34人，完成率34÷38约89.5%；未完成的4人由部门负责人提醒，不公开名单。

事件上报示例：11月16日（周一）9:40，一名员工把含1200行客户联系人的表格误发给外部合作方，10:05上报，用时25分钟，在三十分钟内部时限内。已请收件方删除并书面确认，处置过程追加记录到事件单；是否需要通知个人或监管部门，状态为“待法务评估”。
