# 以旧换新补贴与大促优惠叠加到手价核算

以旧换新最容易算错的不是旧机值多少，而是**几种补贴能不能同时用、先扣哪个、补贴到底抵的是哪一段价**。

## 工作流程（按顺序执行）

1. 先问清：要买的品类与型号、所在城市（补贴按地区）、是否有旧机及旧机品类、是否已领取地方补贴资格、付款方式，缺的标【待补】。
2. 把所有优惠分四类列出：平台补贴（如以旧换新补贴、品类券）、地方消费补贴（按能效或品类比例补贴、有单件封顶）、店铺券与满减、旧机回收款。
3. 逐条核对叠加规则：地方补贴页面写明的「不与 XX 同享」、平台补贴的适用商品范围、店铺券是否限非补贴商品，互斥的只能二选一，均截图留档。
4. 按扣减顺序测算：常见顺序是先店铺券与满减 → 再算地方补贴（按比例且有封顶）→ 再扣平台补贴 → 旧机回收款单独到账，实际顺序以下单页为准。
5. 对比至少两种组合的到手价（如「地方补贴 + 店铺券」与「平台补贴 + 旧机回收」），并把旧机回收款是否直接抵扣、何时到账分开写。
6. 下单前核对资格有效期（地方补贴资格常有领取后 X 天内使用的限制）、发票要求（部分补贴须开具发票并留存），最后按型号列出下单清单与入口。

## 补贴类型与叠加判断

- 地方消费补贴多按成交价比例计算且有单件上限，也可能限定能效等级、品类与指定商户，资格一般一人一类一次。
- 平台补贴与地方补贴是否可叠加以两边公告为准，任何一方写明互斥即不能同享，不要凭经验判断。
- 店铺券、满减、跨店满减是否计入补贴计算基数会影响结果：补贴按「券后价」还是「标价」算，要看补贴规则原文。
- 旧机回收款通常是另一笔钱（先估价、上门或寄回质检、再打款），不一定在下单时抵扣，按单独一行记录。

## 到手价测算方法

- 到手价 = 标价 − 店铺券与满减 − 地方补贴（按比例并受封顶约束）− 平台补贴 − 旧机回收实得款；每一步写出计算式。
- 比例补贴示例：券后价 5000 元、补贴比例 15%、单件封顶 2000 元，则补贴 = min(5000 × 15%, 2000) = 750 元。
- 旧机回收价以质检后实得为准，估价只作参考，测算时用估价区间的下限。
- 分期、以旧换新服务费、上门安装费、延保等附加费用要加回到手价，不能只算优惠。

## 资格核验与红线

- 本技能重点是补贴叠加与到手价，旧机具体估值以回收方质检报价为准，不在此替代估价。
- 补贴资格需实名、本地、按品类限次，不代用户办理、不借用他人资格，不教规避规则的做法。
- 补贴类订单退货可能需退还补贴，退货前看清补贴回收规则。
- 补贴资格、额度、名额与申领流程以当地主管部门与平台官方公告为准，本技能不代为判断资格。不使用「最低价」「全网最便宜」「史低」等极限词，不做价格承诺与「必省 X 元」保证；价格、券面额、门槛与活动规则一律以平台活动页和下单页实时显示为准。不编造价格、库存、销量与活动规则，用户未提供或页面未显示的信息用【待补】占位。

## 示例

用户：「想在 11.11 换一台一级能效空调，标价 4299，店铺满 4000 减 300，本地补贴 15% 封顶 2000，平台以旧换新再补 200，旧空调估价 150–300，这些能一起用吗？到手多少？」→ 先请用户截图补贴规则原文核对互斥：假设地方补贴写明「按券后价计算、可与店铺券同享、不与平台以旧换新补贴同享」；组合 A（店铺券 + 地方补贴 + 旧机）：4299 − 300 = 3999，补贴 min(3999 × 15%, 2000) = 599.85，到手 3399.15，旧机按下限 150 单独到账；组合 B（店铺券 + 平台补贴 + 旧机）：3999 − 200 = 3799；组合 A 更低；再提醒资格有效期与发票留存要求，价格以下单页为准，最后给出下单清单。
