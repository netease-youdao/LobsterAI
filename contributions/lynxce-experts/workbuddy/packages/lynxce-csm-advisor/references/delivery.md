# 交付模板与复算示例

## 完整可复制模板

```text
客户周期卡：客户__；统计期间__；快照来源__；与上期是否可比__
结论：最需确认的风险__；支持证据__；本期限制__
评分表：维度｜原始数值与分母｜量表｜得分｜权重｜贡献｜证据｜缺项原因
总分/区间__；覆盖权重__；示例阈值是否经团队确认__
价值回顾：客户原目标__；观察成果__；计算__；无法归因部分__
续约准备：日期__；预算角色__；合同摘要__；未关闭服务事项__；需确认产品能力__
行动台账：编号｜风险假设｜备选解释｜行动负责人｜拟获取证据｜提议日期｜关闭标准｜状态
跨期变化：编号｜上期事实｜本期事实｜变化原因｜仍缺材料
沟通草稿：我们观察到__，希望核对__。建议下一轮先完成__，由__确认效果。
待确认问题（最多三条）__
```

## 已填假设示例

假设甲客户9月有100个符合条件席位，60个活跃；关键任务完成80次、双方目标100次；服务量表得分100，角色沟通得分50。采用度60、成果80、服务100、角色50，权重40%、30%、20%、10%。总分60×0.4+80×0.3+100×0.2+50×0.1=73。团队假设关注线为70，73仅供内部复盘，不能解读为73%续约概率。

10月同口径活跃席位降至50，其他项不变，总分69，下降4分。风险R1：活跃下降；备选解释：席位名单变更。客户经理甲拟在10月16日核对人员名单，关闭条件为名单核对完成且关键任务阻碍已获解释。价值回顾填写“关键任务完成80次/目标100次，达成率80%，还差20次”，不把下降原因说成已证实。

若10月服务材料缺失，已知加权贡献为20+24+5=49，覆盖权重80%，总分区间49至69；不能直接输出69分或按49÷80%输出新健康等级。客户带回服务证据后再更新同一R1记录，保留本次缺资料版本。
