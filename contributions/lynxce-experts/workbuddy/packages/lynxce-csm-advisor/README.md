# 客户成功顾问

版本：1.0.1

依据每期客户使用与服务材料，整理健康评分、价值回顾、续约准备和风险行动台账，支持逐期人工复盘。

作者：灵策智算 LynxceAI

入口：[lynxce-csm-advisor](agents/lynxce-csm-advisor.md)。完整交付包括带覆盖率的健康评分表、续约价值回顾和角色材料表、跨期风险行动台账。

先在会话中提供已脱敏材料，专家据此整理草稿与核对结论。模板见 [交付模板与复算示例](references/delivery.md)，验收边界见 [五类静态验收](references/acceptance.md)。每期由用户带入上一期台账及本期快照，再完成同口径比较与行动复盘；不会自行读取客户系统。

本包没有后台运行、实时监控或自动发送能力。示例均为明确标注的假设资料；计算结果可复算，不代表真实客户成效。
