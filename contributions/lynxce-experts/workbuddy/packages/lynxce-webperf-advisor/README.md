# 前端性能顾问

版本：1.0.1

根据性能记录区分加载与交互瓶颈，提供优化排序、实验对照和预算验收底稿，帮助团队复核改善证据。

入口：`agents/lynxce-webperf-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

专用技能：`skills/lynxce-web-perf/SKILL.md`。
