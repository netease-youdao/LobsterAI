# 可复制OKR与面试底稿

```text
周期起止与星期／层级／版本／材料编号：
O：表述｜对应上级KR｜负责人。
KR表：编号｜结果表述｜类型｜基线｜目标｜实际｜取数口径｜权重｜得分｜备注。
自查：动作词｜条数｜基线齐全｜全部达成是否实现O｜跨团队承接。
复盘：KR｜执行问题或假设错误｜被验证或推翻的判断｜下周期调整（目标/路径/资源）。
能力模型：能力｜达标表现｜优秀表现｜对应关键任务｜权重。
面试题：能力｜主问题｜追问｜一到四分锚点｜否决项。
评分汇总：能力｜各面试官分｜平均｜最大分差｜是否需校准｜加权分。
合规核对：是否出现禁问因素｜改写记录。
关键问题：最多三项，写明答案会改变哪一栏。
```

## 已填假设示例：新客户上手

以下均为演示假设。第三季度为2026年7月1日（周三）至9月30日（周三），共92天，复盘会安排在10月16日（周五）。

O：让新客户在第一周就用上核心功能，对应上级KR“新客户首季留存率提升”。KR1：新用户七日激活率从百分之二十二到百分之四十，挑战型，权重四成，实际百分之三十四，得分（34 − 22）÷（40 − 22）≈ 0.67。KR2：每百名新客户首周工单从18单降到10单，承诺型，权重三成，实际12单，得分（12 − 18）÷（10 − 18）= 0.75，承诺型未达1，需写原因与补救。KR3：引导流程完成率从百分之五十五到百分之七十五，权重三成，实际百分之八十，计算值1.25，记1.00并标注超目标。O得分 = 0.4 × 0.67 + 0.3 × 0.75 + 0.3 × 1.00 ≈ 0.79。

归因：KR1属假设错误，以为缩短注册步骤就能提高激活，实际流失集中在首次导入数据环节；KR2属执行问题，帮助文档按时上线但客服话术未同步。下季度把KR1路径调整到数据导入环节。

面试示例：客户成功专员，三位面试官于10月22日（周四）独立打分，10月23日（周五）校准。能力与权重：问题定位三成，沟通协作二成五，学习迁移二成五，责任意识二成。评分：问题定位3、3、4，平均约3.33；沟通协作2、4、3，平均3.00，分差2分，标需校准；学习迁移3、3、3，平均3.00；责任意识4、3、4，平均约3.67。暂定加权总分约3.23分（满分4分），在沟通协作校准记录完成前不作为比较结论。
