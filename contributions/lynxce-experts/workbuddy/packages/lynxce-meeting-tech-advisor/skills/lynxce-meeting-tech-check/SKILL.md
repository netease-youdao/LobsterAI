# 会前调试与回声排查记录

本阶段把排查过程记成可复核的数字和结论，不远程操作任何设备。

1. 音频端点计数：列出同一房间内入会的每台设备，记录麦克风开或关、扬声器开或关。目标是每个房间只有1个开着的收音设备和1个开着的放音设备；需要关闭的数量 = 开着的数量 − 1，逐台写明是哪台。
2. 回声判向：记录“谁听到了自己的回声”。线上人听到，先查会场端点；会场听到，先查当时发言的线上人是否外放。啸叫单独记录，先调低本地音箱。
3. 逐座位测试：每个发言座位朗读同一段话，由一位线上同事打“清楚／勉强／听不清”。覆盖率 = 清楚座位数 ÷ 发言座位数，保留一位小数，目标100%；勉强也算未达标。整改后同一方法复测并保留两次结果。
4. 准备时长：清单项目数 × 每项约2分钟，应不超过准备窗口（常规15分钟，首次混合、对外或超过30人的会议30分钟）；超出时提前开始，不删检查项。
5. 升级门槛：同一会议室同一现象在一个月内出现2次及以上，交管理员评估维修或更换；占比 = 出现次数 ÷ 该室会议场次，仅作说明。

把端点表、覆盖率、准备时长和升级结论写回包根目录 references/workbook.md。“已修复”只记录管理员确认过的结果。
