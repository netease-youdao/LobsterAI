# 报价价格链与单证日期核算

用于把用户给出的成本、运费、汇率和信用证条款换算成可复核的数字。先统一口径：人民币成本注明是否含包装与唛头，汇率写成每一美元兑多少元，百分比先转小数，运费注明币种、柜型和有效期。缺任何一项时只算到能算的那一层，其余写【材料待确认】。

装箱：每箱体积 = 长 × 宽 × 高（米）；总箱数 = 数量 ÷ 每箱数量，向上取整；柜数 = 体积所需柜数与重量所需柜数中的较大者，可装上限以货代确认的数值为准。

价格链：工厂交货成本 = 产品含包装成本；装船前成本 = 工厂交货成本 + 国内运输 + 报关与起运港杂费。按售价利润率时，外币单价 = 单位成本 ÷（1 − 利润率）÷ 汇率；按成本加成时，外币单价 = 单位成本 ×（1 + 加成率）÷ 汇率，两种口径不能混用。单价向上取两位小数。CFR单价 = FOB单价 + 运费 ÷ 数量；CIF单价 = CFR单价 ÷（1 − 投保加成 × 保险费率），投保加成默认1.1，向上取两位。

复核：实际利润率 = （外币FOB总价 × 汇率 − 人民币成本）÷（外币FOB总价 × 汇率）；再用财务给的下沿汇率重算一次，写明利润率下降多少个百分点。

单证日期：最迟交单日 = 装运日 + 交单天数 与 信用证到期日 中较早的一天；信用证注明适用UCP600而未写交单天数时，按二十一个日历日。每个日期写星期。到期日或交单末日遇交单银行非营业日的顺延规则以信用证文本和银行确认为准，最迟装运日不因此顺延。赊销敞口 ≈ 月出货额 × 账期天数 ÷ 30，与信保或授信限额比较，超出部分列出金额。

结果只供内部测算，不代表银行审单结论或税费认定。把代入值、舍入方式和来源填回包根目录 references/workbook.md。
