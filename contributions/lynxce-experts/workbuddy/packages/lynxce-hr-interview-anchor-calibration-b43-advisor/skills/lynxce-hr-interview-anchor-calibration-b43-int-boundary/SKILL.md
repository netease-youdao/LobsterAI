# 岗位锚点边界修订单

内部专项任务：岗位锚点边界修订单。只处理相邻等级的观察条件与回评范围，不替代公开任务的完整交付。核心方法为：以相邻档位的可观察差别编写修订版本，分别列触发条件、反例和最低证据；修订后用匿名行为片段回看，记录受影响候选人范围并交负责人确认生效。

## 工作流程

1. 确认专项输入为既定岗位锚点、匿名面试记录与独立评分，锁定所用版本及本次范围，仅抽取与岗位锚点边界修订单有关的字段；缺项标【待补】，不要套用演示例子作为事实。

2. 建立相邻等级的观察条件与回评范围的原始证据列，记录资料编号、原文片段与目前状态；将事实与经办人的解释分栏，矛盾内容保留两种记录。

3. 以相邻档位的可观察差别编写修订版本，分别列触发条件、反例和最低证据；修订后用匿名行为片段回看，记录受影响候选人范围并交负责人确认生效。每项都说明判断顺序、触发条件和例外，缺关键条件时不强行给确定结论。

4. 逐项采用专属方法核查：面试官分差阈值来自用户流程或明确假设，超阈值只触发复核而非认定哪方错误；相同得分也可能依据不同，关键能力仍需核证据是否一致。保留原始值和推演值，让复核人能够独立重现过程。

5. 用专项示例检查数量守恒及分类互斥：假设旧版6条锚点有2条仅用形容词，修订2条、保留4条，2＋4＝6；有3份旧记录涉及修订项，列3份待确认回评，不能只改其中1份。遇到不闭合结果，先找遗漏与重叠，不能为了闭合改写事实。

6. 输出相邻等级的观察条件与回评范围并列待补项、影响范围、复核人及下次更新条件；没有用户反馈的条目不变更为已完成，专项结果交由主流程采用。

## 专项证据方法

- 加权结果写每项分数乘权重再求和，权重合计须为一或百分之百；缺项时报告覆盖权重，不对其余项目偷偷归一化，否则会改变比较含义。

- 面试官分差阈值来自用户流程或明确假设，超阈值只触发复核而非认定哪方错误；相同得分也可能依据不同，关键能力仍需核证据是否一致。

- 复核结果分为维持原分、依据补证修订和暂不计总分，记录谁确认何时生效；不把修订意见写成已经获得委员会同意，不生成自动淘汰或录用结论。

- 最终用岗位相关语言描述需要补证的行为，不用年龄、性别或家庭情况作评价；资料包含无关信息时不进入评分表，输出可审查的证据与程序问题。

## 专项模板与决策

- 以相邻档位的可观察差别编写修订版本，分别列触发条件、反例和最低证据；修订后用匿名行为片段回看，记录受影响候选人范围并交负责人确认生效。

- 每一行以专项对象编号为主键，与公开成果只通过资料编号关联，不复写公开交付全文；表头固定包含原状态、证据位置、专项判断和待核动作。

- 分支状态采用已确认、待证据和存在冲突三类；待证据不是否定，存在冲突不能合并为已确认，后续反馈到来后再记录原状态和新状态。

- 复核意见必须包含可观察依据与采用版本，确认人没有提供时标【待补】；文字建议与实际执行分栏，避免专项草案被误读为已经完成的业务。

## 复核与版本

- 资料入口采用最小必要字段，先核用户提供的版本、时间与适用范围；原始记录和解释意见分别保存，缺项统一写【待补】。存在两份冲突资料时并排列出，不擅自选更有利的一份，也不把演示数字补成真实业务事实。

- 输出每条判断对应的资料编号、所用方法和状态，记录谁需要确认以及确认后会改变哪一项结果。所有数量注明单位，计算保留分子分母和逐步算式；舍入只用于展示，原值与修正值均保留以便复核。

- 表格是根据给定资料编写的文本草案，计划、人员自报、资料核对通过和实际完成分开记录。没有实际反馈就维持待确认，不能声称已经读取业务系统、发送通知或执行现实任务；也不提供任何资格认定或虚构外部验证。

- 完成前先检查每条输入是否有去向、每条输出是否有来源、每个异常是否有承接动作。后续更新只改有新证据的条目，保留旧版本与变更理由；超出本任务的请求列具体缺项或交接建议，不把未核实事实写进结论。

## 假设案例

以下为专项假设，非真实业务结果：假设旧版6条锚点有2条仅用形容词，修订2条、保留4条，2＋4＝6；有3份旧记录涉及修订项，列3份待确认回评，不能只改其中1份。该示例只演示专项判断的分类与数值核对。实际使用时先把资料对象逐行编号，保留原始证据，再执行所列方法；不符合前置条件的对象必须单列待核，不能放入已确认数量。若用户补充记录导致判断改变，记录新增依据、原状态和新状态，重新计算受影响的分母与合计。最终只输出文本对照表和复核建议，不宣称已执行外部任务。复核时逐项检查对象总数、已确认数和待核数是否闭合，注明所用资料版本与计量单位；发现输入修订时只重算受影响条目，并在输出中保留旧值、修订值和差异原因，交由业务负责人确认后再更新主流程记录。

## 能力边界

根据用户提供的资料整理和分析；未知项填【待补】，区分事实、假设与建议。没有实际连接工具时不声称读取或修改业务系统，不编造实时数据或已完成的操作。
