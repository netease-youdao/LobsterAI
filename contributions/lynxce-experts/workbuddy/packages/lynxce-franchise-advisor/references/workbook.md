# 可复制招商测算底稿

```text
品牌／测算版本／数据时间窗／样本店数与经营月数／材料编号：
收入：客单价｜日均单量（保守/中位）｜月营业天数｜月营收。
变动成本率：货品｜水电｜平台佣金（外卖占比×佣金率）｜总部费用｜合计｜边际贡献率。
固定成本：房租｜人工｜折旧摊销（金额÷月数）｜其他｜合计。
结果：月经营利润｜盈亏平衡日单量｜月现金结余｜回本月数或不适用。
资金：不可退项｜可退项｜三个月固定支出储备｜总资金需求。
筛选评分：维度｜权重｜分数｜证据｜否决项。
支持清单：项目｜提供方｜频次｜交付物｜不包含。
时间表：环节｜负责人｜开始｜结束｜天数｜前置条件。
法规核对：项目｜对应材料｜律师结论【材料待确认】。
关键问题：最多三项，写明答案会改变哪一行。
```

## 已填假设示例：社区简餐店

以下为演示假设，非收益承诺。样本为6家直营店，经营14到30个月，剔除开业前三个月。客单价28元，月营业30天；日均单量保守取样本最低店120单，中位取样本中位数160单。月营收：保守28×120×30=100800元，中位28×160×30=134400元。

变动成本率：货品百分之四十、水电百分之三、平台佣金为外卖占比百分之五十乘佣金率百分之二十即百分之十、总部管理费按营收百分之二，合计百分之五十五，边际贡献率百分之四十五。固定成本：房租16000元，人工4人×5500=22000元，装修126000元与设备90000元按36个月摊销即6000元，其他2000元，合计46000元。

保守月经营利润=100800×0.45−46000=−640元；中位=134400×0.45−46000=14480元。盈亏平衡日单量=46000÷0.45÷30÷28≈121.7，向上取整为122单；保守值120单低于该点，须写明部分门店可能亏损。

不可退投资：加盟费40000、装修126000、设备90000、首批货18000、开办费8000，合计282000元。中位情景月现金结余=14480+6000=20480元，回本约282000÷20480≈13.8个月；保守情景月经营利润为负，但加回折旧后月现金结余为−640+6000=5360元，回本约282000÷5360≈52.6个月，超过36个月摊销期，写明摊销期内无法收回投资。可退款项为保证金20000元与三个月房租押金48000元，共68000元；三个月固定支出储备（房租、人工、其他）为3×40000=120000元；总资金需求=282000+68000+120000=470000元。

时间表：2026年11月2日书面提供披露材料与合同文本，按三十日核对点最早2026年12月2日签约；选址确认14天至12月16日，装修35天至2027年1月20日，试营业7天，拟2027年1月27日开业，签约至开业共56天。以上均为拟执行。
