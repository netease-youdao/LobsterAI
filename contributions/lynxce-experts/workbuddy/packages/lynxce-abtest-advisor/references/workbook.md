# 可复制实验底稿

将以下模板完整填写；不适用项说明原因，未知项保留材料标记。

```text
实验名称／方案版本：
业务决策与人群：
假设：对[人群]实施[改动]，因[机制]影响[主指标]。
证据清单：材料编号／时间窗／提供者角色／适用限制。
分流：单位／稳定键／比例／交叉暴露处理／排除条件。
主指标：成功定义／分母定义／归因窗口。
辅助指标：名称／解释目的。
护栏：名称／分母／允许差值／越界动作。
规划：基线／绝对MDE／业务门槛／显著性／功效。
样本：适用条件／公式／代入值／每组人数／总人数。
周期：日可用流量／最短周期／最长等待／固定停止规则。
质量核对：计数一致性／分流异常／缺失／版本变化。
结果：A成功/总数；B成功/总数；绝对差值；相对差值；区间。
决策：推广／不推广／暂缓；证据与限制；护栏判断。
下一步：责任角色／所需材料／复核时点。
关键问题：最多三项，每项说明答案会改变哪条决策。
```

## 已填假设示例：简化注册页

以下数字是演示用假设，不是线上实验记录。实验面向首次访问的独立用户，固定一比一分流，目标减少不必要表单，主指标为入组后当天完成注册的用户比例；同一用户只记一次。基线百分之二十，绝对最小可检测差值两个百分点，业务门槛为一个百分点。采用示例技能的规划参数，每组粗估样本为 `2×7.84×0.2×0.8÷0.02²=6272`，共12544人。可用流量上限为每天2000人，不代表每天保证入组人数。方案预先把固定分析样本定为每组10000人，预计至少十天积累；业务按周循环，结果观察至少覆盖十四天。预先约定前10000名有效入组者构成各组分析样本，达到人数后停止新增入组，等观察期满足后统一分析，不能看效果再改停止规则。

结果假设为完整十四天结束后每组10000人，A注册2000人，B注册2200人。A为百分之二十，B为百分之二十二，绝对差值两个百分点，相对差值百分之十。标准误 `sqrt(0.16/10000+0.1716/10000)=0.005758`，百分之九十五近似区间为 `0.02±0.011285`，即约零点八七至三点一三个百分点。区间未跨零，但下界低于一个百分点，若决策规则要求确信超过业务门槛，则仍不可据此确认达到门槛。

护栏假设为注册页错误率允许绝对增加不超过半个百分点，A为100/10000，B为110/10000，观察差值零点一个百分点，点值未越界；不把这一点值描述为已经证明非劣。报告结论为“主指标有正向证据，严格业务门槛尚未满足，暂缓全面推广，补充护栏不确定性评估”。材料角色为产品负责人和数据分析人员，下一步由二者确认是否坚持原门槛，不能事后为了上线把门槛调低。
