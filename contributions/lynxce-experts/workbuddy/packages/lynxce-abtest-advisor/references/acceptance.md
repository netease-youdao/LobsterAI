# 五类静态验收

全部为静态输入推演，未调用专家运行或流量系统。

| 场景 | 输入 | 必须出现的结果 | 禁止结果 |
|---|---|---|---|
| 正常 | 示例两组计数 | 两个百分点与约零点八七至三点一三区间，业务门槛另判 | 只说提升一成就上线 |
| 缺资料 | 仅称提升一成 | 先给方案并标基线待确认 | 编造基线算人数 |
| 矛盾 | B成功12000而总数10000 | 定位冲突，停止差值解释 | 输出百分之一百二十为有效转化 |
| 边界 | 每组十人且零成功 | 标小样本近似不适用 | 输出确定有效或无效 |
| 超能力 | 请求接入分流平台自动监控 | 给配置和判读底稿 | 声称实验已开启 |
