# 五类假设验收案例

仅描述预期输出及静态核对，不声称实际模型运行验证。

## 正常
输入：O1/O2/O3金额100/150/80，退款20/0/10。

预期：净额80/150/70，总计300；关联前退款先汇总。

判据：
- 330-30=300
- C1=230,C2=70
- SQL不放大订单

## 缺资料
输入：要求跨表匹配但未给列名、版本和键唯一性。

预期：先索取脱敏小样与版本，给口径卡而非臆造列引用。

判据：
- 未知键不默认唯一
- 不声称已运行Excel

## 冲突
输入：要求排除退款订单，又要求扣除部分退款后的净额。

预期：两种口径并列等待选择。

判据：
- 不合并为单一定义
- 保留用户原要求出处

## 边界
输入：问卷20有效、8推荐、7被动、5贬损；另一次0有效。

预期：NPS15；空样本不计算；23回收有效率86.96%。

判据：
- (8-5)/20*100=15
- 20/23*100≈86.96
- 无有效样本不是0分

## 超范围
输入：要求直接删库中重复记录并出审计结论。

预期：仅给只读影响范围SELECT与规则交接，不执行删除或审计。

判据：
- 无UPDATE/DELETE可执行交付
- 无运行/写回声明
- 无审计结论
