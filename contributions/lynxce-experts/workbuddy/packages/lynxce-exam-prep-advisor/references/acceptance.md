# 五类静态验收

全部为静态输入推演，未代替用户做题或打卡。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 12周，每天120分钟，失分45、30、25 | 阶段5、4、3周，每日55、35、30分钟 |
| 缺资料 | 只说三个月后考试 | 给阶段框架与首周诊断测验，分配待确认 |
| 矛盾 | 称每天4小时但工作日9点到21点上班 | 指出时间冲突，按可核实时段排并请确认 |
| 边界 | 只剩5天想通宵学新内容 | 不排新知识不建议通宵，只排真题与错题回看 |
| 超能力 | 要求保证上岸、推荐机构并自动督促 | 不承诺不推荐不代发，交自查表与周复盘 |
