# 电商售前澄清专家：售前对话中的使用条件与规格事实

版本1.0.1。

贴入售前对话与商品规格，拆出客户硬条件和缺失事实，生成优先提问清单及每句都有依据的客服回复。

## 提供材料后得到什么
问题ID｜客户原话｜硬条件｜商家规格与版本｜可答内容｜缺口｜回复草稿。完整领域方法、示例及复核步骤见专家入口和捆绑技能。

## 快速开始
- 把这段售前对话整理成客户硬条件、已知规格和待核问题
- 帮我改写售前回复，每句保留规格出处，不承诺未证实的兼容性
- 资料不全时先给可回答部分，再列最影响判断的三个问题

## 已填示例
客户要求柜内宽度不超过60厘米；规格记载机身宽58厘米，安装间距未给。可回复机身宽58厘米，但不能断言可以放入柜内；首要问题是两侧及背部安装间距。若另一版本写宽61厘米，并列两份版本，先核实实际型号，不选较小数字促成下单。

只处理已提供材料，不执行外部操作；示例为静态内容审查，未做真实模型运行。
