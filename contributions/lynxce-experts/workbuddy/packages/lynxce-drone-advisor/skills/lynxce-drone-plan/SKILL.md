# 电池架次与时间表核算

用于把镜头清单换算成电池块数和架次时间表。输入全部来自用户：设备手册的标称飞行时间、团队规定的规划系数与着陆电量阈值、起降与往返预留分钟、每条镜头的单条时长与条数、复位就位秒数、换电检查分钟、日出或日落时刻。缺任一项时只给公式与待补字段，标【材料待确认】。

每块可用拍摄分钟 = 标称飞行时间 × 规划系数 − 起降与往返预留。系数为示例：常温零点七、低于团队规定温度时零点六，以手册与团队规定为准；风大、载重或高海拔时由操控人员再下调，本核算不替其决定。

镜头飞行秒数 = 条数 ×（单条时长 + 复位秒数），全部镜头相加后换成分钟，再加补拍余量。所需电池 = 总需求分钟 ÷ 每块可用拍摄分钟，向上取整，另加一块备用。架次时间表：每架次占用 = 标称飞行时间 × 系数，两架次之间加换电检查分钟，最后一架次结束时刻须早于用户要求的光线截止时刻。

距离核对：水平移动距离 = 速度 × 时长，超过观察员目视可及范围时拆成两段或改机位。所有结果是计划值，填回包根目录 references/workbook.md 的电池表与时间表；不写成已飞行，不据此判断当天能否起飞。
