# 可复制航拍计划底稿

```text
项目／计划版本／日期时段／地点描述／材料编号：
材料核对：项目｜状态（已提供/待补/需主管部门确认）｜凭证或截图编号｜备注。
空域查询记录：渠道名称｜查询时间｜结果原文｜由谁确认。
天气现场：地面风｜高空风｜阵风与手册抗风等级之比｜能见度｜降水｜气温｜日落时刻｜停止条件是否触发。
镜头表：编号｜运动｜起止高度｜速度｜云台角度｜单条时长｜条数｜含复位飞行秒数｜最小距离｜电池。
电池表：标称分钟｜系数｜预留分钟｜每块可用｜总需求｜块数加备用｜着陆电量阈值。
时间表：电池编号｜拟起飞｜拟降落｜换电间隔。
起飞前检查：检查项｜结果｜检查人。
飞后记录：架次｜实际起降｜着陆电量｜异常｜素材编号。
关键问题：最多三项，写明答案会改变哪一行。
```

## 已填假设示例：郊野公园湖岸外景

以下全部为演示假设，不代表该地可以飞行。用户称场地方已书面同意、实名登记凭证已提供；空域查询记录与适用高度上限尚未提供，标【材料待确认】；经营性活动所需许可与保险标「需主管部门确认」。

设备手册标称飞行时间30分钟，当天预报气温5摄氏度，按团队低温系数零点六：30×0.6=18分钟，扣除起降与往返预留3分钟，每块可用拍摄15分钟。六个镜头各拍2条，单条时长为揭示25秒、推30秒、拉30秒、环绕60秒、跟随45秒、俯冲20秒，合计210秒；每条另加复位60秒，六条为360秒，一轮570秒，两轮1140秒即19分钟。另留补拍与机位调整12分钟，总需求31分钟，31÷15向上取整为3块，加备用共4块。

日落时刻假设为17时32分。每架次占用18分钟，换电检查6分钟：第一块16时20分至16时38分，第二块16时44分至17时02分，第三块17时08分至17时26分，均在日落前结束。日落前一小时从16时32分开始，第一块有一部分早于该时段，用于推、拉、跟随的保底条；揭示与环绕放在完全落入该时段的最早一块，即第二块；第三块用于设计条与补拍。推镜速度4米每秒、时长30秒，水平移动120米，须在观察员目视范围内。

航线最高障碍物为45米观景塔，余量20米，返航高度拟设65米；适用高度上限待用户确认，若低于65米即标矛盾。手册抗风等级12米每秒，团队阈值百分之八十即9.6米每秒；预报阵风10.2米每秒，为抗风等级的百分之八十五，标「停止条件触发」，计划保留为拟执行，是否推迟由现场操控人员决定。
