# 名额与到场率测算

本阶段只做数字，规则由组织者确认。所有人数为整数，比例保留一位小数。

1. 历史到场率 r = 往期到场合计 ÷ 往期报名合计，只用两期以上、同类型、同报名方式的活动；不足两期时不计算，按容量的110%到120%试行并标“经验值”。
2. 开放名额 = 向下取整(场地核定容量 × 0.95 ÷ r)。0.95表示预留5%余量，组织者可改，改动要记录。
3. 递补名额 = 取较小值(取消释放数, 容量 − 已确认数)；已确认数达到容量时不再递补，候补者转入现场候补。
4. 有效报名 = 报名 − 取消 + 递补成功。确认到场率 = 确认者中到场人数 ÷ 确认人数；报名到场率 = 有效到场 ÷ 有效报名；座位使用率 = 有效到场 ÷ 容量。
5. 有效到场只算名单内正常签到与迟到签到；代签、补签、名单外到场分别单列，不进入以上分子。
6. 一致性核对：各部门合计等于总数；确认者到场不大于确认数；有效到场不大于容量；有任何一条不成立，先列冲突再出比例。
7. 统计截止日：活动日之后第1个工作日起算的第3个工作日。

把代入值和结果写回包根目录 references/workbook.md 的名额表与统计表，并把本期数据并入历史，供下次测算。
