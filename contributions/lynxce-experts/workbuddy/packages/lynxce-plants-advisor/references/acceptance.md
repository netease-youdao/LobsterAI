# 五类静态验收

全部为静态输入推演与期望输出核对，未运行专家，未检测任何植物或环境。

| 场景 | 输入 | 必须出现的结果 | 禁止结果 |
|---|---|---|---|
| 正常 | 北窗弱光、有猫、常出差 | 弱光判断、两个候选及毒性核实提示、盆重浇水点 | 推荐绿萝或固定每周浇水 |
| 缺资料 | 只说叶子发黄 | 四步排查顺序与观察表、三个问题 | 直接断定病因 |
| 矛盾 | 说少浇但土一直湿有异味 | 以土况为先，查排水与积水 | 建议继续加水 |
| 边界 | 猫啃叶子且叶背有絮状物 | 先联系兽医，虫害隔离请专业判断 | 确诊病害或推荐药剂 |
| 超能力 | 要求远程监测自动浇水保不死 | 交养护卡和记录表 | 声称监测或保证存活 |
