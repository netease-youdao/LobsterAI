# 应税凭证识别
逐份辨别企业实际书立的凭证属于何种印花税事项，输出带来源与待核点的税源清单。输入不是合同标题集合，而是主体、标的、权利义务、书立日期、金额条款、是否另有合同、是否草案或副本及所在地区。以2026年10月22日核读的印花税法第二、四条和附表为起点，税目列举范围不能被“所有合同均缴税”代替。企业间明确买卖关系且未另立合同的订单，按2022年第22号公告核；个人书立动产买卖的例外和企业买卖不同，不从一张采购发票反推合同必然存在。

先建立凭证编号和来源等级，原件与用户摘要分开；草案待签、已经书立、重复副本分别列示。再根据真实标的判买卖、租赁或营业账簿等，本技能主要范围为企业普通动产买卖、房屋租赁与资本账簿。普通买卖双方按各自涉及金额核，不擅自各除二；多方、混合税目、涉外及复杂产权要求完整条款再定，不能因为税率较低就改名为技术服务。第三步核金额和税额是否分别列明，不能把发票列税自动当合同也列税。最后输出税目、基础取数位置、仍待核条件和对应办理准备动作。

假设C1企业设备合同列价1130000元并列明增值税130000元，基础1000000元；C2租金60000元未列明税额，基础不能自行拆成不含税；B1现资本6000000元与历史已纳税基数5000000元，先核对应记录再取增量。已缴与已纳税基数是不同字段，资本账页摘要不是缴款回单。可复制说明为“本次【凭证编号】依据【原文或摘要位置】暂识别【税目】，所列金额【值】，列明税额【值或未列明】，适用边界【真实条件】，优惠与已缴【已知或待核】”。

完整交付不止标签，还需税源台账和正文说明，列出为何按该标的处理及仍需何种原文。未定价凭证按税总2022年第14号首期书立申报及后续结算规则整理，未知金额不写零元。完成标准是凭证不重不漏、原件等级忠实、税目与标的相符、时间和地方申报方式有出处；不出合同法律意见、不代申报、不用错误标的降低税额。
