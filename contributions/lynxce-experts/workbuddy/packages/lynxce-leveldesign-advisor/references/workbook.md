# 可复制关卡节奏底稿

```text
项目／版本号／统计时间窗／计数单位／材料编号：
目标卡：关卡｜教或考｜新机制｜预期通关时长｜预期失败次数。
节拍表：段落（教学/练习/考核/放松）｜内容｜失败代价｜对应机制。
难度表：关卡｜反应｜信息量｜容错｜资源｜总分｜相对上一关变化｜标记。
检查点：位置｜到难点耗时中位数｜加载秒数｜重试成本｜是否达标。
漏斗：关卡｜进入｜通关｜通关率｜相邻均值｜差值｜每人平均尝试｜标记。
诊断：可疑关卡｜失败位置分布｜回放编号｜偏向原因｜证据。
改动与复测：变量｜原值｜拟改值｜预期指标与方向｜复测口径。
关键问题：最多三项，写明答案会改变哪条结论。
```

## 已填假设示例：平台跳跃第四至第六关

以下数字为演示假设。第五关首次引入「蹬墙跳」。漏斗：第四关进入2000人、通关1840人，通关率百分之九十二；第五关进入1800人、通关1080人，通关率百分之六十，尝试总次数5400次，每位进入玩家平均尝试3次；第六关进入1050人、通关945人，通关率百分之九十。相邻均值为（92+90）÷2=91，第五关低31个百分点，超过十五的阈值，进入人数也高于两百，标为可疑。

失败次数为5400−1080=4320次，其中3024次发生在第一个蹬墙跳点，占百分之七十；抽看20段回放，14段中玩家没有尝试蹬墙，偏向教学缺失。拟在该点之前加一段无惩罚的蹬墙练习墙，不改跳跃数值。

难度打分：第四关反应2、信息量2、容错2、资源1，总分7；第五关反应3、信息量3、容错2、资源1，总分9，同时拉高两个维度，且新机制所在关不应叠加，与规则冲突，拟把信息量降回2，总分8。

检查点原在段首，走到难点的耗时中位数75秒，加载8秒，重试成本83秒，超过六十秒目标；拟移到走廊之后，走到难点35秒，重试成本43秒。复测在下一版本用同一口径看第五关通关率和蹬墙点失败占比，只报告新版本数值，不承诺提升幅度。
