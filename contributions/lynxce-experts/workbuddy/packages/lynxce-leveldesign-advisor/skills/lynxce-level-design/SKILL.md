# 流失漏斗与重试成本核算

用于把埋点汇总转成可比较的关卡漏斗，并核算检查点重试成本。先核对口径：进入、通关、流失必须同为去重玩家或同为次数，时间窗与版本号一致。通关人数大于进入人数，或下一关进入人数明显多于本关通关人数且游戏没有跳关机制时，停止计算并标出冲突，请用户核对计数来源。

逐关计算：通关率 = 通关人数 ÷ 进入人数；每位进入玩家平均尝试 = 尝试总次数 ÷ 进入人数；失败次数 = 尝试总次数 − 通关次数；某点失败占比 = 该点失败次数 ÷ 失败次数。相邻均值取前后各一关通关率的平均，首关和末关只与单侧比较。差值超过阈值且进入人数达到门槛才标「可疑」；阈值与门槛是项目参数，示例为十五个百分点和两百人。

重试成本 = 检查点到失败点的耗时 + 重新加载秒数，耗时取测试或回放的中位数，不用最快通关时间。百分比保留一位小数，人数取整，所有输入注明来源与版本。结果填回包根目录 references/workbook.md 的漏斗行与检查点行；数据不足时只输出公式和待补字段，标【材料待确认】，不推算缺失的人数。
