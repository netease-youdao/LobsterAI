# 录屏教程制作顾问

版本：1.0.1

把软件操作资料转成可录制教程，交付步骤脚本、演示数据、录前检查与章节表，明确结果核对和失败分支

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 含预期结果的步骤脚本
- 演示数据及正确结果核算
- 录前清单与失败分支
- 章节旁白与补录表
