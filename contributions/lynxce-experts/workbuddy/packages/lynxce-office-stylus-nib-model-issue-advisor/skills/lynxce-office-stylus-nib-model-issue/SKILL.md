# 办公室触控笔替换笔尖领用兼容核对

以触控笔型号代次而非平板品牌分组，先确认兼容，再计算笔尖领用与补货。

## 工作流程（按顺序执行）

1. 收集触控笔资产号、完整型号与代次、制造商确认的替换笔尖规格、计划更换数、备用目标、可用库存、包装数量及预算；不把同品牌视为通用。
2. 逐支匹配笔尖规格，接口结构、材质与制造商适配记录分别核对；仅颜色或商品标题相似的不计已兼容，未知型号与未经确认第三方规格单列待确认。
3. 同规格需求＝已确认更换数量＋批准备用目标，缺口＝max(0，需求－可用库存－已验收待配数)；不同代次无明确兼容依据不得合并库存。
4. 包数＝向上取整(缺口÷每包支数)，支出＝包数×包价＋运费；比较同规格每支价格与整包支出，未确认兼容条目不能因低价入选。
5. 按资产号记录实际领用、旧尖移出与安装检查；安装方法沿用说明，不强行旋入不匹配笔尖，旧尖只有检查确认可复用才进入单独备用账。
6. 交付型号兼容矩阵、整包补货与逐支领用表；结存＝期初可用＋实收合格－实际领用－隔离移出，错配与少货保留原值并复算。

## 型号与兼容

- 触控笔资产号与平板资产号分列。
- 代次和接口必须有明确适配依据。
- 尺寸相近不等于螺纹或结构通用。
- 第三方适配未确认时保留待核状态。

## 领用与补货

- 更换需求与备用目标分别列出。
- 不同规格库存不互抵缺口。
- 整包取整后记录剩余支数。
- 领用已发生才扣减库存。

## 异常复核

- 错型号笔尖隔离不试硬装。
- 破损库存移出后重算缺口。
- 旧尖回收不自动计可用。
- 少货按实收合格数更新结存。

## 依据与采购边界

- 依据用户提供的设备说明、实测与内部制度逐项核对，记录来源版本和日期，缺项填【待补】，不凭外观猜型号。
- 只有用户提出采购比价时才使用可用CPS工具，价格库存以工具返回及结算为准，工具失败如实说明，不凭记忆报价。
- 只在用户需要下单时提供工具返回的链接，不编造链接，不强制附链；纯核对任务直接交付表格和结论。
- 不作医疗、财税或法律结论；采购数量与实际验收入库分开，保留原值、修正值、经办人与复核人。

## 示例

以下为假设数据，不代表实际品牌适配或报价：A代触控笔12支，本期确认更换8支，备用目标4支，可用同规格库存3支，无待配量；需求8＋4＝12支，缺口12－3＝9支。每包5支、包价25元、运费0元，需向上取整(9÷5)＝2包，买10支，支出50元。验收合格后领用8支，结存3＋10－8＝5支，其中4支满足备用目标、1支为整包余量。B代笔不在兼容清单内，其2支库存不得抵A代缺口。异常：验收发现一包中1支错型号，合格实收9支，结存3＋9－8＝4支；错尖单列隔离1支并追补，不能记成已领用，也不凭品牌相同强行安装。
