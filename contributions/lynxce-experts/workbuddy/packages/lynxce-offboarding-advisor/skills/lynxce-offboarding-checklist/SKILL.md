# 离职交接依赖与回执验收

只复核交接表及用户提供回执。用类别和对象编号防止同一实物或权限在多个表重复计数；资产应收、实收、差异数量保持同口径。对账号逐项核对资源转移、操作请求、执行和独立复核四个状态，不因存在截图就推断截图所未显示的全部权限已撤销。

对每个未闭环项追溯前置依赖及责任角色，关键管理员或客户任务单列。完成率仅以已确认验收项为分子，新增遗漏系统时应扩大分母并说明下降原因，不能维持旧高比例。输出“项号／证据支持到哪一步／还缺什么／负责角色／更新状态”表，交回专家汇总。证明及结算始终按各自材料跟进，不以操作表替代专业核定。

复核前读取 `../../references/workbook.md` 中的输出模板、示例与静态案例；只返回差异和修订行，交回专家合并，不重复整份初稿。
