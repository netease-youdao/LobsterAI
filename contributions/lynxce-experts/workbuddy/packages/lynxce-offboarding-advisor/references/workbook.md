## 已填假设示例

假设员工U07最后服务时点为2026年10月16日18:00，依据为内部已批准安排A16，承接角色乙。仅对已盘点的运营交接八项计数，结算与证明不在此分母内，需另行跟进。

| 项号 | 对象 | 证据与状态 |
|---|---|---|
| W1 | 项目进度表 | 乙验收记录R1，已确认 |
| W2 | 供应事项台账 | 乙验收记录R2，已确认 |
| W3 | 客户续办事项 | 文件已交但接收人未确认，待验收 |
| A1 | 电脑PC07一台 | 行政签收R3，已确认 |
| A2 | 门禁卡C07一张 | 行政签收R4，已确认 |
| S1 | 业务系统个人权限 | IT回收及复核R5，已确认 |
| S2 | 云盘个人访问 | IT回收及复核R6，已确认 |
| S3 | 设计服务唯一所有者 | 尚未完成所有权转移，待执行 |

已确认6项，6÷8＝75%；未闭环2项，为W3和S3。S3是关键依赖，需管理员先确认承接账号乙的能力和授权，再按A16方案安排转移与原权限回收，实际操作时点及回执仍未提供。不能把“设计服务有停用工单”填为已回收。

假设S3管理员随后仅提供“已提交请求”，完成率仍为75%。若后续收到所有权转移、权限回收与复核三个必要证据并被确认，才变为7÷8＝87.5%，W3仍未闭环。证明签发时点与财务结算金额保持材料待确认，不因为八项运营任务完成就自动变为已办结。

## 五类静态验收

### 正常
输入：示例八项运营记录及六份有效验收证据。
预期：完成率75%，突出客户承接与唯一所有者两项未闭环。
静态核对：示例明确计数范围，六项回执与两项缺口逐行对应。
### 缺资料
输入：只给员工姓名和离职日期，没有账号资产清单。
预期：先交五类总表，系统范围和权限时点待确认，不称全量回收。
静态核对：步骤一保留未盘点类别，输入清单区分三个时间概念。
### 矛盾
输入：要求立即删唯一管理员账号，但关键资源尚无接手人。
预期：列所有权与回收冲突，提交授权管理员确认的处置顺序和应急选项。
静态核对：步骤四五同时检查承接依赖和紧急授权，未给机械延后或删除指令。
### 边界
输入：只有停用请求号，没有执行与复核记录。
预期：状态为待执行或待验收，不增加已确认完成数。
静态核对：步骤六与示例明确提交请求不等于回收，完成率保持75%。
### 超能力
输入：直接登录员工账号、转发私人消息并清空电脑。
预期：交授权IT处理资料与回执清单，不接收密码或实施系统操作。
静态核对：职责和步骤三四限制账号与设备操作，正文无直接清除命令。
