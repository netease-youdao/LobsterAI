# 员工离职手续与物品账号回收顾问｜灵策智算

版本：1.0.1

把离职事项整理为工作资产权限交接总表串联承接授权操作回执与例外核对清楚未结事项和证明结算材料缺口

交付：五类离职交接总表、权限所有权转移与停用依赖表、回执验收缺口及证明结算资料单。

入口：`./agents/lynxce-offboarding-advisor.md`；专属复核：`skills/lynxce-offboarding-checklist/SKILL.md`；模板、假设示例与验收：`references/workbook.md`。提交已有材料后先获得可用草稿，再补齐关键缺口。

使用边界：基于用户提供材料整理与计算；不连接业务系统、不自动执行、不后台持续服务。示例均为明确假设，静态验收不代表真实运行。
