# 施工记录转实绩进度周报

面向建筑装修的明确小任务：分区分项实绩周报、去重工程量对照、阻塞闭环表与条件式下周计划。只依用户提供资料核对，将事实、假设与待确认条件分开；本技能不自动执行任何业务操作。

## 工作流程

1. 确认周报起止日期、截止时刻、项目代号、分区分项列表与计量口径，收集日记录、当周计划、返工及确认材料。把完成描述和数量原值分别保留，写明记录人和来源日期；只有“基本完成”等口头表述时，不据此折算百分比，先给需要补充的量化问题。

2. 按项目、楼栋、楼层、区域、分项建立实绩键，把日期范围与已发生动作关联。识别日增量与累计量，累计记录通过相邻有证据时点求差，但资料缺口不能自动填零；同一工段多人记录采用同一事实合并证据，避免把重复日报加成双倍工程量。

3. 将当周新完成工程量、返工量及已确认量分别汇总，面积、体积、长度等不同单位不能直接求总数。用户给定同口径计划时，周完成率＝当周新完成量÷周计划量；返工不重复计入新增实绩，已施工未确认单列，不能写成工程验收已通过。

4. 对同分项的计划与实绩计算数量偏差，附影响区段及证据。阻塞拆为前置交接、材料未到、资源冲突、等待确认等类型，仅根据已提供信息关联受阻任务；原因描述不等于责任裁定，多种可能性并存时列待核条件，不把天气或供应延误直接写成确定原因。

5. 从未完成事项建立下周条件计划，逐项列前置释放条件、负责人、用户给定可用工期与资源。前置未确认的标“满足条件后安排”，工程量估算需要用户提供产能依据；交叉作业、人员和场地冲突转待现场确认，不凭经验生成具体施工参数或安全处置。

6. 输出事实摘要、分区分项进度表、异常阻塞表、下周条件任务及证据索引。复算累计增量、计划分母与百分比，核对摘要不夸大确认状态；报表修订保留原记录和更正说明。仅整理资料供人工审阅，不作验收、签章、资质或现场安全结论。

## 实绩拆解

- 累计量与日增量分栏，累计数据先求差再进入周汇总。

- 同一区段同一工程量多来源只算一次，多个记录作为共同依据。

- 返工是资源占用而非重复新增实绩，应与净新增工程量分开展示。

- 施工描述缺数量时保留原文，用待补标志而非主观换算完成率。

## 计划偏差

- 计划与实际必须同区域同分项同单位，不能跨项目比较单个百分比。

- 已施工与已确认工程量两条线并列，确认记录不存在就不能标已验收。

- 分母为零时不计算完成率，说明临时新增任务及计划变更待确认。

- 计划版本变化要保留原版与修订版，否则偏差无法解释给审阅人员。

## 阻塞与下周条件

- 阻塞列具体受影响工段、前置交接和可核实事实，不只写协调中。

- 材料预计到场与已到场分状态，前者不能解除下周任务前置条件。

- 周报中的负责人是沟通跟进责任，不自动等同技术或事故责任。

- 每个下周任务附前置确认与复核入口，进度建议供现场管理人员判断。

## 资料与交付复核

- 建立资料目录：每条数值、日期、状态和规则都关联用户提供的来源编号与版本。原始记录、解释性备注及建议动作分栏；资料缺失写【待补】，不得以示例中的数值或常见经验填补真实记录。

- 同一字段出现矛盾时保留两种说法，写清分别来自何人、何时及哪份资料，再指定需要补充的验证材料。没有反证不能选较有利的一版，不将推测原因写成已确认事实，也不替用户判定业务责任。

- 所有数量先核单位、范围、截止时点和分母，再逐行计算并复算合计。四舍五入要注明精度；不适合相加的比例、不同单位或不同批次不直接合计，分母为零时标不可计算并说明需要补充什么。

- 交付文本表格、待补问题和人工确认清单，每个建议写触发条件、经办角色及可核查完成证据。建议、已获用户确认和用户反馈实际完成分状态；收到补证后保留原版及变更原因，不声称已经操作业务系统。

## 五类领域假设验证场景

- 内容设计假设，未作实际模型实测。正常：输入同区段累计200至320平方米，周计划150，确认90。预期净新增120、完成率80%、偏差－30、待确认30平方米。

- 内容设计假设，未作实际模型实测。缺资料：输入日报仅写基本完成，没有数量或累计起点。预期保留原文，新增量与完成率待补，专家不主观折百分比。

- 内容设计假设，未作实际模型实测。矛盾：输入累计差为120平方米，另一个日报50平方米覆盖同一范围。预期识别重复覆盖，不加为170；保留范围证据与去重说明。

- 内容设计假设，未作实际模型实测。异常边界：输入新增30平方米但原周计划为0，且返工20平方米。预期完成率不可计算，新增与返工分栏，提出计划变更确认。

- 内容设计假设，未作实际模型实测。超出能力：输入要求周报同时证明验收通过并签章认可现场安全。预期仅整理已给确认资料及待核事项，不给验收或安全结论。

## 假设案例

假设A楼二层抹灰记录期初累计200平方米、期末累计320平方米，当周计划150平方米。新完成量为320－200＝120平方米，周完成率120÷150＝80%，数量偏差120－150＝－30平方米。另一张日报记录周三完成50平方米，但它已包含在累计差120平方米内，因此不能再加成170平方米。同期返工20平方米单列资源投入，不加进净新增量；用户提供确认材料仅覆盖90平方米，则已施工120平方米、已确认90平方米、待确认30平方米。下周计划补足30平方米需前置材料到场确认，不能直接宣布已安排。若后来修订期末累计为315平方米，新完成改为115平方米，完成率为76.67%（四舍五入保留两位），偏差－35平方米，周报注明修订依据。
