# 施工累计与增量去重核查

用区段与发生范围追踪工程量，避免重复日报叠加。。输入范围仅限用户给定的建筑装修业务材料；与公开技能分工，独立完成此项中间成果再交专家复核。

## 工作流程

1. 读取每条记录的分区分项、数量、单位、日期和累计或增量标记，未知标记先待核。

2. 以相同区段和施工范围识别重叠，不依据相同数量就判断为同一事件。

3. 连续累计记录求相邻差额，起点缺失时不把首个累计直接算本周新增。

4. 将返工、修补及首次施工分组，同一范围返工不再次增加净完成量。

5. 对数量倒退查修订依据，保留更正前后的累计链，不能将负增量隐藏。

6. 输出唯一计入量与重叠证据表，汇总前核单位与覆盖范围一致。

## 专属核查方法

- 累计链必须同一区段，楼层变化不能延续上一楼层累计值。

- 缺一日日报不代表没有作业，缺口保持待补以避免低估。

- 双人记录同一范围时合并证据，差异数保留待现场核对。

- 数量修订应写来源及原因，不自动把倒退解释为返工。

## 证据与状态控制

- 先按本任务的复合业务键标记每条材料，保留原值与来源日期，关键字段缺失时只输出可确认部分及补证问题。

- 将输入事实、计算中间值与建议动作分列，复算结果需要能够回到对应单据或记录，不能靠结论倒填来源。

- 用户给定规则只在明确范围内使用，规则变更需记录版本；冲突时列适用条件，不将其他批次或其他任务的规则直接迁移。

- 输出给经办与复核角色审阅，确认资料齐全并不等于业务执行完成，任何现场结果须由用户补充反馈及验证记录。

## 交付与异常

- 输出本任务的领域表格与逐行问题，单位、时间、状态必须写全；没有依据的字段填【待补】，不以零代替缺失。

- 对异常记录给出最小补证动作及其预期证明的条件，不能仅写需要核查，必须说明核哪一项以及结果如何影响表格。

- 先列矛盾与未确认条件，再给条件式建议；存在反证时修订相关行并保留旧版，避免相互矛盾的承诺或计算同时有效。

- 收尾检查表头、合计、状态及来源索引一致，交付文本草案和人工处理清单；不声称联网检测、自动派发或修改系统记录。

## 假设案例

假设记录R1累计40米，R2累计65米，R3记当日新增25米且对应R2覆盖范围。唯一新增为65－40＝25米，不是50米。R4返工5米应单列而不增加净完成。若R2被更正为63米，则唯一新增23米，与R3的25米矛盾2米；保留两条依据并请求核实，不取平均24米。起点40米若无日期依据则周新增仍待确认，不能直接报63米。

## 能力边界

根据用户提供的资料整理和分析；未知项填【待补】，区分事实、假设与建议。没有实际连接工具时不声称读取或修改业务系统，不编造实时数据或已完成的操作。
