# 施工现场日记录实绩周报与阻塞跟踪专家

版本1.0.1。

贴入施工日记录与周计划，核对累计量和返工口径，生成分区实绩周报、阻塞表及有前置条件的下周计划。

## 提供材料后得到什么
分区分项｜日增量｜累计起止｜返工量｜确认状态｜计划量｜偏差｜来源。完整领域方法、示例及复核步骤见专家入口和捆绑技能。

## 快速开始
- 用这周施工日记录生成实绩周报，分开新增、返工和待确认工程量
- 这些日报数量有重复或累计口径，请逐行去重并保留来源
- 按现有阻塞与可用资源，生成附释放条件的下周任务表

## 已填示例
A区铺贴本周计划100平方米；周初累计120、周末累计180，期间返工8且已包含在施工记录中。新增实绩为180-120=60平方米，计划完成率60%，返工8单列不能再加为68。只有45平方米有确认记录时，表中分别列新增60、已确认45、待确认15，不称已验收。下周剩余40须附材料到场及前道交接条件。

只处理已提供材料，不执行外部操作；示例为静态内容审查，未做真实模型运行。
