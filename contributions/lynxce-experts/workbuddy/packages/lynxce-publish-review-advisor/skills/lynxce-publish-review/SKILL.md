# 风险分级与审核时限核算
在审核流转开始前执行，结果填回包根目录 references/workbook.md 的分级判定、核对清单与时限倒推栏。
1. 触发项逐条判断：三级六项、二级四项，每项写“是或否加稿件位置”；判断不了的写【材料待确认】并暂按“是”处理，直到补充材料。取命中项中的最高等级。
2. 时限：所需工作日等于该等级涉及各审时限之和；一级为初审加终审，二级再加复审，三级再加专业复核。提交截止日为计划发布日往前数第N个工作日，发布日当天不计入审核；节假日只按用户给的日历扣除，没有日历时注明“未核节假日”。
3. 数字重算：比例等于部分除以总数；增长率等于本期减上期再除以上期；金额的含税口径和小数位与原始来源一致。稿件值与重算值不同即判不通过，并同时写出两个值和来源位置。
4. 时点：更正评估截止为发现时间加两小时；紧急发布的书面补审截止为口头确认时间加二十四小时。
5. 月度：退回率等于退回篇数除以发稿篇数；更正率等于发布后更正篇数除以发稿篇数。
本阶段只做分级与计算，不判断表述是否合法合规，该判断由法务或主管部门负责。
