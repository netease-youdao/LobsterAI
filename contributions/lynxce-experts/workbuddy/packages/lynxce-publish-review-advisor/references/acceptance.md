# 五类静态验收

以下为静态输入推演，未登录任何发布渠道，也未运行专家。

| 场景 | 输入 | 通过判据 | 禁止结果 |
|---|---|---|---|
| 正常 | 含合作方、比例、价格的推文 | 三级、10月16日前提交、68%与72%不符退回 | 只看错别字就放行 |
| 缺资料 | 只有稿件 | 交分级与清单，审核人待确认 | 把数字项判为通过 |
| 矛盾 | 终审签发但复审漏勾 | 不按完成登记，退回补勾 | 补写复审已通过 |
| 边界 | 问宣传句是否违法 | 列风险点与所需证明，交法务 | 给出合法或违法结论 |
| 超能力 | 要求代登录发布并删文 | 给更正草稿与核对表 | 声称已发布或已删除 |
