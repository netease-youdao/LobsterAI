# 可复制三审底稿

逐栏填写，不适用写原因，未知写【材料待确认】。

```text
渠道／月发稿量／审核人与替补／各审时限：
分级判定：稿件编号｜三级六项逐项是否｜二级四项逐项是否｜风险等级｜依据位置
核对清单：审级｜核对项｜原始来源位置｜通过或不通过｜问题说明｜审核人｜时间
时限倒推：计划发布日｜所需审级与天数｜合计工作日｜提交截止日｜节假日依据
发布登记：编号｜标题｜渠道｜等级｜初审｜复审｜专业复核｜终审｜发布时间｜页面截图位置｜是否紧急补审
更正记录：发现时间｜评估截止｜错误内容｜严重程度｜处理方式｜更正说明发布时间｜漏审审级与核对项｜清单修订版本
月度统计：发稿数｜退回数｜退回率｜发布后更正数｜更正率｜主要漏审项
待确认问题：最多三个
```

## 已填假设示例：联合调研推文

以下稿件、数字和日期均为假设，用于演示口径，假设期间没有节假日。公众号推文介绍与某行业协会联合发布的中小企业采购调研，正文含协会名称、调研比例、本公司服务客户数和年度会员价格。命中二级的“合作方名称”“第三方数据引用”，也命中三级的“价格与促销规则”“经营数据”，按三级处理。

时限：计划10月23日（周五）发布，三级合计初审1、复审1、专业复核2、终审1，共5个工作日，发布日不计入，往前数第5个工作日为10月16日（周五），即当天上班时须提交。

初审重算：样本1200份，选择“已使用线上采购”的816份，比例为816÷1200=68%，稿件写72%，不通过；服务客户数从350家增至420家，增长率为（420−350）÷350=20%，稿件写25%，不通过。两处同时写出稿件值、重算值和数据表位置，退回作者修改后重新初审。复审核对协会同意书的授权范围包含“联合发布”字样，会员价格与价目表一致。

更正：发布后10月23日10:30发现协会简称少一个字，评估截止12:30，属名称类重大错误；渠道允许修改则修改并在文末附更正说明，否则另发更正说明。复盘漏在初审“名称与官方写法一致”一项，原因是未附协会官方简称的依据，清单修订为“名称须附来源截图”，版本加一。

月度统计：本月发稿20篇，退回3篇，退回率15%；发布后更正1篇，更正率5%。待确认问题：专业复核由谁担任、各渠道能否在发布后修改、公司节假日日历。
