# 可复制校园拍摄底稿

将以下模板完整填写；不适用项写明原因，未知项保留【材料待确认】。

```text
账号定位／拍摄者身份／学段／是否商用：
三道闸：场地（通过／待批／不拍）｜人（台账齐全？）｜用途（平台与商用说明）。
栏目选题：栏目｜选题｜场景｜区域级别｜是否需申请｜涉及他人出镜｜计划发布日。
场地许可：区域｜级别｜受理部门或联系人角色｜申请日期｜用途说明｜书面答复｜有效时段。
同意台账：代号｜是否可识别｜是否未成年｜本人同意｜监护人书面同意｜用途与平台｜是否商用｜留档位置｜撤回记录。
画面巡检：学号证件｜校园卡｜门牌｜课表成绩｜快递面单｜屏幕聊天｜车牌｜定位标签。
排期：学期周数｜考试周数｜平时每周条数｜考试周条数｜全学期条数｜囤稿数｜可拍时段与小时数。
复盘：视频｜播放｜完播｜完播率｜点赞评论收藏｜互动率｜调整动作。
关键问题：最多三项，写明答案会改变哪条镜头或哪次发布。
```

## 已填假设示例：大二学生个人账号

以下为演示假设，不是真实账号数据。大二学生个人账号，非商用，栏目为一天流程、学习方法、社团活动。学期18周，期中考试1周、期末考试2周，共3个考试周，常规周18−3=15周。平时每周2条，考试周每周1条且全用囤稿，全学期15×2+3×1=33条，需在第一个考试周前一周囤好3条。

可拍时段：周三下午14点至17点共3小时，周六上午9点至11点半共2.5小时，每周合计5.5小时；单条拍摄约2小时，每周2条需4小时，未超过5.5小时。

场地：食堂与教学楼走廊属二级，已向辅导员说明用途与平台并取得书面答复；宿舍属三级，未取得书面许可前不拍。

出镜：某期一天流程中有5位同学可识别。3人书面同意；1人为17岁大一新生，本人同意但监护人书面同意尚未收到，收到前打码；1人不同意，相关镜头剪掉。本期可露脸3人。画面巡检发现桌面课表与快递面单各1处，已在剪辑稿中标记遮挡。

复盘：该条播放1200次，完播300次，完播率300÷1200=25%；点赞60、评论21、收藏15，互动96次，互动率96÷1200=8%。单条样本只作趋势参考，下月对比同栏目再决定是否调整开头。
