# 拍摄容量与选题配比计算

用于把老板的可用时间换算成每期可录条数，再按主目的把条数分到四类选题，结果填回包根目录 references/workbook.md。

一、每期可录条数 = （本期可用分钟 − 布景调试分钟 − 提纲过稿分钟）÷ 单条录制分钟，向下取整，再减一条作余量。单条录制分钟包含重录，没有记录时示例按二十分钟起估，首期拍完用实际值替换。

二、配比起点（可按材料调整，四类合计百分之百）：获客为客户答疑四成、行业认知三成、创业经历两成、管理心得一成；招聘为管理心得四成、创业经历两成半、行业认知两成、客户答疑一成半；品牌信任为创业经历与行业认知各三成半、客户答疑两成、管理心得一成。

三、条数分配用最大余数法：先算 条数 × 占比，全部向下取整，剩余条数按小数部分从大到小补齐；小数相同按客户答疑、行业认知、创业经历、管理心得的顺序。

四、选题库可用周数 = 库存条数 ÷ 每周发布条数；低于四周时提醒补题，补题优先取销售与客服记录里重复出现的问题。

五、复盘指标：每条有效咨询 = 该类有效咨询数 ÷ 该类发布条数。有效咨询只算销售确认有真实需求的首次咨询，来源靠首次咨询时登记；无法登记的记为来源未知，不分摊到任何类别。

六、调整阈值：某类连续两个月有效咨询为零且播放低于账号当月中位数，才下调该类占比；单月为零只标观察。每次调整不超过十个百分点。
