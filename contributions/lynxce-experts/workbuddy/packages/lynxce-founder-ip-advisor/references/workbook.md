# 可复制规划底稿

```text
人设卡：一句话定位｜核心领域（不超过两个）｜主目的｜目标观众
经历核实：编号｜时间｜事实｜形成的判断｜可核实材料｜老板确认
配比：主目的｜四类占比｜本期条数分配（最大余数法）
选题库：编号｜类别｜问题句｜三个要点｜例子出处｜适合时长｜状态
拍摄日：日期｜场地｜可用分钟｜布景调试｜提纲过稿｜单条分钟｜可录条数｜选题编号｜服装｜设备｜负责人
红线：不说的内容｜原因｜标准回应｜确认人｜确认日期
月度复盘：类别｜发布条数｜播放合计｜有效咨询｜每条有效咨询｜招聘投递｜调整与理由
关键问题（不超过三个）：问题｜会改变哪项结论
```

## 已填假设示例：家装公司老板

以下全部为演示假设，不代表真实企业或数据。老板从事家装十五年（营业执照与项目合同可核实），每周可出镜两小时，主目的获客。人设写作“做了十五年家装的老板，讲装修哪些钱不该花”，核心领域只取预算与施工两项。

容量：每两周一期，可用2×2×60=240分钟；布景调试30分钟、提纲过稿30分钟、单条20分钟，可录(240−30−30)÷20=9条，留一条余量排8条，即每周4条。按获客配比分配8条：客户答疑8×40%=3.2、行业认知2.4、创业经历1.6、管理心得0.8，取整3、2、1、0共6条，剩余2条补给小数最大的管理心得与创业经历，结果3、2、2、1共8条。

选题库四十条按同一配比：16、12、8、4条。以每周4条计，库存可用40÷4=10周；第七周末剩40−7×4=12条，只够12÷4=3周，低于四周阈值，此时提醒补题。

月度复盘（假设一个月两期共16条）：客户答疑6条带来有效咨询9个，每条1.5个；行业认知4条3个，每条0.75个；创业经历4条1个，每条0.25个；管理心得2条0个。合计有效咨询9+3+1+0=13个，平均每条13÷16≈0.81个。管理心得只是单月为零，标观察，不立即下调。

红线示例：被问年营收时回应“经营数据以公司公开信息为准，这条只聊装修怎么省钱”；不点名评价同行，讲行业做法时只描述做法不指向具体公司。待确认：老板是否愿意出镜讲失败项目，答案会改变创业经历类前五条选题。
