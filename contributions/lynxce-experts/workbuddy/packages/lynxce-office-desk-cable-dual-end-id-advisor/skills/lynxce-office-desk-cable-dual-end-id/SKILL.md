# 桌面线缆双端标签编号

先交付已确认结果与待补项目，再给逐项可复核的规格、数量、费用和异常记录。一根线一个编号，两端一致并分别记录位置。

## 工作流程（按顺序执行）

1. 收集工位内部编号、设备资产代号、端口名称、实际线缆根数、两端可贴位置、标签规格、库存和用户批准损耗备量；不读取设备文件或账号秘密。
2. 拟定工位号与线缆序号组合，先查台账再分配唯一编号；同一根线两端共用编号，两端位置另设A与B列，不给同一根线建立两个独立资产。
3. 逐根追踪来源设备端口和目标设备端口，经负责人确认才标映射完成；未知走向标【待补】，不得为追线擅自拔插正在使用的设备。
4. 双端标签需求＝已确认根数×2＋批准补领量；采购缺口＝max(0,需求－可用空白库存)，包装数＝向上取整(缺口÷每包张数)，余量计库存，不混同线缆根数。
5. 核标签贴合尺寸、材料与厂家使用条件，先小样粘贴并检查文字可读性、端口空间及拆换；预算＝包装数×包价＋确认耗材配送费用，不把颜色当唯一编号。
6. 输出线缆端口映射采购表与改接异常表；设备搬迁或线缆更换保留旧号停用记录，新号防重复，复核两端标识与映射一致后关闭异常。

## 核算与判断标准

- 一根线一个编号，两端一致并分别记录位置。
- 只统计实际追踪确认的线，不按设备数推根数。
- 贴纸张数、成对标签数和线缆根数分开。
- 旧号保留停用状态，不能回收后马上重号。

## 异常处理与复核

- 遇同号先隔离记录再分配新号。
- 走向不清标待核，排期由授权人员追踪。
- 标签脱落补贴时先核映射，不能照颜色猜。
- 改接目标端口后更新台账并进行双方复核。

## 执行边界与交付要求

- 所有尺寸、时长、备量与报价取自用户方案、实测或厂家说明；未确认项标【待补】，示例假设不作为实际报价或执行事实。
- 仅在用户请求采购比较且工具可用时查询规格与报价，工具失败记录待补；不编造优惠、不承诺最低价，不强制附链，二维码支架任务不输出外链。
- 交付保留公式、单位、数据来源、负责人、版本与关闭条件；没有现场验收记录不能把初筛或计划记成实际通过。
- 只处理办公排期、规格采购与台账，不做医疗、财税或法律结论，不放外链或邮箱，不要求用户购买才能获得办公结果。

## 示例

假设8个工位，每位实物清点5根线，共8×5＝40根，每根双端各1张，需求80张；负责人批准补领8张，合计88张，现有可用空白18张，缺口70张。标签每包50张、每包12元，向上取整(70÷50)＝2包，新增100张，配送6元，预算＝2×12＋6＝30元，完成发放后预计空白余量＝18＋100－88＝30张。编号示例D08-C03，两端分别登记显示器输入口与扩展坞输出口。异常：发现2根线同用D08-C03，先保留记录并核实其中一根改为未使用的D08-C06，需要替换双端2张；原补领8张中使用2张、余6张，若旧标签不可复用不重新计库存。另有1根走向未知，标待追踪而非已完成，映射完成率＝39÷40＝97.5%，不能报全部完成。
