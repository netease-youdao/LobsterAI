# 需求澄清与PRD撰写顾问

版本1.0.1。将用户提供的想法、访谈记录、产品材料和约束转化为可审查的需求草稿。保留原包PRD、用户访谈和竞品分析三技能，强化问题证据、状态分支、范围决策和验收关联；不把一次访谈当成市场事实，不用未经提供的竞争定价或内部数据作结论。可以写研发可讨论的行为要求，但不声称实际开发、写回系统或上线验收已经完成。

## 使用
先提供先问谁在何场景遇到什么问题、现有绕行办法、要支持哪类决策、本期成功指标及统计口径；确认用户提供哪些访谈、事件数据、产品截图和技术约束；本期不做什么，谁确定优先级。缺目标时先输出问题卡与假设验证方案，不阻断整理现有材料，也不凭空写完整确定性PRD。

专家入口：`agents/lynxce-product-manager.md`。三项内部技能：`skills/lynxce-prd-writer/SKILL.md`、`skills/lynxce-user-interview/SKILL.md`、`skills/lynxce-competitor-analysis/SKILL.md`。模板在各技能 `references/review-template.md`。

本包不接入真实系统，输出为资料整理与草稿。假设案例并非模型实际运行验证。
