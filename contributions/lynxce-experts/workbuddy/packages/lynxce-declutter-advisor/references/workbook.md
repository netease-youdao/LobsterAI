# 可复制收纳规划底稿

```text
空间／使用者／测量日期／家中幼儿老人宠物（有/无）：
测量：柜内净宽｜净深｜净高｜挂杆净长｜层板高度｜实测腰高｜实测肩高
整理顺序：类别｜计划日期｜负责人（物品主人）｜完成确认
去留统计：类别｜清点总数｜保留｜转赠或出售｜丢弃｜待定｜减量比例
待定箱：箱号｜封箱日期｜复核日期（加三个月）｜复核结果（本人确认）
分区：区域高度范围｜频率（高/中/低）｜放置物品｜重物轻物｜安全措施
容器核算：位置｜容器宽深高｜单层个数｜层数｜顶部余量｜总个数｜每个容量

维持：一进一出记录｜每日归位时段｜缓冲筐清空日｜两周复查结论
关键问题（最多3个）：
```

## 已填假设示例：卧室衣柜

以下全部为演示假设，不是任何家庭的真实记录。只整理本人的衣物，家人衣物不在范围内。全部拿出清点共186件：保留112件、转赠或出售38件、丢弃21件、待定15件，合计186件。减量比例为(38+21)÷186，约31.7%；待定15件另行报告。待定箱于2026年10月18日封箱，复核日为2027年1月18日，由本人开箱决定。

测量：本人实测腰高95厘米、肩高130厘米，黄金区为95到130厘米。挂杆净长120厘米，10件实挂共占25厘米，每件平均2.5厘米，挂放容量为120÷2.5即48件，按八成上限最多挂48×0.8即38.4件，取38件。保留的112件中挂38件，其余74件折叠。高频当季上衣挂在取用高度位于黄金区的挂杆段，高频折叠衣物放上层抽屉，换季衣物装进顶层带盖箱，顶层只放轻物。

顶层格子净宽90、净深55、净高35厘米。原计划买30厘米宽的箱子：向下取整((90−2)÷30)只能放2个。换成宽28、深50、高25厘米的箱子：单层可放向下取整(88÷28)即3个，三个共宽84厘米；深50厘米不超过53厘米；层数向下取整(35÷25)为1层，顶部留10厘米。如果选高16厘米的扁箱，算出可叠2层，但剩余35−32即3厘米不足5厘米，只能放1层。

装载率：4个抽屉实测每个约放20件，共80件，加3个顶层箱每个约10件，共30件，折叠容量110件。计划放入74件，装载率74÷110约67.3%；挂放38÷48约79.2%，都不超过八成。维持：每天晚上五分钟归位，门口缓冲筐每周日清空，两周后复查。关键问题：换季衣物能否移到储藏间；家人是否共用这个衣柜；抽屉每格实际能放多少件。
