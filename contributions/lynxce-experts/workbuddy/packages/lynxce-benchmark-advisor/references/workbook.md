# 可复制拆解底稿

```text
账号定位：受众｜解决问题｜内容形式｜粉丝数｜统计日期｜数据来源。
对标筛选：账号｜领域受众｜形式｜近30天更新次数｜粉丝倍数｜是否入选｜剔除原因。
样本编码：编号｜账号｜组别｜播放｜账号中位数｜倍数｜选题｜开头｜结构｜时长档｜前3秒画面｜封面句式｜转折秒｜互动秒｜发布时段。
共性判定：维度取值｜高表现组次数与占比｜对照组次数与占比｜差值｜判定｜样本编号。
差距打分：共性维度｜自己近10条做到次数｜得分｜改动成本｜是否入选改进项。
选题清单：序号｜选题｜借鉴形式｜自有素材｜开头第一句｜验证指标。
验证计划：改动变量｜基准中位数｜测试作品数｜测试结果｜判定｜下一步。
待确认：最多三项。
```

## 已填假设示例：职场技能口播账号

以下均为演示假设，不是任何真实账号的数据。自己账号做职场技能口播，粉丝8000。对标4个口播账号，粉丝3万至7万，倍数3.75至8.75，近30天均每周更新；另加一个近90天从2000涨到1.2万粉的小号作参考。

样本：4个对标账号各取高表现5条、对照3条，共20条和12条。其中一条播放18万，该账号中位数4万，倍数4.5。编码结果：
- 开头结论前置：高表现15条即75%，对照4条约33.3%，差41.7个百分点，判为共性。
- 第8秒前出现第一次转折：高表现16条即80%，对照5条约41.7%，差38.3个百分点，判为共性。
- 时长30至60秒：高表现14条即70%，对照7条约58.3%，差11.7个百分点，判为行业常规。

差距打分：自己近10条中结论前置2条，得1分；第8秒前转折0条，得0分，平均12秒才进正题。两项都改动成本低，先改开头结论前置，转折前移放在下一轮。

选题示例：“三步写出领导愿意看的周报”，借鉴结论前置开头，素材来自自己带团队时的周报模板，第一句为“周报只需要回答三个问题”，验证指标为完播率；其余四条按同一格式写入选题清单。

验证：自己近10条完播率中位数18%。两周内只改开头，发布4条，完播率为22%、19%、25%、21%，中位数21.5%，比基准高3.5个百分点，判为“方向正确，继续测试”；下一轮保持其他变量不变再发4条，与本轮合并判断。
