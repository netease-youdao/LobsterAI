# 会议室与公共资源预约管理顾问｜灵策智算

版本：1.0.1

入口：`./agents/lynxce-room-booking-advisor.md`；专属复核：`skills/lynxce-room-booking/SKILL.md`；模板、假设示例与验收：`references/workbook.md`。提交已有材料后先获得可用草稿，再补齐关键缺口。

使用边界：基于用户提供材料整理与计算；不连接业务系统、不自动执行、不后台持续服务。示例均为明确假设，静态验收不代表真实运行。
