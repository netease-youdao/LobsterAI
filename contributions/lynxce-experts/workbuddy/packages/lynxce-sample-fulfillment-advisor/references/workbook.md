# 可复制寄样底稿

```text
批次编号／品类／合作形式／寄出份数／单份样品成本／单份运费：
筛选表：达人｜平台｜近30天作品数｜品类相关占比｜互动核实信号｜过往履约｜结论（寄样/付费商单/需核实/不寄）。
条款清单：形式｜条数时长｜必提卖点｜禁用说法｜发布窗｜平台账号｜合作标识｜预审时限｜修改次数｜样品归属｜逾期处理｜数据回传｜金额与付款节点｜确认方式与日期。
台账：编号｜达人｜样品｜单价｜单号｜寄出日｜签收日｜发布窗｜第一次提醒｜第二次提醒｜实际发布日｜作品标识｜核验结果｜状态。
提醒话术：收货确认｜截止前提醒｜逾期提醒（用户自行发送，记录发送时间）。
复盘：寄出｜签收｜已发布｜核验通过｜待整改｜逾期｜观察名单｜总成本｜两种发布率｜平均成本｜卖点覆盖率。
商单对账：达人｜合同金额｜已付｜扣减条款原文｜逾期天数｜扣减金额｜应付｜凭证｜财务确认人。
待确认：最多三项。
```

## 已填假设示例：十月护手霜寄样批次

以下全部为演示用假设。寄出20份，单份样品成本80元、运费12元，总成本20×（80＋12）＝1840元。签收19份，1份运输丢失，快递理赔进度【材料待确认】。统一发布窗为2026年10月20日（星期二）至10月31日（星期六），必提卖点3项。

节点：第一次提醒10月28日（星期三），11月1日（星期日）核对，第二次提醒11月3日（星期二），11月5日（星期四）仍无回应者列入观察名单。

截至11月5日：已发布14条，其中13条核验通过，1条缺合作标识记待整改；未发布5人中2人书面说明延期到11月10日，3人两次提醒均无回应，列入观察名单并暂停寄样。签收口径发布率14÷19＝73.7%，寄出口径14÷20＝70.0%；核验通过13条，单条平均成本1840÷13＝141.54元；13条中9条覆盖全部3项卖点，覆盖率9÷13＝69.2%。一致性：13＋1＝14，14＋2＋3＝19，19＋1＝20。

商单对账：达人C为付费商单，合同金额3000元，签约时已付30%即900元，尾款2100元；合同写明“发布窗截止后每逾期一天扣合同金额2%，上限10%”。C于11月3日发布，逾期3天，扣减6%即180元，应付尾款1920元，合计实付2820元。C的作品内容核验通过，逾期另行记录；最终金额待双方书面确认，付款与开票由财务处理。

收货确认话术示例：“您好，物流显示样品已签收，麻烦确认一下包装和产品是否完好。按约定，发布时间是10月20日至10月31日，有问题随时告诉我。”
