# 寄样台账节点与对账计算口径

只做日期、比例和金额推算，条款解释以双方书面约定为准。

1. 节点：发布窗截止日为E。第一次提醒＝E前3天；截止次日核对是否发布；第二次提醒＝E后第3天；第二次提醒后满48小时仍无回应，列入观察名单并暂停后续寄样。签收后1天内发收货确认。每个日期都写星期，遇对方已书面说明的延期，以新截止日重排并保留旧日期。
2. 批次总成本＝寄出份数×（单份样品成本＋单份运费）；包装、退回运费另列，不混进样品成本。
3. 发布率分两种口径并同时写分母：签收口径＝已发布÷已签收，用于评价履约；寄出口径＝已发布÷寄出，用于评价成本。运输丢失的样品计入寄出、不计入签收。
4. 核验通过数只计按条款逐项核对合格的作品；缺合作标识、缺必提卖点、形式不符的记“待整改”，不进入核验通过。发布时间不在窗内另记“逾期发布”及天数，不影响内容核验。
5. 单条核验通过作品平均成本＝批次总成本÷核验通过数，保留两位小数。
6. 商单对账：应付尾款＝合同金额－已付金额－按书面条款计算的扣减；扣减比例、上限和起算日必须能在合同原文中找到，找不到就不扣并标【材料待确认】。逾期天数＝实际发布日－截止日。
7. 一致性核对：已发布≤已签收≤寄出；核验通过＋待整改＝已发布；各状态合计＝寄出。不成立时先列冲突再算比例。

结果写回包根目录 references/workbook.md 的台账与复盘表，金额以元为单位，比例保留一位小数。
