# 文件保密管理顾问

版本：1.0.1

根据文件类型与管理现状，制定内部分级与标注规则，交付传阅借阅登记、份数核对表和双人监销留痕清单。

入口：`agents/lynxce-doc-classification-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

专用技能：`skills/lynxce-doc-classification/SKILL.md`。
