# 可复制保密流转底稿

```text
单位／适用范围／制度版本／编制日期／责任人：
范围判断：可能涉及国家秘密（是则移交，不继续）｜涉密资质｜确认对话中不提供正文。
分级判定表：等级｜判定标准｜典型文件｜初判人｜核定人｜受控期限或解除条件｜复审周期。
标注规则：纸质页眉｜页脚编号｜份号格式｜复印续号；电子文件名前缀｜页眉｜水印｜加密与密码传递渠道。
传阅登记：编号｜文件名｜等级｜份号｜传阅人｜接收时间｜应交回｜实交回｜批准人。
借阅台账：借阅人｜用途｜份号｜借出日期｜应还日期｜实还日期｜逾期工作日｜处理。
份数核对：印制加复印｜归档保存｜本次销毁｜历史已销毁｜外发未收回｜在借未还｜差额。
销毁清单：文件名｜编号｜份号｜份数｜方式｜依据｜监销人一｜监销人二｜日期｜备份到期日。
待确认：最多三项，写明影响哪一条规则。
```

## 已填假设示例：投标报价单

以下均为演示假设。投标报价单判为受控：泄露会让竞争对手掌握报价，直接影响中标和合同收益。起草人为商务专员，核定人为销售总监；受控期限为开标后30天。纸质共印10份，份号01/10至10/10；经批准复印2份，续编为第11、12份，登记簿注明来源份号03。

借阅：法务助理于2026年10月19日周一借出份号05，借期5个工作日，借出当日不计，应还日期为10月26日周一；实际10月28日周三归还，逾期2个工作日，未到第3个工作日的上报节点，管理员已于逾期首日提醒并登记原因。

会议：评审会按份号01至08发放8份，会后清点收回7份，待查1份为份号06，当场查找，确认被参会人误夹入笔记本，当场收回并登记。

假设开标日为2026年11月6日周五，受控期限到12月6日周日，顺延到12月7日周一处理：归档的份号01降为内部并更新标注，其余11份按作废件销毁。份数核对：印制10份加复印2份共12份；归档保存1份，本次销毁11份，历史已销毁0份，外发未收回0份，在借未还0份，1+11+0+0+0=12，差额为0，可以签字。销毁清单登记份号02至12，交叉切碎纸，监销人为行政主管与法务助理；电子版清除共享盘与邮件附件，云端备份到期日【材料待确认】，到期后补记。
