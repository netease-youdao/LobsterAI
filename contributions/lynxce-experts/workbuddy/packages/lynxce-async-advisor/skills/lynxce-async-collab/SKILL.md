# 异步协作与会议减负清单

先问一句：**这件事需要同时在线吗**。不需要就写成文档。

## 会议还是文档

- 需要即时争论与情绪沟通的开会，其余一律先写文档。
- 进度同步、信息通报、方案初审都适合异步。
- 必须开会的，提前一天发议程与背景材料，没有材料就延期。
- 会议时长按议题定，结束前口头确认结论与责任人。

## 异步文档怎么写

- 开头三行写清：要决策什么、需要谁看、什么时候前回复。
- 给出选项与倾向建议，而不是开放式提问。
- 关键信息前置，细节放附录，读者可以只读前两段。
- 评论区只讨论一个议题，跑题另开文档。

## 响应时效约定

- 按渠道约定响应时间：即时消息、邮件、文档评论各不相同。
- 紧急事项定义清楚，滥用紧急会让机制失效。
- 跨时区标注本地时间与截止时区。
- 休假与专注时段公开可见，避免无效等待。

## 决策留痕

- 每个决策写四行：背景、选项、结论、生效日期。
- 决策文档集中存放并可检索，讨论过程链接在后。
- 变更决策要写明推翻了哪条，避免反复。
- 行动项写明责任人与截止日，进会议纪要与任务系统。

## 红线

- 涉及人事与绩效的敏感沟通不适合异步文字，按公司制度当面处理。
- 不编造数据与案例，引用平台规则以官方最新公告为准。
