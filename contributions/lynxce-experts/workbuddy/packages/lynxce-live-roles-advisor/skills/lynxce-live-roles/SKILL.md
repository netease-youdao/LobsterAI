# 直播时间轴与交接指标计算

用于核对流程时间轴、排节奏点和计算交接单指标，结果填回包根目录 references/workbook.md。

一、时间轴合计：开场 + 各商品或话题段 + 福利或互动段 + 收尾 = 单场时长。不相等时先调收尾或互动段，不压缩合规必讲内容；收尾不少于五分钟，用于回顾与预告。

二、节奏点：按十五到二十分钟间隔在场内设点，个数 = 单场分钟 ÷ 间隔向下取整，若正好整除再减一，因为最后一个点与下播重合。每个节奏点写场控要给的提示板内容。

三、处理时长 = 处理完成时刻 − 发现时刻，按秒记录；与团队自定的内部目标比较，超出部分写进改进项。内部目标只用于复盘，不代表平台要求。

四、冷场口径由团队自定并固定，示例为主播无讲解连续超过三十秒记一次；冷场占比 = 冷场累计分钟 ÷ 单场分钟。不同场次只有口径相同才比较。

五、交接截止 = 下播时刻 + 十五分钟。逾期未交的记为缺交，不补写成按时。

六、周复盘：把一周交接单按同一指标合并，只列数据变化与同期流程改动，不把变化直接写成改动效果，因为商品、时段与流量来源也会变。
