# 可复制直播协作底稿

```text
直播类型／单场时长／每周场次／团队人数／方案版本：
角色分工：角色｜人员｜开播前｜直播中｜下播后｜备份人｜一人多岗时的优先级
口令表：口令或手势｜含义｜谁发出｜谁执行
流程时间轴：段落｜开始分钟｜结束分钟｜内容｜主讲｜提示板内容
节奏点：分钟｜场控提示内容
突发预案：情况｜第一处理人｜动作｜内部时限｜事后记录
交接单：场次｜下播时刻｜交接截止｜数据截图｜问题（时刻/现象/处理人/处理时长）｜改进项｜负责人｜完成时间
周复盘：指标｜口径｜各场数值｜同期流程改动｜下周只改的一到两项
关键问题（不超过三个）：
```

## 已填假设示例：三人服饰带货直播

以下全部为演示假设，不代表真实直播间或数据。三人团队、单场一百二十分钟：主播甲只讲解；助播乙兼场控；运营丙负责链接、价格、库存与推流设备，乙为甲的讲解备份。

时间轴：开场5分钟，8个商品各12分钟共8×12=96分钟，两次福利环节各5分钟共10分钟，收尾120−5−96−10=9分钟，合计120分钟。节奏点每二十分钟一次，120÷20=6正好整除，减去与下播重合的一个，共5个，分别在第20、40、60、80、100分钟。

交接单：第一场20:00开播、22:00下播，交接截止22:15。问题一：三号链接价格挂错，20:31:10发现，20:32:40下架，处理时长90秒，超出团队内部目标60秒共30秒；改进项为丙按讲解顺序预排链接，开播前由乙、丙双人核对价格，负责人丙。冷场口径为主播无讲解连续超过三十秒，本场4次、累计6分钟，占比6÷120=5%。

周复盘：假设第二场同口径记录冷场1次、累计1分钟，占比1÷120≈0.8%。复盘只写“冷场次数由4次变为1次，同期改动为改价移交运营”，不写成改动的必然效果，因为两场商品与时段不同。下周只再改一项：福利环节提前一个节奏点预告。
