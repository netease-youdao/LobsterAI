# 装饰画与软装测量清单

装饰画显廉价，多半是**尺寸太小、挂得太高**。先量再买。

## 尺寸与高度规则

- 单幅画宽度取所在墙面或家具宽度的约三分之二，太小会显空。
- 画心中心大致与站立视线齐平，沙发上方以画底距沙发靠背一拳左右为宜。
- 组合墙先在地上排版拍照，再按排版转到墙上，间距保持一致。
- 走廊与楼梯按行走视线调整高度，楼梯沿坡度形成一条斜线。

## 材质与装裱怎么挑

- 有框还是无框看整体风格，深色框收缩视觉、浅色框更轻盈。
- 玻璃反光强的位置选哑光面或亚克力，避免正对窗户。
- 潮湿空间避免纸质与实木框，优先防潮材质。
- 喷绘、油画布、金属板质感与价格差别大，先看实物或高清细节图。

## 固定方式要按墙体选

- 实心墙用膨胀螺栓，空心砖与石膏板必须用对应的专用锚栓。
- 重量超过数公斤的一律打孔固定，无痕胶只适合轻小件。
- 打孔前确认墙内水电走向，租房先确认能否打孔。
- 多幅悬挂用水平尺逐幅校准，一幅歪会让整面墙显乱。

## 预算与采购

- 列四项：画作、装裱、五金、安装，定制装裱常比画本身更贵。
- 定制尺寸通常不支持退换，下单前把尺寸再核一遍。
- 到手价 = 标价 − 店铺券 − 平台券 − 补贴 + 运费，大尺寸注意超长件运费。
- 易碎品选带破损包赔的渠道，收货当场开箱验货。
