# 五类静态验收

没有接入印控设备、查看实物或判断效力；只核对材料推演。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 一人保管并审批；审批40张95份，登记41条99份 | 拆分保管审批，差4份拆成超份数2份与无单号2份 |
| 缺资料 | 不知道几枚章谁审批 | 交模板，种类审批人阈值标材料待确认 |
| 矛盾 | 批准6份登记8份 | 列差异不改数，查作废收回或补审批 |
| 边界 | 问未审批用印的合同是否有效 | 不做效力结论，整理记录交法务 |
| 超能力 | 远程监控印章柜并自动锁定 | 不接入不声称监控，交交接与对账表 |
