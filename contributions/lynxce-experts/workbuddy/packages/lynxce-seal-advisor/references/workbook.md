# 可复制印章管理底稿

```text
印章台账：印章名称｜类型｜保管人｜备份保管人｜存放位置｜钥匙持有人｜审批人｜启用日期｜状态。
交接单：交出人｜接收人｜监交人｜日期｜印章逐枚清点｜钥匙｜登记本页码｜未结外带｜三方签认。
审批矩阵：用印事项｜印章｜金额或类别条件｜审批层级｜必附材料｜备注。
用印登记：日期时间｜审批单号｜印章｜文件名称与版本｜批准份数｜实盖份数｜作废收回｜对方单位与用途｜经办人｜监印人｜是否外带。
外带表：审批单号｜印章｜去向事由｜带出时间｜预计归还｜实际归还｜超时时长｜外带审批份数｜外带期间实盖份数｜印面检查｜核验人。
月度对账：月份｜审批单张数与批准份数｜登记条数与实盖份数｜匹配条数与份数｜差异类型｜份数｜说明｜责任人｜整改日期。
状态：可启用／补审批权限后启用／先做临时登记；关键问题最多三项。
```

## 已填假设示例：一家贸易公司的十月对账与外带

以下人员、单号和数字均为演示假设。公司有公章、合同章、财务章、法定代表人名章各一枚，之前由行政一人保管全部印章并自行决定是否盖章。拆分后：公章和合同章由行政保管，按矩阵由部门负责人或总经理审批；财务章由财务主管保管，法定代表人名章由总经理助理保管，两枚分柜存放。

十月对账：审批单40张，批准合计95份；登记41条，实盖合计99份。按审批单号匹配，39张审批单与39条登记一一对应，两边份数都是89份。审批单“用印-2026-1017”批准6份，对应登记写8份，超出2份。另有1条登记没有审批单号，盖了2份。核对：审批侧39加1为40张，89加6为95份；登记侧39加1加1为41条，89加8加2为99份；份数差99减95为4，等于超出2份加无单号2份，没有未解释差额。差异单两行：超出的2份查明是否盖坏，盖坏则补登“作废收回”并收回原件，否则由经办人补审批；无单号的1条由经办人说明用途并补审批，保管人写明当时放行的原因。

外带：合同章经审批外带到客户处签约，10月20日（周二）9点带出，预计当天18点归还，外带审批4份。实际10月21日（周三）9点30分归还，超时15.5小时。归还核验：印面无损，外带期间实盖4份，与审批一致；超时原因为签约推迟到次日上午，监印人全程随行，补写说明并由审批人签认知悉。
