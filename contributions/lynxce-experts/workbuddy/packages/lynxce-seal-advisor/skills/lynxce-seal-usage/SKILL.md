# 用印对账与外带核验

用于月度对账和外带归还核验的计算，只做数字与留痕，不判断某次用印是否有效。

对账步骤：先分别合计审批单张数与批准份数、登记条数与实盖份数；再按审批单号逐条匹配，得出匹配条数和匹配份数。差异分四类逐行列出：登记无审批单号（未经审批用印）；同一单号实盖份数大于批准份数（超份数）；有审批无登记（待确认是取消还是漏登）；实盖少于批准（少盖，确认剩余审批是否作废）。一张审批单分几次用印时，几条登记的份数合计后再与批准份数比较。

平衡校验：登记总份数减审批总份数，应等于超出份数合计加无单号份数合计，减去未登记审批的批准份数合计，再减去少盖份数合计。等式不成立时，把差额单独列为“未解释差额”，交对账人和保管人共同查明，不得为了平衡改动任何一侧的记录。

外带核验：超时时长等于实际归还时间减预计归还时间，跨日按每日二十四小时累计，精确到半小时；外带期间实盖份数不得超过外带审批份数；印面检查写“无损”或具体异常。超时、超份数或印面异常任一出现，外带表都要有说明、监印人签认和审批人知悉记录。

对账人应由不经手用印的人担任。所有更正保留原值、更正值、依据和更正人。结果填回包根目录 references/workbook.md 的月度对账与外带表。
