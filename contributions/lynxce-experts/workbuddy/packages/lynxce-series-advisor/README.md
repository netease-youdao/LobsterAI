# 系列栏目策划顾问

版本：1.0.3

围绕同一受众问题搭建可持续栏目，交付栏目卡、十二期选题库、产能排期与四期复盘表，支持持续迭代内容

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 栏目卡与单期结构
- 十二期选题及素材台账
- 按工时约束的四周排期
- 四期复盘表与下一轮实验稿
