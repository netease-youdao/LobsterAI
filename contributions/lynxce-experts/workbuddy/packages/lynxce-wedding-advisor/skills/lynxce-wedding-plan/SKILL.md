# 婚礼流程与预算核算
本技能只做交付前的数值核对，结果填回包根目录 references/workbook.md；数值来自用户材料或明确标注的假设，不替用户做取舍。
1. 桌数：开席桌数 = 宾客人数 ÷ 每桌人数，向上取整；备桌另列，写明未开是否计费。桌数超过场地容量时停止排座，输出冲突与取舍选项。
2. 时间链：每段结束时间等于下一段开始时间；各段时长相加等于首段开始到场地截止的总分钟数，不相等就定位断档或重叠。
3. 缓冲：可变环节 = 车程 + 可压缩环节；要求缓冲 = 可变环节合计 × 15%；已安排缓冲小于要求时，先压缩可压缩环节，不动硬节点。
4. 敬酒：敬酒分钟 = 开席桌数 × 每桌分钟数，并检查结束时刻早于场地截止且留有退场时间。
5. 预算：六类金额相加等于总预算；各类占比 = 类别金额 ÷ 总预算，保留一位小数；预备金占比低于8%时标红并按用户优先级从末位类别降档补足。
6. 日期：付款、人数确认、彩排日期都写上星期几，倒推日期用日历逐日核对。
7. 变更：任何数值变化登记日期、项目、原值、新值、原因、确认人，重新执行第2至5步，旧版本保留。
