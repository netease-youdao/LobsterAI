# 可复制婚礼底稿

```text
基础：日期星期｜宾客（确定／待定）｜每桌人数｜开席桌数与备桌｜场地容量｜场地截止时间｜总预算与硬上限｜优先级排序
流程单：起止时间｜时长｜环节｜类别（不可压缩／可压缩／硬节点／缓冲）｜地点｜负责人｜备份人｜所需物品
缓冲核算：可变环节合计分钟｜×15%｜已安排缓冲｜是否满足
预算表：类别｜项目｜基础／改善／加价｜本档包含内容｜单价×数量｜金额｜占比｜状态（报价／已签／已付）
易漏项：押金｜加时费｜加桌｜服务费｜开瓶费｜进场费｜电费｜超时超里程
付款倒计时：供应商｜款项｜金额｜到期日期星期｜凭证编号
供应商确认：条款要点｜对方书面答复｜确认件位置｜待确认项
变更记录：日期｜项目｜原值｜新值｜原因｜确认人
关键问题（最多3个）：
```

## 已填假设示例：二百人午宴

以下全部为演示假设，不是任何新人的真实方案。婚礼为2027年5月22日星期六，宾客200人，每桌10人，开20桌，另备2桌；餐标每桌3000元，服务费10%，场地使用截止14:30，总预算硬上限15万元。

预算：①场地餐饮 = 餐费20 × 3000 = 60000元、服务费6000元、酒水8000元，共74000元，占49.3%；②人员服务20000元，占13.3%；③服装造型12000元，占8.0%；④布置物料22000元，占14.7%；⑤交通住宿8000元，占5.3%；⑥预备金 = 150000 − 136000 = 14000元，占9.3%，高于8%。若两张备桌开席，增加餐费6000元与服务费600元，预备金剩7400元，占4.9%，低于8%，需按优先级从④或⑤降档补足，并登记变更。

流程单：06:00—08:00化妆（不可压缩）、08:00—08:30车队至女方（车程）、08:30—09:15接亲敬茶、09:15—10:00车队至酒店（车程）、10:00—10:30缓冲、10:30—11:30迎宾合影、11:30—11:45补妆换装（不可压缩）、11:45—12:00缓冲、12:00—12:30仪式（硬节点）、12:30—13:20敬酒（20桌 × 2.5分钟 = 50分钟）、13:20—14:00送客、14:00—14:30退场余量。各段合计510分钟，等于06:00至14:30。可变环节 = 30 + 45 + 45 + 60 + 50 + 40 = 270分钟，乘15%为40.5分钟，已安排缓冲30 + 15 = 45分钟，满足。每段负责人和备份人按用户名单填入，未提供前写【材料待确认】。

倒计时：最终人数确认日为婚礼前7天，即2027年5月15日星期六；尾款日期以合同为准，合同未签前标【材料待确认】。
