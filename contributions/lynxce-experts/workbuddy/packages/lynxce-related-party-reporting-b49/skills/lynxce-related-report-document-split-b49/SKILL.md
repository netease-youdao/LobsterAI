# 年度关联报告与同期资料分流
把年度关联业务报告、国别报告、主体文档、本地文档和特殊事项文档分别判断，不能说企业规模小或仅境内交易就全部免申报。二〇一六年第42号第一条要求相应查账居民企业及境内据实纳税非居民机构场所就关联业务年度申报；年度无业务但国别报告条件涉及的另核。国别报告第五条涉及居民最终控股企业上一年度合并收入超过五十五亿元，或被集团指定报送等分支；母公司不大或自己非最终控股不能排除被指定路径。
主体文档第十一条有跨境交易且最终控股集团已准备主体文档，或关联交易总额超过十亿元两种触发；不知道集团文档状态时不能仅因低于十亿元就说免主体。第十三条本地文档对有形所有权超过两亿、金融和无形所有权分别超过一亿、其他交易合计超过四千万元分流，只有完整交易范围才可判断；预约定价及仅境内等例外按第十八条具体范围核。第十五条成本分摊和资本弱化等特殊事项不由货物金额小自动免除。
第十九条区分主体文档集团年度结束十二个月内、本地及特殊事项次年六月底前准备与税务要求后三十日提供；“准备完毕”不是每年全套报送。实际延期须有法定依据或真实批准，不从今天重起期限。二〇一七年第26号第一条澄清国别收入关联方以集团成员实体范围填，不把所有税法关联个人都塞入国别报告；该公告对二〇一六年度的历史更正时点不能当本年通用宽限。交付分流说明和待核责任页，所据2026官方办事指南仍列2016版报告，不能编一个2026版新表。金额未超过并不等于独立交易价格已经合规，本项不出可比数据库分析、预约定价或转让定价无风险保证。
