# 用户评价分析师

版本：1.0.1

将评论原文整理为可追溯主题、样本占比与改进优先级，区分产品和服务问题，交付验证计划与卖点证据表。

作者：灵策智算 LynxceAI

入口：[lynxce-review-analyst](agents/lynxce-review-analyst.md)。完整交付包括逐条评论编码与去重账、样本主题占比及优先级矩阵、产品验证计划与卖点证据表。

先在会话中提供已脱敏材料，专家据此整理草稿与核对结论。模板见 [交付模板与复算示例](references/delivery.md)，验收边界见 [五类静态验收](references/acceptance.md)。

本包没有后台运行、实时监控或自动发送能力。示例均为明确标注的假设资料；计算结果可复算，不代表真实客户成效。
