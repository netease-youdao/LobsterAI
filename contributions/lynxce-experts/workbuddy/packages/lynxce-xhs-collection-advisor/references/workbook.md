# 可复制合集规划底稿

```text
账号定位／目标读者／清单导出日期／版本号：
盘点表：笔记编号｜标题｜主题标签｜主问题｜观看｜收藏｜收藏率｜去向（入集/待定或待扩充/不入集/重复下线）｜所属合集。
盘点平衡：清单总数｜入集｜待定或待扩充｜不入集｜重复下线｜是否相等。
合集规划：合集名｜主轴｜目标读者｜现有篇数｜入口篇｜计划补充｜目标动作。
单篇排序：序号｜标题｜解决的问题｜上一篇｜下一篇｜收藏率｜备注。
封面标题规范：版式｜主色｜序号位置｜标题前缀｜原标题与修改日期。
补稿排期：周次｜日期｜篇目｜所属合集｜负责人｜状态（计划/已发布+发布日期）。
复核表：复核日期｜合集｜平均收藏率｜拆续集候选｜合并重写候选｜过期信息处理。
待确认：最多三项，每项写明会改变哪个合集。
```

## 已填假设示例：八十篇护肤笔记

以下数据全部为演示假设。护肤账号已发80篇笔记：干皮14、油皮12、敏感肌18、成分入门11、防晒6、彩妆4、杂谈与开箱15，合计80篇。

主轴选人群（肤质），另设基础入门合集。防晒6篇中4篇针对具体肤质，按主轴归入干皮1篇、油皮2篇、敏感肌1篇，另2篇通用的并入基础入门。敏感肌中有两篇讲同一修护问题，保留信息更新的一篇，旧稿改为指向新稿。结果：干皮合集15篇、油皮14篇、敏感肌18篇、基础入门13篇，入集共60篇；彩妆4篇偏离护肤定位列为待定；杂谈与开箱15篇彼此无关不入集；重复旧稿1篇下线。60加4加15加1等于80，盘点平衡。

收藏率：干皮合集观看合计45000、收藏合计2700，平均收藏率6.0%。其中笔记A观看3000、收藏420，收藏率14.0%，不低于平均的两倍12.0%，列为拆续集候选；笔记B观看2000、收藏50，收藏率2.5%，低于平均的一半3.0%，本次先标记，下次复核仍低于一半再合并重写。

入口与排期：干皮和基础入门已有可用入口篇，油皮和敏感肌各需新写一篇导读。每周产能2篇，4篇补稿需要2周。第一周10月20日发油皮导读、10月23日发敏感肌导读；第二周10月27日发由笔记A拆出的干皮续集、10月30日补基础入门一篇。补完后干皮16篇、油皮15篇、敏感肌19篇、基础入门14篇，均不超过20篇；敏感肌接近上限，再增加时按修护和日常护理两个阶段拆分。首次排期周一为10月19日，季度复核日为13周后的2027年1月18日。
