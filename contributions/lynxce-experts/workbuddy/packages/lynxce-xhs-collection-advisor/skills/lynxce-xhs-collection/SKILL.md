# 合集盘点与更新排期核算
用于把存量笔记的去向算平、把收藏率阈值算清、把补稿和复核日期排准，结果写回包根目录 references/workbook.md。数据只用用户提供的笔记清单和后台导出，注明导出日期。
盘点平衡：总篇数等于入集篇数加待定系列篇数加不入集篇数加重复下线篇数，四类相加必须等于清单总数，每篇只能落在一类、一个合集。跨主题笔记按主轴归入一个合集，其他合集只在正文中指引。
收藏率等于收藏数除以观看数，保留一位小数；合集平均收藏率用合集内收藏总数除以观看总数，不用各篇比例的简单平均。默认阈值：单篇收藏率不低于合集平均的两倍，列为拆续集候选；连续两次复核都低于合集平均的一半，列为合并重写候选。阈值可按账号调整，但调整要写明。
篇数：合集篇数超过建议上限二十篇时按阶段拆分；不足五篇时标为待扩充，补齐所需篇数等于五减现有篇数。
排期：补稿日期按每周产能排列，写具体日期与篇目；补稿完成周数等于待补篇数除以每周产能向上取整。季度复核日等于首次排期周一加十三周。排期是计划，发布与否以实际记录为准。
