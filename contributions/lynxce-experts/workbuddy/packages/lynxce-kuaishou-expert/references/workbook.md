# 可复制快手运营底稿

```text
账号／版本／数据导出日期／材料编号：
人设：身份｜专长证据（编号）｜表达方式｜一句话关联货品。
栏目：名称｜类型（信任/实用/转化）｜占比｜频率｜示例选题。
脚本：栏目｜前三秒｜卖点（只一个）｜证据画面｜动作请求｜时长与字数。
直播：日期与星期｜时段｜开场福利与库存｜单品顺序与时长｜重复提示间隔｜场控记录栏。
话术核对：绝对化用语｜功效表述｜限量与库存｜原价依据｜抽奖规则。
粉丝分层：新关注｜互动粉门槛｜成交粉｜复购粉｜各层动作。
复盘：播放｜完播｜互动｜观看人数与人次｜成交人数与金额｜退款｜五项比率｜样本是否足够。
关键问题：最多三项，写明答案会改变哪一栏。
```

## 已填假设示例：自家桃园黄桃

以下均为演示假设。主理人在北方自家桃园种桃十二年，以果园现场和采摘过程为证据，人设句为“自家种桃的人卖自家桃”。栏目：桃园日常（信任）、挑桃与储存（实用）、上新与直播预告（转化），比例约四比四比二。

脚本示例，按四十五秒、一百五十至一百八十字控制：前三秒“这批桃今天为什么不能发？”；中段拍摄测糖与挑出磕碰果的过程，只讲“磕碰果不发”一个卖点；结尾“周六晚八点直播间现场挑桃，点预约就能收到提醒”。

直播安排：2026年11月5日（周四）与11月6日（周五）各发一条预告作品；11月7日（周六）20:00至22:00开播，共120分钟。开场10分钟介绍福利规则，福利数量按后台库存核对；四款货品每款12分钟、循环两轮共96分钟；最后14分钟答疑、售后说明与下场预告，合计120分钟。

作品复盘：一条挑桃作品播放20000次，完整播放5600次，完播率百分之二十八；点赞600、评论150、分享50，互动率百分之四。同栏目四条作品完播率分别为百分之二十八、三十一、二十五、三十二，平均百分之二十九，样本刚满四条，可做初步比较。

直播复盘：观看3200人、4800人次，成交96人共7680元，退款384元。观看成交转化率百分之三，千次观看成交额1600元，客单价80元，退款率百分之五。单场只描述，下一场只调整开场福利一个变量，连续三场后再判断方向。
