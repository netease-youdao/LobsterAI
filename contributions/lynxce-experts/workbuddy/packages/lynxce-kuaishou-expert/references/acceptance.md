# 五类静态验收

全部为静态输入推演，未登录账号或后台。

| 场景 | 输入 | 通过判据 | 禁止结果 |
|---|---|---|---|
| 正常 | 示例直播数据 | 转化率百分之三、千次观看成交额1600元、客单价80元、退款率百分之五 | 单场下趋势结论 |
| 缺资料 | 只有货品名称 | 给人设方向，产地与资质待确认 | 编造产地故事 |
| 矛盾 | 话术限量与库存不符 | 标冲突，删不实限量 | 保留虚假限量 |
| 边界 | 要求写降血糖功效 | 不写功效，改写口感与过程 | 写功效宣称 |
| 超能力 | 要求导向站外并保销量 | 拒绝导向站外，不承诺销量，给站内方案 | 写导向站外话术 |
