# 可复制合拍底稿

```text
账号领域／选题日（含星期）／成片目标时长／原片引用上限：
我能补的价值：专业纠正｜实操验证｜进阶补充｜答疑｜结果追踪；对应证据：
候选打分：原片｜作者｜发布日（含星期）｜距选题日天数｜必选两项｜否决项｜时效分｜疑问分｜趋势分｜总分｜结论。
时间轴：段号｜起止秒｜内容｜类型（我方／原片）｜时长。
校验：各段合计＝成片时长；原片合计÷成片时长≤上限。
素材登记：段号｜原片标题｜作者｜原片内起止｜用途｜使用方式｜授权状态。
来源标注：画面文字位置｜作品描述写法。
异议记录：日期｜提出人身份｜内容｜处理动作｜负责人｜结论。
关键问题：最多三个，写明会改变哪一项。
```

## 已填假设示例：小户型衣柜收纳

以下全部为假设。账号做家居收纳，选题日为2026年10月14日（星期三），成片目标60秒，团队引用上限30%。

候选A为2026年10月9日（星期五）发布的衣柜收纳方法，距选题日5天，时效2分；前五十条评论中8条在问“柜子只有45厘米深怎么办”，疑问2分；互动在涨，趋势2分；总分6分，优先做。候选B为2026年9月20日（星期日）发布，距选题日24天，时效1分；同类疑问3条，1分；互动平稳，1分；总分3分，备选。候选C以电视剧片段为主体，否决。

补位角度为实操验证：原片推荐深50厘米的收纳盒，放进45厘米深的柜子会超出5厘米，换成深40厘米的盒子留出5厘米余量；层板间距36厘米、盒高11厘米，只能叠3层（3×11=33厘米），原片说的4层需要44厘米，放不下。这就是开头要说的“两处要改”。

时间轴：0–3秒开头补位句；3–9秒原片片段一（原片00:12–00:18，6秒）；9–30秒我方实操演示21秒；30–36秒原片片段二（原片00:41–00:47，6秒）；36–55秒我方尺寸对比19秒；55–60秒结论与评论区邀请5秒。合计3+6+21+6+19+5=60秒；原片片段6+6=12秒，占比12÷60=20%，低于30%上限，我方内容48秒。

素材登记两段均写原片标题、作者与起止时间，使用方式假设为平台内置合拍功能且作者已开放；作者主页未见禁止声明，授权状态写“平台功能开放，未另行取得书面许可”，不写已获授权。来源标注放在开头画面左上角与作品描述首句。
