# 可复制体检组织底稿

```text
体检项目／年度／参检范围／编制人／版本：
两类区分：职业健康检查名单来源与负责人｜福利体检范围｜各自预算。
人数结构：年龄段｜性别｜人数（只填人数，不填个人信息）。
套餐预算：档位｜适用人群｜人数｜单价｜小计｜项目明细来源｜自费加项规则。
机构门槛：机构｜执业资质｜体检服务范围｜报告直达本人｜个人信息条款｜是否进入评分。
比选评分：机构｜项目同等30｜报告时效20｜接待与距离20｜价格20｜服务10｜总分｜说明。
排期表：日期｜星期｜部门｜人数｜每日上限｜时段｜补检日。
预约须知：发出日期｜到检日期地点｜机构提供的检前要求原文｜改期截止｜个人项目调整直接告知机构。
复盘：应检｜实检｜到检率｜改期数｜按实结算额｜报告按时率｜满意度｜调整建议。
待确认：最多三项。
```

## 已填假设示例：180人福利体检

以下均为演示假设。福利体检180人：30岁以下70人、30至45岁85人、45岁以上25人，单价分别为450元、600元、800元。预算：70×450=31500元，85×600=51000元，25×800=20000元，合计102500元，人均约569.44元；人均预算600元即108000元，结余5500元留作价格调整。另有生产线12名噪声岗位人员的职业健康检查由职业卫生负责人单独立项。

比选：三家均过门槛。甲承诺12个工作日出报告，时效得18分；乙8个工作日得20分；丙16个工作日得14分。甲：27+18+16+17+8=86分；乙：24+20+18+15+7=84分；丙：28+14+12+19+6=79分，选甲并把12个工作日写入合同。

排期：甲日接待50人，每日上限50×0.6=30人，180人需6天，另加1个补检日。2026年11月10日周二研发30人、11日周三研发30人、12日周四销售30人、17日周二运营30人、18日周三客服30人、19日周四职能30人，补检日为24日周二，避开月底。须知于11月3日周二发出，首批改期截止为11月6日周五。

复盘：原定日到检166人，14人未到，其中8人改期到补检日、实到6人，最终实检172人，到检率172÷180约95.6%，改期率8÷180约4.4%。未检8人中30岁以下3人、30至45岁4人、45岁以上1人，按实结算102500−3×450−4×600−1×800=97950元，实检人均约569.48元。报告按时送达165份，按时率165÷172约95.9%。匿名汇总按三个年龄段统计，实检人数分别为67、81、24，均不少于10人。
