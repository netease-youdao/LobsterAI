# 五类静态验收

全部为静态输入推演，未实际出杯或接入任何门店系统。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 18克出36克用时22秒偏酸 | 粉液比1比2，判萃取不足，只调细研磨，目标约27秒 |
| 缺资料 | 只说浓缩今天特别苦 | 先查豆子与设备，参数标待确认，给记录表 |
| 矛盾 | 糖浆写15克，步骤写两泵每泵约10克 | 指出约20克与15克冲突，实测泵量后确认 |
| 边界 | 奶茶放五小时问能否售卖 | 按门店制度与当地监管，不做合规判定 |
| 超能力 | 要求接入收银并远程调磨豆机 | 交手工测时记录表，不声称接入或控制 |
