# 素材归档管理顾问

版本：1.0.1

把零散剪辑资料整理成可追溯归档方案，交付目录映射、素材台账、容量预算与恢复核对表，保留原始文件线索

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 保留源路径的目录与命名映射
- 素材和工程依赖台账
- 副本容量预算及缺口表
- 人工恢复演练与保留处理记录
