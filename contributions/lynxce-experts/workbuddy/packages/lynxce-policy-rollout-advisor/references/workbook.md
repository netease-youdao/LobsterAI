# 可复制制度修订底稿

```text
制度名称／旧版本→新版本／发起部门／适用范围：
修订原因：编号｜类别（法规／业务／执行问题／审计发现）｜要解决的问题｜对应条款。
对照表：条款号（旧→新）｜原条款｜修订后条款｜类型（新增／修改／删除／仅编号调整）｜实质或文字｜修订理由。
条款数核对：旧条款数｜删除数｜新增数｜新条款数｜是否成立。
影响清单：岗位｜流程／表单／系统／模板／知识库｜需要做的调整｜负责人角色｜完成日期。
关键日期：审批日｜发布日｜确认截止日｜生效日｜过渡期止｜复盘日。
一页速读：改了什么｜影响谁｜生效日期｜过渡安排｜咨询部门。
已读确认：部门｜在册人数｜长期休假｜应确认｜已确认｜完成率｜跟进人角色。
复盘：执行偏差｜例外申请｜新增提问｜归类（再修订／补宣贯／维持）。
结论：可发布／补材料后发布／暂停；最多三个关键问题。
```

## 已填假设示例：差旅制度V3.0修订为V3.1

以下为演示假设，不是任何公司的真实制度。修订原因：一线城市酒店价格上涨导致超标频繁（业务变化），超标住宿缺少财务把关（执行问题）。

对照表：第5条（5→5）修改，一线城市住宿标准由每晚500元调为600元，差额100元，增加 `100÷500=20%`，实质变化；第8条（8→8）修改，超标住宿由部门经理审批调整为部门经理审批后财务复核，增加一个审批节点，实质变化；旧第9条删除，纸质报销单流程不再要求，替代做法为在报销系统提交电子单据；旧第10至12条对应新第9至11条，仅编号调整；新增第12条，未经事前审批的超标部分由个人承担，实质变化。条款数核对：`12-1+1=12`，成立。

影响清单：订票系统一线城市住宿上限由500元调整为600元（行政系统管理员）；报销审批流增加财务复核节点（财务系统管理员）；差旅申请表模板和员工手册差旅章节更新（行政）；知识库V3.0标“已废止”（行政），各项完成日期不晚于11月13日。

关键日期：11月2日审批通过，11月4日发布，11月16日生效，发布到生效间隔12天；已读确认截止11月13日；11月6日为销售部和售后部开短会，常见问题11月13日前更新；生效日前已审批的出差按V3.0执行，过渡期至11月30日；复盘日12月16日。

已读确认（截至11月12日）：销售部在册50人，长期休假2人，应确认48人，已确认45人，完成率93.75%；售后部22人全部确认，100%；财务部6人全部确认，100%；行政部10人中已确认8人，80%。合计应确认 `48+22+6+10=86` 人，已确认 `45+22+6+8=81` 人，完成率约94.19%。销售部3人和行政部2人的名单交部门负责人在截止前跟进，2名休假人员返岗后补确认。
