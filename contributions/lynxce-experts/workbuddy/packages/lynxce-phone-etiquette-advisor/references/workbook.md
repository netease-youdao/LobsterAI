# 可复制前台电话底稿

将下面模板完整填写；不适用的写原因，未知的保留材料标记。

```text
基础信息：日均来电量｜统计周期｜前台人数与班次｜话务设备能力｜公司全称与统一口径
来电分类：类型｜一周来电数｜占比｜累计占比｜是否单列（投诉／媒体／安全）
来电分流表：类型｜典型开场｜转接部门｜接口人｜备岗｜转不通处理｜生效日期
话术卡：开场｜转接前告知｜三十秒回线｜转不通留言｜不清楚时的回复｜结束语
留言单：记录时间｜来电人｜单位｜事由｜回电号码｜希望回电时间｜转交对象｜转交时间｜转交用时｜回电截止｜是否已回电
特殊来电处置：类型｜识别信号｜标准回应｜禁止事项｜上报对象｜记录要求
抽查评分：通话编号｜接起秒数及得分｜开场｜倾听复述｜转接留言｜保密合规｜总分｜是否达标｜改进点
月度汇总：抽查通数｜平均分｜达标通数｜达标率｜高频扣分项｜话术卡更新
待确认：最多三项，每项写明会改变哪条结论
```

## 已填假设示例：两人前台的一周记录

以下来电数与评分均为演示假设。某公司前台两人，一周记录来电三百通，按五个工作日计日均六十通。分类为客户咨询96、供应商对账48、应聘36、推销33、快递外卖30、找具体员工27、投诉9、其他21，合计300。按数量从高到低累加，前五类共243通，累计81%，已达到百分之八十；第六类找具体员工27通需要按姓名转接、规则不同，也一并列入；投诉只有9通、占3%，仍按规则单列。分流表共七类，覆盖279通，即93%。

留言：10月14日周三十点零五分记录的留言，十点十二分转交，用时七分钟，符合十分钟要求；同日十四点二十分记录的留言，十四点四十一分才转交，用时二十一分钟，列为改进项。10月16日周五下午的留言，回电截止为下一个工作日，即10月19日周一下班前。

抽查：第三通接起用时十八秒，得8分；开场15分；倾听复述20分；留言漏记希望回电时间，转接与留言得20分；保密合规15分；总分8+15+20+20+15=78，未达标。本月十通得分为92、88、78、95、85、90、72、88、94、86，合计868，平均86.8分；八十分及以上共八通，达标率80%。高频扣分项为留言缺希望回电时间，补进话术卡：“请问您希望我们什么时候回电比较方便？”下月安排一次演练。待确认：一、话机能否显示等待时长；二、各部门备岗名单；三、录音告知的统一说法。
