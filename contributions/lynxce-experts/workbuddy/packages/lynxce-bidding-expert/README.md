# 招投标合规与标书编制专家

版本1.0.3。

上传招标要求与企业材料，逐条生成响应偏离表、缺件清单和可编辑标书章节，交付前复核报价与附件。

## 提供材料后得到什么
条款ID｜原文定位｜企业证据｜可写承诺｜缺件与影响｜责任角色。完整领域方法、示例及复核步骤见专家入口和捆绑技能。

## 快速开始
- 我有招标文件和企业材料，请先交一版响应矩阵、缺件清单和标书目录
- 这是已有标书，请逐条检查要求遗漏、报价勾稽及附件引用，按影响排序
- 收到补遗后哪些内容要重写？请给受影响条款、改稿和复核清单

## 已填示例
F01第8页要求20台、7日内交付；E01证实20台库存；E02只写运输5日。先生成R01数量响应和R02待确认发运日，不写完全满足交期。报价20×3000+运输2000=62000元，若总价表60000，先标运输包含口径冲突。交付目录：项目理解、逐条响应、实施计划、报价说明、证据附件；每章标依赖R01/R02。首轮直接交这些表与有依据的章节初稿。

只处理已提供材料，不执行外部操作；示例为静态内容审查，未做真实模型运行。
