# 可复制收件箱与周计划底稿

```text
角色／时区／工作时段／本周关键产出：
来信概况：来源｜日均量｜回复时限｜当前未读。
首轮清理：批次｜条件｜数量｜去向｜例外。
逐封分流：当场回｜转任务（产出、截止）｜归档｜转办（承接人、期望日、跟进日含星期）｜待判断。
规则表：编号｜条件｜动作｜例外｜设置人｜复查日期。
回信模板：主题（动作＋对象＋截止）／结论或请求／背景／请对方做什么何时交谁／不回复时的默认处理。
会议清单：名称｜单次时长｜每周频次｜人数｜周分钟｜人时｜调整建议（待组织者确认）。
周计划：日期星期｜时间块｜内容｜类型（深度／会议／邮件／缓冲）。
负荷核算：周工作分钟｜会议分钟与占比｜邮件时段分钟｜深度块分钟｜剩余可安排。
跨时区：会议｜本地时间｜对方当地时间｜夏令时切换日。
关键问题：最多三项。
```

## 已填假设示例：项目经理周一清理与周计划

以下为演示用假设。2026年10月19日（周一）上午共有未读320封。首轮批量：系统通知与订阅190封移入低优先，抄送60封移入抄送文件夹，剩下直接来信70封逐封分流：当场回复18封、转任务22封、归档21封、转办9封，合计70封。当场回复按每封不超过两分钟估算，上限36分钟。转办邮件周一发出，三个工作日后跟进，跟进日为10月22日（周四）。

会议清单：周一项目例会60分钟、每日站会15分钟共5次、周三客户会60分钟、周四评审90分钟、三场一对一各30分钟。固定会议合计60＋75＋60＋90＋90＝375分钟，即6.25小时，占每周40小时的15.6%。项目例会8人参加，每周8人时；若组织者同意按议程缩短到45分钟，为6人时，每周少占用2人时。

时间块：每天两个邮件处理时段各30分钟，每周共300分钟；周二至周五上午各一段120分钟深度工作，共480分钟。每周40小时即2400分钟，扣除会议375、邮件300、深度480后，剩余1245分钟用于临时会议、任务与缓冲。

跨时区：每周二北京时间16:00与伦敦同事通话。10月20日（周二）对方为当地9:00；伦敦于10月25日（周日）结束夏令时，10月27日（周二）同一北京时间对应当地8:00，需提前与对方确认是否调整。

关键问题示例：哪些发件人必须当天回复；一对一能否合并到同一个下午；周四评审是否必须本人全程参加。
