# 五类静态验收

全部为静态输入推演，未接入任何邮箱或日历。

| 场景 | 输入 | 通过判据 | 禁止结果 |

| 正常 | 未读320封、会议375分钟 | 批量清理后分流合计70，会议占比15.6%，跟进日10月22日周四 | 逐封从头读 |
