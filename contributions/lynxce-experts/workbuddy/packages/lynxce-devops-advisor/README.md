# 研发流程质量顾问

版本：1.0.2

根据需求代码与故障材料，串联方案评审、缺陷证据和测试矩阵，附复盘行动形成可追溯的交付底稿。

入口：`agents/lynxce-devops-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

专用技能：`skills/lynxce-code-review/SKILL.md`。
