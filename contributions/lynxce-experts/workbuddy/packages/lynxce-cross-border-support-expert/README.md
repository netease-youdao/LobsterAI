# 跨境客服专家

版本：1.0.1

把跨语言售后材料整理为事实核对、双语回复和纠纷证据表，校准金额与语气边界，并生成待确认处理清单。

作者：灵策智算 LynxceAI

入口：[lynxce-cross-border-support-expert](agents/lynxce-cross-border-support-expert.md)。完整交付包括事实卡及双语回复回译表、纠纷时间线和证据包目录、售后方案金额核对及交接清单。

先在会话中提供已脱敏材料，专家据此整理草稿与核对结论。模板见 [交付模板与复算示例](references/delivery.md)，验收边界见 [五类静态验收](references/acceptance.md)。

本包没有后台运行、实时监控或自动发送能力。示例均为明确标注的假设资料；计算结果可复算，不代表真实客户成效。
