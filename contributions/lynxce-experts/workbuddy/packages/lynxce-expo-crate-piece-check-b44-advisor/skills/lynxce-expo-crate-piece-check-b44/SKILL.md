# 撤展逐箱展品核对

公共独立小任务：核展品件号是否恰好装入一只有效箱。用户为展品保管与撤展清点员。输入只需本次应返展品件号、逐箱内容行、留场或借出批准记录。此项按自己的证据键、方法和输出表工作，不以专家摘要替代专项交付，不依赖任何外部接入。

## 工作流程

1. 锁定本项任务：核展品件号是否恰好装入一只有效箱。最少输入为本次应返展品件号、逐箱内容行、留场或借出批准记录；先给材料范围和截止时点，超出本项范围的请求单独记录。

2. 按最少字段建立证据索引：锁定应返展品集合，留场与已批准外借分别列，并保存批准依据；搭建耗材不默认属于返运展品。

3. 建立对象与事件关系：每件展品连到箱号、装箱行与清点时刻，同型号不同件号分开；一箱写两台设备而无件号时保持未定位。

4. 执行专项推演：检查漏装、重复装箱和非本次展品，交集先排除重复后核箱内唯一件数，不用总件数相同证明装箱正确。

5. 检查专属异常与边界：封箱前未定位件保留待核，装箱计划与用户反馈已装分列；已封箱发现错箱只能给复核建议，不宣称已开箱。 对照缺资料与冲突案例，确认缺项没有被填成示例值。

6. 交付撤展逐箱展品核对文本表与补证队列，逐格保留资料编号及状态。重新核正常与边界算式，给负责人确认入口；实际完成状态以用户后续反馈为准。

## 专项方法与证据顺序

- 锁定应返展品集合，留场与已批准外借分别列，并保存批准依据；搭建耗材不默认属于返运展品。

- 每件展品连到箱号、装箱行与清点时刻，同型号不同件号分开；一箱写两台设备而无件号时保持未定位。

- 检查漏装、重复装箱和非本次展品，交集先排除重复后核箱内唯一件数，不用总件数相同证明装箱正确。

- 封箱前未定位件保留待核，装箱计划与用户反馈已装分列；已封箱发现错箱只能给复核建议，不宣称已开箱。

## 专属异常和采用条件

- 件号E1被拆成主机附件时主机仍计一件，附件进入绑定表而非新增展品。

- 箱号重复需展位或批次限定键，不能跨参展商合箱推断。

- 留场批准只有型号而无件号时待确认适用对象，不随机扣一件。

- 展品数量闭合后继续核附件和封箱记录，不能自动标可提货。

## 资料状态与交付复核

- 引用材料使用资料代号、版本和行号，事实摘录与推演结果分栏。未知值统一写【待补】；补证问题指出缺什么、为什么影响本项判断，以及用户应返回哪一格资料，不能仅泛称完善材料。

- 所有统计注明对象、单位及截止时点，记录数、唯一对象数与关联边数分开。计算从原始值逐步列算式，残差保留符号；不通过四舍五入隐藏冲突，零分母写不适用而非百分之百。

- 文本表是材料审阅草案。建议动作、用户确认拟执行、用户反馈实际完成采用不同状态；无反馈时不得变为完成。这里只用已给文字与表格手工推演，不声称已查询系统、通知人员或操作实物。
