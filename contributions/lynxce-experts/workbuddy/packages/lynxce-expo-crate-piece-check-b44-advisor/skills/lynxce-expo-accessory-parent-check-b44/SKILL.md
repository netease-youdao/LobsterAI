# 展品附件绑定缺口表

内部独立专项：只核每件主展品的附件类型数量是否按给定清单齐备。用户为展品保管与撤展清点员。输入只需主机件号、随附清单、附件编号或类型、已装数量。此项按自己的证据键、方法和输出表工作，不以专家摘要替代专项交付，不依赖任何外部接入。

## 工作流程

1. 锁定本项任务：只核每件主展品的附件类型数量是否按给定清单齐备。最少输入为主机件号、随附清单、附件编号或类型、已装数量；先给材料范围和截止时点，超出本项范围的请求单独记录。

2. 按最少字段建立证据索引：按主机件号引用用户原配清单，不依据设备型号猜标配；共享附件必须有归属约定。

3. 建立对象与事件关系：逐类型比较应附和实装，同名但接口或规格不明的附件只记候选，不自动替换。

4. 执行专项推演：缺附件＝应附－已确认实装，超额保持负值并核是否归错主机，不用另一主机余件抵消。

5. 检查专属异常与边界：附件在独立箱时保留主机箱与附件箱双关联，提货需能查到两箱，不能强求同箱而修改记录。 对照缺资料与冲突案例，确认缺项没有被填成示例值。

6. 交付展品附件绑定缺口表文本表与补证队列，逐格保留资料编号及状态。重新核正常与边界算式，给负责人确认入口；实际完成状态以用户后续反馈为准。

## 专项方法与证据顺序

- 按主机件号引用用户原配清单，不依据设备型号猜标配；共享附件必须有归属约定。

- 逐类型比较应附和实装，同名但接口或规格不明的附件只记候选，不自动替换。

- 缺附件＝应附－已确认实装，超额保持负值并核是否归错主机，不用另一主机余件抵消。

- 附件在独立箱时保留主机箱与附件箱双关联，提货需能查到两箱，不能强求同箱而修改记录。

## 专属异常和采用条件

- 租赁件和自有件分开，借出附件有批准仍不算已装。

- 非唯一编号附件按主机加类型核数量，未知兼容性不作适配结论。

- 空包装和实物分开，附件盒不能当附件。

- 清点完成后输出待寻找位置和承接角色，不说已经追回。

## 资料状态与交付复核

- 引用材料使用资料代号、版本和行号，事实摘录与推演结果分栏。未知值统一写【待补】；补证问题指出缺什么、为什么影响本项判断，以及用户应返回哪一格资料，不能仅泛称完善材料。

- 所有统计注明对象、单位及截止时点，记录数、唯一对象数与关联边数分开。计算从原始值逐步列算式，残差保留符号；不通过四舍五入隐藏冲突，零分母写不适用而非百分之百。

- 文本表是材料审阅草案。建议动作、用户确认拟执行、用户反馈实际完成采用不同状态；无反馈时不得变为完成。这里只用已给文字与表格手工推演，不声称已查询系统、通知人员或操作实物。

- 收到新增材料后只重算受影响对象，保留旧值、采用版本和修改理由。冲突未解决的对象不能挤入已确认集合；结束时检查每条输入有去向、每条判断有来源、每个未决项有最少补证动作。
