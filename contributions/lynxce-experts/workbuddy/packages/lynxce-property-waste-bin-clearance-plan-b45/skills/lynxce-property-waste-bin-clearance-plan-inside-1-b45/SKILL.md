# 分段桶内余量递推

## 要解决的具体问题
逐段找出清运前最高装载，避免只看日总量与清空后的零值。
这是专家工作链中的第1项独立能力。只处理本节写明的对象与口径，不接管其它子任务。用户可以直接给脱敏文字表格，交付也是可复制的文本；没有外部服务依赖。

## 最低输入与进入条件
期初升数、分段新增、桶数与每桶可用升数、每次清走量及发生时点。
先以任务代号固定对象，再写本轮截点。输入有一项缺失时，先把已知对象写进本节的交付格式；只有依赖缺项的计算或措辞暂留【待补】，不让用户重填全部材料。对真正影响决策的缺口一次最多问三个问题。

## 专属操作方法
每段先加新增得到清前峰值，再扣清走量得到下一段余量。清走量不大于清前余额；全清时取当时余额。逐段对容量比较，新增非负且段内无中途清运或容量变化时，清运前段末量即峰值；若有中途事件则细分，缺分布时不保证具体时点可行。不同垃圾类别分开递推，不能用另一类别空桶抵消。

## 可直接使用的输出与已填例子
假设容量192升，08:00为0，08—10新增100升，10点全清，清前100清后0；10—12新增130升，12点全清；12—14新增90升，末余90。总320−清230=90升。
