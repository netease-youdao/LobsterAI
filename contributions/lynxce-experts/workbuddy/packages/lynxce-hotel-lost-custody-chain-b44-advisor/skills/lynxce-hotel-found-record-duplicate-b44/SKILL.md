# 遗失物疑似重复登记核对

内部独立专项：只审查两条发现记录是否有足够依据认作同一物品。用户为酒店跨班保管员。输入只需登记号、物品特征脱敏摘要、发现时点、位置代号和封袋编号。此项按自己的证据键、方法和输出表工作，不以专家摘要替代专项交付，不依赖任何外部接入。

## 工作流程

1. 锁定本项任务：只审查两条发现记录是否有足够依据认作同一物品。最少输入为登记号、物品特征脱敏摘要、发现时点、位置代号和封袋编号；先给材料范围和截止时点，超出本项范围的请求单独记录。

2. 按最少字段建立证据索引：先保留原登记两行，颜色品牌相同仅生成疑似关联，不直接去重；序列号只用用户给定脱敏尾段。

3. 建立对象与事件关系：比较发现事件、封袋迁移和人工确认材料，唯一封袋也需排除袋号误写；缺关键字段时疑似不能变确认。

4. 执行专项推演：被确认重复时保留主登记与从登记关系，从登记不再计独立件，但历史发现记录不得删除。

5. 检查专属异常与边界：输出确认重复、确认不同和证据不足三类，记录确认角色与日期，给保管主流程传递唯一物品集合。 对照缺资料与冲突案例，确认缺项没有被填成示例值。

6. 交付遗失物疑似重复登记核对文本表与补证队列，逐格保留资料编号及状态。重新核正常与边界算式，给负责人确认入口；实际完成状态以用户后续反馈为准。

## 专项方法与证据顺序

## 专属异常和采用条件

- 同一物品不同时间的再次发现可能涉及临时取用，先核事件链而非当作重复录入。

- 照片相似度不是实物身份结论，仅使用用户描述的证据。

- 袋号重复使用可能使不同物品错误合并，查登记规则和复用时点。

- 不输出失物主的个人信息或推断住客消费习惯。

## 资料状态与交付复核

- 引用材料使用资料代号、版本和行号，事实摘录与推演结果分栏。未知值统一写【待补】；补证问题指出缺什么、为什么影响本项判断，以及用户应返回哪一格资料，不能仅泛称完善材料。

- 所有统计注明对象、单位及截止时点，记录数、唯一对象数与关联边数分开。计算从原始值逐步列算式，残差保留符号；不通过四舍五入隐藏冲突，零分母写不适用而非百分之百。

- 文本表是材料审阅草案。建议动作、用户确认拟执行、用户反馈实际完成采用不同状态；无反馈时不得变为完成。这里只用已给文字与表格手工推演，不声称已查询系统、通知人员或操作实物。

- 收到新增材料后只重算受影响对象，保留旧值、采用版本和修改理由。冲突未解决的对象不能挤入已确认集合；结束时检查每条输入有去向、每条判断有来源、每个未决项有最少补证动作。
