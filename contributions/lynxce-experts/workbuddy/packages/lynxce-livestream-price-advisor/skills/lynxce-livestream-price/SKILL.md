# 直播间价与货架价对比与下单核对

直播间的「专属价」常常不是同一件东西的更低价，而是**换了规格、搭了赠品、把几件拼在一起报了个整数**。

## 工作流程（按顺序执行）

1. 让用户记下直播间商品链接信息：直播间报价、主播口播的券与赠品、规格（容量、重量、件数、型号），缺的标【待补】，不凭记忆补全。
2. 找同款货架价：在同一品牌官方店或同一商家店铺找同型号同规格商品，记货架价与可领券后的到手价，规格不同的不直接比。
3. 折算单价：统一换算成每毫升、每克、每片或每件价格，直播间套装拆成主品加赠品分别核价。
4. 赠品计价：只计用户确实会用的赠品，按同款正装单价折算；小样、非卖品、限量不确定发放的赠品记 0 或单列为附加。
5. 下单前三核对：一核价格（下单页实付金额与口播到手价是否一致）、二核规格（下单页型号容量件数与口播一致）、三核赠品（下单页或商品详情是否写明赠品及发放条件）。
6. 输出对比表与结论：单价更低、持平或更高，任一核对不一致的建议先暂停下单并截图询问客服；最后按商品列出可下单入口。

## 对比方法

- 比单价不比总价，套装先拆主品与赠品，主品单价与货架同规格单价对比。
- 货架价按领券后的到手价计，券的门槛与叠加规则以下单页显示为准。
- 直播间限时价要记录截图时间，同一商品在不同时段的直播间价格可能不同，以实际下单页为准。
- 同名商品注意是否为直播专供款，型号尾缀、批次或配置可能与货架款不同，规格不一致的不做价格结论。

## 三核对清单

- 价格：下单页应付金额与口播到手价差额超过 1 元即标出并询问，不以主播口头说法为准。
- 规格：型号、容量、件数、颜色版本逐字核对，截图保存下单页商品快照。
- 赠品：看赠品是否写入商品详情或下单页，写明「前 N 名」「付款后多少分钟内」的核对自己是否满足条件。
- 售后：确认直播间下单与货架下单的退换规则是否一致，赠品退货时是否需要一并退回。

## 红线

- 不评价主播或品牌的诚信，只按页面信息做对比。
- 不代用户判断直播间一定更便宜或更贵，结论只基于用户提供的截图与页面信息。
- 口播内容与页面不一致时以下单页与平台规则为准，提醒用户保存截图。
- 不使用「最低价」「全网最便宜」「史低」等极限词，不做价格承诺，不保证「必省多少元」；价格、券与活动规则一律以平台活动页与下单页实时显示为准；不编造价格、销量与规则，用户未提供的信息用【待补】占位。

## 输出模板

直播间信息：直播间报价【待补】；口播券与赠品【待补】；规格【待补】；截图时间【待补】。

## 示例

用户：「直播间洗发水 2 瓶加 3 个小样 139，货架单瓶 79，划算吗？」→ 先核规格：直播间每瓶 500ml，货架单瓶为 750ml，不能直接比；折算后直播间主品每毫升约 0.139 元，货架领券后价格【待补】需用户提供；小样按不确定使用记 0；三核对中发现下单页未写明小样发放条件，建议先截图问客服再下单；最后按商品列出直播间与货架两个下单入口供用户选择。
