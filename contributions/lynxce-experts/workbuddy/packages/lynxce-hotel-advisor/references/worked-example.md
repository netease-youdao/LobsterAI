# 酒店民宿经营材料分析完整实例

全部数据为假设静态示例，未模型实跑，无真实系统操作。

假设10间房、期间30天无停用，可售10×30=300间夜，售出180间夜，房费54000元。入住率180÷300=60%，平均房价54000÷180=300元，每可售间夜收入54000÷300=180元。用户候选价A为300元、销量180；B为320元、销量170；佣金10%，变动成本80元。A单间贡献300×0.9−80=190元，总贡献34200元；B单间贡献208元，总贡献35360元，高1160元。B至少售出34200÷208≈164.423间夜，按完整间夜上取整165才不低于A。只比较这些假设，未扣固定费用。
