# 外贸样品签收反馈对应表

面向外贸跟单员与样品对接人的独立小任务：外贸样品签收反馈对应表。适用阶段为样品已寄出、客户签收与测试反馈待对应的阶段。最少事实输入为样品编号与版本、装箱样品清单、寄送及签收摘录、客户实际反馈原文、约定反馈项目与截点；交付样品签收与反馈双状态表、版本归属待核单、未反馈项目询问草案。核心方法：先以包裹到样品的包含关系核签收范围，再按样品编号加版本绑定反馈；物流签收、客户确认收到、反馈可归属三个状态独立，未回复不算否定评价。输入仅接收用户主动提供的脱敏文本或表格摘录，记录来源代号与原文位置；不要求业务系统接入，示例不能补真实资料。

## 工作流程

1. 锁定已寄出的样品批次，登记样品编号、版本和包裹代号；客户询盘需求只作背景，不重做报价前规格澄清。 接收时先登记来源、版本、对象范围和记录截点；若用户只给部分记录，交付已知范围并列最少缺项，不把没提供的数据补成零。

2. 拆包裹与样品关系，一包多样逐件列出；签收摘录仅支持包裹送达，样品完整收到要有客户或实物清单确认。 对象编号与资料行号应分开，整理值不覆盖原值。重复引用是证据复用而不是新增业务对象，同名对象必须查身份关系再合并。

3. 按用户约定反馈项目拆客户原话，颜色、尺寸、试用表现分别关联样品号及版本；没有版本的意见不直接写入最新版。 处理时按本任务方法逐项核查，事实、陈述、派生计算和建议分别标识。支持某一条件的证据不可自动扩展到其它条件。

4. 区分可归属反馈、需澄清反馈与尚未反馈，保留客户实际描述；内部判断与客户意见分栏，不把满意表述升级为验收通过。 条件不全给局部成果，矛盾给双值及来源；请用户指定确认角色，不取平均、不选更有利数值，也不把询问草稿记为完成动作。

5. 检查寄出、送达确认和反馈的时间顺序，保留原时区；负间隔先核时区和登记误差，不自动判运输异常。 复核应从来源重新取原值，检查单位、分母、版本和状态互斥性；已明确未知的字段保持未知，不以合计能对齐反推缺失事实。

6. 交付台账及按未反馈项目编的询问草稿，使用条件句；没有用户反馈实际发送时，状态只写待发送，不能承诺客户已答复。 交付时保留仍未解决的行和下一核实动作，说明接收角色与完成凭据。新资料到来按原对象续版，人工确认与实际执行仍分开。

## 对象与资料门槛

- 样品版本应来自用户标签清单，同名产品不能直接合并为一个样品。

- 寄出日期与预计到达日期分开，预计日期不能替代实际签收。

- 同一包裹拆两次寄送要有新的事件编号，不覆盖首次寄件。

- 签收人姓名等个人信息用代号，只保留判断签收范围需要的角色。

## 专属判断与异常分支

- 客户说收到三款时核清款与件单位，三款可能各有多件。

- 颜色反馈与性能反馈不是同一项目，少一项仍标该项未反馈。

- 英文原话中的否定词与条件保留，不把尚未测试译成测试失败。

- 旧版反馈只归旧版，新版继承需客户明确确认适用，不能按最近寄件时间猜。

## 输出验收与状态边界

- 对同样品两次矛盾反馈记录测试条件差异，条件不明则先请求说明。

- 无人答复时只核约定反馈时间是否已到，不按内部惯例给客户贴失信标签。

- 跨时区按明确偏移换算，缺时区不计算小时差，保留原值。

- 验收看样品到反馈的可追溯关系，不用成交率、内容发布或佣金作为完成证据。

## 五类内容设计假设案例（非模型实测）

- 正常：假设寄出6件样品，客户确认收到4件，其中3件反馈可归属、1件未反馈，另2件仍在途。 预期：已收到4=3+1，总6=4+2；可归属反馈占已收到3/4=75%，不以6件作已收到分母。

- 缺资料：假设一包含A、B两样，只有物流签收，无客户逐样收到确认。 预期：包裹已签收，A与B收到确认【待补】，不能同时标已反馈。

- 矛盾：假设客户称V1偏硬，业务员在表里录成V2，而原反馈无V2。 预期：反馈归属冲突，保留原话并请求版本确认，不把V1意见转V2。

- 边界：假设客户当地UTC减5的10日18时签收，寄出记录UTC加8的11日1时。 预期：签收为11日7时UTC加8，比寄出晚6小时；不能按原日期误判提前签收。

- 超出能力：假设要求查询承运商实时轨迹或判进口认证通过。 预期：仅整理提供的轨迹摘录与反馈，不联网取轨迹，不作认证结论。

## 本任务结果的使用顺序

- 先核样品号/版本与来源：本成果的每行以该对象为锚，后续收到修订资料必须回填同一对象。对象换了要新建行，不能沿用旧证据省略核对。

- 再核方法是否具备前提：先以包裹到样品的包含关系核签收范围，再按样品编号加版本绑定反馈；物流签收、客户确认收到、反馈可归属三个状态独立，未回复不算否定评价。 没有对应输入时只交缺项说明，不将演示算式当成业务记录。

- 异常行独立交接：样品签收与反馈双状态表、版本归属待核单、未反馈项目询问草案中每个待确认项注明影响字段、缺少的事实材料、接收角色和复核时点。只提能改变判断的问题，不要求与本任务无关的整套资料。

- 最终验收按下一询问草案及版本记录复核，逐条回查证据。文本完成、负责人确认、现场执行是不同状态；本表整理完成不代表整段业务已闭环，也不替用户作专业结论。
