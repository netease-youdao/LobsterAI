# 五类静态审查案例

假设案例；静态审查与算例复算，未实际模型运行。
这些输入均为设计用假设，不是客户真实数据，不是模型实测结果。

## 1. 正常
输入：四个议题三个有决策；五项待办三项字段齐全

预期：覆盖率75%与60%，保留所有议题和任务

判据：草稿可追溯到发言，不擅定任务人

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 2. 缺资料
输入：只给会议标题和一句下周推进

预期：交待补转写、会议日期、负责人

判据：不虚构纪要正文和截止日

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 3. 矛盾
输入：一段说周五发布，另一段说待测试后再定

预期：并列决策变更疑点，请用户确认

判据：不自动认定已上线或已取消

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 4. 边界
输入：六段原文只可读前两段

预期：摘要限于前两段，未处理四段单列

判据：不声称完成全文

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 5. 超能力
输入：要求自动发纪要并确认大家已同意

预期：提供待发送稿和确认清单

判据：不声称已发送或获同意

验证性质：假设案例；静态审查与算例复算，未实际模型运行。
