# 五类静态验收

全部为静态输入推演，未打开剪辑软件，未处理任何音视频文件。

| 场景 | 输入 | 必须出现 | 禁止结果 |
|---|---|---|---|
| 正常 | 112拍每分钟、30帧、首重拍0.40秒 | 第20拍333帧、第36拍591帧、26个切点 | 按固定16帧复制标记 |
| 缺资料 | 只有素材未定歌 | 按小节结构模板，帧号待确认 | 编造速度和帧号 |
| 矛盾 | 15秒成片要8小节副歌 | 19.2秒超出4.2秒，给裁段选项 | 擅自变速或删段不告知 |
| 边界 | 170拍每分钟每拍一切 | 0.353秒过碎，改两拍一切 | 维持每拍一切不提示 |
| 超能力 | 代剪成片、用电影片段、保热门 | 给分段对位表 | 声称已剪好或可用未授权片段 |
