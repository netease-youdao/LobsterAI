# 可复制卡点剪辑底稿

将以下模板完整填写；不适用项写明原因，未知项保留【材料待确认】。

```text
项目名称／平台与画幅／目标时长／版本号：
音乐：曲名｜授权来源与使用范围｜速度｜拍号｜第一个重拍时间｜裁剪起止。
工程：工程帧率｜成片帧率｜素材帧率统一方式。
分段表：段落｜起止拍｜小节数｜起止秒｜起止帧号｜情绪｜切点密度（拍每刀）｜切点数。
标记帧号：拍序号｜计算时间（秒）｜帧号｜时间码（秒:帧）｜回放核对结果。
素材分级：编号｜内容｜时长｜拍摄帧率｜等级A/B/C｜可拆景别。
对位表：切点序号｜起始帧号｜素材编号｜景别｜时长（帧）｜视觉变化｜动作峰值是否对准。
数量核对：切点总数＝各段切点数之和；A级条数×可拆刀数≥副歌切点数。
出片：分辨率｜帧率｜码率｜响度｜调色｜回看问题及修正。
变更记录：版本｜变更内容｜受影响的拍序号与帧号范围。
待确认：最多三项。
```

## 已填假设示例：22秒探店混剪

以下为演示假设。音乐速度每分钟112拍，四四拍，授权来自平台曲库，只在该平台发布；第一个重拍在0.40秒；工程与成片均为30帧，竖屏1080×1920。一拍为60÷112≈0.536秒，一小节约2.143秒，每拍约16.07帧。

分段：前奏1小节（第0至4拍）放一条开场全景；主歌4小节（第4至20拍）两拍一切，最后两拍放慢放镜头作停顿，共8个切点；副歌4小节（第20至36拍）一拍一切，共16个切点；收尾1小节（第36至40拍）放一条慢速特写。切点合计1＋8＋16＋1＝26个。

帧号按“帧号＝四舍五入（（0.40＋拍序号×60÷112）×30）”计算：第0拍为12帧；第4拍为76帧，开场镜头从0到76帧，约2.53秒；第20拍为333帧，即00:11:03；第36拍为591帧，即00:19:21；第40拍为655帧，成片约21.83秒。副歌共591−333＝258帧，16刀平均约16.1帧，单刀为16或17帧，即约0.53到0.57秒。若从第12帧起每16帧复制一个标记，第36拍会落在588帧，比正确值早3帧，超出两帧容差。

素材共21条：A级8条、B级10条、C级3条。A级8条各拆两刀，共16刀，正好覆盖副歌16个切点；B级10条用于开场1刀、主歌8刀和收尾1刀；C级3条备用。每刀把动作峰值帧对准该刀起始鼓点帧。出片响度按-14 LUFS参考，码率取10 Mbps。待确认：收尾是否需要更长的尾音，以及平台对片尾时长的要求。
