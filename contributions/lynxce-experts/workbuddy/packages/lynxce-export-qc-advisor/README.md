# 成片质检顾问

版本：1.0.1

依据成片资料建立导出规格与质检记录，定位字幕画面声音问题，交付修改单和复查清单，逐项标明验证证据

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 材料与导出规格差异表
- 字幕画面声音缺陷台账
- 文件体积估算
- 修改单与复查证据表
