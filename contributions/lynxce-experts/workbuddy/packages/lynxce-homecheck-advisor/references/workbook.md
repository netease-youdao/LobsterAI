# 可复制验房底稿

```text
房屋信息：交付类型（毛坯/精装）｜合同面积｜实测面积｜面积误差比｜合同处理比例。
文件核对：文件名｜是否提供｜页码或照片编号｜备注。
表计：水｜电｜燃气｜交房读数｜照片编号｜复验读数｜用量。
房间编号对照：R1…Rn｜房间名称。
问题台账：问题编号｜位置｜构件｜现象｜实测值与工具｜照片编号｜对照依据（合同条款或【材料待确认】）｜期望整改｜状态。
需专业确认：问题编号｜原因（结构部位/渗漏来源/合同争议）｜建议找谁｜已提交日期。
整改期限：书面原文｜口径（自然日/工作日）｜起算日｜截止日（星期）。
复验表：问题编号｜复验日期（星期）｜复测值｜复验照片｜结果（已销项/未通过/争议）｜双方签认。
汇总：登记总数｜已销项｜未通过｜争议｜销项率。
待确认：最多三项。
```

## 已填假设示例：两室一厅精装房

以下全部为演示用假设。2026年11月14日（星期六）收房，两室一厅精装交付。房间编号：R1客厅、R2次卧、R3主卧、R4厨房、R5卫生间、R6入户。合同面积89.50平方米，实测资料88.21平方米，面积误差比为（88.21－89.50）÷89.50×100%＝－1.44%，处理方式对照合同条款，交专业人员确认。交房电表读数35.2千瓦时。

登记8项：R1-C01客厅顶面斜向裂缝长约60厘米、宽0.2毫米，列入需专业确认；R2-W01次卧北墙空鼓30厘米×20厘米即600平方厘米（0.06平方米）；R2-W02次卧东墙靠尺最大缝隙6毫米，允许偏差待对照合同交付标准；R3-D01主卧窗密封条脱落约40厘米；R4-E01厨房台面上方插座检测显示缺地线；R5-P01卫生间地漏倒水后积水，水流背离地漏；R5-P02台盆下水接口纸巾擦拭潮湿；R6-D01入户门锁舌回弹不畅。经物业同意，卫生间11月14日10:00开始蓄水，最浅处约20毫米，计划24小时，11月15日（星期日）10:00由物业陪同查看楼下顶面。

整改期限：对方书面写“15日内整改完毕”，未注明口径，按自然日自交接次日起算，截止11月29日（星期日）；若对方确认为15个工作日，则截止12月4日（星期五），两种口径并列待确认。

复验：12月1日（星期二）按原编号复测。R2-W01、R3-D01、R4-E01、R5-P01、R5-P02、R6-D01共6项已销项；R2-W02复测仍为6毫米，记复验未通过，新增复验记录，原记录保留；R1-C01对方称为表层裂缝，业主已委托有资质的检测机构，报告未出，记争议待专业确认。销项率6÷8＝75.0%。复验时电表读数41.7千瓦时，整改期间用电41.7－35.2＝6.5千瓦时，费用由谁承担按双方约定，未约定的标待确认。
