# 问题台账编号与期限计算口径

只做编号、换算和日期推算，质量是否合格不在本阶段判断。

1. 房间编号在房型图上写明对应关系：R1为客厅，其余房间从入户起顺时针依次编号，入户门和公共部位排在最后。构件代码：C顶面、W墙面、F地面、D门窗、E电气、P给排水。问题编号＝房间号－构件代码＋两位序号，例如R2-W01。
2. 照片编号＝问题编号－序号，每个问题至少三张：1全景定位、2近景特写、3带尺或带检测工具读数。复验照片用同一编号加“复”字，同角度拍摄。
3. 面积换算：空鼓等面积＝长×宽，单位平方厘米，10000平方厘米＝1平方米。平整度、裂缝宽度记毫米，写测量工具。
4. 面积误差比＝（实测面积－合同面积）÷合同面积×100%，保留两位小数；与合同写明的处理比例对照，处理方式交合同条款和专业人员确认。
5. 整改截止日：书面写“N日”且未说明时，按自然日、自交接次日起算，第N日为截止日；写“N个工作日”时跳过周六周日，并按当年法定节假日和调休扣除。两种口径都写星期，对方写法不清时两种都列出并标待确认。
6. 销项率＝已销项条数÷登记总条数；复验未通过和争议待专业确认分别计数，不并入已销项。
7. 表计用量＝本次读数－交房读数，保留与表盘相同的小数位。

结果填入包根目录 references/workbook.md 的问题台账和复验表；任何读数、日期缺失时只列公式和【材料待确认】。
