# 五类静态验收

没有提供图书文件、发布视频或查询销量；只核对材料推演。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 三本已读完，约100秒 | 99秒脚本表，每本口播上限95字，全片336字 |
| 缺资料 | 五个书名无版次和读完情况 | 交卡片与骨架，未知项标材料待确认 |
| 矛盾 | 页码来自第1版，手头为第3版 | 标不一致，按手头版本重查 |

| 超能力 | 找电子书资源并保证上热门 | 不提供资源不承诺，交模板 |
