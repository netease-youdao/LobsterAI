# 可复制书单底稿

```text
期号／版本／目标人群／目标时长／语速（字每秒）：
书单卡（每本一张）：书名｜作者｜译者｜出版社｜版次印次｜信息来源｜是否读完或读到哪里｜一句判断｜使用场景｜短引原文｜页码｜局限。
脚本表：起止秒｜段落｜秒数｜口播字数上限｜口播要点｜画面｜字幕。
拍摄清单：每本封面／翻页／段落特写｜每组条数｜俯拍高度与焦段｜灯位｜反光处理｜汇总图。
核对表：书名｜作者译者｜出版社版次印次｜页码与版次一致｜无整页清晰内页｜无资源引导｜商品标注。
状态：可拍摄／补书目信息后拍摄／需要换书；关键问题最多三项。
```

## 已填假设示例：职场新人时间管理三本书

以下书名用《书甲》《书乙》《书丙》代替，作者、版次、页码与数字均为演示假设，不指向任何真实图书。目标人群为工作一到三年的职场新人，三本都已读完，语速假设为每秒4字。

时长：钩子5秒，每本28秒，结尾10秒，总计5加3乘28加10，共99秒。脚本表起止为：0到5秒钩子，5到33秒《书甲》，33到61秒《书乙》，61到89秒《书丙》，89到99秒结尾。口播字数上限：钩子5乘4乘0.85为17字；每本28乘4乘0.85为95.2，取95字；结尾10乘4乘0.85为34字；全片上限17加95乘3加34，共336字。

《书甲》卡片：一句判断为“适合总被临时任务打断的人，用固定时段集中处理杂事”；场景为“周一早上同时收到五个零散请求时”；短引一句，注明假设的第2版第3次印刷第88页。版权页列有译者，口播和字幕都写上译者。

拍摄：每本封面、翻页、段落特写三组，各拍2条，共3乘3乘2即18条；段落特写只露出引用的两行。手机二倍焦段，从约45厘米高度起试，调整到书本约占画面八成；主光在侧前方四十五度加柔光布，《书乙》覆膜封面有反光点，把灯向外侧挪开直到反光离开画面。

核对结果：三本的书名、作者、出版社与版权页一致；《书丙》想引用的句子在笔记里记的是第1版第120页，手头实体书是第3版，页码待重查，状态为“补书目信息后拍摄”。不挂商品，结尾建议“先读《书甲》第二章”。
