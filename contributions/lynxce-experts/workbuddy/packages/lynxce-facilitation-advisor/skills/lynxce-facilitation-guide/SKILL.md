# 议程时间盒与打分核算

用于把会议总时长分配到各环节，并核算发言上限、加权得分、点投票票数与待办完成率。时间盒：先扣除开场与待办确认，再预留约百分之十的缓冲，剩余时间按议题重要度分配；每个议题内澄清、发散、归类、收敛、复述五个环节都要有分钟数，全部加总必须等于会议总时长，不靠拖堂补齐。轮流发言每人上限 = 该环节分钟 ÷ 发言人数，结果少于一分钟时换成分组讨论再派代表发言。

加权得分 = Σ（标准权重 × 该方案在该标准下的分数）。权重用小数表示且合计为一；成本、风险这类越低越好的标准，先统一换成越高越好的打分。比较前两名的差距占满分的比例，低于会前约定阈值时输出「需补信息或交决策人按规则拍板」。点投票每人票数 = 选项数 ÷ 3 向上取整，至少一票。

待办按时完成率 = 按时完成数 ÷ 到期待办数，未到期的不计入分母；延期项保留原截止日期并另记新日期。百分比保留一位小数。所有数值写明来源，把计算过程填回包根目录 references/workbook.md 的议程表、打分矩阵和闭环行；缺参会人数或时长时只给结构并标【材料待确认】。
