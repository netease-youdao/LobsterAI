# 可复制会议引导底稿

```text
会议名称／日期与时长／类型／材料编号：
产出句：散会时我们拿到……
决策人｜决策规则｜决策人缺席时的处理。
参会人：姓名或角色｜为何必须在场｜会前须读材料。
议程表：时段｜议题｜环节（澄清/发散/归类/收敛/复述）｜分钟｜负责人。
打分矩阵：标准｜权重｜方案A｜方案B｜方案C｜加权分｜前两名差距占满分比。
控场预案：情形｜信号｜动作｜话术示例。
停车场：事项｜提出人｜会后处理人。
纪要：结论｜待办（动词开头、责任人、截止、完成标准）｜未决事项。
闭环：到期待办数｜按时完成数｜完成率｜延期原因与新日期。
关键问题：最多三项，写明答案会改变哪个环节。
```

## 已填假设示例：季度渠道预算决策会

以下为演示假设。会议60分钟，七人参加，决策人为市场负责人，规则为听取意见后拍板。议程倒排：开场5分钟；议题一「预算分配方案」30分钟，其中澄清5、静默书写6、轮流发言7、归类4、打分6、复述2；议题二「下季度试点渠道」14分钟；待办确认5分钟；缓冲6分钟，占百分之十；合计60分钟。轮流发言7分钟分给7人，每人1分钟。

打分标准与权重：预期影响0.4、成本0.3、执行风险0.3，成本与风险都换成越低分越高，满分五分。方案A为4、3、4分，加权4×0.4+3×0.3+4×0.3=3.7；方案B为5、2、3分，加权3.5；方案C为3、5、3分，加权3.6。A与C相差0.1分，占满分百分之二，低于百分之五的约定，不当场强行决定：会上确认缺的是C方案的执行风险数据，由渠道经理在三个工作日内补齐，之后由决策人按规则拍板。若改用点投票，三个选项每人1票。

纪要拟于会后次日上午发出，异议截止为发出后48小时。上次会议到期待办9条，按时完成7条，按时完成率约百分之七十七点八；两条延期项保留原截止日期，另写新日期与原因。
