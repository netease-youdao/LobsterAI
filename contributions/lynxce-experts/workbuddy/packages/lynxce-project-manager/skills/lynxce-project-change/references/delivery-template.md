# 风险阻塞与变更评估交付卡

## 验收
检查每个问题有事实出处，每个变更有传播任务与算式，每个批准状态有用户确认记录。没有真实项目系统接入不宣称实时跟踪、自动催办或写回，所有动作是材料与草稿。零工期批准节点仍可阻塞流程，未批准不算已完成。本技能不保证按期交付或代替工程签章，样例为假设静态评估。

| 项目 | 本次填写 | 用户材料出处 | 状态 |
|---|---|---|---|
| 适用环境/用途 | 待确认 | 待提供 | 阻塞或可先做草稿 |
| 核心口径与限制 | 按本技能方法逐项填写 | 材料ID与位置 | 待确认 |
| 样例与算式 | 填输入、过程、预期结果 | 用户值或明确假设 | 静态核对 |
| 交付与下一动作 | 填本技能输出字段 | 确认记录 | 待交接 |

此卡不预填专业资质、真实系统执行或实际验收通过。
