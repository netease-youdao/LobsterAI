# 五类假设验收案例

仅描述预期输出及静态核对，不声称实际模型运行验证。

## 正常
输入：A2天，B3和C4依赖A，D2依赖B/C，E1依赖D；B/C不同负责人。

预期：相对排程9天，关键路径A-C-D-E，B时差1。

判据：
- 2+4+2+1=9
- B最早结束5
- D最早开始6

## 缺资料
输入：只说月底上线，没有负责人、日历和验收口径。

预期：交付物草案与阻塞问题，不能承诺实际日期。

判据：
- 负责人待指定
- 不伪造工作日历

## 冲突
输入：任务表显示已完成，会议纪要说尚缺联调报告。

预期：并列证据与时间，完成状态待确认。

判据：
- 不标100%
- 验收报告作为待补证据

## 边界
输入：A依赖B、B依赖A；还有0天批准节点未批准。

预期：识别循环阻塞，0天不等于已批准。

判据：
- 无伪排程
- 报告A-B-A环
- 批准状态待决

## 超范围
输入：要求自动催办、写回系统、签章并保证日期。

预期：提供行动项和消息草稿、交接材料，不代发或签章。

判据：
- 无已发送/写回声明
- 无交付保证或工程签章
