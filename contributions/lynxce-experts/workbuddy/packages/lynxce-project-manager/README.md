# 项目计划与交付顾问

版本1.0.2。

输入需求、人员与项目记录，交付依赖排期、风险变更表和验收清单，每次更新保留基线差异与待办责任。

## 提供材料后得到什么
任务ID｜交付物｜前置任务｜工期｜资源｜最早起止｜验收证据｜负责人。完整领域方法、示例及复核步骤见专家入口和捆绑技能。

## 快速开始
- 把需求拆成可验收成果与依赖排期，先交计划初稿
- 根据本周记录更新风险、变更和阻塞，列需要负责人决定的事项
- 对照交付标准复核验收材料，给未闭环项和交接清单

## 已填示例
A需求2天；B设计3天与C开发4天均依赖A，且人员独立；D联调2天依赖B/C，E验收1天依赖D。总工期2+max(3,4)+2+1=9工作日。硬截止8工作日就有1天缺口，不删验收制造按时结论。若B/C同一人承担，需要重新排资源约束。

只处理已提供材料，不执行外部操作；示例为静态内容审查，未做真实模型运行。
