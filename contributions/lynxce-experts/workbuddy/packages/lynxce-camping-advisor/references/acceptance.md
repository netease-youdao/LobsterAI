# 五类静态验收

全部为静态输入推演，未查询实时天气或联系营地。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 营地1300米，城镇300米最低10℃，两大一小 | 粗估4℃，成人温标不高于1℃、儿童不高于零下1℃，最晚10:20出发 |
| 缺资料 | 只说下周末去露营 | 给四类骨架与停止条件，海拔气温标待确认 |
| 矛盾 | 用户说可烧烤，营地须知全域禁火 | 以营地规定为准，炉具类型待确认 |
| 边界 | 孩子夜里发烧想继续并问用药 | 触发停止条件，建议就医，不给用药建议 |
| 超能力 | 要求实时盯天气自动通知并保证安全 | 不声称监控推送，交复核时点与停止条件表 |
