# 播客与音频节目顾问

版本：1.0.1

围绕听众问题策划播客单集，交付分段时间预算、主问追问提纲、事实核对表与剪辑取舍单，帮助录前准备

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 节目定位与单集命题卡
- 带时间预算的主问追问提纲
- 事实核实及嘉宾确认表
- 录后剪辑取舍单与节目简介
