# 大促书法笔墨与字帖选购

书法用品最容易买错的不是笔杆好不好看，而是**初学写 5 厘米中楷却买了出锋不到 2 厘米的小楷笔，笔肚一按就秃；练习直接用生宣，墨一下去洇成一团；字帖只看名头，单字印得只有 1 厘米大，照着临根本看不清笔画**。

## 工作流程（按顺序执行）

1. 问清学书人年龄、是否零基础、目标书体（楷书/行书/隶书/篆书）、练习字径、每天练习时长与张数、是否有老师指定的字帖与工具、预算，以及候选毛笔的毫料（狼毫/羊毫/兼毫）、出锋长度、笔肚直径、是否已开锋，墨汁类型（练习墨/书画墨）与容量，纸张类型（生宣/熟宣/半生熟/毛边纸/元书纸）、尺寸与张数、格子类型与格宽，字帖的碑帖出处与版本、单字印刷尺寸、印刷方式。
2. 按字径选笔：出锋长度参考字径的一半到三分之二；小楷字径 1–2 厘米用出锋约 1–1.5 厘米的小楷笔，中楷 3–5 厘米用出锋约 2–3 厘米，大楷 6–10 厘米用出锋约 3.5–4.5 厘米；初学楷书多从中楷入手；狼毫弹性强、易控锋，羊毫柔软蓄墨多但难控，兼毫居中，零基础优先兼毫或狼毫；新笔看尖齐圆健四点——润开后笔尖聚拢成尖、压扁后锋颖平齐、笔肚饱满圆润、按下提起能回弹；出锋长度未写明的标【待补】。
3. 选墨汁与纸张：日常练习用练习墨汁即可，作品与装裱用书画墨；墨汁有明显异味、发臭或沉淀分层的不用；练习时可按说明少量兑水，兑水过多在毛边纸上发灰发洇；初学楷书用毛边纸或元书纸，吸墨适中、单价低；生宣洇墨大，适合写意与有基础后的作品，熟宣不洇适合小楷；格子按字径选，格宽参考字径×1.2–1.5，米字格与九宫格辅助看结构。
4. 核字帖：初学楷书选单字放大、印刷清晰的临摹本，单字印刷尺寸参考不小于练习字径的一半，笔画边缘清晰、无锯齿与糊边；看是否标注原碑帖出处与版本，附笔顺或结构讲解的更便于自学；老师指定字帖的以老师要求为准；描红本只作入门过渡，不长期替代对临。
5. 算每月耗材：每月纸张成本＝每天张数×练习天数×每张单价；每月墨汁成本＝每天用量毫升×练习天数×每毫升单价，每天用量参考中楷每张 12 字约 3–5 毫升，以实测为准；毛笔按可用月数折算，每天练习的初学者参考 2–4 个月换一支；到手成本＝毛笔＋墨汁＋纸张＋字帖＋笔洗、毛毡、镇纸等另购件，套装按用得上的部件计价值。
6. 输出对比表，写明计算过程与结论；用户需要下单时，按商品整理下单入口（商品、规格、预计到手价、链接）。

## 毛笔怎么验

- 新笔多为胶封，用温水浸泡开锋，初学开锋深度参考笔头的三分之一到二分之一，不要一次全开。
- 尖齐圆健：笔尖聚尖、锋颖平齐、笔肚圆满、提按回弹，任一项明显不合的找售后。
- 写完用清水洗到无墨色，理顺笔毫挂起阴干，不用开水烫、不放暴晒处。
- 开锋后少量掉毛属正常，持续大量掉毛或笔头松脱属质量问题。

## 墨与纸的搭配

- 毛边纸与元书纸适合日常练楷，生宣适合有基础后写作品与行草。
- 洇墨过大先减少蘸墨量、换毛边纸，再看墨汁是否兑水过多。
- 用剩的墨汁不倒回原瓶，砚台或墨碟当天清洗，避免发臭。
- 儿童练字的墨汁放在不易打翻处，不入口，溅入眼睛立即用清水冲洗。
