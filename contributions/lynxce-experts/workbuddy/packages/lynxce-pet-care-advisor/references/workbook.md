# 可复制养护底稿

```text
基本信息：犬/猫｜年龄｜是否绝育｜特殊状况（幼年、怀孕哺乳、老年、慢性病→交兽医）
就医信号核对：呕吐腹泻带血｜拒食时长｜呼吸｜排尿｜抽搐外伤｜疑似误食｜结论（就医／继续）
体重体况：日期｜体重kg｜体况评分（九分制）｜评分人｜目标体重粗估｜兽医确认值
热量：采用体重｜静息能量＝70×体重^0.75｜系数｜每日热量｜零食上限10%｜主粮热量
喂量：包装每千克热量｜主粮克数＝主粮热量÷每千克热量×1000｜每日餐次｜每餐克数
趋势：两周变化kg｜每周变化%｜目标区间｜动作（保持／带记录问兽医）
粪便：日期｜成形/偏软/稀水/带血｜换粮天数
日常护理：日期｜饮水毫升｜每千克饮水｜猫砂盆数与清理｜刷牙｜指甲
训练：行为目标｜奖励物｜每次时长｜10次成功数｜是否加难度｜加哪一项
出行：承运方要求｜检疫证明｜A／B／C／D｜箱内长宽高下限｜适应训练开始日
兽医日程：项目｜日期星期｜兽医给出的间隔或下次日期｜推算日期星期｜完成凭证
关键问题（最多3个）：
```

## 已填假设示例：超重犬与抓沙发的猫

以下全部为演示假设，不是任何宠物的真实记录。已绝育成年犬，当前15公斤，兽医评体况7分：目标体重粗估 = 15 ÷（1 + 0.1 × 2）= 12.5公斤，交兽医确认。按目标体重计算静息能量 = 70 × 12.5^0.75 ≈ 465千卡/天，减重起步按465千卡。零食上限 = 465 × 10% = 46.5千卡，上限向下取整按46千卡，主粮 = 465 − 46 = 419千卡；狗粮每千克3500千卡，主粮 = 419 ÷ 3500 × 1000 ≈ 120克/天，不喂零食时约133克。每周减重目标为当前体重的1%至2%，即0.15至0.30公斤，减2.5公斤粗算约9至17周。两周后复称14.6公斤，两周减0.4公斤，每周约0.2公斤，占15公斤的约1.3%，在区间内，保持喂量。

兽医日程：兽医记录上次体内驱虫为2026年10月10日星期六，兽医给出间隔90天，推算下次为2027年1月8日星期五，以兽医最终安排为准。

航空箱：A为60厘米、B为30厘米、C为20厘米、D为55厘米，箱内长不小于75厘米、宽不小于40厘米、高不小于55厘米，再与承运方规格核对。

猫抓沙发：第1周记录每天平均抓沙发4次、抓板1次，抓板占比20%；放置竖、平两种抓板并即时奖励后，第2周抓沙发1次、抓板5次，抓板占比约83%。继续记录两周再撤掉沙发罩布的一半。
