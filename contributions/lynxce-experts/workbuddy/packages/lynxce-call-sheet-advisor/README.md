# 拍摄统筹顾问

版本：1.0.1

结合场地时段与人员档期编排拍摄计划，交付通告单、到场表、器材清单及冲突备用方案，便于逐项确认执行

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 拍摄约束表
- 通告单与时间核算
- 人员到场及器材对照表
- 延误重排与收工交接清单
