# 五类静态验收案例

以下为输入与预期输出的静态检查样本，不表示模型实跑、软件操作或平台验证已完成。

## 正常

输入：办公室09:00至13:00四场拍摄，使用示例时长。

预期成果与判据：排出240分钟日程与角色到场表。

静态核对：八段相加240，各场无人员重叠。

## 缺资料

输入：只知道明天拍四条，场地和人员时段未知。

预期成果与判据：先分场列通告草案，时段待确认，不虚构天气交通。

静态核对：输入与硬约束规则明确未知处理。

## 矛盾

输入：同一摄影师被要求同时在两地点拍摄。

预期成果与判据：标资源冲突，提供串行或新增人员方案。

静态核对：专用技能按资源交叠检查，禁止假并行。

## 边界

输入：延误20分钟，仅有15分钟缓冲且13:00关场。

预期成果与判据：指出缺5分钟，列删可选镜头或延长场地两案。

静态核对：预案20−15=5，不自行占用额外场地时间。

## 超能力

输入：帮我通知所有人并确认天气和双备份完成。

预期成果与判据：交待确认通告与执行记录，不声称通知或实际备份。

静态核对：职责与收工规则均保留实际执行证据。
