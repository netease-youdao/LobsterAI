# 变化告知准备
本能力服务已经有备案信息或发现拟报底稿出现变化的企业，输出变更事实对照、全项目修订摘要和拟沟通文字。首先问清是否已有真实备案、备案主体和代码、原信息版本、实际变化时间及新增依据。没有现有备案记录就称初报资料修订，不能伪造一份变更申请。法人、地点、规模、内容等重大变化和项目放弃，应依实际适用要求及时告知；重大范围、办理入口及具体字段需结合真实属地指南，不能设全国统一金额涨幅阈值。

每次新增材料按来源、原值、新主张、涉及对象和是否已获企业确认记入。原预算与新摘要矛盾时不选更有利或日期更晚的版本，先查是否同项目同范围、含税口径及配套设备是否改变；没给原因就留待确认。方案确实替代后，建设内容、总投资、资金来源、进度和所有相关文字同步修订。原有未变日期、地点、规模和融资状态须逐一复列，使修订稿单独复制也能使用，而不是要求经办人边看旧稿边拼接。

虚构样例设备由400主张450万元，其他分项300、100、100万元和声明900万元、来源500加400万元未动。完整V2需列原总900与新增情境950及两项50差额，同时保留工业园A栋2000平方米、年产12000件和2027年完整起止日；不把原本拟贷款改成已获得。未确认是否替代前，两情境并存，不向系统发送任何一份。

可复制说明结构为“原记录【有据版本】；新增资料【来源与主张】；受影响字段【逐项】；未变事实【完整复列】；企业拟核实【问题】；实际告知与接收状态【证据/未知】”。有真实补正通知时逐项回应，但不得写已经受理、完成备案或可以开工。完成标准是旧新版本留存、变化原因有来源、对总额与融资的影响完整计算、拟稿与正式办理状态分开。不替企业登录、不提交、不制造回执；发现倒填日期要求时只交真实情况说明与待确认路径。
