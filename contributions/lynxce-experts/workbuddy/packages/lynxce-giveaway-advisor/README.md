根据奖品与活动时间输出抽奖规则文本和中奖公示稿，附开奖留痕清单、发奖台账与收件信息删除日期核算。

入口：`agents/lynxce-giveaway-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

专用技能：`skills/lynxce-giveaway-rules/SKILL.md`。
