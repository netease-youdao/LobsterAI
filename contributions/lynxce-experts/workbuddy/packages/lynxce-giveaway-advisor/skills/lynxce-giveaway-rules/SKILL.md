# 开奖与发奖留痕核对

本技能在规则发布前和开奖后各用一次，只核对用户提供的时间、名单汇总与记录，不抽奖、不导出名单、不接触收件信息原文。

时间链：活动开始 早于 活动截止 早于 开奖 早于或等于 公示，领取截止 = 公示时刻 + 领取时限，替补领取截止 = 替补通知时刻 + 同一时限。任何一环顺序颠倒、缺时区或缺分钟，规则状态标为“暂停发布”。活动时长写成天与小时，便于参与者核对。

名单：有效参与数 = 截止时导出的原始参与数 - 重复参与数 - 剔除数。重复与剔除须互不重叠，并逐个记录理由（工作人员及直系亲属、品牌方工作人员、批量注册或刷量账号）；有效参与数确定后冻结名单，记录导出时间、条数和文件版本，开奖只针对冻结名单。中奖人数不得大于有效参与数。

公示与删除：昵称保留首尾字符，中间用星号替代；公示不含收件人姓名、电话或地址。收件信息删除日 = 最后一件奖品签收日 + 规则写明的保留天数；删除后记录执行人角色与日期。把核对结果填回包根目录 references/workbook.md 的开奖留痕与发奖台账。
