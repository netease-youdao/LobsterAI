# 可复制抽奖底稿

```text
活动名称／平台／规则版本／发布时间：
确认关口：平台规则｜法务｜财务｜品牌合作标注；各自状态与确认人角色。
规则正文：活动时间（起止到分钟＋时区）｜参与方式｜有效参与定义｜奖品（品牌型号规格颜色数量／参考价来源日期）｜提供方与发货方｜开奖方式与时间｜通知方式｜领取时限｜替补规则｜不参与情形｜个人信息使用与删除｜规则变更说明。
开奖留痕：导出时间｜原始条数｜重复数｜剔除数及理由｜有效参与数｜冻结文件版本｜录屏文件名｜中奖编号｜替补编号。
中奖公示：中奖昵称（首尾保留）｜有效参与人数｜开奖方式｜领取方式｜领取截止。
发奖台账：中奖昵称｜奖品｜通知时间｜收件信息收到时间｜寄出日期｜快递单号｜签收日期｜删除日期｜执行人角色。
结论：可发布／待确认暂不发布／暂停；最多三个关键问题。
```

## 已填假设示例：粉丝破万感谢抽奖

以下为演示假设，不是真实活动。平台提供官方抽奖工具，但本例假设用户选择录屏自抽以演示留痕；平台规则与法务确认状态由用户回填。奖品为蓝牙耳机3副，黑色，型号【材料待确认】，参考价299元（来源与日期待注明），每件运费约12元，预算 `3×299+3×12=933` 元。参与方式为在活动帖下评论，不要求购买或付费。

时间（北京时间）：11月2日10:00开始，11月7日20:00截止，活动时长5天10小时，即130小时；11月8日12:00开奖，12:30公示，领取时限72小时，截止11月11日12:30。

开奖留痕：截止后导出原始评论1300条，同一账号重复评论52条只计一次，剔除8个（工作人员3个、批量注册账号5个，逐个记理由），有效参与 `1300-52-8=1240` 人；冻结名单后编号1至1240，录屏抽出3个中奖编号和2个替补编号。公示示例：昵称“小林爱跑步”显示为“小***步”，写明有效参与1240人。

发奖台账：两位中奖者在时限内提交收件信息；第三位到11月11日12:30仍未回复，按规则替补顺延，11月11日14:00通知替补第1位，其领取截止为11月14日14:00。三件奖品最后一件于11月18日签收，规则写明签收后保留30天，收件信息删除日为12月18日，删除后记录执行人角色。
