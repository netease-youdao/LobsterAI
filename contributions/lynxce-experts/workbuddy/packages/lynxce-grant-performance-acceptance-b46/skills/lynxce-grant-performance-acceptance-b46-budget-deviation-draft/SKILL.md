# 经费偏差自评
本能力对照项目任务书预算与同口径实际发生资料，形成资金执行表、偏差说明和自评稿经费章节。先询问金额单位、资金来源、支出范围、是否已付、是否含冲销及跨期项目，用户已给就直接采用，未给只标未知。预算差额不是银行余额，合同签订额不是支付额，财政到账也不是财政支出，四者分开登记。只有具备相同口径的分母分子才计算执行率；零预算不除零，负值需区分冲销退回而非直接解释为节约。

假设工作分类预算四十、三十五、十五、十万元，实际三十八、三十、十四、十，合计预算一百、实际九十二，差额八，执行率百分之九十二。财政来源预算四十实际三十六，差额四，执行率百分之九十；自筹预算六十实际五十六，差额四，执行率约百分之九十三点三三。两来源实际合计九十二与分类总支出一致。具体分配财政为二十、十、三、三，自筹为十八、二十、十一、七，各行合计必须等于总实际。试用分类虽然总额十未变，其财政四变三、自筹六变七仍是来源差异，必须标出依据待核。

偏差原因只能来自用户材料。用户给了设备议价节约二、算法复用节约五、材料批采节约一，可作为八万元预算差额的说明；但不能将它们说成审计已认可，也不能把试用点获批变化自动推断为节约原因，因为该行实际十并未变。未给到账资料就明确无法计算账户现金余额。财政预算差四是否退回、留用或结转，必须绑定适用资金管理办法及主管要求，不能自动生成付款指令或保证可留用。

可复制经费段落先写预算、实际、执行率，再分别写财政与自筹执行及每类差异，最后列待核事项。来源分配和总额差异分开，技术达标不替代经费核对。补资料后保留旧口径和新口径差别，逐项修订表格及正文，不擅自把未支付款纳入已付。完成标准是每行每列平衡，金额和比例复算，原因有出处，未知不补零，输出为完整说明稿并附准确表格，不出审计鉴证或法定合规结论。
