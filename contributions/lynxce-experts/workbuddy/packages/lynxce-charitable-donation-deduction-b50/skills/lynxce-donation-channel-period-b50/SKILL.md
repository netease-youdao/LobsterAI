# 捐赠渠道与资格期间
围绕企业公益捐赠的真实受赠渠道、发生日期、资格有效期和专门票据建立证据链。先确认企业所得税主体、货币或非货币及普通限额还是有据特别政策，个人、合伙投资者和特别全额不得直接套本路线。输入包括受赠全称、捐赠用途及协议、支付、公益捐赠票据、适用名单与取消调整、发生年度和已列费用。慈善登记、公开募捐、免税资格和公益捐赠税前资格不是同一证明，不能有公益收据就认条件全部成立。

2020年第27号区分社会组织和县级以上机关等，资格三年及起算需看公告具体年度，取消公告也要核。第十一条涉及相应财政监制的公益事业捐赠票据并留存，普通付款回单不替代全部法定条件。名单主体简称相似不算同主体，不能拿2026新资格追认所有2023款；群众团体另按实际专门规则。真实客户须在捐赠时落入有效期间，不以本稿查证日代替发生日。

假设A2025实付并列费用12万元，Q1只是模拟完整公告摘要记组织A全称和2025至2027，T1为票据支付用途摘要，原件及后续取消尚待核；可以做条件准备，不宣称现实已具备或机关认可。B2025直接向个人2万元且明确无普通规定渠道和特别依据，本路线不纳候选，也不是超限额结转。若客户仅说“组织可能有资格”，不得删去可能二字写已取得；有冲突公告保留来源及效力问题。

可复制核实稿为“本笔【编号、年度、金额】经【真实渠道】用于【有据用途】，当前资格材料【来源、年度及原件状态】，票据支付【已知或待核】；尚不能据【登记或一般收据】直接认扣除。请补【具体名单、取消信息及票据】”。交付逐笔资格说明、证据目录和实际补证文本，不止法规清单。完成标准是发生日期和资格期间对应、主体用途票据真实、原件摘要等级忠实，资格未核不当可扣，拟目录不当已附入，不造票或倒签。
