# 捐赠专项说明与完整修订
把资格链、会计利润、旧新分配及账税调整写成可直接复制的财务准备说明和补证函。输入原全量台账、实际申报状态、新报表或资格票据资料；原件、用户摘要和拟稿分开。正文要同时写发生对象、来源、限额、当期费用调增、历史调减和各年度剩余，不把本年可扣和总扣金额混为一谈，不把准备数升级已申报认可。

正常假设甲为查账居民企业2025利润100万元，已列A12和B2，旧2023余5、2024余4，Q1记模拟组织A2025至2027资格及T1票据支付用途摘要，原件取消信息待核；B2直接个人无普通渠道和特别依据。完整稿应写共同限额12、旧先9、A扣3余9至2028、两旧余0、调增11调减9净2及专项所得桥102，原申报和更正未知，不代报。拟目录列报表、资格票据支付及历史链，不能称随文均附。

新P2利润80与P1的100冲突时，V2必须完整复列企业主体、2025年度、费用A12/B2、Q1/T1资格期间及未核、旧5原期2024至2026及旧4原期2025至2027。两分支限额12/9.6、A本扣3/0.6与余额9/11.4、调增11/13.4和旧减9、所得桥102/84.4全部重列；不能仅说其余不变，更不能说已完成主管补正。未变对象、金额、日期与未知状态都需写进可复制稿，表格同口径。

可复制函为“当前【两值、来源及待核】影响【限额及本年/旧额】，请财务核完整报表同口径及有效关系；资格及票据请提供【具体资料】，历史余额请逐年给原额已用未用，不能借新名义重复扣。拟目录实际附入、签章、递交及税务处理结果【真实状态】”。完整交付含全表、说明和针对询证，原因不明不编笔误、捐赠增加或退款。拒绝虚假组织资格、票据、隐瞒原扣和赞助改公益，交真实差异与合法核实，不出鉴证或保证扣除。
