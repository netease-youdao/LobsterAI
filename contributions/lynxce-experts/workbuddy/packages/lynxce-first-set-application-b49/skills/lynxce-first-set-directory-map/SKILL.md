# 目录与同型号证据
本能力为装备制造企业整理首台套目录条目与拟报产品的对应证据，输入必须有本轮目录版本、具体条目、型号及配置、检测报告和实际使用场景。仅有产品宣传不能推定目录内，也不能从“本公司第一台”推定首台套资格。先确认制造主体和实际申报阶段，对地方认定、国家资格审定和资金申请分流。一个条目对应多型号时分别列，不把最高配置样机参数直接给低配量产型号。
每个关键参数写原要求、比较方向、报告值、单位、工况与页段。产能不低于表示下限，误差不高于表示上限；压力负载或持续时长不一致先列不可比，不自行拟出等效公式。检测值、设计目标、设备标称和用户体验分别记录，有报告也不能冒称覆盖报告未测的其他项目。目录分类、参数符合性与价值合理性最终由相应审核方确认，本工具只交证据准备和有据差异。
模拟S01中M同工况120件每小时及误差0.04毫米，对照下限100和上限0.05分别支持两项；不得声称现实2024版目录就有该条。若新增报告0.06毫米与旧0.04冲突，保留报告版本、样机号和工况，不用产能高弥补误差未达一项；其他装备及既有交付事实仍保留。交付完整参数说明、逐项匹配表和待核请求，不能只列缺报告清单。缺原文时完成设备事实稿与最多三类问题，不编知识产权、创新高度或进口替代金额。完成标准是每个结论可回到同主体同型号同工况原证据，拟符合与正式审定状态清楚，未提供原件不称已验证。

同型号改进配置只有在正式文件适用范围与指标证据支持时再归入，不能因名称相似沿用旧审定。检测文件缺页时标记缺页位置，不截取局部通过值掩盖限定条件。
