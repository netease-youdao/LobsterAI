# 两阶段材料与完整补正
本能力把参数匹配、型号交付和保费额度写成制造企业可以核对的完整说明。资格阶段写产品对象、目录条目、参数证据、应用事实与缺口；资金阶段先核既有审定范围和有效额度，再写制造交付投保、原付退费、条件测算和未核事项，不把二者合为交钱即可申报。最低需要本轮通知、真实阶段与同型号证据索引，缺窗口不编受理日期。
稿件必须说明用户摘要和正式原件的差别，列的是证据及拟报送目录时，不默认已经附入。签章、提交、受理、资格审定及资金到账分开，不把企业内部整理完成叫主管部门审核完成。国家2026年度推荐报送日期不能继续当当前开放；地方首台套奖励按地区另核，不把保险补偿比例套到采购总额。正文不得捏造用户证明、专利、销售数量和技术达到国际水平等事实。
收到B实付10/6冲突后，重出完整V2而非只更新金额：A30、B退2、同出厂号交付投保、Q总100历史60、剩40及T01参数全部保留，净额38/34与准备30.4/27.2分情境。原因未知写待核，不能选较晚摘要或较有利金额。配套补正正文具体索取原支付组成及批单退费关联，岗位、日期没给不编责任人承诺。拒绝补造检测、保单、验收或隐瞒退款，改给实际缺口和核实请求。完成标准是两阶段边界清楚、原来未变的对象完整、全部数字和状态同步、任何条件变化传播到正文台账及结论，用户能据真实流程继续，不保证审定和拨款。

对参数报告、保单与交付日期各设版本索引，新增资料的影响限于明确对象，不能覆盖同名不同出厂号。原有实报回执只记录实际版本，拟修订稿另标草稿，不因已生成就声称报送成功。
