# 调查范围定版
本能力在动手整理数据前确认企业实际对应哪个调查年度、哪张表和什么处理阶段。输入为企业登记及行业信息、调查通知或名录反馈、有效制度、系统要求和此前已报资料。全面调查、抽样和重点调查不能混同，规模以下也不能仅凭规模说一定不需统计；是否纳入本轮任务要有正式依据。没有通知就整理可迁移项目人员台账，不替企业断言调查义务已经发生或已经解除。

截至2026年10月22日已核的2025年报公开制度只能支持对应年度说明，107-1、107-2在所读版本标有效至2026年6月。未来年度不能沿用旧有效期、截止日和省市收件安排。用户要做2026年度准备，应先把“新制度待核、调查通知待核”写入版本卡；取得新表后逐字段映射，旧字段未必同名同义。历史复核、逾期处理、正式更正是否允许由主管实际要求决定，不能把本地整理完成说成系统现已受理。

项目名称要对任务书与会计或辅助账，记录实际起始、已鉴定完成、年底仍继续而预期完成的月份。项目跨年只归本报告期活动，不用整个合同年月数作为人月。自主、合作、委托形式先看真实业务，不按哪个表格好填选择代码；对应2025表委托形式31、32、33的部分人员字段免填，应标免填而不是未知或零。其他属性及特殊指标适用范围若未给，不自行编成果类别和任务目标。

可编辑版本卡含“主体【】、调查依据【文号页段】、年度【】、有效表单【】、适用字段【】、本次阶段【准备/复核等】、系统报送审核证据【】、下一步实际要求【】”。虚构知行制造给了2025纳入通知摘要，所以可以整理该年历史核心底稿，但不能称2026已纳入。交付是有据范围卡与可复制任务概况，不只提醒看通知。完成标准是年度、对象、版本和办理状态互不替代，全文来源和地方范围清楚，原表失效不被包装成当前仍可申报，缺新制度时仍能交已知活动台账且明确未决。
