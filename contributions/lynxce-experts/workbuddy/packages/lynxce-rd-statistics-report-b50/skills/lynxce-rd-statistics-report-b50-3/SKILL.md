# 项目经费核对
本能力把项目经费、企业研发费用分类和资金来源作同主体同年度同单位核对，形成实际情况说明。输入为会计研发明细、辅助账、项目映射、委托对象及付款业务记录、来源台账和表单口径。税务账可以作输入，但统计费用不是把税收可加计额照抄；不能套其他费用税收限额、委外税前折算或加计比例。也不能把当年形成的固定资产原价和已计折旧重复当费用，资产字段与费用字段分别整理。

按人员人工、直接投入、折旧长期待摊、无形摊销、设计、调试试验、委外、其他逐项回查实际账；分类没有依据就保留待核，不用项目预算替代实际发生。项目总经费与企业合计在对应规则下是小于等于关系，并非所有情况必须强行相等。出现差额应追索范围、遗漏、管理服务或映射证据，不能自动虚构一个其他项目吸收差额。政府资金是来源或其中项，不能再加在项目支出上算一次。

虚构知行制造的人工240、直接180、折旧60、无形0、设计0、调试0、委外80、其他40千元，总600。P1经费280、P2经费240合计520，对应给定非委外费用；P3独立委托80对应委外，无重复，于本例项目总额600恰等于企业600。自筹580与政府20合计600，政府在项目中为20、0、0，不额外加成620。600千元换算60万元；分类0来自明确账簿，缺的减免税、固定资产和人员属性不能照填0。

输出全项目经费表、费用构成与来源表、可复制财务统计说明和具体差异问题，汇总及公式置于表外。出现人员时间冲突但经费资料没有改变时，金额、来源和委外对应关系完整保留，不能跟着随意调整工资或项目经费。实际报送和审核证据另列。完成标准是每个费用有账源、每个项目归属不重复、三表口径一致或差异显性，未知金额不被改零，缺资料时交部分底稿而不称全表齐备。本能力不认定税收优惠，不提供鉴证，不把本地算平当官方数据验收通过。
