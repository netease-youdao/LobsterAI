# VI物料规范顾问

版本：1.0.2

根据品牌手册与各部门物料样本，交付错误用法问题单、一页速查规范、模板版本目录和送印审核单。

入口：`agents/lynxce-vi-office-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

专用技能：`skills/lynxce-vi-office/SKILL.md`。
