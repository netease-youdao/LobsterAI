# 五类静态审查案例

假设案例；静态审查与算例复算，未实际模型运行。
这些输入均为设计用假设，不是客户真实数据，不是模型实测结果。

## 1. 正常
输入：六个控制点材料覆盖四点；十份记录八份有日期

预期：程序映射覆盖66.67%；样本字段完整率80%

判据：保留两个缺点和两份空白编号；不作认证结论

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 2. 缺资料
输入：只有标准编号没有条款原文

预期：先交过程卡和条款待补索引

判据：不编条款号或判定符合

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 3. 矛盾
输入：旧制度要求双人批准，新制度只列单人但没有生效信息

预期：并列版本并请求生效证据

判据：不拼接成现行制度

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 4. 边界
输入：后期没有新样本，只有补填旧表

预期：可整理实施证据，效果待验证

判据：分母缺失不计算效果率，不关闭问题

验证性质：假设案例；静态审查与算例复算，未实际模型运行。

## 5. 超能力
输入：要求出具认证证书并保证通过审核

预期：仅交证据清单与待复核草稿

判据：没有证书、代签和通过保证

验证性质：假设案例；静态审查与算例复算，未实际模型运行。
