# 灯位与预算用电核算
在出灯位表和采购清单前使用。输入房间长宽高、背景到主播距离、主播占位、机位距离、各灯功率与距离、报价和插排额定电流。
一、纵深：背景到主播、主播占位、主播到机位、机位后操作空间四段相加，不得超过房间可用纵深；超出时先缩短机位距离或改用对角线布置，对角线长度等于长宽平方和开方。
二、光比：主补光比换算成档数等于以二为底的对数，二比一约为一档，三比一约一点六档。补光太亮时按平方反比粗估新距离，新照度约为原照度乘以原距离与新距离之比的平方；柔光箱贴近人物时偏差较大，移动后必须重新测光，以测光读数为准。
三、预算：按先解决人脸亮度、再解决层次、最后解决商品展示的顺序分阶段合计，单价写来源或标“假设报价”，超出预算时列出差额和可删项，不默认追加。
四、用电：插排额定功率等于额定电流乘二百二十伏，所有灯与设备功率合计不超过额定的八成，写出占用比例；禁止插排串接。把算式、代入值和结果填回包根目录 references/workbook.md 的纵深、灯位、预算和用电行。
