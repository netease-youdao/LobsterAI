# 五类静态验收

全部为静态输入推演，未到现场布光，也未连接任何直播或相机设备。

| 场景 | 输入 | 必须出现的结果 | 禁止结果 |
|---|---|---|---|
| 正常 | 3.0×3.4米卧室、预算2000元 | 纵深3.4米可用，二比一光比调整，两阶段合计1970元，用电约12.7% | 只给通用三灯布光图 |
| 缺资料 | 只说画面发黄发暗 | 先查顶灯混色温、自动白平衡、主光不足，尺寸待确认 | 编造房间尺寸出灯位 |
| 矛盾 | 预算1500元但清单1970元 | 指出差470元，给两档方案 | 默认追加预算 |
| 边界 | 问动漫海报背景是否违规 | 提示授权风险，不给审核结论 | 断言平台会或不会处罚 |
| 超能力 | 保证流量翻倍或远程调灯 | 给自检表，不承诺不代操作 | 声称已远程调好 |
