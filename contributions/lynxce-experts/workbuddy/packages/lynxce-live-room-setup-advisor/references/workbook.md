# 可复制直播间底稿

将以下模板完整填写；不适用项写明原因，未知项保留材料标记。

```text
直播类型／画幅／房间长宽高／版本日期：
纵深：背景到主播｜主播占位｜主播到机位｜机位后空间｜合计｜房间纵深｜是否改对角线。
背景：主色｜物品类别（不超过三类）｜品牌元素位置｜需移除的商标与隐私物品。
灯位表：灯｜用途｜位置与角度｜距主播｜高度｜色温｜显色指数｜功率｜亮度读数｜现有或需购。
光比：亮侧读数｜暗侧读数｜比例｜档数｜目标比例｜调整动作。
相机：机位高度｜焦段｜距离｜白平衡｜快门｜帧率｜曝光锁定｜美颜滤镜状态。
商品区：灯位｜反光处理｜试色核对方法。
预算：阶段｜项目｜单价来源｜数量｜小计｜累计｜预算余额。
用电：插排额定电流｜额定功率｜八成上限｜设备功率合计｜占用比例。
开播自检：脸部亮度｜眼神光｜肤色｜背景｜商品颜色｜闪烁｜遮挡｜隐私。
待确认：最多三项，每项写明会改变哪条设置。
```

## 已填假设示例：卧室护肤品直播

以下数字均为假设，报价也是假设报价。房间宽3.0米、深3.4米、高2.7米，竖屏坐播卖护肤品，预算2000元，顶灯为3000开尔文暖光。纵深按1.2米背景距、0.5米主播占位、1.2米机位距、0.5米操作空间计，合计3.4米，刚好等于房间纵深；如需加大背景距，改沿对角线布置，对角线约为3.0与3.4平方和开方≈4.53米。

灯位：关掉顶灯，全部灯统一5600开尔文。主光放前方左侧45度、距脸1.2米、略高于眼睛；补光在右侧。初测补光放在1.0米时两侧读数相同，光比一比一，脸偏平；按平方反比移到1.4米，照度约为原来的（1.0÷1.4）²≈0.51，接近一半，即二比一、约一档，移动后再测确认。

预算分两阶段。第一阶段：主光含柔光箱650元、灯架两支120元、反光板60元、带过载保护插排70元、手机支架90元，小计990元。第二阶段：补光含柔光罩320元、轮廓管灯220元、商品小灯120元、灯架一支60元、浅色背景布与小置物架260元，小计980元。合计990+980=1970元，余额30元。

用电：主光150瓦、补光60瓦、轮廓灯40瓦、商品灯30瓦，合计280瓦。插排额定10安，额定功率10×220=2200瓦，八成上限1760瓦，占用280÷2200≈12.7%，余量充足。相机设5600开尔文白平衡、二十五帧、快门五十分之一秒，试色环节关闭美颜滤镜，开播前对比面霜包装实物与画面颜色。
