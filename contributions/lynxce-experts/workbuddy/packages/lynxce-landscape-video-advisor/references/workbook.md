## 已填假设示例：从散乱笔记到资料目录

假设六条短片A45秒讲收集、B50秒讲分类、C40秒讲命名、D35秒讲查找，E30秒重复收集，F20秒重复命名，共220秒。目标是回答“怎样为一个小项目整理可查找的资料”，做成240秒横屏稿；没有真实软件操作素材，内容为通用整理方法。

取舍为A留40删5、B留45删5、C留35删5、D留30删5，E和F全删，共保留150秒、删70秒，150+70=220秒。源区间没有提供，待确认；以下目标时间是策划分配，不是已剪成片。

| 目标时间 | 内容 | 脚本或保留材料 |
|---|---|---|
| 00:00至00:20 | 开场20秒 | 资料散落时，先别急着改名。本期按收集、分类、命名和查找四步，整理一个小项目的资料。先保留原位置，再做清单。 |
| 00:20至01:00 | 收集40秒 | A，保留原位置与文件清单方法 |
| 01:00至01:10 | 过渡10秒 | 清单齐了，下一步按用途分组。相同用途先放一起，不急着删除看起来重复的文件。 |
| 01:10至01:55 | 分类45秒 | B，保留资料用途区分 |
| 01:55至02:05 | 过渡10秒 | 分类解决放在哪里。命名要解决看见名称时，能不能知道它属于哪件事。 |
| 02:05至02:40 | 命名35秒 | C，保留项目、主题和版本字段 |
| 02:40至02:50 | 过渡10秒 | 名字清楚以后，试着从清单找回一份资料，检查目录是不是与记录对应。 |
| 02:50至03:20 | 查找30秒 | D，保留一次人工查找核对 |
| 03:20至04:00 | 总结40秒 | 请拿一个小项目试一遍：记原位置、按用途分组、写清主题版本、照清单找回。遇到打不开的文件，先记录问题，保留原件。最后检查清单有没有指向不存在的位置，再把待确认项交给负责人。 |

新增20+10×3+40=90秒；150+90=240秒，旧片占62.5%。口播是初稿，实际试读后可调整句子或停留，但需同步重算时长，不能宣称这些句子天然恰好读满预算。

假设竖屏源为1080×1920，目标1920×1080，按高度1080等比放入后宽为607.5像素，实际布局约取608，左右各约656像素留边；保留完整操作与字幕，留边放四步进度标签。该值仅为布局计算，清晰度待预览。标题可选“一个项目的资料怎么整理”“四步建立可查找的资料清单”“从散乱笔记到项目目录”，均不承诺自动整理或一分钟找回。
