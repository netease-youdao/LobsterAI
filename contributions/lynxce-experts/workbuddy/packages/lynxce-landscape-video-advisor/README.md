# 中视频改编顾问

版本：1.0.1

把已有短片重组为主题明确的横屏内容，交付素材取舍、章节脚本、补拍清单与构图方案，逐段核对时长逻辑

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 素材取舍与章节映射
- 开场过渡结尾脚本
- 补拍时长与镜头清单
- 横屏构图标题和章节点
