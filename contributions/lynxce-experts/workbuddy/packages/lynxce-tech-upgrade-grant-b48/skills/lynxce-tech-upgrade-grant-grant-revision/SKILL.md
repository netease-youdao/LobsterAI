# 门槛测算与完整补正
本能力把通知的支持基数、比例、封顶和重复支持条件变为可核对测算，并在投资或文件冲突后交完整申报修订稿。先取得本轮原文，写清上限是一项目还是一企业一年度，比例分母是固定资产、设备软件、已付未税额还是总投入。没有通知不设默认8%、20%或全国统一门槛；样例规则仅作为清楚标注的假设。确认已申报、获批与到账分别是什么证据，未知不写无重复资助。
模拟T01规定基数不低于150万元、比例8%、最高20万元。基数156时算12.48，达到门槛且未封顶；若A票110有效导致基数146，未达门槛，11.68只能是比例算术值，不能仍写可申请11.68。等于150可以按“不低于”核，不能因显示保留整数把149.999凑150。合同180、付款176和有效投资分别列，差额归因只用实际资料。多政策支持不默认可以叠加，按同项目、设备或支出规则逐项核。
修订时保存旧原值、来源和原文，记录新增A票摘要110与旧120冲突，合同付款未变。全文V2保留B30、C计入6、D排除20和技术记录，给156/146双情境及资格影响，不能只返回新总额。然后写完整补正说明、全表和拟追索原票及冲红关系的任务。未取得有效凭证时不说已解决，未签署或报送时不称已补正提交。拒绝虚构票款、倒签验收、分拆同设备重复申报，改交真实缺口和核实请求。完成标准是每个变化传播到正文、表格与结论、未变对象完整，实际附件状态与拟报送区分，用户可据此交财务和设备岗位核实。
补正任务应逐项写明所需原件、提供岗位与未解决影响，责任人和时点未给就留待确认。仅有拟报送目录时不写已附入；收到签署扫描件也不据此宣称主管部门已受理。
