# 改造内容与成效说明
本能力将真实生产环节、设备软件变化和指标记录写成完整技改章节，不把设备清单直接当技术方案。先收原工序瓶颈、旧设备情况、改造动作、安装验收阶段、改造前后测量、统计时间和同工况依据。没有材料的旧设备年限、行业领先、专利或检测机构都不补写。设备已验收只证明材料显示的交付范围，拟目标不能写成已实现效果。普通工艺更新不冒充原创研发，已有高企资格也不替代项目技改性质。
章节按原问题、改造对象、措施与系统衔接、实施情况、成效口径、未核事项六段生成，各段指向材料。小时产出、单位产品能耗、质量良率等先明确单位和分母。假设内部同工况记录产出从100至125件每小时，增幅为25%；单位能耗从8至6千瓦时，降幅25%。两项比较不能合并成利润增长25%，也不能在没有电价与产量时编节省电费。样本范围或工况不一致时不作同口径改善结论，可如实分别介绍并列补充测量计划。
交付要有实际可复制的改造说明及指标表述，而非只要求用户填写模板。某设备金额争议不直接推翻已有成效记录，也不能凭性能好就忽略投资不达标；财务与技术分别给状态，再在申报说明中连线。收到新测量若与旧报告冲突，保留条件、时间、设备版本和两数，未确定有效记录不择优。若用户只有计划，写“拟采用、拟测”，责任人及完成日期未知留待定。完成标准是改造内容具体到本项目、每个效果来自材料、事实与目标时态清楚，不能承诺补贴获批或以文稿生成冒称验收通过。
