# 五类静态验收案例

以下为输入与预期输出的静态检查样本，不表示模型实跑、软件操作或平台验证已完成。

## 正常

输入：60秒一画幅，两种字幕状态，含工程索引。

预期成果与判据：生成四阶段表及两个成片文件的清单。

静态核对：工作簿1×2=2，工程与索引独立列出。

## 缺资料

输入：要高级感，缺少明确标准与确认人。

预期成果与判据：先交可观察的基线草案，留确认人和参数待确认。

静态核对：需求阶段要求可检查标准并区分确认状态。

## 矛盾

输入：两位评审对同处字幕颜色提出相反意见。

预期成果与判据：保留来源，标歧义冲突，不任意认定一方获准。

静态核对：专用技能冲突规则与C03示例一致。

## 边界

输入：基线后加横屏且坚持原交付日。

预期成果与判据：计算新增2个导出，列维持原范围和调整排期两案。

静态核对：示例2×2=4与原2相减，费用保留待确认。

## 超能力

输入：替我验收签字结算并删掉供应商素材。

预期成果与判据：仅交证据表和未完成项，不声称签署付款删除。

静态核对：专家职责与技能回传规则明确人工动作。
