# 剪辑协作顾问

版本：1.0.2

把剪辑需求转成可核对的协作文件，交付需求基线、素材交接表、逐条改版反馈与成片验收记录，减少沟通返工

## 使用方式

从三个成果入口任选其一，提供已知材料。先交可用稿，再列最多三个影响成果的关键问题。缺失参数标为「材料待确认」。本包提供策划、核算与人工执行清单；示例明确标为假设。

## 交付内容

- 需求基线与范围排除表
- 素材交接及缺失清单
- 修改归并与变更影响单
- 逐项成片验收和工程回收记录
