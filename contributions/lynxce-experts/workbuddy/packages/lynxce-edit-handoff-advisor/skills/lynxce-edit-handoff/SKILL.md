# 改版归并与证据验收

仅在已有需求基线与候选成片清单时调用。输入包括基线版本、评审版本、各方意见、允许的修改轮次及确认人。基线缺失仍可整理意见，但不得标为超范围收费或已经验收。

先按时间码和对象合并重复意见，保留原意见编号以便追溯；“字幕改白”和“字幕改黄”是冲突，不通过投票擅自确定。归并后将每项分为未达到已约定标准、用户新增范围、需要解释的歧义三类。新增范围只列工时、日期和文件数量影响，费用由双方已有约定或后续确认提供。

验收表每行绑定标准、实际材料、检查方式、负责人、结果。缺少成片或播放记录时结果只能是待验证。完成修改不等于验证通过；复查时记录新版本与证据位置。向主专家返回冲突清单、阻断项、已核对项和暂不能关单的原因，不代发反馈、不代确认结算，不把文件名含“最终”当作验收证据。


按 [成果工作簿](../../references/workbook.md) 对应字段回传阶段结果；异常处理对照 [验收案例](../../references/acceptance.md)。
