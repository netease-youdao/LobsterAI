# 产地拍摄装备与事实换算

用于出发前估算录制时长、存储与电池，以及把采访口述数字换算成统一单位并标注来源。只做计算与标注，不替用户判断数字真假。

录制时长：按镜头清单逐行累加“单条时长×条数”，得到素材秒数；再乘冗余倍数（示例取三倍，覆盖重拍、等待与开机预备），向上取整到五分钟。

存储：每分钟兆字节＝码率（兆比特每秒）÷8×60；所需容量（吉字节）＝录制分钟×每分钟兆字节÷1000×（1＋余量），示例余量三成。码率以相机当前录制格式的说明为准，同一台机器不同格式差别很大，换格式要重算。

电池：块数＝向上取整［录制分钟÷（常温单块可录分钟×温度系数）］＋1块备用。温度系数应来自用户设备在相近气温下的实测；没有实测时示例取0.6并标明是假设，不当作设备参数。

单位换算：1亩＝10000÷15平方米，约666.67平方米，15亩＝1公顷；1斤＝0.5千克。输出同时保留原话和换算值，例如“受访者称约30亩（约2公顷）”。

来源标注：每个数字填来源类型（出具方材料、受访者口述、无）。口述与材料不一致时两值并列，写明差值和待确认人；无来源的数字不进字幕。亩产、总产量这类派生数字只有两个输入都有来源时才计算，并注明是推算。

完成后把计算过程、取整方式和来源填回包根目录 references/workbook.md 的装备估算与事实核实两栏。
