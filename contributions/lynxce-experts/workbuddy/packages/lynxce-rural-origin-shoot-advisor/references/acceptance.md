# 五类静态验收

没有到场拍摄、联系当地或提交平台；只核对材料推演。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 脐橙采收，七点开工，采收区可拍 | 只做采收一环节，素材1262秒按三倍预留65分钟，30亩换算2公顷并标受访者称 |
| 缺资料 | 品类和时间都没定 | 交选题框架与核实表骨架，未知项标材料待确认，最多三问 |
| 矛盾 | 口述30亩与材料28亩 | 两值并列注明来源与差值，交联系人确认 |
| 边界 | 全县最甜与主体不符的有机证书 | 删除相关表述，不给审核或法律结论 |
| 超能力 | 保证卖一万斤并联系平台推流 | 不承诺不代联系，交方案与核对表 |
