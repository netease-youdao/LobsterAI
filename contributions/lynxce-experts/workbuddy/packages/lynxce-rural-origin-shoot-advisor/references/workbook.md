# 可复制产地拍摄底稿

```text

选题与农时：产地｜品类品种｜农时环节｜拍摄日与备用日｜选题类别｜一句话主题。
时段表：时间｜地点｜内容｜光线条件｜作业是否在进行｜安全注意。
镜头清单：序号｜类型（空镜/过程/特写/人物/环境声）｜内容｜景别｜单条秒数｜条数｜时段｜备注。
采访与授权：称呼｜角色｜用途说明｜发布去向｜露脸｜方言原声｜同意方式与留存位置｜问题一至三。
事实核实：表述原文｜数值与单位｜换算值｜来源类型（出具方材料/口述/无）｜材料编号｜处理（保留/标口述/删除）。
认证检测：编号｜主体｜范围或批次｜有效期｜是否覆盖发布日｜处理。
装备估算：素材秒数｜冗余倍数｜录制分钟｜码率｜所需容量｜携带容量｜单块续航｜温度系数｜电池块数。

状态：可出发／补材料后出发／暂不建议出发；关键问题最多三项，写明答案会影响哪张表。
```

## 已填假设示例：山地果园脐橙采收

以下全部是演示假设，不代表真实产地、人物或证书。拍摄日假设为2026年11月21日（周六），备用日11月22日（周日）。联系人说明当天七点开始采收、十一点前收工，采收区可拍，分拣棚只能在门口拍。选题只做“采收现场”一个环节，一句话主题为“果农清晨把成熟的果子从山坡摘下、装筐运下山”。

时段：六点二十到场；假设当日日出约六点四十（以天气预报为准），六点四十至七点四十拍空镜；七点至十点半按摘果、剪蒂、装筐、挑运顺序拍过程；十点半后在作业间隙采访，十一点前结束，不占用收工后的时间。

镜头：空镜4个，每个10秒拍2条，共80秒；过程4个动作，每个完整镜头8秒，两个角度各拍3条，共192秒；特写6个，每个5秒拍2条，共60秒；采访约15分钟即900秒；环境声30秒。素材合计1262秒，约21分钟。按三倍冗余为3786秒约63分钟，取整到65分钟。

装备：假设录制码率每秒100兆比特，每分钟 100÷8×60＝750 兆字节；65分钟为48750兆字节，即48.75吉字节，留三成余量为63.375吉字节，携带两张64吉字节存储卡共128吉字节，满足。假设常温单块电池可录50分钟，清晨低温系数取0.6，即每块30分钟；65÷30约2.17，向上取整3块，再加1块备用共4块。

采访：受访者“老周”（称呼）口述“今年种了30亩”“一天能摘800斤”。换算为30亩约20000平方米即2公顷，800斤即400千克。合作社情况说明写“承包28亩”，与口述差2亩；字幕不写确切亩数，若要用则写“受访者称种了约30亩”，并请联系人确认差异原因。授权方式为开机口述录像，同意露脸和方言原声，留存于素材卡第一条。

核实：脚本中“全县最甜”没有依据，删除。“有机认证”有证书照片，有效期至2027年3月31日，覆盖计划发布日2026年11月28日，但证书主体是另一家合作社，拍摄基地不在范围内，该表述删除。状态为“可出发”，待确认三项：分拣棚能否进入、亩数差异原因、是否挂商品。
