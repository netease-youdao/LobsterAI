# 可复制录像归档底稿

```text
单位／适用范围／制度版本／编制日期／责任人：
录制规则表：会议类型｜录制档位｜告知或同意方式｜决定人｜权限档｜保存期限。
告知文案：用途｜保存期限｜查看范围｜负责人；邀请与开场各一次。
索引台账：编号｜会议名｜日期｜时长｜分段｜参会范围｜权限档｜存放路径｜保存至｜责任人。
议题索引：序号｜议题｜起始时间点｜时长｜结论所在纪要段落。
转存核对：会议编号｜转存日期｜播放抽查｜时长一致｜副本删除人。
调阅记录：日期｜调阅人｜会议编号｜用途｜批准人。
销毁记录：文件名｜到期日｜保全状态｜销毁日期｜备份处理｜销毁人。
季度抽查：在册数｜抽样数｜命名合格｜权限合格｜检索合格｜到期条目与合格数｜整改项。
待确认：最多三项。
```

## 已填假设示例：产品部会议录像

以下均为演示假设。产品部每月约20场会议。2026年10月20日周二的产品评审会时长95分钟，命名“20261020-产品评审-01”，分两段：P1为第0至50分钟，含开场与需求评审；P2为第50至95分钟，含排期与结论。议题索引：00:00开场5分钟，05:00需求评审45分钟，50:00排期讨论30分钟，80:00结论与待办15分钟，5+45+30+15=95分钟。录像于10月21日周三转存，未超过1个工作日。评审类保存1年，保存至2027年10月20日周三，最迟2027年10月27日周三完成销毁。

10月15日周四的周例会为一般会议，保存6个月至2027年4月15日周四，最迟4月22日周四销毁。若届时该录像涉及一起未结的员工申诉，则登记保全、暂停销毁，待人事书面解除后从解除日起7天内处理。

季度抽查：台账在册60条，10%为6条，不足10条按10条抽。命名合格9条即90%，权限合格8条即80%，检索合格7条即70%。当季到期8条：按时销毁6条，登记保全1条计为合格，逾期未处理1条，合格率7÷8=87.5%。权限、检索和到期处理低于90%，列整改：文件服务器管理员两周内清理指定名单，会务专员补齐议题索引，档案专员当周补做逾期销毁并登记，下季度复查。
