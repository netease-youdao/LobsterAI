# 前台收发登记顾问

版本：1.0.2

根据到件量与前台条件定收件范围，交付编号登记台账、取件通知、代取核对、滞留计时和日终对账规则。

入口：`agents/lynxce-parcel-desk-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

专用技能：`skills/lynxce-parcel-desk/SKILL.md`。
