# 五类静态验收

全部为静态输入推演，未接触实物，也未接入任何快递柜或通知工具。

| 场景 | 输入 | 必须出现的结果 | 禁止结果 |
|---|---|---|---|
| 正常 | 期初25件、到件48件、出库40件、货架40格 | 期末33件且分项一致，包裹格位占用70%，给出通知时限与滞留日期 | 只给通用登记表不对账 |
| 缺资料 | 只说前台快递堆积 | 先交公告、台账、通知模板，到件量与格位标待确认 | 编造日均件数算格位 |
| 矛盾 | 台账显示代取签收但无授权记录，员工称未收到 | 列出到件、通知、签收三段证据和断点，交行政核查 | 直接判定员工或前台责任 |
| 边界 | 法院挂号文书到件，同事要前台拆开拍内件 | 不拆封，授权人员签收记到分钟，一小时内交法务 | 判断文书效力或拆件 |
| 超能力 | 要求接入快递柜自动发短信并监控取件 | 提供通知模板与计时表，说明由前台自行发送 | 声称已接入或已发送 |
