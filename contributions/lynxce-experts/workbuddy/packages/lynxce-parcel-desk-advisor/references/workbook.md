# 可复制收发底稿

将以下模板完整填写；不适用项写明原因，未知项保留材料标记。

```text
公告版本／生效日期／适用楼层：
收件范围：必收｜可代收｜不入库或拒收（生鲜、到付、超尺寸、查无此人）｜例外处理人。
台账列：编号｜到件时间｜件型｜收件人｜部门｜承运方｜单号后四位｜外包装状况｜存放位置｜通知时间｜取件时间｜签收人｜代取人｜备注。
通知：【编号】【件型】已到前台，存放于【货架-层-格】，请于【日期】下班前本人取件；如需代取，请由本人发授权消息写明编号与代取人姓名。
代取核对：编号｜本人｜代取人｜授权方式｜授权时间｜核对人｜是否交付。
贵重件交接：编号｜判定依据｜柜号｜交接时间｜收件人验看结论｜双方签字。
滞留计时：编号｜到件日｜取件时限｜二次提醒日｜告知对接人日｜按公告处理日｜处理方式｜照片编号｜双人签字。
日终对账：期初在库｜当日到件｜签收｜代取｜转交｜退回｜期末在库｜盘点实数｜差异说明。
格位：货架格数｜在库普通包裹｜占用比例｜是否触发清理或临时区。
待确认：最多三项，每项写明会改变哪条规则。
```

## 已填假设示例：一百二十人办公室

以下数字均为假设，只演示口径，不是实际记录。某公司一百二十人，前台一人，普通包裹货架四十格，贵重件有一个上锁柜。假设11月5日为周四，期初在库25件，其中包裹22件、信件3件；当天到件48件：信件6件、公司文件4件、普通包裹36件、贵重件2件。

当天出库40件：公司文件4件均在两小时内转交并取得回执；本人签收33件，其中信件5件、包裹27件、贵重件1件；代取包裹2件，均有本人授权消息；退回1件，为已到公告处理日的期初滞留包裹。对账：25+48−40=33件。分项复核：包裹22+36−27−2−1=28件，信件3+6−5=4件，贵重件2−1=1件，公司文件4−4=0件，合计33件，与总数一致。包裹格位占用28÷40=70%，低于八成清理线。

编号1105-12为普通包裹，当天未取。到件当天不计，11月6日、9日、10日依次为第一至第三个工作日，取件时限为11月10日下班前；11日二次提醒，12日为第五个工作日，告知部门对接人；19日为第十个工作日，按公告处理。假设期间无法定假日，遇假日顺延并在台账注明。

格位规划按“日均包裹到件×平均在库天数×峰值系数”粗估：36×0.8×1.3=37.44，向上取整为38格，现有四十格可以覆盖。平均在库天数和峰值系数都是假设，应在积累两周台账后回算替换，大促后的峰值周单独再算一次。
