# 口径差异交集核查

内部专项任务：口径差异交集核查。只处理重复与过滤集合的相交记录表，不替代公开任务的完整交付。核心方法为：用主键画文字集合交叉表，先记录独立集合计数，再给交集和处理优先级；最终抵扣量使用互斥集合，禁止为了闭合结果临时改变归属。

## 工作流程

1. 确认专项输入为两份历史报表、定义版本与匿名明细样本，锁定所用版本及本次范围，仅抽取与口径差异交集核查有关的字段；缺项标【待补】，不要套用演示例子作为事实。

2. 建立重复与过滤集合的相交记录表的原始证据列，记录资料编号、原文片段与目前状态；将事实与经办人的解释分栏，矛盾内容保留两种记录。

3. 用主键画文字集合交叉表，先记录独立集合计数，再给交集和处理优先级；最终抵扣量使用互斥集合，禁止为了闭合结果临时改变归属。每项都说明判断顺序、触发条件和例外，缺关键条件时不强行给确定结论。

4. 逐项采用专属方法核查：在表头写计量单位、金额含税状态和精度，金额与订单数各建归桥；同名指标不能自动视为同一统计对象，目标口径必须能从提供资料追溯到定义版本。保留原始值和推演值，让复核人能够独立重现过程。

5. 用专项示例检查数量守恒及分类互斥：假设重复集合8条、测试集合7条、交集2条，合并排除数为8＋7－2＝13条；先去重后剩余测试排除5条，8＋5＝13条。遇到不闭合结果，先找遗漏与重叠，不能为了闭合改写事实。

6. 输出重复与过滤集合的相交记录表并列待补项、影响范围、复核人及下次更新条件；没有用户反馈的条目不变更为已完成，专项结果交由主流程采用。

## 专项证据方法

- 在表头写计量单位、金额含税状态和精度，金额与订单数各建归桥；同名指标不能自动视为同一统计对象，目标口径必须能从提供资料追溯到定义版本。

- 用闭开区间表达统计时间，如当日零点到次日零点之前，说明时区；边界记录落在哪一天必须一致，单凭报表标题写某月不足以确定实际过滤范围。

- 为两份报表记录生成时点，迟到数据是否已入库影响对比；比较同一天但不同截断时点的报表时，应分离时点差异与定义差异，不混成业务增长。

- 核业务主键与唯一性，一个用户多次支付不能在人数与订单数之间混用；缺匿名明细时列需提供的最小字段，不索取无关姓名或其他识别个人的信息。

## 专项模板与决策

- 用主键画文字集合交叉表，先记录独立集合计数，再给交集和处理优先级；最终抵扣量使用互斥集合，禁止为了闭合结果临时改变归属。

- 每一行以专项对象编号为主键，与公开成果只通过资料编号关联，不复写公开交付全文；表头固定包含原状态、证据位置、专项判断和待核动作。

- 分支状态采用已确认、待证据和存在冲突三类；待证据不是否定，存在冲突不能合并为已确认，后续反馈到来后再记录原状态和新状态。

- 复核意见必须包含可观察依据与采用版本，确认人没有提供时标【待补】；文字建议与实际执行分栏，避免专项草案被误读为已经完成的业务。

## 复核与版本

- 资料入口采用最小必要字段，先核用户提供的版本、时间与适用范围；原始记录和解释意见分别保存，缺项统一写【待补】。存在两份冲突资料时并排列出，不擅自选更有利的一份，也不把演示数字补成真实业务事实。

- 输出每条判断对应的资料编号、所用方法和状态，记录谁需要确认以及确认后会改变哪一项结果。所有数量注明单位，计算保留分子分母和逐步算式；舍入只用于展示，原值与修正值均保留以便复核。

- 表格是根据给定资料编写的文本草案，计划、人员自报、资料核对通过和实际完成分开记录。没有实际反馈就维持待确认，不能声称已经读取业务系统、发送通知或执行现实任务；也不提供任何资格认定或虚构外部验证。

- 完成前先检查每条输入是否有去向、每条输出是否有来源、每个异常是否有承接动作。后续更新只改有新证据的条目，保留旧版本与变更理由；超出本任务的请求列具体缺项或交接建议，不把未核实事实写进结论。

## 假设案例

以下为专项假设，非真实业务结果：假设重复集合8条、测试集合7条、交集2条，合并排除数为8＋7－2＝13条；先去重后剩余测试排除5条，8＋5＝13条。该示例只演示专项判断的分类与数值核对。实际使用时先把资料对象逐行编号，保留原始证据，再执行所列方法；不符合前置条件的对象必须单列待核，不能放入已确认数量。若用户补充记录导致判断改变，记录新增依据、原状态和新状态，重新计算受影响的分母与合计。最终只输出文本对照表和复核建议，不宣称已执行外部任务。复核时逐项检查对象总数、已确认数和待核数是否闭合，注明所用资料版本与计量单位；发现输入修订时只重算受影响条目，并在输出中保留旧值、修订值和差异原因，交由业务负责人确认后再更新主流程记录。

## 能力边界

根据用户提供的资料整理和分析；未知项填【待补】，区分事实、假设与建议。没有实际连接工具时不声称读取或修改业务系统，不编造实时数据或已完成的操作。
