# 已填示例：文案与复算，非发布或后台实跑
用户：表格教学视频总长42秒，片尾最多4秒；本条教会同表对齐，已有“同表对齐”系列，下期题材未确定。
结论：保留一个结论和一个现有系列信息，不虚构下期日期；不安排福利或资料交换。
|区间|口播|画面文字|画面|状态|
|38—40秒|先统一字段，再做对齐。|统一字段→对齐|已演示表格的结果区|方案，待试读|
|40—42秒|系列里还有同表核对。|同表核对系列|已有系列标题，若入口未建则只显示标题|方案，待预览|
候选短版：“先统一字段，再对齐；同主题继续做核对。”实际是否能在4秒内自然说完需要试读，不能按字数宣称已满足。
用户将片尾缩为3秒时：只留39—42秒一句结论，不把原四秒方案挤入三秒；如果删除前段而仍从38秒开始，会留下时长/区间冲突，须改时间表。

教学复盘输入：旧版视频A1000次播放/8个视频归因关注；B9000次/27个；窗口均发布后7天，无其他变更信息。A率8/1000=0.8%，B率27/9000=0.3%；合并(8+27)/(1000+9000)=35/10000=0.35%，不能取两率均值0.55%。新版C12000次/60个，率0.5%。新旧差0.15个百分点；相对变化约42.86%；播放量增加2000次即20%，关注数增加25个约71.43%，这些是三个不同分母，不能互换。没有投流与选题资料，不能说“这次片尾让转化提升42.86%”。
片尾到达数据假设：10000次播放中2000次到达片尾，按播放次数计到达占20%；若同时有35个全片归因关注，不能计算35/2000并称“片尾关注转化率”，因为无法证明这些关注来自到达片尾的那批。
25fps下[38,40)为[950,1000)，50帧；[40,42)为[1000,1050)，50帧，总100帧=4秒。30fps下分别[1140,1200)与[1200,1260)，总120帧=4秒；旧帧号不可照搬。静音版本也要预览字幕是否遮挡。
缺数据示例：只有账号净增45和播放1万，不填视频关注率；交文案与统计底稿，将视频归因新增关注列待补。旧率0、新率0.5%，只写增加0.5个百分点，相对变化不可计算。
