# 可复制话题与时段底稿

```text
平台／账号领域／目标观众／材料编号：
关键词：核心词｜长尾词｜来源（下拉词/评论提问/搜索来源词）｜在标题中的位置。
话题组合：大话题｜垂直话题｜系列或活动话题｜相关性三问（出现/对题/主体）｜保留或删除。
单条发布卡：标题｜核心词｜话题｜封面文字｜计划时段｜状态（计划/已发）。
测试排期：轮次｜日期｜星期｜时段｜作品编号｜内容类型｜是否剔除及原因。
测试记录：作品｜时段｜一小时播放｜二十四小时播放｜完播率｜点赞评论分享收藏｜互动率｜截图编号。
判定：时段｜有效条数｜二十四小时中位数｜平均数（参考）｜领先幅度｜胜出轮次｜结论（固定/无明显差异/样本不足）。
关键问题：最多三项。
```

## 已填假设示例：家居收纳号

以下为演示假设，不是真实账号数据。账号做家居收纳，以前每条随手带五六个热门话题。新发布卡：标题"小户型收纳：衣柜一格变三格的做法"，核心词"小户型收纳"位于标题开头；话题为大话题收纳、垂直话题小户型收纳与出租屋改造、自有系列话题周末收纳计划，共四个。原来带的明星同款类话题三问全部不满足，删除。

工作日测试12:00、19:30、21:30三个时段，四周四轮共十二条，每周一、三、五发布，轮内顺序轮换。二十四小时播放：12:00为820、760、1900、700，中位数790，平均1045；19:30为1150、1320、1240、1180，中位数1210，平均1222.5；21:30为900、1010、870、1120，中位数955，平均975。若看平均数，12:00会因一条1900排到第二，按中位数则21:30第二。

逐轮比较：第一轮19:30胜，第二轮19:30胜，第三轮12:00胜，第四轮19:30胜，19:30共胜三轮，达到四分之三。领先幅度为（1210−955）÷955，约26.7%，不低于20%。两项均满足，判定工作日固定19:30，周末另测。19:30第二轮那条播放1320，点赞66、评论12、分享8、收藏46，合计132，互动率10.0%。

下月复核：19:30继续记录，周末测试10:00、15:00、20:30三个时段。结论只说明本账号近四周工作日的倾向，不代表平台通用的最佳时间。
