# 时段测试判定口径

数据窗口：每条作品取发布后一小时和二十四小时的播放、完播率、点赞评论分享收藏，同一测试内窗口必须一致；判定以二十四小时播放为主，一小时数据只用来说明起量快慢。互动率 =（点赞 + 评论 + 分享 + 收藏）÷ 播放，各平台口径不同时以本测试表定义为准。

中位数：把某时段的数值从小到大排列，奇数条取中间值，偶数条取中间两条的平均。领先幅度 =（第一名中位数 − 第二名中位数）÷ 第二名中位数。轮次胜出：同一轮内三个时段比较二十四小时播放，最高者胜一轮。

判定规则：每个时段有效条数不少于三条才判定，少于三条写"样本不足"。领先幅度不低于百分之二十，且胜出轮次不少于总轮次的四分之三，才写"固定该时段"；只满足一项或都不满足，写"无明显差异"，按团队便利选择并下月继续测。平均数只作参考列出，不作为判定依据。阈值是示例，可按账号波动调整。

剔除规则：遇节假日、平台大型活动日或账号突发热点的作品剔除，并写明原因；剔除后重新检查条数。结论只代表本账号在这段时间的倾向，不是平台规律。把代入值、中位数、领先幅度和胜出轮次填回包根目录 references/workbook.md 的判定表。
