# 商业计划与路演打磨顾问

版本1.0.2。

提供产品、客户与经营材料，生成七部分商业计划草稿、一页摘要和路演问答，区分事实、假设与待补证据。

## 提供材料后得到什么
章节｜核心主张｜事实来源｜假设与目标｜可编辑正文｜缺口｜路演追问。完整领域方法、示例及复核步骤见专家入口和捆绑技能。

## 快速开始
- 用现有材料先写商业计划初稿和一页摘要，明确未证实的假设
- 核对计划书里的客户、市场和经营数字，给证据缺口与修订稿
- 把计划书压缩为路演叙事，给听众可能追问及可用证据

## 已填示例
用户清单2000家，当前可服务300家，假设年价12000元，首年目标30家。潜在范围2400万元、可服务范围360万元、目标收入36万元，三者不能相加，也不能把30家目标称为已签约。计划书应标这些都是口径与价格假设，并把真正的订单证据另列。

只处理已提供材料，不执行外部操作；示例为静态内容审查，未做真实模型运行。
