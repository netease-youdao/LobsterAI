# 小红书爆款笔记

小红书的分发逻辑是「封面标题决定点击、前三行决定停留、结构决定收藏」。本技能按这个顺序产出，不写通用软文。

## 开工前必须问清（缺一项就先问，别自己编）

1. **品类与产品**：具体到型号/规格，以及一句话卖点。
2. **目标人群**：年龄段、身份、她此刻的痛点。
3. **笔记目的**：种草转化 / 涨粉 / 测评对比 / 探店。
4. **账号人设**：素人分享、专业博主、还是品牌号（三者语气完全不同）。

## 四段式产出

### 一、封面标题（给 3 个选项）

- 20 字以内，必须含**具体数字或强对比**，例：「30 块的收纳盒，让我扔掉了 3 个柜子」。
- 三个选项走三条路线：痛点直击 / 结果前置 / 反常识。
- 禁用「震惊」「必看」「速看」这类标题党词，会被限流。

### 二、开头三行（决定停留）

第一行给场景或结论，不铺垫；第二行给冲突或数据；第三行给「往下看能得到什么」。
不要用「大家好我是XX」开场。

### 三、正文

- 每段 1–3 行，段间空一行，手机上不出现大段文字墙。
- 用「场景 → 尝试 → 翻车 → 解决 → 结果」的叙述骨架，比罗列卖点可信。
- 关键结论前加 emoji 作视觉锚点，全篇 emoji 控制在 8 个以内，别铺满。
- 数据、成分、价格必须来自用户提供的材料；没有就留 `【待补充】`，绝不编造。

### 四、话题与标签

- 3 个大词（品类词）+ 3 个精准长尾词 + 1 个当下热点词（不确定热点就不给，别猜）。
- 结尾给一句互动引导（提问式优于「求关注」）。

## 平台合规避雷（写完自查）

| 风险 | 处理 |
|---|---|
| 绝对化用语（最、第一、顶级、国家级） | 一律改成相对表述 |
| 功效承诺（治疗、消炎、根治、瘦几斤） | 化妆品/食品不得宣称功效，改为主观感受 |
| 医疗器械、处方药、医美项目 | 提示用户该品类需资质，本技能不产出承诺性文案 |
| 未标注的合作内容 | 品牌合作必须提示用户走蒲公英报备 |
| 二维码、微信号、外链 | 正文不出现，提示用户走平台内转化 |

## 输出格式

先给 3 个封面标题，再给完整正文，最后单独列话题标签与合规自查结论。
用户只要标题时不要顺带写正文。
