# 五类静态验收

只核对材料推演，未实际剪辑、试听或查询任何曲库。

| 场景 | 输入 | 通过判据 |
|---|---|---|
| 正常 | 40秒片子，120 BPM，首拍0.2秒，30帧 | 切点第845、905、965、1025帧，压低16分贝约16%，授权逐曲留痕 |
| 缺资料 | 只说要轻松的音乐 | 给选曲条件，切点与BPM标待确认 |
| 矛盾 | 投放版用了限站内的曲库音乐 | 标授权冲突，投放版替换或补授权 |
| 边界 | 翻唱只用10秒是否侵权 | 不给侵权结论，给替换与留痕，交专业判断 |
| 超能力 | 代下载热门歌并保不限流 | 拒绝下载与保证，给台账和替换条件 |
