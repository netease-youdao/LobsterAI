# 临时闭店复业任务依赖核对

面向临时闭店后的复业协调员与店长的独立小任务：临时闭店复业任务依赖核对。适用阶段为临时闭店原因已由负责人处理、计划复业前的任务依赖核对。最少事实输入为临时闭店事件及负责人处理记录、计划复业时间、内部复业任务与前置条件、暂停业务清单、实际完成摘录；交付复业任务依赖图表、已完成与阻塞清单、暂停业务恢复待确认表。核心方法：按任务编号建立前置关系，对实际完成证据与负责人内部确认分别核；关键前置未满足时其后继只列阻塞，完成率高不能替代依赖可行性。输入仅接收用户主动提供的脱敏文本或表格摘录，记录来源代号与原文位置；不要求业务系统接入，示例不能补真实资料。

## 工作流程

1. 限定一次临时闭店事件和计划复业时间，要求用户明确原因已处理的负责人记录；缺少记录时先列前提待补，不自行认定可开业。 接收时先登记来源、版本、对象范围和记录截点；若用户只给部分记录，交付已知范围并列最少缺项，不把没提供的数据补成零。

2. 从用户给定任务拆出前置编号、完成证据和确认角色，暂停订单、预约和营业展示分列，不能从普通巡检项目自动派生全部复业条件。 对象编号与资料行号应分开，整理值不覆盖原值。重复引用是证据复用而不是新增业务对象，同名对象必须查身份关系再合并。

3. 按前置关系核顺序，前置无证据或未完成则后继为阻塞；发现循环依赖保留环路并请负责人拆解，不编造执行次序。 处理时按本任务方法逐项核查，事实、陈述、派生计算和建议分别标识。支持某一条件的证据不可自动扩展到其它条件。

4. 把实际完成、待证、待做和阻塞分开，内部负责人确认与现场操作证据分栏；一句已搞定若无具体对象不能关闭所有任务。 条件不全给局部成果，矛盾给双值及来源；请用户指定确认角色，不取平均、不选更有利数值，也不把询问草稿记为完成动作。

5. 核预计完成时间是否影响复业截点，只用给出的持续时间推算；同时列关键前置，不因总完成率高就建议恢复全部业务。 复核应从来源重新取原值，检查单位、分母、版本和状态互斥性；已明确未知的字段保持未知，不以合计能对齐反推缺失事实。

6. 交付依赖表和暂停业务恢复确认表，限定可审查的任务范围；由店长决定复业，未给实际开放或业务恢复记录不标已恢复。 交付时保留仍未解决的行和下一核实动作，说明接收角色与完成凭据。新资料到来按原对象续版，人工确认与实际执行仍分开。

## 对象与资料门槛

- 闭店事件不同不能混用完成证据，首次停业处理不自动覆盖后来再次闭店。

- 闭店原因处理记录只是负责人提供的事实，不由表格判断安全、许可或法律合格。

- 用户只给复业时间没给条件时，不能反推所有条件已经满足。

- 任务编号独立，前置必须能定位到任务或用户明确的外部条件。

## 专属判断与异常分支

- 循环A等B、B等A时两个都标待拆解，不能按编号顺序伪造路径。

- 后继已有完成陈述但前置无据时保留异常，要求核任务顺序与证据时间。

- 人员确认在岗不等同于设备或现场条件满足，各类证据不互抵。

- 暂停预约清单只记录后续处理状态，不作退款、违约或赔偿结论。

## 输出验收与状态边界

- 营业时间展示待更新只出核对稿，不声称已更新地图、平台或门店系统。

- 部分恢复需用户给服务范围和限制条件，不能擅自把整店拆成已许可分区。

- 实际开放时间和计划时间分列，改期要记录受影响任务及暂停业务。

- 验收看每项条件和证据是否可追溯，完成8项仍不能代替关键前置1项未完成。

## 五类内容设计假设案例（非模型实测）

- 正常：假设内部任务10项，6项有证据完成、1项待证、1项待做、2项因该待做前置阻塞。 预期：6+1+1+2=10，完成60%；两后继仍阻塞，不能宣布复业。

- 缺资料：假设只有明早营业通知，没有闭店原因处理记录或复业条件。 预期：前提与任务条件【待补】，通知不是完成证据。

- 矛盾：假设后继写10时完成，前置记录11时才完成，给定规则不允许倒序。 预期：顺序冲突，核时间及任务范围；不静默改时间。

- 边界：假设A须等B，B须等A且无负责人拆解记录。 预期：2项循环待拆解，不给伪造顺序；即使其它8项完成也不越过环路。

- 超出能力：假设要求出具门店安全合格、允许营业证明。 预期：只交内部任务核对表，专业许可与安全判断交相应负责人。

## 本任务结果的使用顺序

- 先核闭店事件/任务号与来源：本成果的每行以该对象为锚，后续收到修订资料必须回填同一对象。对象换了要新建行，不能沿用旧证据省略核对。

- 再核方法是否具备前提：按任务编号建立前置关系，对实际完成证据与负责人内部确认分别核；关键前置未满足时其后继只列阻塞，完成率高不能替代依赖可行性。 没有对应输入时只交缺项说明，不将演示算式当成业务记录。

- 异常行独立交接：复业任务依赖图表、已完成与阻塞清单、暂停业务恢复待确认表中每个待确认项注明影响字段、缺少的事实材料、接收角色和复核时点。只提能改变判断的问题，不要求与本任务无关的整套资料。

- 最终验收按复业决定待确认及版本记录复核，逐条回查证据。文本完成、负责人确认、现场执行是不同状态；本表整理完成不代表整段业务已闭环，也不替用户作专业结论。
