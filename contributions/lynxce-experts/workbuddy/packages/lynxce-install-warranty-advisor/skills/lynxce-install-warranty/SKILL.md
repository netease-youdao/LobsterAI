# 大促大件家电延保与安装费用核算

大件家电到手价之外，常被忽略的是**延保买了用不上、安装时才冒出的辅材费与远程费、送装两次跑、签收时没验就签了字**。

## 工作流程（按顺序执行）

1. 问清家电品类、型号、到手价、原厂保修期（整机与核心部件分别多少年）、延保产品的年限与价格、安装地址情况（楼层、有无电梯、打孔墙体、原有旧机需不需要拆）。
2. 判断延保：延保价占比 = 延保价 ÷ 到手价，占比 ≤ 5% 且覆盖原厂保修期外的故障高发件时可考虑，5%–10% 视使用强度与维修成本判断，> 10% 默认不建议，并写出判断依据。
3. 核延保覆盖范围：逐条核对是否含上门费、是否限次数、是否含人为损坏、是否只保核心部件、起保时间是否从原厂保修结束后开始，条款以延保服务说明为准。
4. 列安装费用明细：基础安装费、辅材费（空调铜管超出免费长度按米计、支架、热水器阀门与混水阀、洗碗机进排水管）、远程费（超出服务范围按公里计）、高空作业费、拆旧与搬运费、打孔费，逐项写单价与数量。
5. 排送装时间：确认是否送装一体，不是的话分别约送货与安装时间，安装前 1–2 天确认预留水电位、墙体条件与安装尺寸，避免上门后无法安装二次收费。
6. 输出延保判断表、安装费用明细表与验收清单，最后按商品列出下单入口清单。

## 延保值不值

- 故障高发件参考：空调看压缩机与电脑板、冰箱看压缩机与制冷系统、洗衣机看电机与电脑板、热水器看内胆与加热管、电视看屏幕与主板，以各品牌说明书与保修条款为准。
- 原厂保修已覆盖核心部件多年（如压缩机、电机 5–10 年）时，延保的增量价值主要在整机其他部件与上门服务，按增量部分评估。
- 维修成本估算写【待补】让用户向售后查询或参考官方收费标准，不编造维修价。
- 延保判断只给依据与区间建议，不承诺一定会或不会发生故障。

## 安装费与辅材费

- 下单前先在商品页或服务说明里找「安装收费标准」，逐项截图保存，上门时对照收费。
- 空调常见包含一定长度的免费铜管（如 3 米以内），超出部分按米收费；支架、加长管、高空作业是否收费以收费标准为准。
- 安装师傅现场报出收费标准外的项目时，要求出示收费依据，不确定的先联系官方客服核实再付款。
- 拆旧机、搬运上楼（无电梯按层计费）常单独收费，下单前问清是否包含。

## 送装与验收红线

- 验收清单：外观无磕碰划痕、配件与说明书齐全、机身条码与包装一致、通电试运行 10–15 分钟、空调查外机固定与排水走向、热水器查漏水与接地、洗碗机与洗衣机查进排水无渗漏。
- 有外观损伤先拍照再联系客服，未验收完毕不急于签收或确认收货。
- 所有额外收费索要收据或电子凭证，便于后续售后与争议处理。
- 不使用「最低价」「全网最便宜」「史低」「绝对划算」等极限或绝对化用语。价格、优惠与活动规则一律以平台活动页、商品详情页与下单结算页的实时展示为准，本技能只做核算与提示，不做价格承诺，不保证必省多少钱。涉及退款纠纷、消费者权益认定的，以平台规则与主管部门规定为准，本技能不做法律结论。不编造价格、历史数据与活动规则，用户未提供或查不到的信息用【待补】占位。

## 示例

用户：「买一台 3999 的空调，整机保修 6 年，压缩机 10 年，延保 3 年要 299，值吗？另外安装会不会加钱？」→ 延保价占比 299÷3999≈7.5%，属视情况区间；原厂已覆盖压缩机 10 年，延保增量主要在第 7–9 年的电脑板等部件与上门服务，建议查延保是否含上门费与次数后再决定；安装费逐项列：基础安装是否免费、免费铜管长度、超出按米单价、支架与高空作业费，均按商品页收费标准截图核对，缺的标【待补】；约送装一体时间并提前确认插座与打孔位置；给出验收清单，最后列出下单入口。
