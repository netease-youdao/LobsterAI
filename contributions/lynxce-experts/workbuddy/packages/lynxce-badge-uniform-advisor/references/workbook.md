# 可复制工牌工服底稿

将下面模板完整填写；不适用的写原因，未知的保留材料标记。

```text
配发标准：岗位｜工牌类型｜工服款式与件套｜更换周期｜发齐时限｜防护要求（安全负责人确认）
尺码汇总：款式｜尺码｜人数｜每人件数｜需求件数｜余量比例｜备货件数（逐码向上取整）
发放签收台账：工号｜姓名｜部门｜工牌卡号｜临时卡号及有效期｜款式尺码｜件数｜发放日期｜签收｜经办人
补办与损坏登记：日期｜工号｜事项（遗失／损坏／换码）｜接报时间｜停用时间｜原卡号｜新卡号｜审批人｜费用口径（人事确认）
离职回收单：工号｜项目｜编号或件数｜已交回｜停用提交时间｜确认人｜日期｜未交回说明
半年盘点（工牌）：在职人数｜持临时卡新员工｜应有正式卡｜系统有效正式卡｜应有临时卡｜系统有效临时卡｜差异卡号及原因｜停用申请
半年盘点（工服）：款式尺码｜期初｜入库｜退回｜发放｜报废｜应有｜实盘｜差异｜核查记录
待确认：最多三项，每项写明会改变哪条结论
```

## 已填假设示例：门店夏装与半年盘点

以下人员、卡号与数量均为演示假设。门店岗四十人，每人夏装三件，尺码分布为S六人、M十四人、L十二人、XL六人、XXL二人。需求件数依次为18、42、36、18、6，合计40×3=120件。按百分之五余量逐码向上取整：S为18×1.05=18.9取19，M为44.1取45，L为37.8取38，XL为18.9取19，XXL为6.3取7，备货合计128件。S、XL、XXL人数都不到十人，各多出一件，符合至少留一件的规则。

新员工于2026年11月9日周一入职，入职当日算第一个工作日，工牌最晚在11月11日周三发齐；入职当天先发临时卡，有效期七个自然日含签发日，到11月15日止。

遗失：11月18日九点四十分接到报失，九点五十五分门禁管理员完成停用，间隔十五分钟，在假设制度规定的三十分钟以内；补办期间发临时卡并登记到期日。

半年盘点：在职118人，其中3名新员工持临时卡，应有正式卡115张、临时卡3张。门禁导出有效正式卡121张、临时卡4张，多出正式卡6张、临时卡1张，共7张。逐卡号核查：4张属于已离职人员未停用，2张是补办后旧卡未注销，1张临时卡签发时未设到期，合计4+2+1=7，与差异一致，列入停用申请交门禁管理员处理。

工服：M码夏装期初45件，入库0件，换码退回1件，发放42件，报废0件，应有45+0+1−42−0=4件；实盘2件，差异为−2件。先核对签收台账与换码记录，不直接认定个人责任。待确认：一、门禁卡挂失的制度时限；二、工服换码是否收费；三、车间防护服是否另有发放标准。
