# 尺码备货与盘点差异核对

只用用户提供的名单、尺码、库存与门禁导出数据；缺哪一项就在对应行写【材料待确认】，不按平均身材猜尺码。

一、需求件数等于该尺码人数乘每人件数。备货件数等于需求件数乘以一加余量比例后向上取整，逐码计算再合计，不先合计再分摊。为避免小数误差，余量百分之五时按整数计算：需求件数乘一百零五，再除以一百向上取整。人数不到十人的尺码至少比需求多一件。

二、日期：工作日计数以入职当日为第一个工作日，跳过周末与公司公布的休息日；自然日有效期含签发日。

三、时间间隔等于停用时间减接报时间，用分钟表示，再与制度时限比较。

四、工牌差异：应有正式卡等于在职人数减持临时卡的新员工数；差异等于系统有效卡减应有卡，正式卡与临时卡分开算。每张差异卡都要对应一个原因，原因合计应等于差异数，对不上就继续查，不用“其他”凑数。

五、工服差异：应有库存等于期初加入库加退回减发放减报废；差异等于实盘减应有。负差先查签收与报废记录，正差先查是否漏登发放。

六、结果写回包根目录 references/workbook.md 的尺码汇总与半年盘点行，注明计算日期与数据导出时间。
