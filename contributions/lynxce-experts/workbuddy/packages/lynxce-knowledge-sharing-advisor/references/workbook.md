# 可复制组织底稿

逐栏填写，不适用写原因，未知写【材料待确认】。

```text
目的／团队人数／已确认主讲人数／频率／固定时段／节假日依据：
选题征集：选题（写成问题）｜面向谁｜解决什么｜提议人｜可讲人｜预计时长｜投票数
筛选打分：选题｜具体｜受众｜可复用产出｜主讲确认｜一线｜总分｜排期/改写/退回
排期倒推：期数｜开讲日｜主讲｜搭档｜提纲确认日｜试讲日｜场地通知日｜文章截止日｜变更记录
读书会：人数｜是否分组｜开场｜领读｜发言｜收尾｜总时长｜三个讨论问题
会后记录：期数｜参与人数｜回收份数｜评分合计｜平均分｜回收率｜问答要点｜文章编号与位置
季度复盘：计划场次｜实际场次｜完成率｜平均参与｜总体平均分｜文章按时率｜一线占比｜下季调整
待确认问题：最多三个
```

## 已填假设示例：技术部双周分享

以下人数、日期与评分均为假设，用于演示口径；假设涉及日期均为正常工作日，实际以公司日历为准。技术部四十人，已确认主讲七人，固定双周周四16:00，计划六期：2026年10月29日、11月12日、11月26日、12月10日、12月24日、2027年1月7日。六期不超过七名主讲，容量足够。

选题打分：“报价审批如何从5天缩到2天”为具体2、受众1、可复用2、主讲确认2、一线2，共9分，排期；“浅谈效率”为0、1、0、2、0，共3分，退回改写。

倒推：第一期10月29日（周四）开讲，提纲确认10月15日，试讲10月26日（周一），场地通知10月27日，文章截止11月3日（周二）。第六期2027年1月7日（周四）开讲，提纲确认12月24日，试讲1月4日（周一），场地通知1月5日，文章截止1月12日。

会后：第一期参与18人，回收评分12份，评分合计51分，平均4.25分，回收率12÷18约为66.7%。

读书会：10人一组时长为5+10+5×10+5=70分钟；若14人报名则分两组各7人，每组5+10+35+5=55分钟。

季度复盘：12月24日因项目上线取消，主讲顺延到下季，实际5期，完成率5÷6约为83.3%；五期参与18、16、15、17、14人，平均16人；回收份数12、10、9、11、8共50份，评分合计51、41、37、46、32共207分，总体平均分207÷50=4.14分；按时交文章4期，按时率80%；一线选题3期，占比60%，下季把一线选题提到至少一半。待确认问题：公司节假日日历、录像默认查看范围、主讲激励方式。
