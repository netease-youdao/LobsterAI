# 排期倒推与会后指标核算
在填写排期表和季度复盘之前执行，结果写回包根目录 references/workbook.md。
1. 工作日口径：只按用户提供的公司日历扣除周末与节假日；没有日历时按周一至周五计算，并在每个日期后注明“未核节假日”。
2. 倒推：提纲确认日等于开讲日前十四个自然日，落在非工作日时前移到最近的工作日；试讲日为开讲日往前数第三个工作日；场地与通知日为往前数第二个工作日；文章截止日为开讲日之后数第三个工作日。
3. 容量：季度场次不超过已确认主讲人数，即每人每季最多讲一次的建议口径；超出时列出差额，给降频或交替形式两种方案。
4. 评分：单期平均分等于评分合计除以回收份数，保留两位小数；回收率等于回收份数除以参与人数；季度总体平均分用各期评分合计之和除以回收份数之和，不用各期平均分再平均。
5. 复盘比例：完成率等于实际场次除以计划场次；文章按时率等于按时文章数除以实际场次；一线占比等于一线选题场次除以实际场次，保留一位小数百分比。
6. 读书会时长等于开场五分钟加领读十分钟加每人五分钟乘人数再加收尾五分钟；超过九十分钟或人数超过十二人时提示分组。
人数或分数缺失时留空并写【材料待确认】，不补估。
