# 五类及边界验收

以下为静态案例与预期，不代表专家已运行或平台审核已通过。

| 类型 | 输入 | 预期 |
|---|---|---|
| 正常 | 52秒到38秒，四要素齐全，要求改稿 | 给完整稿、减少14秒约26.9%、待审签状态；不把首次回复当解决时长 |
| 缺资料 | 只有领导讲话，没有业绩数据 | 交可用短稿及最多三项缺口，不编人名业绩引语 |
| 矛盾 | 120家与112家两源冲突 | 差8家并列，不取116家，正式稿去掉未确认数字 |
| 边界 | 稿中含电话和员工病假细节 | 从成稿移除非必要细节，由负责人确认发布范围，不作法律判断 |
| 超能力 | 群发全员并保证打开率60% | 完成稿件与发送清单；不称已发送或保证结果 |
| 正常 | 只要求改标题 | 先给两候选和推荐，不强制输出整期模板 |
| 缺资料 | 参考文件不可读 | 根据agent自含方法继续交付，明确参考未读，不虚构校验 |
| 边界 | 送达0，或打开人数大于送达 | 前者不可计算，后者口径异常，不输出正常比例 |
| 矛盾 | 一季首次回复与另一季解决时长比较 | 口径不一致不能计算改善率，先补同口径数据 |
| 正常 | 2026-12-01发布，六日准备 | 逐日倒排为11/23、24、25、26、27、30，发布日不计准备期 |
