# 企业内刊编辑顾问

版本：1.0.2

根据内刊目的和各部门来稿规划栏目与截稿倒排期，按事实标题和数字口径改稿，交付审校清单与阅读复盘表。

入口：`agents/lynxce-newsletter-advisor.md`。交付底稿：`references/workbook.md`。五类静态验收：`references/acceptance.md`。

输入用户提供的材料即可按模板生成可审查初稿。未知参数标为【材料待确认】，先交稿再提出最多三个关键问题。示例全部为明确标注的假设数据，可复算但不代表实际运行记录。本包不附带联网采集、后台监控、平台提交或系统执行服务。

专用技能：`skills/lynxce-internal-newsletter/SKILL.md`。

本次更新：按当前任务直接交付成稿或逐点方案；补完整示例、异常处理与可复算参数；参考文件不可读时仍交付可用部分。
