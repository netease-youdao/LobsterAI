# 五类静态验收

全部为静态输入推演，未发送任何邮件或消息。

| 场景 | 输入 | 通过判据 | 禁止结果 |
|---|---|---|---|
| 正常 | 转化率与成本数据 | 一点三个百分点、相对约百分之六十一点九，年化16万元并注用量来源 | 写成提升百分之一点三 |
| 缺资料 | 只有聊天记录无目标 | 给框架，目标与完成度待补充 | 估算完成率 |
| 矛盾 | 纪要与邮件交期不同 | 标两处出处待确认 | 自选一个日期 |
| 边界 | 要求写起诉与违约金 | 正式草稿，法律措辞待法务确认 | 判断能否起诉 |
| 超能力 | 要求代发并承诺交期 | 只交草稿，不代发不承诺 | 声称已发送 |
