# 物业维修工单优先级与派工草案

面向建筑物业的明确小任务：去重工单优先级、资源约束派工草案、延后说明、回访与重开表。只依用户提供资料核对，将事实、假设与待确认条件分开；本技能不自动执行任何业务操作。

## 工作流程

1. 收集工单号、位置、现象、影响范围、发现时刻、用户给定优先级和响应规则，以及人员技能记录、班次、材料与可入户时窗。联系人用角色代号。相同设施同一现象的重复报修关联为一事件但保留报修人数；资料不清时先补影响事实，不自设普适服务时限。

2. 依据用户提供规则判定优先顺序，先核涉及人身或扩大损害的现象是否需要转用户的现场应急流程。优先级是报修调度判断而非设备故障诊断；疑似危险且信息不足时列立即转现场负责人核实，不指导带电操作、私自停用设备或判断现场已安全。

3. 为每项工单核人员技能记录、班次可用时段、预计作业时长、行程和材料前置，记录哪些条件已确认。用户只提供技能标签时可做匹配建议，不能认定证书有效或人员具备法定资格；缺作业时长或入户许可时列待排，而不是填入任意空档。

4. 在已确认条件下排派工草案，同一人时间段不得重叠，必要间隔和移动耗时采用用户给定值。优先级同级时按响应截止、影响范围和报修先后等已确认规则排序；窗口冲突列备用人员或改约待确认方案，缺材料只能安排核查或等待，不声称可完成维修。

5. 生成分角色派工说明与延后沟通草稿，区分预计到场、预计处理结束与用户确认的实际反馈。临时紧急单插入时重新核受影响工单的窗口和期限，并保留原排程；超时原因用资料支持，授权不足交给值班负责人决定，不擅自向住户承诺赔付或完成时间。

6. 交付工单优先级、资源匹配、派工草案、冲突待决及回访表。核工时总量与不重叠条件，维修人员反馈完成后仍需用户提供验证和回访结果才能建议闭环；复发保留原单并关联重开。输出文本调度方案，不声称已派单、联系住户、预约或操作维修系统。

## 受理与优先级

- 设施和现象同一时先关联重复报修，影响户数按唯一住户计数。

- 响应时限只使用提供的制度版本，紧急与一般的名称不能代替规则。

- 影响扩大迹象单列现场核实，不用文本信息宣称故障已诊断。

- 用户未提供安全处置流程时仅建议联系现场负责人确认，不编操作步骤。

## 资源与时窗

- 人员技能记录、证书资料和任务匹配分别记，不给资格认定。

- 班次时段扣除已占任务与用户给定移动缓冲，不能只算总工时够不够。

- 入户时窗是硬约束，材料未齐与预约未确认分别标阻塞。

- 一单需双人协作时同时占两人的可用时段，不排成串行单人任务。

## 闭环与重开

- 到场、处理结束、功能复核和住户确认四个节点分别记证据。

- 未回访不能自动标满意，用户未回应列待回访并保留问题。

- 复发工单关联原事件与处理记录，避免重复计算新的问题数量。

- 派工草案变更写受影响单号、原因及新窗口，供值班人员批准执行。

## 资料与交付复核

- 建立资料目录：每条数值、日期、状态和规则都关联用户提供的来源编号与版本。原始记录、解释性备注及建议动作分栏；资料缺失写【待补】，不得以示例中的数值或常见经验填补真实记录。

- 同一字段出现矛盾时保留两种说法，写清分别来自何人、何时及哪份资料，再指定需要补充的验证材料。没有反证不能选较有利的一版，不将推测原因写成已确认事实，也不替用户判定业务责任。

- 所有数量先核单位、范围、截止时点和分母，再逐行计算并复算合计。四舍五入要注明精度；不适合相加的比例、不同单位或不同批次不直接合计，分母为零时标不可计算并说明需要补充什么。

- 交付文本表格、待补问题和人工确认清单，每个建议写触发条件、经办角色及可核查完成证据。建议、已获用户确认和用户反馈实际完成分状态；收到补证后保留原版及变更原因，不声称已经操作业务系统。

- 内容设计假设，未作实际模型实测。缺资料：输入报修无影响范围，人员工时和入户窗口也未提供。预期优先级与具体派工待核，先输出受理补项而非任意填空档。

- 内容设计假设，未作实际模型实测。矛盾：输入同一维修员两单都拟排10:00至11:00，住户窗口不同。预期输出60分钟重叠及改约或换人待决，不能把两单标已派发。

- 内容设计假设，未作实际模型实测。异常边界：输入双人共同空闲60分钟，但加移动后只剩45分钟可施工。预期任务60分钟缺15分钟，列不可排，不按个人总空闲量通过。

- 内容设计假设，未作实际模型实测。超出能力：输入要求判断电气故障安全并自动派单或确认人员资格。预期转用户现场负责人核实，提供文本草案，不诊断或认定资质。

## 假设案例

假设值班人员甲可用09:00至12:00，用户给定任务间移动缓冲15分钟。工单A需60分钟且入户窗09:00至10:30，工单B需45分钟且入户窗10:00至12:00，两单技能记录均匹配、材料齐备。草案A排09:00至10:00，移动10:00至10:15，B排10:15至11:00，共占用60＋15＋45＝120分钟，可用180分钟剩余60分钟。若紧急工单C在09:30提出且需甲处理30分钟，A正在执行不能假设立即中断；需值班负责人确认处置与备用人员，再更新B窗口。若B改排11:15至12:00仍在入户窗内，但须确认缓冲与负责人同意。执行后只有B的人员完成反馈、没有住户复核，就列待回访，不能标已闭环。
