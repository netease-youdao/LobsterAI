# 复位见证与再次移位核对

本任务只处理复位见证与再次移位核对。最少输入为逐设施复位声明、位置与功能证据、用户见证要求、后续观察和轮次时间，独立交付复位证据覆盖表和再次移位重核卡。仅使用用户提供的记录、规则和人工确认。来源以资料代号、版本、时间定位，未知字段写【待补】。原始事实、计算结果、假设条件与建议分栏，不能以案例填真实空白。只交文本与表格，不声称已连接业务系统、修改台账、发送信息或执行现场操作；不索取账号口令。不作专业医疗、财税、法律结论，不判定设备安全或材料技术合格；需要专业处置时整理证据给用户指定人员。

## 工作流程

1. 确定本轮小任务为复位见证与再次移位核对，接收最少事实资料：逐设施复位声明、位置与功能证据、用户见证要求、后续观察和轮次时间。明确对象键、单位、版本和截点，关键字段不足先交局部事实表与待补问题。

2. 为每件设施配位置反馈及用户要求的功能观察，单条搬回声明只支持搬回声明，不能扩成两个证据节点。复核人是否需要独立由用户制度决定，不自行给其认证资格。原始值、解释值和未知分别记录，重复对象保留对应关系。

3. 逐项核证据时序，结束观察、复位反馈、见证复核依次定位。早于本轮复位的见证只属旧轮次，除非用户说明其可用范围，不拿旧照片覆盖新活动。列出逐行算式或证据配对规则，不以常识补齐必要数据。

4. 后续异常按设施号关联原轮次，已经确认复位后又移动与原声明矛盾为两种分支。前者新增轮次和当前状态，后者重核原反馈，不将所有重复观察都算新增设施。正常、缺资料、来源矛盾及端点边界走不同分支，只有输入满足前提才输出条件结果。

5. 证据覆盖按满足全部给定节点的设施数除本轮需复核设施数，只展示记录覆盖，不称现场安全率。资料为零对象时记不适用，开放是否获批准另列负责人反馈。把专属异常、欠证对象、下一核实角色和关闭依据放进附件，处理超出能力请求时交证据而不执行。

6. 交付复位证据覆盖表和再次移位重核卡。逐行复算单位、分母与版本，按用户反馈登记人工确认和实际状态；新资料保留旧版并仅重核受影响行。

## 对象识别与领域方法

- 为每件设施配位置反馈及用户要求的功能观察，单条搬回声明只支持搬回声明，不能扩成两个证据节点。复核人是否需要独立由用户制度决定，不自行给其认证资格。

- 逐项核证据时序，结束观察、复位反馈、见证复核依次定位。早于本轮复位的见证只属旧轮次，除非用户说明其可用范围，不拿旧照片覆盖新活动。

- 后续异常按设施号关联原轮次，已经确认复位后又移动与原声明矛盾为两种分支。前者新增轮次和当前状态，后者重核原反馈，不将所有重复观察都算新增设施。

- 证据覆盖按满足全部给定节点的设施数除本轮需复核设施数，只展示记录覆盖，不称现场安全率。资料为零对象时记不适用，开放是否获批准另列负责人反馈。

## 状态分支与证据方法

- 资料索引逐项保留原记录代号、发生时刻、记录时刻和版本；先判断是否覆盖当前对象，再引用数值。没有资料证明的动作保留待核，不能将上一轮示例、计划值或人员口述改写成实际完成证据。

- 补件按字段更新而非整表覆盖：记录旧值、新值、修改理由及受影响行，原始冲突保留双版本。用户尚未指定哪个版本生效时给条件式结果和一个可回答的确认问题，不能自行选择有利版本消除异常。

- 汇总前检查单位、对象范围和唯一键，整数件数不平均处理，缺失不等于零。每个公式保留输入值与结果，数量、时长和状态覆盖率分开；分母为零标不适用，比例不能充当所有对象已完成的证明。

- 交付时列当前可确认事实、阻塞条件、最少补证与人工复核角色。执行建议、人工批准、现场反馈和复核通过分别登记；收到反馈仍需逐对象检查关闭依据，资料只覆盖局部就明确保留局部范围。

## 复核与交付约束

- 本表按设施/轮次 | 复位声明 | 位置证据 | 功能观察 | 见证/时间 | 后续观察 | 重核原因 | 覆盖状态组织逐项核对，先保留输入原文字段再列解释，解释不得覆盖原始值。适用范围仅为复位证据覆盖表和再次移位重核卡，完整业务决定仍须查看相应主表及用户实际确认。

- 从输入的逐设施复位声明、位置与功能证据、用户见证要求、后续观察和轮次时间中筛选覆盖当前小任务的记录，逐条检查出处是否可回看。对任务之外的字段不强行推算；用户补充资料改变范围时明确新增核对行，原有已证实的行保持证据链接。

- 五类案例分别用于检查正常推进、关键字段缺失、来源互斥、恰好边界和执行权限边界。以当前资料确定对应分支，不能把假设中的数字复制到实际表内；案例结果仅说明方法可复算，不说明模型表现。

- 复核附件应让另一名经办人员从原值重算并找到欠证对象，发现分母、时间窗或版本不一致则返回原字段修订。交付时注明本小任务完成的是文本核对，现场动作和审批状态仍按用户反馈登记。

## 五类假设检查

- 正常案例（明确假设）：假设4件需位置和见证，3件都有两节点，1件只有位置。预期处理：完整覆盖3/4，欠1件见证，未全部完成。复算：3/4=75%；4-3=1

- 缺资料案例（明确假设）：只有全部完成文字，无逐设施证据。预期处理：覆盖分子待核，不默认100%。复算：无可计算条件；保留原值和待核范围，不补数。

- 矛盾案例（明确假设）：F1复位17:00，所附本轮见证16:50。预期处理：时序逆向10分钟，要求对应本轮证据。复算：17:00-16:50=10分钟

- 边界案例（明确假设）：本轮需复核0件，用户明确无移动和临时物。预期处理：覆盖率不适用，不计算0/0；开放条件仍按用户范围核。复算：分母0，不适用

- 超出能力案例（明确假设）：要求凭记录替负责人批准开放并出安全证明。预期处理：只交证据覆盖与待核项，不代批准或出证明。复算：无可计算条件；保留原值和待核范围，不补数。
