# 可复制测评底稿

将以下模板完整填写；不适用项写明原因，未知项保留材料标记。

```text
产品／型号／版本号／测试日期／脚本版本：
利益关系：样品来源｜报酬或分成｜审稿权｜是否归还｜披露档位｜口播｜画面角标｜文案首行｜平台标签。
维度表：维度｜测试方法｜工具｜环境｜次数｜判定口径｜本品结果｜竞品结果｜备注。
测试记录：维度｜第一次｜第二次｜第三次｜中位数｜极差｜极差占中位数｜是否补测。
有效性：环境底噪｜被测值｜差值是否达十分贝｜单次结果标注｜两款差值与极差比较｜措辞。
个人感受：项目｜描述｜与测量结果分开呈现的位置。
脚本：段落｜时长｜口播｜画面｜字幕｜对应测试记录。
发布前核对：广告标识｜绝对化用语｜贬低竞品｜功效声称｜缺点保留｜自测非检测报告。
待确认：最多三项，每项写明会改变哪条结论或披露。
```

## 已填假设示例：扫地机器人

以下数据均为假设，不是任何产品的实测记录。扫地机A为品牌寄样，无报酬，无需归还，品牌未审稿；竞品B为同价位自购。披露为开头口播“本期样品由品牌寄送，品牌未支付费用”，文案首行同步说明。两台均在同一瓷砖客厅、标准模式下测试，记录版本号与日期。

吸尘：每次撒50克燕麦。A三次回收46.5、47.8、45.9克，中位数46.5克，清洁率46.5÷50=93.0%，极差47.8−45.9=1.9克，占中位数约4.1%，未超一成。B三次44.0、46.2、45.1克，中位数45.1克，清洁率90.2%，极差2.2克，约占4.9%。两款中位数相差46.5−45.1=1.4克，小于A的极差1.9克，结论只写“吸尘表现接近”。

噪音：环境底噪38分贝，有效线48分贝。A三次62.4、63.1、62.8分贝，中位数62.8；B三次65.0、64.6、65.3分贝，中位数65.0；两款极差均为0.7分贝，差值65.0−62.8=2.2分贝大于极差，可以写“A比B低约2.2分贝”。越障用两厘米门槛条各测三次，A通过2次、B通过1次；避障六类障碍物各测三轮，A通过16÷18≈88.9%，B通过13÷18≈72.2%。续航A为132分钟、B为118分钟，各只测一次，标“单次结果”，不下优劣结论。

脚本：开头5秒、开箱外观40秒、吸尘噪音越障避障四项各45秒共180秒、续航单次说明15秒、结尾35秒，合计5+40+180+15+35=275秒，约4分35秒。结尾缺点保留“两厘米门槛三次中有一次卡住”，并说明适合硬地面为主、门槛较低的家庭。
