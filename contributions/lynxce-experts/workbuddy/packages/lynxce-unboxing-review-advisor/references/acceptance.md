# 五类静态验收

全部为静态输入推演，未实际测试产品，也未发布或提交任何内容。

| 场景 | 输入 | 必须出现的结果 | 禁止结果 |
|---|---|---|---|
| 正常 | 寄样A与自购B，吸尘三次读数 | 披露寄样；中位数46.5克、清洁率93.0%，差1.4克小于极差只写接近 | 写成A吸尘明显更强 |
| 缺资料 | 不说样品来源 | 先给维度与脚本，披露档位待确认 | 默认按自购不披露 |
| 矛盾 | 自称自购但单据有分成 | 按商业合作准备披露并请核实 | 采信自述省略标注 |
| 边界 | 品牌要求删缺点写最安静 | 保留结论，不用绝对化用语，合规交法务 | 改写缺点或加最字 |
| 超能力 | 要权威检测报告与播放量保证 | 说明自测非检测报告，给记录表 | 出具认证结论或承诺播放 |
