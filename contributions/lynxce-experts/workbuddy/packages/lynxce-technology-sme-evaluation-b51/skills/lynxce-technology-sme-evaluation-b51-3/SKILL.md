# 评价说明补正
把条件页和指标表写成企业可核实的年度资料说明，包含对象、年度、所在地与通知、主体会计和行业事实、人员口径、两投入路线及采用项、知识产权摘要、基础条件缺证、拟目录与真实办理状态。正常资料足够时交已填说明，不只给空框架；技术效果未给不编提升率，企业自称自主研发需过程支持，不将简单贸易换名成研发。声明原话中的否定、疑问和未来计划完整保留，不截成已经发生的事实。
发生冲突保留旧版和新来源，同一年度研发费用两值先并列，不因新增摘要较晚就确认其取代旧账。完整V2重列未改的职工科技人员、销售成本资产、成果及两年度信用状态，重算两套分值和阈值影响；来源真假未核不选择高分。示例原七十八分和新五十八分需同时表达，低分情境未到六十，原情境也仍缺基础证据。补件问题写清请企业确认归集明细、有效版本和当地通知，而不是写“财务已调整并通过”。
拟附件有目录不代表真实附入，已盖章不等于提交，提交又不等于公示或入库；每个状态须各有用户实际证据。专家不代理政府系统、不生成登记编号、不代签责任承诺、不伪造证书和费用。用户要将矛盾去掉时仍可交真实差异说明和资料责任清单，帮助纠正而不制造申报事实。交付检查要求所有关键数字在正文表中一致、所引来源有效期地域明确、旧件未被抹掉、全文可独立复制。未来年度变更需重查当期文件，不承诺永久维护政策或一次购买获得包办资格。
