# 大促跨境进口商品税费与到手价核算

跨境商品最容易算错的不是券，而是**页面价没含税、这一单超了单次限额、直邮等了三周还退不了**。

## 工作流程（按顺序执行）

1. 问清商品名称、规格、页面价、是否已标「含税」、运费、发货方式（保税仓发货还是海外直邮）、所需时间，以及用户本年度已用的跨境购买额度，缺项标【待补】。
2. 核限额：跨境电商零售进口单次交易限值为 5000 元、个人年度交易限值为 26000 元（以海关现行规定与平台展示为准），本单金额与年度已用额度逐项比对，超限的明确提示。
3. 估综合税：完税价格 = 商品实际成交价 + 运费 + 保险费；限值内关税税率暂按 0，进口环节增值税、消费税按法定应纳税额的 70% 征收，综合税 = 完税价格 × [(消费税率 + 增值税率) ÷ (1 − 消费税率)] × 70%，具体税率以海关与平台结算页展示为准。
4. 算到手价：页面价 − 各项优惠 + 运费 + 综合税（页面已标含税则不重复计），与同款国内一般贸易渠道价格并列对比。
5. 比时效与售后：保税仓发货常见 3–7 天、海外直邮常见 7–20 天（以页面承诺为准），逐项核对是否支持七天无理由、退货寄回地址是国内还是海外、退货运费由谁承担。
6. 输出限额核对、税费估算与到手价对比表，最后按商品列出下单入口清单。

## 限额与计税口径

- 单次限值 5000 元、年度限值 26000 元是现行口径，额度与订购人身份信息绑定，订购人、支付人信息须一致，以海关与平台规定为准。
- 完税价格超过单次限值但低于年度剩余额度、且订单只有一件商品的，按一般贸易方式全额征税，此时不能再按 70% 口径估算，需提示用户以结算页税费为准。
- 常见估算：只涉增值税、税率 13% 的商品，综合税率约 13% × 70% = 9.1%；涉消费税 15% 的商品，综合税率约 (15% + 13%) ÷ (1 − 15%) × 70% ≈ 23.1%，仅作估算参考。
- 跨境购买的商品限个人自用，不得再次销售；本技能不提供代购、拆单规避限额、低报价格等任何做法，遇到此类需求直接拒绝。

## 保税仓与海外直邮

- 保税仓发货：商品已在国内保税区，清关后国内快递配送，时效较快，物流信息通常可在国内快递查询。
- 海外直邮：从境外发出，需经国际运输与入境清关，时效较长，大促期间清关排队可能进一步延长，必须预留时间。
- 两种方式的完税价格、运费与退货路径可能不同，同一商品两种发货方式要分别算到手价。
- 有使用时间要求（如节日送礼）的，按页面承诺的最晚送达时间倒推，赶不上的直接建议国内渠道。

## 退货难度与红线

- 跨境商品是否支持七天无理由以商品页标注为准；部分商品拆封后不退，下单前要明确告诉用户。
- 退货寄回地址可能在保税区或境外，运费与时效远高于国内商品，已缴税费的退还以平台与海关流程为准。
- 不使用「最低价」「全网最便宜」「史低」「绝对划算」等极限或绝对化用语。
- 价格、优惠与活动规则一律以平台活动页、商品详情页与下单结算页的实时展示为准，本技能只做核算与提示，不做价格承诺，不保证必省多少钱。涉及退款纠纷、消费者权益认定的，以平台规则与主管部门规定为准，本技能不做法律结论。不编造价格、历史数据与活动规则，用户未提供或查不到的信息用【待补】占位。税率与限额仅为估算口径，本技能不做税务筹划与税务结论。

## 示例

用户：「一瓶进口精华跨境页面价 680 元不含税，保税仓发货，国内专柜 890，哪个划算？」→ 先核限额：680 元低于单次 5000 元，询问年度已用额度；该类化妆品若涉消费税 15%，综合税率约 23.1%，预估税费约 157 元；若商品不涉消费税，只按 9.1% 约 62 元，需以结算页展示为准；到手价约 742–837 元，与专柜 890 元对比；保税仓时效约 3–7 天；提示拆封后可能不支持退货、退货寄回保税区；最后列出两个渠道的下单入口。
