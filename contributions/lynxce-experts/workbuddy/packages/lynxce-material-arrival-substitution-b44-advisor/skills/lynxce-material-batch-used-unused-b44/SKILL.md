# 替代批次已用未用数量核对

本任务只处理替代批次已用未用数量核对。最少输入为到场数量、批次包装系数、领用退回和实际使用摘录、现场分区剩余，独立交付逐批次已用未用守恒表和跨批混记疑点。仅使用用户提供的记录、规则和人工确认。来源以资料代号、版本、时间定位，未知字段写【待补】。原始事实、计算结果、假设条件与建议分栏，不能以案例填真实空白。只交文本与表格，不声称已连接业务系统、修改台账、发送信息或执行现场操作；不索取账号口令。不作专业医疗、财税、法律结论，不判定设备安全或材料技术合格；需要专业处置时整理证据给用户指定人员。

## 工作流程

1. 确定本轮小任务为替代批次已用未用数量核对，接收最少事实资料：到场数量、批次包装系数、领用退回和实际使用摘录、现场分区剩余。明确对象键、单位、版本和截点，关键字段不足先交局部事实表与待补问题。

2. 只核数量链，不给接受结论。到场、领出、退回、实际铺装与现场剩余为不同事件；领出量不等于实际用量，未有安装反馈时保留领出未核消这一状态。原始值、解释值和未知分别记录，重复对象保留对应关系。

3. 逐批次核到场减实际用减已退货等于未用量，未用可再分仓内与已领未用。每条退回区分退回暂存点或退给供方，前者不减少现场总拥有量，后者有出场证明才扣除。列出逐行算式或证据配对规则，不以常识补齐必要数据。

4. 原定P与替代Q分账，即使型号同名也不能串批抵差。包装系数变化单独标版本，碎片或损坏必须按用户计量规则单列，不用四舍五入消除数量异常。正常、缺资料、来源矛盾及端点边界走不同分支，只有输入满足前提才输出条件结果。

5. 发现剩余与计算不一致时列残差、可能缺凭据和复盘对象，不直接判损失。仅交复核表，数量守恒仍不能证明替代批准、技术合格或施工质量达标。把专属异常、欠证对象、下一核实角色和关闭依据放进附件，处理超出能力请求时交证据而不执行。

6. 交付逐批次已用未用守恒表和跨批混记疑点。逐行复算单位、分母与版本，按用户反馈登记人工确认和实际状态；新资料保留旧版并仅重核受影响行。

## 状态分支与证据方法

- 资料索引逐项保留原记录代号、发生时刻、记录时刻和版本；先判断是否覆盖当前对象，再引用数值。没有资料证明的动作保留待核，不能将上一轮示例、计划值或人员口述改写成实际完成证据。

- 补件按字段更新而非整表覆盖：记录旧值、新值、修改理由及受影响行，原始冲突保留双版本。用户尚未指定哪个版本生效时给条件式结果和一个可回答的确认问题，不能自行选择有利版本消除异常。

- 汇总前检查单位、对象范围和唯一键，整数件数不平均处理，缺失不等于零。每个公式保留输入值与结果，数量、时长和状态覆盖率分开；分母为零标不适用，比例不能充当所有对象已完成的证明。

- 交付时列当前可确认事实、阻塞条件、最少补证与人工复核角色。执行建议、人工批准、现场反馈和复核通过分别登记；收到反馈仍需逐对象检查关闭依据，资料只覆盖局部就明确保留局部范围。

## 五类假设检查

- 正常案例（明确假设）：假设Q到场80片，领出20，实际用8，领出剩余12，仓内60，无退供方。预期处理：未用72片，仓内与领出未用合计72，残差0。复算：80-8=72；60+12=72；72-72=0

- 缺资料案例（明确假设）：只给领出20片，没有实际使用反馈。预期处理：已用量待补；只列领出20，不写已用20。复算：无可计算条件；保留原值和待核范围，不补数。

- 矛盾案例（明确假设）：按凭据未用72片，现场仓内60、领出余10。预期处理：差2片待复盘，不能扣另一批次抵平。复算：72-(60+10)=2

- 边界案例（明确假设）：80片全部有使用记录，未用为0。预期处理：数量守恒可列，但仍须独立核接受范围，不将零剩余写批准全量。复算：80-80=0

- 超出能力案例（明确假设）：要求按短少2片判承包人赔款。预期处理：只交残差证据，不归责或确定赔偿。复算：无可计算条件；保留原值和待核范围，不补数。
