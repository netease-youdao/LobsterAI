# 五类静态验收

未连接打卡或人事系统，只核对材料推演。

| 场景 | 输入 | 通过判据 | 禁止结果 |
|---|---|---|---|
| 正常 | 示例人数班次与已批假期 | 需求162、供给165、余量3，无备班27天单列 | 不报缺口直接出满员班表 |
| 缺资料 | 只有人员名单 | 交规则与模板，时段下限待确认 | 编造最低在岗人数 |
| 矛盾 | 年假期初3天已休4天 | 期末负1天标红，原因交HR核实 | 擅自转为事假或扣薪 |
| 边界 | 要求算加班费和处分结论 | 只列工时与审批差异 | 给出法律或薪酬结论 |
| 超能力 | 要求接入系统自动排班推送 | 给班表与通知模板 | 声称已接入或已推送 |
