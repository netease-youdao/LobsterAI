# 可复制排班与对账底稿

```text
团队／月份／班表版本／材料编号：
班次定义：班次｜起止时间｜是否跨天｜餐休是否计工时｜必须技能。
覆盖核算：日期类型｜天数｜每日需求人班｜小计｜供给｜余量｜备班需求｜无备班日期。
硬约束：最长连续上班天数｜最短班间休息小时｜冲突清单（人员｜日期｜规则｜处理）。
排班表：日期｜班次｜时段｜在岗人员｜备班｜最低在岗｜冲突提示。
公平统计：人员｜夜班｜周末｜节假日｜统计窗口｜下期调整。
换班登记：申请人｜对方｜日期｜原班次｜新班次｜批准人｜新版本号。
假期台账：人员｜类别｜期初｜新增｜使用｜期末｜来源或审批单号｜预警。
三方对账：人员｜日期｜排班表｜打卡记录｜审批单｜差异类型｜责任人｜结论｜补录截止日。
待确认：最多三项，每项写明会改变哪一格。
```

## 已填假设示例：八人客服组十一月班表

以下数据全部为演示假设。客服组员工A至H共8人，早班08:00至16:00，晚班14:00至22:00。制度假设：最短班间休息11小时，连续上班不超过6天。晚班22:00下班到次日早班08:00只有10小时，小于11小时，所以晚班后的次日只能排晚班或休息。

2026年11月共30天，其中工作日21天、周末9天。工作日每班至少3人，每天6人班，计126人班；周末每班至少2人，每天4人班，计36人班；月需求162人班。每人计划出勤21天，供给8乘21为168，减去已批假期员工A年假2天、员工B调休1天，实际供给165人班，余量3人班。备班按8人的一成向上取整为每天1人，全月需30人班，余量只够3天，其余27天无备班，交组长决定是否增援或接受风险。

公平统计：上季度节假日班次A至H依次为3、3、2、5、1、4、2、4，合计24，最大5减最小1为4，超过1。假设元旦三天每天两班各2人，共12人班。按次数少者优先依次分配：先把E补3次、C补2次、G补2次、A和B各补1次，全员达到4次，用去9人班；剩余3人班给三位当季夜班较少者，分配后各人为4或5次，差值为1，且同一人同一天只排一班。

假期台账：员工A年假期初5天、新增0、使用2天、期末3天；员工B调休期初0小时、新增8小时（来源10月31日加班审批单）、使用8小时、期末0小时。

月底对账：8人乘30天共240人日，差异3项，差异率1.25%。员工D在11月5日（周四）早班缺下班卡且无补卡单，补录截止为三个工作日后的11月10日（周二）；员工E在11月12日班表为晚班、打卡为早班，有与员工F的换班审批，结论是更正班表为V2并保留原值；员工G在11月21日（周六）休息日打卡9:00至17:30共8.5小时、无加班审批，若制度扣除1小时餐休则为7.5小时，两种口径都列出，结论为待HR判断，不自行计为加班或调休。
